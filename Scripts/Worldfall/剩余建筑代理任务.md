每个代理只制作指定的一类资产，不派生代理，不读其他代理的模型。每批最多三项。禁止启动、关闭或操作游戏，不用图片生成、Tripo、Trellis或API；本轮用Blender自己构形，游戏状态为`pending_user_manual`。

必须实际看本物体的全部main与ruin图，包括动画帧。main_N是独立外观，main_N_M第二编号为动画；保留动画来源但不把每帧当新物体。原图外观不同时分别建模，不能复制同一网格冒充全部外观。废墟只变暗则保留相应轮廓，由游戏统一变暗；不要擅造破碎结构。没有施工图不添加施工阶段或玩法。

从主要特点解构成完整三维，保留原图构件数量、位置、开口、前后关系、配色和特征。不得逐像素拉厚、贴一张正面板或凭资产名套用普通塔；须有真实侧背厚度。不可见背面补全与用途推断另记。近中远预算先参考`Doc/修仙贴图三维化/验收/2026-10-12-Worldfall内置面数/README.md`并写理由。

本批群系建筑保持自身原色，`kingdom_slots=none`；精确紫色也不能自动当文明国家模板。实际材料与类别分开：木构3、真实砌砖4、瓦顶5、金属10、自然整石14；肉、骨、晶体、整块碑石等用0或确切自然类别，避免异常砖纹。每模型不超过64槽，原槽前缀、部件名、父子关系、轴均保留；新增几何归合理原部件，旧错误语义部件可留空。

X左右、Y前后、Z向上，正面-Y；主体宽1、深度按注册Depth/Width，小幅内缩可以，不能拉扁正面或高台填占地。底部落地。重要孔、镂空、尖顶、冠、树枝或器官三档均保留，远景只减少细节。底面/内腔绕序正确，不能仰视透明。

使用`Scripts/Worldfall/civil_building_tools.py`，已支持mobs目录：

```python
import sys
from pathlib import Path
ROOT=Path(__file__).resolve().parents[4]
sys.path.insert(0,str(ROOT/'Scripts/Worldfall'))
from civil_building_tools import CivilAsset,Mesh,roof,gable,beam
asset=CivilAsset('指定ID',budgets=(自己设计的近景上限,中景上限,远景上限))
def draw(frame,level):
    m=Mesh(level)
    # 本资产独有立体布局；返回原部件名到Mesh的字典。
    return {'base':m}
asset.build(draw,colors={'stone':'#778899'},kinds={'stone':14},kingdom_slots='none',
            notes='真实结构与来源',assumptions=['背面补全与动画等限制'])
```

`CivilAsset.frames`包含style/state/index/frame/path/animations；会自动导出全部外观和废墟三档，保留原部件、生成实际GLB与可编辑源。源图分组由工具负责，形状必须自己逐项设计。`Mesh`函数读`biome_native.py`签名；凹内腔自行安排绕序，不依赖中心外向猜测。
