# 第2阶段-名称与水墨望气图

## 目标

让玩家通过独立望气图理解整片龙脉的气势、干支汇流、局部脉节、结穴地与自然灵眼，不显示路线图、箭头、圆形节点或徽章。

## 具体说明

### 命名正式对象

正式命名对象只有龙脉、支龙、结穴地和灵眼：

```text
苍梧龙脉
听松支龙
落霞明堂
落霞灵泉
```

名称使用世界编号、对象编号、祖山或所在地区、主要元素、结穴类型和灵眼显化稳定生成。祖山、过峡和水口只显示附近地貌描述，不强制再生成专名。

龙脉规模使用微型、小型、中型、大型、祖脉；支龙有四档规模；结穴地使用下品至天成五档品相；灵眼显示显化类型和动态浓度。

### 处理重名与身份延续

同一世界运行期间先使用基础名，重名时依次加入方位和序号。名称生成后不会因储量、污染、纯净度或规模变化而改变。

地势重流时先保留已匹配对象名称，再为真正新生的支龙、结穴地和灵眼命名。远距离移穴后的新主穴使用新名，旧址仍有来气时成为保留旧名的残穴。

### 绘制连续脉域

`SpiritVeinMapRenderer` 使用整张逐格脉域纹理绘制水墨晕染：

- 普通地形先覆盖一层低透明暗色，山川城市仍可辨认。
- 脉域颜色以玉白和淡墨为主，元素色只作轻量点染。
- 每格透明度直接来自灵势、聚气、脉节充盈、通畅度和纯净度。
- 脉域边缘来自生成时的不规则贡献并使用双线性过滤自然消散。
- 结穴地范围获得稍强聚气晕染。
- 壅塞和污染使用发暗、浑浊表达，不画虚线。

显示不读取不可见引导骨架，也不生成路径网格。

### 绘制行气墨丝

脉域内部从高灵势格稳定抽取许多短墨丝：

- 墨丝按当前位置逐格行气方向移动。
- 速度随灵势变化，离开所属脉域后回到自己的稳定起点。
- 充盈、纯净度和污染控制颜色与透明度。
- 远景隐藏墨丝，中景降低数量，近景显示完整细流。

墨丝用于表达一片气场内部的流动，不连接成单根主线。

### 表现结穴地与自然灵眼

每处结穴地以覆盖范围相称的雾气和局部纹理表现。灵眼根据显化选择不同程序纹理：

| 显化 | 望气表现 |
| --- | --- |
| 灵泉、阳池 | 多层涟漪与轻雾 |
| 地窍 | 周期吐纳的上升墨气 |
| 石髓 | 岩隙状辉光 |
| 木华 | 花冠或树冠般聚散 |
| 风眼 | 缓慢旋转的气流 |
| 火穴 | 不规则热焰与呼吸 |
| 阴潭 | 贴地低雾 |
| 混沌地窍 | 扭曲、方向不稳的墨流 |

所有纹理在运行时程序生成，不使用旧灵眼徽章图片。

### 实现脉域悬停

鼠标选择顺序为：

1. 灵眼实际位置及紧邻格。
2. 当前格所属结穴地。
3. 当前格主要脉节。
4. 空白格关闭说明。

Tooltip 复用原版系统，`is_sim_tooltip` 保持关闭；只要鼠标仍在同一对象上而原版 Tooltip 被清除，渲染器会重新打开，避免只显示一帧。

脉节说明展示龙脉或支龙、地势角色、地区、规模、元素、充盈、通畅、供灵和纯净度。结穴地说明展示主客来龙、品相、灵眼、明堂面积、聚气、藏风和泄气。灵眼说明展示显化、浓度、元素和状态。

### 显示普通地图征兆

`SpiritVeinWorldSignSystem` 只为主穴、交龙地和上品以上副穴显示低透明自然征兆：

- 征兆限制在灵眼附近，不显示整条脉域。
- 充盈与纯净度控制强弱。
- 打开望气图或小地图时自动隐藏。
- 世界切换时统一销毁，不保存。
