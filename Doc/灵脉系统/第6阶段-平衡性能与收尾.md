## 具体说明

### 整理统一平衡表

`Tables/SpiritVein.csv` 是唯一手工平衡源，由 `Scripts/csv2json.py` 生成 `Content/SpiritVein.json`。启动时 `SpiritVeinSettings` 严格读取全部当前字段，不保留旧键兼容。

当前参数分组：

| 分组 | 内容 |
| --- | --- |
| 世界 | 背景灵气、世界上限、龙脉最少最多和绝对上限 |
| 生成 | 干支最低长度、祖山范围、脉域基础与最大宽度、最低灵势 |
| 结构 | 脉节目标长度、副穴数量、结穴距离与三种结穴范围 |
| 变化 | 重流等待年数和重大地形影响范围 |
| 修炼 | 最大正向元素加成 |
| 运行 | 污染抽样、规模容量门槛、恢复、供灵和输送比例 |
| 地势 | 普通地、高地和山地推导高度 |

### 限制生成成本

- 主线程地形读取每批 4096 格，分散到多个协作步骤。
- 祖山、水口、引导骨架、脉域、风水值、脉节和结穴都在后台简单快照上计算。
- 寻路与大循环定期检查取消标记。
- 安装前执行一次完整不变量检查，不逐帧重复验证。
- 世界身份不一致时拒绝安装。

### 限制月度运行成本

每月只遍历：

- 已生成脉节。
- 已存在的脉域格编号数组。
- 每个脉节按固定比例抽取的污染代表格。
- 等待中的重大地形变化集合。

月度运行不重新搜索半径、不重新寻路、不扫描所有地理地区。供灵预算按脉节编号使用紧凑临时数组，主次来气在一次逐格循环中共同结算。

### 限制显示成本

望气图按职责刷新：

- 拓扑变化时复制一次脉域快照、重建纹理、墨丝采样和结穴显示对象。
- 储量或纯净度变化时只更新像素颜色和现有显示对象颜色。
- 地图关闭时不处理墨丝、动画或悬停。
- 墨丝和结穴显示对象重复使用，不逐帧创建销毁。
- 远景隐藏墨丝并只保留重要结穴地；近景再显示完整细节。
- 普通地图自然征兆只覆盖主穴、交龙地和上品以上副穴。

### 删除旧模型与资源

当前代码已经删除：

- `SpiritVeinPath`、`SpiritVeinNetwork` 和统一 `SpiritVeinGrade`。
- 线上格、到路径距离和固定影响半径查询。
- 路径网格、三层粗线、流光沿线和点状灵眼徽章绘制。
- 旧 `WakanMap` 与 `DirtyWakanMap` 双重资源入口。
- 灵眼徽章图片和旧线宽、图标大小平衡参数。
- 保存、迁移、兼容和未来建筑空接口。

### 完成编译和静态检查

必须执行：

```text
dotnet build Cultiway.csproj -c Debug --no-restore -clp:ErrorsOnly
python Scripts/csv2json.py Tables/SpiritVein.csv
```

生成结果自身检查编号、归属、数组尺寸、储量范围、上下游和一穴一眼关系。代码搜索不得再出现旧路径类型或旧平衡键。

### 完成实际游戏检查

仍需在 WorldBox 中覆盖：

1. 小、普通和大地图的龙脉数量与祖山水口关系。
2. 远中近三档缩放下脉域、墨丝、主穴和副穴可读性。
3. 悬停灵眼、结穴地、干龙脉节、支龙脉节和空白地区。
4. 关闭望气图后只保留重要灵地的微弱自然征兆。
5. 多名修士长期聚集后局部脉节衰弱，上下游状态不同。
6. 停止吸收后脉节逐月恢复。
7. 在支龙或主穴制造浊气，观察局部污染和下游传播。
8. 相合元素最高获得 25% 正向加成，不合时无惩罚。
9. 宗门优先选择可建明堂，而不是水中或山壁灵眼格。
10. 大范围改变山体、陆水和熔岩，观察等待、重流、移穴和残穴。
11. 后台生成或重流期间快速切换世界，确认旧结果不会安装。
12. 长时间高速运行，确认储量、纯净度和天地灵气保持有限值。

当前执行环境无法写入 WorldBox 的 `LocalLow` 数据库与日志时，游戏内检查必须在正常本地游戏进程完成，不能用编译成功替代视觉验证。
