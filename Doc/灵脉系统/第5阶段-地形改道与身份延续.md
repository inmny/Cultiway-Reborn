# 第5阶段-地势重流移穴与身份延续

## 目标

让长期稳定的重大山水结构变化重新塑造行气、结穴和水口，同时保留本次世界运行中能够对应的龙脉身份、局部状态与旧穴痕迹。

## 具体说明

### 接收稳定地形变化

地区系统提交 `StableTerrainChangesCommittedEvent`，只携带世界编号、地图尺寸、变化格和是否改变主体结构。灵脉服务重新检查世界身份并在主线程更新这些格子的简单地形快照。

地区核心不引用修仙玩法类型；灵脉服务也不读取地区系统内部变化记录。

### 区分表面变化与结构变化

普通生物群系或地表变化不会触发地势重流，只让相邻脉节的元素组成缓慢向新环境靠近。

陆水、山地、熔岩、黏液等主体结构变化只有靠近现有脉域时才进入候选。远离全部脉域的变化不会启动后台工作。

### 延迟并合并重大变化

候选变化收集在当前世界内，默认等待十个世界年：

- 等待期内的连续施工或灾害合并处理。
- 每月只推进等待计时，不逐帧求解。
- 同一时刻最多存在一个地势重流任务。
- 离开世界时立即取消任务并丢弃结果。

### 后台重新求解地势

等待结束后复制最新地形快照，在后台重新执行纯数据龙脉求解。完整求解用于避免只修改一个局部数组后在边界产生断层；相同世界编号和未变化地形仍使用固定顺序，因此不依赖全局随机状态。

后台不访问 `WorldTile`、Unity 网格、Tooltip、角色或宗门。主线程只接收完整结果并检查世界编号与地图尺寸。

### 匹配运行时身份

安装新结果前按祖山位置匹配旧龙脉：

- 龙脉复用原来的 `SpiritVein` 实例与元对象编号，并保留名称、收藏和自定义名称状态。
- 新布局编号可以变化，脉节与结穴地按新布局重新关联，不会把布局编号误当成对象身份。
- 支龙按所属龙脉和源域距离匹配名称。
- 脉节按龙脉、地势角色和中心位置匹配。
- 已匹配脉节按比例继承当前储量，并继承纯净度。
- 结穴地按龙脉、类型和距离匹配。
- 原位置附近延续的结穴地和灵眼保留名称。
- 未匹配的新对象才进入稳定命名流程。

容量变小后按新容量乘旧充盈比例，不会凭空增加灵气。新脉域也不会瞬间重置整张天地灵气图，而是由后续月度供灵逐渐形成。

### 处理移穴与残穴

旧主穴没有在附近匹配到新主穴时：

1. 如果旧址仍位于同一条新脉域且保留最低来气，将旧范围与新脉域取交集。
2. 旧主穴降一档品相并成为残穴，保留原结穴地和灵眼名称。
3. 残穴灵眼基础浓度下降，后续随脉节状态运行。
4. 新主穴作为真正新生结穴地获得新名称。
5. 旧址完全失去来气时不建立残穴，原地灵气由消耗和扩散自然衰退。

龙脉名称始终保持，体现的是同一条山川龙脉发生移穴，而不是生成一条毫无关系的新脉。

### 取消旧世界任务

任务使用 `CancellationTokenSource`：

- 世界清理时取消并观察后台异常。
- 过期结果不能安装到新世界。
- 任务完成、取消或失败后都释放取消对象。
- 本功能不写入存档，也没有迁移和兼容代码。
