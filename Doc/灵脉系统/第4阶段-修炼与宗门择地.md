## 具体说明

### 提供当地龙脉环境

`SpiritVeinManager.GetLocalInfo` 按格返回：

- 主要龙脉、次要龙脉、主要脉节、结穴地和灵眼编号。
- 主要与次要灵势。
- 行气方向、聚气、藏风和泄气。
- 当前脉节充盈与纯净度。
- 主次来气混合后的当地元素。
- 龙脉、结穴地和灵眼名称。

空白地区明确返回无影响，不伪造平均元素。

### 接入统一修炼结算

所有消耗天地灵气的修炼继续经过 `CultivationSettlementService` 和 `WorldWakanService.WithdrawClean`。角色先扣地块资源，地块形成缺口后，脉节在后续月份补充并实际消耗自己的储量。

灵脉不提供“直接给角色灵气”的入口，因此无法绕过地块浓度、扩散、供灵衰弱和浊气污染。

### 保持正向元素加成

`GetElementMatchBonus` 计算灵根与当地元素组成的非负重叠，再乘以灵势、聚气和纯净度。最大值来自平衡表，当前为 25%。

规则保证：

- 没有脉域时为零。
- 元素不相合时为零，不产生惩罚。
- 充盈、清净且聚气的结穴地更接近上限。
- 衰弱或污染后加成自然降低。
- 原有水域、山地、植被、熔岩等修炼条件不被龙脉替代。

加成放在统一天地灵气结算中，自动修炼与主动修炼不会使用两套结果。

### 评价长期来气与明堂

`GetLongTermSupplyScore` 不只读取当前地块灵气，还评价：

- 主要脉节的月供灵与月输送能力。
- 脉域灵势与当前纯净度。
- 次要来气的少量补充价值。
- 结穴品相、聚气、藏风和泄气。
- 当前格是否位于明堂可用范围。

`SectResidencePlanner` 在候选驻地中组合平均值与峰值。暂时被吸空但长期供给良好的明堂仍有价值；污染、泄气或不在明堂内会降低分数。

灵眼可以位于水中、山壁或其他不可建筑格。宗门选择的是明堂内可建位置，原有建筑空间、城市限制、宗门距离和地形硬条件仍优先执行。

### 保持玩法边界

| 职责 | 唯一入口 |
| --- | --- |
| 洁净灵气与浊气逐格资源 | `WorldWakanService` |
| 修炼消耗与角色收益 | `CultivationSettlementService` |
| 当地龙脉环境与长期供给 | `SpiritVeinManager` |
| 宗门驻地计划 | `SectResidencePlanner` |

当前不实现宗门自动搬迁、灵脉所有权、占领、聚灵阵、开采建筑或争夺战争。
