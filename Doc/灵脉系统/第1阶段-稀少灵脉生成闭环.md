# 第1阶段-地势场与结穴生成

## 目标

从山川地形生成少量风水龙脉。最终结果必须是宽广连续的脉域、局部脉节、主副结穴地和自然灵眼，不能把一次寻路结果当成灵脉本体。

## 具体说明

### 建立运行数据

当前数据分为五层：

| 类型 | 职责 |
| --- | --- |
| `SpiritVein` | 无成员元对象；保存龙脉共同身份、祖山、水口、规模和结构索引 |
| `SpiritVeinBranch` | 支龙身份、源域、汇流位置和元素 |
| `SpiritVeinSection` | 局部储量、恢复、输送、通畅度、纯净度和上下游关系 |
| `GatheringGround` | 主穴、副穴、交龙地或残穴的范围、明堂和风水品质 |
| `SpiritVeinEye` | 一穴一个的自然显化，不重复保存资源池 |

逐格 `SpiritVeinFieldSnapshot` 保存主要与次要龙脉、主要与次要脉节、灵势、流向、聚气、藏风、泄气和结穴地归属。后台生成阶段只产生纯数据 `SpiritVeinDraft`，回到主线程后才由当前世界的 `SpiritVeinManager` 创建或复用 `SpiritVein` 元对象；管理器不扫描单位，也不参与保存和历史统计。

### 分批读取固定地形

`GeoRegionsReadyGenerateSpiritVeinsEventSystem` 在主线程按批次读取地块，并复制为 `SpiritVeinTerrainSnapshot`。后台数据只包含简单值：

- 陆水、山地、高地、沙滩、熔岩和黏液标记。
- 生物群系编号。
- 主地区与地貌地区名称。
- 推导后的地势高度和八项元素组成。

后台生成不访问 `WorldTile`、`GeoRegion`、角色、宗门、窗口或 Unity 显示对象。

### 选择祖山与水口

祖山候选优先连续山地内部、高地密集且远离地图边缘的位置。多个祖山保持距离，普通地图通常形成 3 至 6 条龙脉；地图面积变化时数量按陆地面积平方根增长。

水口优先选择与陆地相邻的河湖或海岸格。找不到合格山水关系时允许少生成，不为了凑数跨越深海或穿过熔岩和黏液。

### 形成连续脉域

后台先用不可见引导骨架确定祖山到水口的总体方向和支龙汇流关系，再把沿途多股贡献栅格化：

- 干龙比支龙拥有更强、更宽的基础贡献。
- 山地与高地帮助保持来气，水口附近收窄。
- 每个贡献使用稳定扰动形成不规则边缘。
- 同一龙脉的重叠贡献融合为一片脉域。
- 不同龙脉只保留最强与次强来气。
- 每格由局部流向混合、周围山势、水势和地面平缓程度推导聚气、藏风与泄气。

引导骨架不写入生成结果。安装后没有有序线路、线上格或到中心线距离查询。

### 划分脉节网络

干龙和支龙按地势角色与目标长度划成脉节。干龙依次形成祖山源域、上游、过峡或汇流、入首和水口；支龙形成上游与汇流脉节。

脉节的地块范围直接来自最终脉域归属。容量按实际范围、灵势总量、脉节角色和干支关系计算，再建立明确上下游连接。

### 识别主穴副穴与交龙地

结穴候选只在已有脉域中产生，评分包括：

```text
灵势 + 流向汇聚 + 山势环抱 + 藏风 + 地面平缓
- 泄气 + 下游位置修正
```

每条龙脉最高分候选成为主穴，其他相距足够远的候选最多形成三处副穴。严格局部极值不足时，从下游可用明堂中选择聚气最好的位置；没有任何可用地时允许不结穴。

两条强脉域外缘重叠、聚气和藏风同时合格时，才形成稀有交龙地。交龙地记录主供与客供脉节，运行时由两边实际补充灵气。

结穴范围随品相扩大，其中可用陆地且不位于山峰、泄气不过高的格子组成明堂。

### 生成自然灵眼

每处结穴地选择聚气最强位置形成一个灵眼。显化由地形和元素共同决定：灵泉、地窍、石髓、木华、风眼、火穴、阴潭、阳池或混沌地窍。

显化只调整已有容量、恢复、输出或污染敏感度，不建立新资源类型。

### 检查生成不变量

生成结果返回前检查：

- 所有逐格数组尺寸一致。
- 龙脉、支龙、脉节、结穴地和灵眼编号不重复。
- 所有归属和上下游编号存在。
- 脉节地块不越界，容量和当前储量合法。
- 交龙地同时拥有有效主客来气。
- 每处结穴地恰有一个有效灵眼。
- 每个脉域格拥有有效龙脉和脉节归属。
