# 第3阶段-脉节供灵衰弱与污染

## 目标

让龙脉按局部脉节恢复、向下游输送、供养宽广脉域并承受污染。局部消耗或破坏不能让整条龙脉同步变化。

## 具体说明

### 建立月度顺序

`SpiritVeinMonthlySystem` 按世界月份推进：

1. 读取灵气潮汐倍率。
2. 各脉节自然恢复。
3. 上游向下游输送灵气。
4. 脉节按预算补充自己的脉域格。
5. 各脉节抽样结算局部污染与净化。
6. 污染沿下游少量传播。
7. 结穴地与灵眼刷新当前状态。
8. 处理长期稳定的重大地形变化。

世界暂停时不推进，同一月份只结算一次。

### 实现局部恢复与下行输送

每个脉节分别保存容量、当前灵气、月恢复、月供灵、月输送和通畅度。

```text
实际恢复 = 月恢复 × 潮汐 × 纯净度修正 × 脉节角色修正
可下行量 = min(当前灵气的一部分, 月输送 × 潮汐 × 通畅度)
```

下行量按有效下游分配，受下游剩余容量限制；实际传出多少就从上游扣除多少。灵气每月只前进一个脉节，因此上游变化需要时间传到主穴。

祖山源域恢复较强，过峡通畅度较低。通畅度很低时脉节进入壅塞状态，上游可以积气，下游则依靠自身储量继续运行。

### 由主次来气共同供灵

月度供灵只遍历已有脉域格，不搜索中心线或半径。动态目标由以下部分组成：

```text
低背景灵气
+ 主要脉节基础值 × 主要灵势 × 充盈 × 纯净 × 通畅 × 风水形态
+ 次要脉节基础值 × 次要来气 × 较低权重 × 对应状态
+ 结穴地品相与灵眼集中值
```

地块低于目标时，先按主次来气比例分配请求。每个脉节都受自己的月供灵预算和当前储量限制；实际增加多少地块资源，就扣除多少脉节储量。

交龙地记录有效客供脉节，因此一侧衰弱后，另一侧仍可维持部分灵气。

### 实现局部衰弱与壅塞

脉节状态由当前储量比例和通畅度决定：

| 状态 | 含义 |
| --- | --- |
| 旺盛 | 储量接近上限，完整输出 |
| 充盈 | 储量稳定，可正常输出 |
| 吃紧 | 输出开始连续下降 |
| 衰弱 | 只能维持有限输出 |
| 枯竭 | 保留极少输出，停止消耗后可恢复 |
| 壅塞 | 通畅度过低，上下游输送受阻 |

状态不会删除对象，也不改变名称。龙脉没有全网统一储量，所以主穴、支龙和水口可以处于不同状态。

### 实现污染传播与有偿净化

每个脉节从自身范围抽取固定比例代表格：

- 浊气相对洁净灵气超过门槛时，局部纯净度缓慢下降。
- 环境清净时，纯净度缓慢恢复。
- 净化附近浊气会实际扣除脉节当前灵气。
- 重度污染时，少量供灵转化为浊气输出。
- 污染按上下游连接逐月少量传递，不会一月传遍整条龙脉。

自然显化提供轻量差异：灵泉与阳池较易净化，阴潭较易积浊，火穴略易躁动，混沌地窍最不稳定。

### 刷新结穴地和灵眼

普通结穴地读取主要脉节状态；交龙地按主供与客供加权。灵眼继承结穴地充盈和纯净度，再据基础浓度显示稀薄至化液五档状态。

数值变化只增加显示修订，不重建脉域形状。洁净或浊气发生实际变化后，由 `WorldWakanService` 统一公布地图显示副本。
