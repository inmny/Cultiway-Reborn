# 地区定制

## 已确定的玩法

- 未划定区域保留原版建村与扩张规则。
- 玩家用原版领地格子绘制独立地区，一格对应 8×8 地块，不改变地形。
- 每个地区最多容纳一个村庄，该村庄只能在本地区内扩张。外面的村庄不能吞并空闲地区。
- 村庄灭亡后释放名额；征服、叛乱和国家变化不改变所属地区。
- 在已有村庄上开始绘制时，先纳入村庄现有的全部领地；遇到另一个地区或第二个村庄时拒绝本次操作。
- 擦除用于缩小尚未被村庄占用的部分；删除整个地区会解除限制并保留村庄、建筑和地形。
- 定制区域随世界存档保存，切换世界时清理选区。
- 地区可以命名，名称为 1～40 个字符的单行文字，默认显示“地区 + 编号”；名称随世界保存。

## 操作

“修仙 → 世界”的世界工具栏提供三组按钮：

1. **新建地区**：点击地图开始一个地区，然后自动切换到绘制。
2. **选中地区**：点击已有色块，显示名称、所属村庄和面积，然后继续绘制。
3. **绘制地区**：按住拖动扩展当前选区，支持原版笔刷大小。
4. **擦除地区**：按住拖动缩小当前选区的空闲部分。
5. **删除地区**：点击色块删除整个地区的定制范围，保留村庄。
6. **编辑地区名称**：点击地图上的地区，在窗口中输入名称并保存；取消不会提交修改。

地图显示区提供独立的“地区图层”开关，显示地区边界与名称。使用地区工具时自动打开，当前选中地区以亮色突出。名称文字复用原版地图名称样式，不拦截地图点击；关闭图层时一并隐藏。

## 实现

数据和边界规则放在 `Source/Content/Territories/`，通过地区编号、名称、村庄编号和领地格子编号保存。按格子和村庄建立索引，建村与扩张检查只查索引，不每帧扫描全图。

在原版建村候选判断中排除已有村庄的地区；在 `City.addZone` 修改列表前检查边界，避免原版新村庄初始领取周围八格时越界。首次领取地区的村庄立即占用名额。

通过原版世界数据的 `custom_data` 随世界保存；保存时才序列化，读档完成后自动恢复范围和颜色，暂停世界也会显示。原版加载领地期间不阻拦数据恢复。

地图图层只读取不可变的格子颜色快照。完整笔刷处理完成后才批量发布一次，不为笔刷中的每个地块分配数组；不持续生成全图数组。

名称窗口和名称图层放在 `Source/Content/UI/Territories/`。名称或范围变化时重算文字与地区中心位置，平时仅跟随镜头；使用现有对象池复用原版地图文字。名称提交以打开窗口时的地区为准，删除或切换世界后不能向旧地区提交。

复制原版名称文字时关闭其子图标，避免模板内的收藏星标被误显示为地区标记。

## 验证

- 未划定区域仍可建村、扩张。
- 同一块内第一座村庄可以成立，第二座被排除。
- 初始领取相邻格子和后续扩张均不能越界。
- 其他村庄不能进入已占用或空闲的定制领土。
- 圈入已有村庄时保留全部旧领地，冲突操作不产生部分修改。
- 擦除、删除、村庄灭亡、易主、保存恢复和换世界均保持规则。
- 游戏内检查工具选择、连续绘制、不同笔刷、地图显示及中文提示。
- 检查中文改名、首尾空格、空白与过长名称、取消编辑、地图即时刷新和实际存档重载。
