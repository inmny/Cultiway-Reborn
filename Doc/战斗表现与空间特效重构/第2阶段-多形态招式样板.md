## 具体说明

### 步骤1：明确样板的玩法边界

先重制已有能力的表现。没有现成玩法的形式，明确列出需要新增的判定、动作、支付和作用方式，再决定具体样板；不能借视觉重制悄悄增加额外伤害、击退、拦截或地形修改。

下文的节奏与组合是样板提案。具体时长在游戏中打磨，不在文档阶段统一指定为所有招式通用的固定秒数。第二阶段分批完成，每批交付可玩的招式，而非先写完所有通用组件。

### 步骤2：完成拳掌与兵器近战

近身格斗必须单独完成，至少包含无兵器接触动作、真实武器动作和实际角色位移，不能只把飞出的剑气放得更靠近身体。

| 样板 | 一招内部的组合 | 需要成立的实际规则 |
|---|---|---|
| 贴身掌击或拳击 | 收势、身体朝向或重心变化 → 拳掌前局部压缩 → 短程接触 → 接触震荡 → 回收 | 新样板提案；先确认攻击范围、身体动作、命中窗口与支付；震荡不自动等于第二次伤害 |
| 武器突刺 | 收枪或收剑 → 沿轴线加速 → 尖端接触 → 窄轨迹收尾 | 复用破甲突刺等现有能力；真实装备与接触方向对应 |
| 横扫或重击 | 身体与武器预备 → 扫掠或下砸 → 实际命中处反馈 → 带重量的回收 | 复用震退、蓄势重击等能力；范围提示不能超过真实作用范围 |
| 多段连击 | 一段动作收尾成为下一段准备，方向与间隔有变化；每段只在实际命中时反馈 | 可使用传奇连斩；不把三次伤害伪装成单次动画的三条装饰线 |
| 冲锋或坠击 | 起步蓄势 → 角色真实位移与尾迹 → 终点接触或落地 → 尘屑和恢复 | 保留各自的位移会话；途中作用与终点作用不混为一处爆炸 |
| 格挡与反击 | 武器进入防守角 → 真实接触产生短偏转与火花 → 反击动作与命中 | 复用既有状态和反击规则，不凭空增加武器互撞判定 |

无兵器动作的基本要求是：能看出身体发力、接触部位与回收。若现有角色动作无法支撑，明确补充动作能力；不能用一个飞出去的掌形贴图代替贴身掌击。三维侧没有完整肢体绑定时，记录身体与武器动作的实际覆盖程度。

爪击、尾击、角撞可以复用接触轨迹和反馈，但其作用位置必须来自妖兽相应部位或明确的近似点，不能统一挂在人物手部。它们在第三阶段随器官来源接入。

### 步骤3：完成不同空间形式的法术

每种形式至少完成一个完整样板；同一类的相似技能随后按数据与素材差异接入，不要求这一阶段重做所有元素变体。

| 形式与候选 | 一招内部的组合 | 不能被弱化的特点 |
|---|---|---|
| 弹丸：火球或冰棱 | 起点成形 → 主体加速或旋转 → 清晰拖尾 → 接触碎裂或燃尽 | 主体可见；火与冰不是同一光球换色 |
| 光束：灵力束或太阳光束 | 起点聚焦 → 通道建立 → 端点跟随与实际作用脉冲 → 由起点收束 | 起终点和宽度稳定，瞬时与持续光束区别明确 |
| 喷吐：火焰、寒流或器口喷流 | 发射口收紧 → 有宽度的前缘推出 → 内部流动持续 → 停止后残流消散 | 本项为形式补足提案，先查现有能力并确认缺失玩法；不能退化为火球连发 |
| 连锁：连锁雷 | 首段成立 → 按实际顺序跃迁 → 各接触点短闪 → 最后分支消退 | 顺序来自真实连锁；装饰分叉不代表额外击中 |
| 束缚：灵藤 | 目标处生长或连接 → 围绕、绷紧 → 状态维持 → 解开或断裂 | 跟随真实约束状态，不把未被限制的角色画成已经锁死 |
| 竖向发生：地刺与落雷 | 地面预兆或高处聚集 → 原地突起或落下 → 真实作用 → 碎屑或电弧消散 | 发生方向不同，不能共用横向投掷动画 |
| 宽面推进：浪潮 | 前缘抬升 → 宽面推进与内部水流 → 经过目标时反馈 → 回落消散 | 宽前缘与覆盖面可辨，非单张平移的水球 |
| 持续区域：毒雾或阴性领域 | 边界建立 → 低强度内部流动 → 实际作用时局部变化 → 边界收散 | 持续区与一次爆炸可分辨；不遮住所有目标 |
| 墙与屏障：冰墙或水幕 | 沿方向建立 → 主体维持 → 接触或受损变化 → 撤去或破裂 | 厚度与方向清楚；是否阻挡按当前能力规则表现 |

地面预兆只在玩法允许的提前量中出现，不能为了炫目给瞬发技能擅自增加预警时间。已有瞬时作用可以使用极短建立过程，但不能让伤害先发生、主体很久后才到达。

### 步骤4：完成法宝、防御与辅助

| 样板 | 组合要求 | 与其他样板的区别 |
|---|---|---|
| 飞剑或剑阵 | 主体姿态、各剑实际阶段、局部聚力、运动轨迹、接触和回收 | 每柄真实攻击与装饰残影有区别，不能将显示数量当成攻击数量 |
| 非飞剑法宝 | 从当前已实现能力中选择非长条主体；由实际部件发射、受力或布设 | 检查器口、底面、镜面或阵眼，不能继续沿用剑尖专用处理；若候选需新增玩法，先列出缺口 |
| 护盾 | 低强度待机 → 实际受击点形变或波纹 → 吸收、反射或破裂的对应反馈 | 按真实防御结果表现；不把减伤增益画成实体拦截球 |
| 阵法或部署区域 | 节点建立 → 连接与范围出现 → 实际作用脉冲 → 撤去 | 阵眼、边界和节点分工明确；显示节点不自动变成可攻击实体 |
| 治疗与净化 | 目标端施加提示 → 实际恢复或移除状态时变化 → 低亮结束 | 不沿用命中爆炸；治疗、净化与普通增益有区别 |
| 附体与武器强化 | 在真实部位建立局部变化 → 维持简洁标记 → 生效反馈 → 到期撤去 | 不能为了显示强化而改变攻击距离或碰撞尺寸 |

召唤、元神和妖兽器官不需要各自重新发明光束、爪击与护盾的画法，但必须在第三阶段验证实际载体、外观锚点和生命周期。独有的显化、召回和解体过程另行补充。

### 步骤5：验证组合效果与辨识度

逐招保留起手、主要作用、实际接触与结束的分解画面，同时保留正常速度片段。必须能够解释每个可见部件跟随谁、何时出现、由哪个真实事件结束。

重点比较：拳掌与兵器、光束与喷吐、地刺与落雷、浪潮与毒雾、护盾与治疗、飞剑与非飞剑法宝。隐藏技能名称时，仍应看得出它们以不同方式作用。

在混战中检验颜色以外的轮廓与运动差别。普通攻击不持续震屏；关键交锋反馈需有间隔，原版与 Worldfall 操控都保持稳定。

## 资源说明

| 资源组 | 具体设计 | 制作边界 |
|---|---|---|
| 身体与武器动作 | 收势、短程接触、横扫、下砸、回收、招架偏转 | 先复用真实角色与装备；缺少的身体动作单独列明，不以全屏光效代替 |
| 轨迹与接触 | 窄刺线、短弧面、重击面、局部火花和压缩波 | 共用路径和几何；不同攻击使用不同宽度、方向和寿命 |
| 弹丸与硬质体 | 火团、冰棱、地刺的稳定主体与碎片 | 可控形状、小材质；无需每个方向重画整段动画 |
| 流体与连接 | 光束主干、喷流前缘、连锁段、藤蔓路径、浪潮前缘 | 共享基础部件，保留各自的空间形态与运动 |
| 持续面与体 | 毒雾层、墙厚、区域边界、护盾受击面 | 控制透明叠加；三维必须检查侧面与内部视点 |
| 法宝外观与作用点 | 主体、发光部位、尖端、底面、器口或阵眼 | 优先使用组合模型和原始锚点；确需新部件时列明外观目录变更 |
| 状态与辅助提示 | 治疗向目标汇聚，净化短促散开，强化局部附着 | 持续期低亮，尽量少遮挡角色，不依赖大型循环动画 |
| 声音 | 轻重、材质和持续方式可区分；一招具有清楚主音 | 先核对原版可复用项，新增音频逐项记录来源与用途 |

## 验收条件

至少完成一套无兵器近身、一套兵器近战、一套位移动作，以及表中各主要法术形式的完整样板；完成飞剑和非飞剑法宝、防御与辅助的交叉检查。未实现的形式留在清单中，不能以其他样板通过代替。

每个样板验证命中、落空、中断与结束；需要持续的样板验证目标移动和变速，具有实际防御的样板验证吸收或拦截结果。Worldfall 尚未通过的项目逐项标注，不与原版完成度混算。
