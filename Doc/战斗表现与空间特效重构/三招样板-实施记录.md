## 本批实现

| 招式 | 已接入的过程 | 玩法边界 |
|---|---|---|
| 原地掌击 | 身体蓄势、相连的两段手臂、立掌前送、接触停势、回收；真实伤害与格挡各用自己的反馈 | 新增独立主动能力，徒手人形肉身可用；一次原版徒手攻击，使用原版恢复，不另收资源，不替换全部普攻 |
| 落雷第零变体 | 固定折线主干、两处分支、随真实下降位置伸展、地面放电、收细消散 | 保留原阶段、轨迹、范围和伤害；其他变体继续原显示 |
| 金钟护界 | 实际组合钟体微振、由组合模型提取的通透轮廓、符纹、局部吸收反馈、耗尽破裂、正常收散 | 保留原护盾池、支付、持续时间及冷却；没有新增弹丸碰撞拦截或反射 |

以上表现读取同一份世界状态，在原版和 Worldfall 场景中共用固定几何与姿态。几何、声道和短动作不写入长期存档，正式存档格式及原能力编号保持原约定。

## 框架接入

金钟继续通过已有的能力循环、信号与显示租约管理。最后一次吸收在发信号时记录“容量已耗尽”，避免之后的状态清空被误认为正常到期或反过来误报破裂。来向取攻击来源；当前仍是近似接触位置。

落雷只替换第零变体的显示。它的出现阶段已经允许移动，因此表现从轨迹启动时就跟随下降，不等待出现动画结束。折线从有限组固定几何中选择，不逐帧随机或重新上传模型。

掌击使用现有主动能力入口、公共攻击恢复、原版近战结算和最终伤害关联。动作锁定原目标及出手方向，接触时重新检查存活、可攻击性、距离、高度与方向。一个逻辑步跨过接触点时也只能结算一次；目标离开则挥空，换装、死亡或身体失效则取消。

原地动作复用战术层的停步记录，并补到原版玩家移动入口。Worldfall 替换了原版受控移动，因此还需在其实际移动和重叠推离入口遵守同一记录。第一人称掌击期间只让共用模型接管右臂，左臂保留，结束后恢复原来的右臂。

身体脚下位置直接取人物离地高度，不使用原版额外的命中高度补偿。身高优先按固定站立帧计算，避免走路、攻击切帧改变掌击距离或肩部位置。掌击仍按原版近战规则结算，这些身体挂点不构成一套新的骨骼系统。

护罩、雷光和接触气浪标记为保持自身颜色的能量表现，接入 Worldfall 的自发光属性；手臂、法宝实体与地刺仍受正常光照。这能避免能量线在背光处变成黑色杆件，但不等于已经完成夜景光照、雾层或所有材质的制作。

钟音由自制的衰减泛音合成，使用游戏已启用的声音系统，缓存一次采样并在世界切换时释放。实机确认游戏关闭了 Unity 自带音频系统；创建声音对象不能作为播放成功的证据。声音按当前视点计算左右和距离，并持续响应总音量与音效音量。

## 已完成的检查

| 检查 | 结果及证据 |
|---|---|
| 开发编译 | 当前实现通过，零错误；保留仓库原有十二条警告 |
| 掌击单次接触 | 专用世界中普通速度和五倍速均结算一次，挥空零次，换装取消零次，拒绝友方；最终正数伤害回调有效，接触时角色位移为零，暂停不推进动作。报告：`artifacts/combat_visuals/palm.json` |
| 掌击第一人称显示入口 | 确认镜头跟随本次角色后，其附近包含两段手臂和掌部；右臂暂时隐藏，左臂保留，收招后恢复。动作期间受控移动返回零，暂停时身体位置不变。报告：`palm-firstperson.json`。肩部和手掌使用近似挂点，近景比例仍需打磨 |
| 落雷显示与结算分离 | 两个相同第零变体在同一输入点只切换显示方式，均在 0.34 秒落点结算，各一次，最终回收；暂停稳定。不同落点可能发生不同环境碰撞，不能将其作为严格时点对照。报告：`lightning.json` |
| 金钟真实吸收与耗尽 | 开启支付约 2.139 灵力；容量约 101.129。来袭吸收 10 点，护盾相应减少，生命不变；耗尽记录为破裂，结束后显示资料为零。报告：`bell.json` |
| 身体挂点 | 脚下离地高度为零，原版命中高度另含 0.3 的补偿；切换八个人物帧，身体尺度保持 0.8。右掌位于正确身体侧。报告：`body-anchors.json` |
| 金钟到期 | 约 10.593 秒持续时间后安静收散，没有破裂标记，法宝本身保留。报告：`bell-expiry.json` |
| 金钟内外与声音 | 外部和内部均有同一钟形轮廓，切换视角不推进能力；一次真实吸收启动一次实际播放声道。能量标记为自发光，人物手臂保持正常明暗。报告：`bell-views.json` |
| 世界切换 | 重读正式格式世界后，掌击动作、金钟显示条目、播放计数归零，声音停止。报告：`samples-clear.json` |

启动时仍有仓库既有的王国旗帜补丁找不到目标方法的报告；本批未处理该界面补丁。上述运行检查以脚本执行期间没有新增错误为条件。

运行脚本在 [Scripts/CombatVisualTests](../../Scripts/CombatVisualTests/README.md)。报告和截图保留在本机验收产物目录，不打包进模组。
