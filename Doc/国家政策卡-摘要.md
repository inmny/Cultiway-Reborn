# 国家政策卡与世界日长

## 已确定的范围

国家统一选择政策，同国村庄采用同一套制度；职业人数、工作月份、家庭田块尺寸和具体军队名称仍保留原来的编辑入口。国家政策决定这些制度是否启用。公有制与私有制互斥，至少启用一种；这里的私有制指家庭经营土地，收成仍进入村庄仓库，不新增税收或家庭私有仓库。

| 政策卡 | 开启效果 | 关闭或替代效果 |
| --- | --- | --- |
| 公有制 | 原版围绕风车、由村庄统一管理的农田 | 改为私有制 |
| 私有制 | 家庭按劳动力经营近城矩形田块 | 改为公有制 |
| 童工 | 满原版童工年龄门槛的未成年人可参与生产，默认8岁；城市忠诚度−10 | 仅成年人生产，移除该项忠诚度修正；不允许孩童借此参军 |
| 劳动作息 | 普通居民按村庄工作月历劳动 | 不受工作月限制 |
| 职业分工 | 按库存、人口或玩家定员分配职业，允许农闲支援 | 使用原版岗位安排，保留已保存的定员供以后恢复 |
| 分级军制 | 唯一Army下分营队、军功任官、矩形跟队和例行操练巡逻 | 原版Army自行管理，保留军功与编制设置 |
| 两季农时 | 春麦、冬麦按播种、生长和收获月份运行 | 原版自由播种与自然生长 |
| 风车加工 | 收获不可食用原粮，再经风车加工 | 直接获得可食用麦粮；已有原粮仍可加工 |
| 施肥增产 | 单株一次施肥、消耗1份、收成翻倍 | 原版催熟；季节作物保持农时约束，不对其浪费肥料 |
| 城建优先 | 农田地表可接受房屋和公共建筑选址 | 沿用原版农田地表限制 |
| 儿童教育 | 达到可调入学年龄的未成年儿童空闲时进入本城图书馆阅读真实藏书；童工任务优先；城市忠诚度+10 | 不主动安排儿童课程，移除该项忠诚度修正；原有学习方式保留 |
| 流浪救助 | 无住房居民可在本城安全空房内临时睡觉，不改变住房归属；城市忠诚度−5 | 无房居民仍露宿，移除该项忠诚度修正 |

默认保留现有私有制与其余已启用制度，童工、儿童教育和流浪救助默认关闭。儿童教育默认6岁入学，可设1至100岁，成年后不再自动参加儿童课程。特殊者、国王、领主仍保留自主活动规则。易主后采用新国家政策，个人军功、实际库存和现有作物不清空。

教育需要本城已有完工可用、可步行到达的图书馆，以及儿童能够阅读的真实藏书。建造图书馆不会自动生成教材；没有藏书时不派发阅读课程。2026-11-19对当前世界的检查中，6座城市均已启用教育，但世界书籍总数为0，其中4座城市有可用图书馆；缺书是这一世界尚无儿童入馆阅读的直接原因。

政策忠诚度按本国已启用的项目相加，其他政策目前为0；不按月份累积，也不会因反复应用而叠加。国家政策窗口显示单卡影响、已生效合计和草稿预览；原版城市忠诚度提示列出同样的明细。首都和其他原版忠诚度规则保留。

## 世界日长

日长是世界共享设置，默认6秒/日，按1倍速计，可输入0.1至86400秒。每天12时、每月30日、每年12月不变，暂停与游戏倍速继续生效。每次修改记录生效时间和已经走过的日期，年龄、历史与作物月龄按各段实际日长累计。
