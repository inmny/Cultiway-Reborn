## 具体说明

### 入口与布局

原版村庄详情增加“人员与军务”入口，打开绑定该村庄的弹窗。原版 Army 窗口增加“编制管理”，进入同一窗口的编制页。

入口可以参考 `PatchRailwayInfo.AddRailwayEntry()` 的城市统计行接法。不要把当前尚未启用完整内容的 `AdditionCityWindow` 当成可直接复用的成品人员窗口。

建议四页：

| 页面 | 主要内容 |
| --- | --- |
| 总览 | 当前月份及工作状态、四类人数、现役与后备、任务状态 |
| 月份 | 12个月的工作／休息选择及应用按钮 |
| 编制 | 三层设置、唯一 Army 树、指挥者及矩形阵列预览 |
| 人员 | 分类筛选、后备标记、军功排序、当前任务和编制归属 |

总览同时显示两种统计口径：

```text
人员分类：士兵｜工人｜管理者｜特殊者
军事状态：现役总数（普通士兵＋特殊军职者）｜后备候选｜待补缺
```

四类人数互不重复，后备和特殊军职只是附加标记。特殊士兵不能在人员总数中算两次，后备不能被显示为现役。

### 月份页

月份按6列2行显示原版月份名称。每格明确显示“工作”或“休息”，当前月有独立标记，不能仅靠颜色区分。

- 点击月份切换状态。
- 提供“全年工作”“全年休息”“恢复默认”。
- 直接说明管理者、特殊者全年自由活动，以及士兵可能因明确军令临时集结。
- “应用”提交草稿；“取消”丢弃未提交修改。
- 设置全休时显示当前生产岗位与劳动力状况，但允许玩家提交。
- 修改未来月份不触发当前人物重新选工。

### 编制页

上半部分显示三层编辑表：

| 层级 | 可编辑名称 | 指挥称谓 | 数量要求 |
| --- | --- | --- | --- |
| 第一层 | 队／自定义 | 队长／自定义 | 每队人数，含队长 |
| 第二层 | 营／自定义 | 营长／自定义 | 每营队数 |
| 第三层 | 团／自定义 | 统领／自定义 | 当前唯一 Army 的营数 |

第三层不提供“创建第二支 Army”。原版 Army 的实例名称、营名称和队名称都可单独编辑；默认名称使用层级名和顺序号组合，实例可以单独改名。

下半部分为原版 Army—营—队的展开树，显示实员／编制、指挥者、军功、当前任务与缺额。后备名单放在独立列表，不伪装成第四层或一个空营。

提交前预览变化，例如“总编制1000→500；现役640；将转后备140”。正在战斗或运输的人员明确显示“该段结束后改编”，不让用户误以为已经释放。

数量必须为可表示的正整数；名称建议使用1—40个字符的单行文本。重编预览由服务计算，界面本身不直接移动人物、改职业或扣除兵员。

提供“按军功重新评定”按钮，先展示预计发生的任命变化，应用后统一执行。日常查看树形列表不自动重选指挥者。

阵列预览显示指挥点在前、成员矩形在后，区分正式指挥者、日常代理、有效成员和空位。选中营或 Army 时使用下级矩形块展示，标明整体宽高，避免缩放后看不出队伍重叠。

### 人员与军功

人员列表支持四类身份筛选、军籍与后备筛选、姓名搜索和军功排序。点击人物打开现有生物详情，不创建第二套人物面板。

人物详情增加“军功”数值；军职行可点击回到所属编制。候选比较显示军功、军事能力、等级及当前是否满足资格。

状态文案应能直接解释：

- “休息月，自由活动。”
- “特殊者，全年自由活动；接到军令时归队。”
- “后备候选，平时参与村庄工作；当前无缺额。”
- “暂不能补缺：原版征兵资格或粮食条件不满足。”
- “代领本次巡逻，正式队长保持不变。”
- “明确军令执行中，结束后恢复休息。”

页面不显示内部对象编号、路径预算、临时任务令牌等实现细节。军功规则与任命依据在具体数值或动作说明中解释。

### 资源与公共控件

功能窗口建议放 `Source/Content/UI/VillageDuties/`；使用现有 `UiSegmentedTabs`、`UiScrollPane`、`UiModal`、输入框、按钮和池化行。公共 UI 层不依赖具体村庄玩法类型。

原版资源已在本机核实：

| 用途 | 参考文件／使用方式 |
| --- | --- |
| 村庄与军队窗口入口 | `.GameSource/Resources/windows/city.prefab`、`army.prefab` |
| 新窗口的原版外壳 | `.GameSource/Resources/windows/empty.prefab`，经现有窗口与边框控件创建 |
| 村庄、Army 图标 | `ui/icons/iconVillages`、`ui/icons/iconArmy` |
| 工人、士兵图标 | 优先读取原版岗位资产的 `path_icon`；已核实 `iconCitizenJobBuilder`、`iconCitizenJobFarmer`、`iconCitizenJobAttacker` |
| 军功 | 已核实 `ui/icons/iconKills`，配合明确“军功”文字 |
| 编辑和休息动作 | 优先使用公共图标；已核实 `ui/icons/iconEdit`、`ui/icons/iconPause` |
| 管理者、特殊者、月份 | 先用文字和原有角色图标，不猜测不存在的资源路径 |

首版不需要新增贴图资源。若新增独立军功徽章，另行核对原版风格与资源目录后登记。

窗口内容使用安全区和统一留白，长列表复用条目，不在每次刷新重建所有成员。打开窗口时绑定村庄，提交时验证目标仍存在；村庄被删除或切换世界时不向旧对象写入。

## 验收

- 三层名称和数量字段能独立修改，第三层始终为一个原版 Army。
- 月份草稿取消无副作用，应用后的统计与实际执行一致。
- 无Army、无士兵、全特殊者、后备很多、超长名称、较小分辨率均能正常显示。
- 任命预览说明军功的作用，不因为打开页面自动替换现任。
- 切页、关闭、返回和重复打开不叠加监听，原版返回历史和暂停语义保留。
- 中文、英文、长文本、滚动条和弹窗关闭均满足 `Prompts/UI.md`。
