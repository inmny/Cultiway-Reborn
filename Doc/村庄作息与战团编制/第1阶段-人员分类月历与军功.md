## 具体说明

### 四类人员

分类范围为本村存活的智慧居民。列车、船、坐骑和普通动物不占这四类居民名额。未达到原版劳动或征兵资格的居民只显示状态，不因归类自动获得资格。

按以下顺序确定唯一的显示类别：

1. `isKing()` 或 `isCityLeader()`：管理者。
2. 实际拥有 `Xian`、`Magic`、`Knight` 修行体系之一：特殊者。拥有多种体系仍只统计一次。
3. 其余原版 `UnitProfession.Warrior`：士兵。
4. 其余居民：工人。

有修行潜力、持有法杖或名字包含“骑士”等情况，不代替修行体系的实际判断。宗门身份与军队身份各自保留，军功不改写宗门贡献。

人员类别与军籍是两项信息。例如，一位修炼者可以显示“特殊者／第二队队长”，并计入正式兵额；后备修炼者显示“特殊者／后备候选”，不计入现役。

管理者不自动参与普通征召或担任本系统的三层军事指挥者。士兵被任命为领主、国王时释放原军职，触发继任；原版管理、谋划和个人自卫行为照常运行。

### 工作与休息

每村保存12个月份的工作标记，未标记的月份就是休息月。同一个月只能有一种状态。

- 使用原版 `Date.getCurrentMonth()` 和月份名称；暂停时月份不推进，加速时随世界时间推进。
- 建议默认1—8月工作、9—12月休息，允许自由交错、全工作和全休息。
- 管理者、特殊者不读取月历来限制自身活动。
- 普通士兵休息时停止日常操练、巡逻，仍保留士兵职业、Army 关系和编制。
- 工人休息时停止领取村庄强制岗位；进食、睡眠、社交、逃生和即时自卫正常进行。
- 工人休息月不因库存下降被暗中改回工作状态，弹窗显示劳动力和库存状况供玩家判断。

特殊者和管理者仍可由原有自主行为选择活动，是否自愿参与某项原版工作沿用原有规则；本系统不会按月份向他们追加必做岗位。

跨月时先拒绝新的不合规任务，再让当前任务在最近的安全动作结束点释放。携带资源者完成当前交付，未完成建筑保持施工进度；不等待整座建筑或整条道路完工。战斗、登船、乘车和不可分割的结算动作先结束该段，再决定下一步。

设置修改在“应用”后生效。若只改了未来月份，不打断当前任务；若改变了当前月份的工作状态，采用同一套切换流程。

### 个人军功

新增独立个人数值 `MilitaryMerit`，作为持久化整数，由人物数据保存，界面显示为“军功”。它不作为攻击、防御或修炼倍率。

建议默认规则：

| 项目 | 规则 |
| --- | --- |
| 一次有效击杀 | +1 军功 |
| 击杀范围 | 原版确认归属的全部个人单位击杀，不额外按敌我、兵种或是否入伍筛选 |
| 获得者 | 原版记账的实际击杀者；士兵、工人、管理者、特殊者均可积累 |
| 助攻、指挥者、队友 | 不因他人击杀自动分得军功 |
| 首次启用 | 建议将原版已有个人击杀数一次性记作初值；新生人物初值0 |
| 退役、休息、转村、转换身份 | 军功保留 |
| 任命或升职 | 不消耗军功 |

原版 `Actor.newKillAction()` 调用 `Actor.increaseKills()`。只在统一个人击杀记账入口增加军功，不同时在伤害、死亡、武器击杀和军队汇总中各加一次。

首次初始化必须使用该次记账之前的击杀数作为基线，再计入本次增量，避免首次击杀重复获得军功。已有军功记录直接读取，存档加载和面板刷新不补发。复活后再次形成有效击杀时按原版新记账处理。

军功变化只标记相关任命排序需要更新，不每次击杀重排全军。具体任命规则见第2阶段。

### 任务资格入口

内容代码建议放在 `Source/Content/VillageDuties/`，使用少量职责清楚的服务：

| 建议对象 | 职责 |
| --- | --- |
| `VillageDutyPolicy` | 月份设置和已应用的配置 |
| `VillageResidentClassifier` | 唯一人员分类及当前劳动资格 |
| `VillageDutyService` | 判断能否开始、继续、退出某类村庄任务 |
| `MilitaryMeritService` | 初始化、读取及增加个人军功 |

不要修改原版 `Actor.canWork()` 的全局含义：该函数还服务于年龄、文化、宗门等规则。

统一资格判断至少接入三处：

1. `City.checkCitizenJob` 在 `jobs.takeJob()` 之前拒绝休息人员的村庄岗位申请。
2. 日常军事行为与模组工作选择器在开始和继续任务前检查资格。
3. 城市集体工程的角色参与策略检查作息；宗门和特殊者的独立任务保留自己的权限规则。

结束岗位借鉴宗门的“领取—执行—释放”流程。原版岗位占用会在城市刷新时重新统计，切换时需检查当前源码的实际清理入口，防止重复释放或留下假占用。

## 验收

- 四类统计无重复；特殊士兵同时保有军籍，但只显示在特殊者分类。
- 普通士兵进入休息月不退役，后备人员则确实没有正式军籍。
- 特殊者与管理者在任意月份均不被日常作息调度拉走。
- 采集、建造、修路等岗位按安全结束点退出，下一月能继续领取。
- 普通攻击、范围技能、持续伤害、复活后再次被击杀分别验证军功归属；一笔原版击杀只加一次。
- 保存、读档、反复打开面板不改变军功。
