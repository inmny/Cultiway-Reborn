## 具体说明

### 步骤1

游戏内按以下清单逐项检查（每换一种风格重复一轮，重点抽查 唐/元/扶桑/朝鲜 四种差异最大的）：

| 名称类型 | 触发方式 |
| --- | --- |
| 单位 | 用神力在东人文化领地刷人；婴儿出生 |
| 城市 | 文化扩张建新城 |
| 王国 | 城市独立建国 |
| 文化 | 东人单位建立新文化 |
| 氏族/家族 | 单位成家、家族壮大 |
| 语言 | 新文化建立时伴随产生 |
| 宗教 | 单位创立宗教 |

同时确认：非东人种族、无文化的野人、未选风格的东人文化，命名行为与原版一致（回归检查）。

### 步骤2

- 皮肤风格循环切一整圈（10 种），期间持续生成实体，无报错、无空名。
- 删除某个风格 JSON 文件再加载：应回退原版命名并输出日志，不崩溃。
- 存档→读档：已生成的名字保持不变；读档后新实体继续按当前风格命名。
- 长时间运行（数小时加速）观察帧率无明显变化（补丁只在取名时执行，理论零开销）。

### 步骤3

- 清理调试日志，保留加载失败等必要告警。
- `dotnet build Cultiway.csproj -c Debug --no-restore` 0 错误，`git diff --check` 通过。
- 按 Conventional Commit 提交（例如 `feat: 东人名称按服饰风格生成`），提交信息中文。
