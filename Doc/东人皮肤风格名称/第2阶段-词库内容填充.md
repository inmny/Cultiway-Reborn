## 具体说明

### 步骤1

中文历史风格共用一套结构，但各朝代词表体现差异：

| 风格 | 取名习惯要点 |
| --- | --- |
| 通用 | 中性常用姓氏与双字名，作默认风格 |
| 春秋 | 单名为主；姓氏含先秦古姓与复姓（姬、姜、嬴、公孙、司马）；国号用春秋诸侯国（齐楚燕韩赵魏秦鲁吴越郑宋）；城市后缀用 丘/邑/阳/陵 |
| 唐 | 双字名为主，用字端正（承、玄、彦、卿）；国号可用隋唐之际政权名 |
| 宋 | 文雅用字（文、彦、端、宗）；城市后缀多用 州/府/军 |
| 元 | 混入蒙古语音译名（帖木儿、脱欢、海山类），姓氏保留汉姓；国号可含 大元 类 |
| 明 | 双字名，行辈感用字；国号含 大明；城市后缀 府/卫/所 |
| 清 | 混入满语音译名（相应音译表），其余同汉俗；国号含 大清 |

数量要求（每风格）：姓氏 ≥ 40、男名 ≥ 60、女名 ≥ 40、城市前缀 ≥ 30、城市后缀 ≥ 12、国号 ≥ 20、其余各类 ≥ 8。

### 步骤2

现代风格：当代常见姓名用字，名表避免生僻字；城市名可用 现代市/县 通名（市、区、州、江、河前缀）；国号用 共和/联邦 类后缀；宗教用 新教/学会 类后缀。

### 步骤3

- 扶桑：姓氏用日式姓（佐藤、田中、源、平…），名分男女（太郎、次郎 / 樱、小百合）；城市用 町/村/城 后缀；国号用 倭/扶桑/架空的 令制国名；宗教后缀 用 神社/宗/教。
- 朝鲜：姓氏用 金、李、朴、崔…；名以单字为主；城市后缀 用 州/郡/洞；国号可用 高丽/新罗/济州 类；宗教后缀 用 教/道堂。

### 步骤4

写一个临时的批量生成抽查（可用 DebugToolbox 脚本，不进仓库）：对每个风格各生成 50 个单位名、30 个城市名、20 个王国名，人工浏览输出确认：

- 无重复堆顶（同名率过高说明词表太小）；
- 无违规/不雅组合（相邻字拼出怪词）；
- 日文韩文词表未被中文词表污染。
