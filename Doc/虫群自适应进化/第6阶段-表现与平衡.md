## 具体说明

### 步骤 1：视觉与动画

视觉层级：

- 固定形态使用独立主贴图和基础动画。
- 甲壳与个体终身变化使用有限覆盖层、色调和粒子，不绘制全部组合整图。
- 武器腺通过攻击前摇、发射点、弹体和命中特效表达。
- 个体终身变化标识必须弱于完整遗传模块，避免玩家混淆。
- 对照试验分组仅在选中单位时显示轻量标记。
- 巢器官使用建筑阶段贴图或独立附着视觉，不用缩放母巢图片代替结构。

必须完成的动画：

| 动画 | 对象 | 触发 |
| --- | --- | --- |
| 孵化 | 幼虫 | 生物单位出生完成 |
| 结蛹 | 幼虫 | 开始蜕变请求（`BeginMetamorphosis`）已经提交 |
| 蜕变 | 全职虫 | 完成蜕变结果（`CompleteMetamorphosis`）已经提交 |
| 脱壳 | 可脱壳个体 | 后果队列已经提交脱壳结果 |
| 酸液喷吐 | 喷吐虫 | 主动能力实际释放 |
| 骨刺发射 | 对应职虫 | 主动能力实际释放 |
| 采集/运回 | 工虫 | 采集/运回（`Collect` / `Deliver`）工作阶段 |
| 建巢 | 建巢母虫 | 建巢进度和完成 |
| 巢器官施工 | 母巢 | 器官建设进度和完成 |

动画只表现已经提交的模拟状态，不在动画回调中决定资源、伤害或固化结果。

### 步骤 2：界面与信息呈现

界面必须遵守 `Prompts/UI.md`，只消费不可变只读资料，使用现有滚动容器、分段条、对象池和说明浮窗。

#### 个体详情页

“虫群实际身体”页组合共享 `CreaturePhenotype` 与虫群玩法只读资料，完整展示：

- 所属母巢和生态型。
- 出生遗传代数、职虫和共享固定形态。
- 虫群身体方案的五个器官槽、等级及虫群来源。
- 个体终身适应。
- 当前对照试验和分组；这些试验资料不属于身体组合编号。
- 当前职责、小队和群体策略影响。
- 共享器官带来的能力、收益与代价摘要。

#### 母巢观察窗口

| 标签页 | 内容 |
| --- | --- |
| 概览 | 人口、生物质、巢核状态、生态型 |
| 压力 | 主要压力、证据、趋势、最近来源 |
| 基因 | 各职虫形态与五槽模板、巢器官、群体策略 |
| 试验 | 候选原因、分组数量、目标指标、期限和结果 |
| 生产 | 目标比例、选择原因和孵化队列（`HiveBroodQueue`） |
| 历史 | 最近 16 次固化、淘汰、分巢和危机 |

需要覆盖：空母巢、无压力、无对照试验、未解锁职虫、长模块名、历史满载、目标失效和母巢崩溃状态。正式界面不显示固定随机种子或未压缩中间公式，只显示候选的主要收益和代价。

#### 世界日志

记录母巢建立、首次对照试验、固化/淘汰、新形态、生态型、分巢和崩溃。文字必须包含主要原因，例如“因长期火焰伤亡，赤脊巢群固化了火元素折射膜”。

所有文本、模块名、原因和日志必须本地化。

### 步骤 3：性能预算

设计负载：

- 32 座活动母巢。
- 4096 个虫族个体。
- 每座母巢最多一个对照试验、24 个压力类别、32 个样本和 16 条历史。
- 每个个体使用虫群身体方案的固定五槽，不为每个个体保存动态字典（`Dictionary`）。
- 共享实际身体编译缓存由组合生灵层拥有，同一实际组合跨母巢和对照试验复用。
- 母巢用 `HivePopulation` 保存各职虫数量，用 `HivePressure` 保存本月证据、当前压力和历史峰值。
- 对照试验成绩只保存在试验自己的 `TrialCohortMetrics` 中，普通个体不保存成绩组件。

复杂度目标：

| 操作 | 目标复杂度 |
| --- | --- |
| 一次伤害观察 | O(实际元素数)，常数上限 |
| 个体死亡 | O(1) + 已编译固定器官结算 |
| 实际身体表达 | O(固定槽位 + 静态贡献)，只在出生/蜕变时 |
| 成员加入/退出 | O(1) 归属关系操作 |
| 月度压力结算 | O(母巢 × 压力项) |
| 候选评估 | `O(可用候选定义 × 压力类别)`，低频限额 |
| 对照试验结算 | O(固定指标数) |
| 单个只读资料 | O(单巢固定摘要或请求成员集) |

禁止：

- 每帧遍历全部虫族单位列表（`ActorAsset.units`）。
- 每次伤害重建母巢成员列表。
- 每个个体保存母巢压力数组。
- 每帧为敌人构建完整语义资料（`SemanticProfile`）。
- 在伤害、主动能力枚举或渲染热路径编译 `CreaturePhenotype`。
- 渲染系统修改模拟状态。
- 界面每次刷新复制整个世界状态。

初始每帧预算：

| 工作 | 数量 |
| --- | ---: |
| 母巢常规更新 | 8 |
| 候选评估 | 2 |
| 孤虫归巢 | 8 |
| 生物质残留维护 | 32 |
| 到期蜕变提交 | 16 |
| 对照试验决策 | 2 |

超出预算进入队列，不全量补算。普通伤害记录不得产生托管堆分配；关闭界面时不得持续构建只读资料。

### 步骤 4：参数基线

所有参数集中在 `InsectBalanceProfile`，不得散落硬编码。

| 参数 | 初始值 |
| --- | ---: |
| 母巢人口上限 | 64 |
| 孵化队列（`HiveBroodQueue`）容量 | 8 |
| 同时活动对照试验 | 1 |
| 候选评估间隔 | 1 年 |
| 同槽固化锁定 | 3 年 |
| 普通伤害半衰期 | 3 年 |
| 样本半衰期 | 10 年 |
| 遗传记忆半衰期 | 20 年 |
| 对照试验最短/最长时间 | 2/5 年 |
| 每组最低结算个体 | 8 |
| 最低相关交互 | 12 |
| 目标收益最低提高 | 15% |
| 一般生存最低比例 | 基准组的 90% |
| 变异组占目标职虫 | 50% |
| 变异组占全部新生上限 | 25% |
| 单个个体个体终身适应 | 1 |
| 体细胞相对完整模块强度 | 不超过 40% |
| 语义样本条目上限 | 32 |
| 历史摘要上限 | 16 |
| 子巢最短间隔 | 10 年 |

长时间模拟调优必须同时观察压力响应速度、对照试验完成率、母巢崩溃率、职虫分布、资源净增长和模块多样性，不能只提高单位战斗胜率。
