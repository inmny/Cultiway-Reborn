## 具体说明

### 步骤 1：视觉与动画

视觉层级：

- 固定形态使用独立主贴图和基础动画。
- 甲壳与体细胞变化使用有限覆盖层、色调和粒子，不绘制全部组合整图。
- 武器腺通过攻击前摇、发射点、弹体和命中特效表达。
- 体细胞标识必须弱于完整遗传模块，避免玩家混淆。
- Trial 分组仅在选中或开发模式显示轻量标记。
- 巢器官使用建筑阶段贴图或独立附着视觉，不用缩放母巢图片代替结构。

必须完成的动画：

| 动画 | 对象 | 触发 |
| --- | --- | --- |
| 孵化 | 幼虫 | Actor 出生完成 |
| 结蛹 | 幼虫 | BeginMetamorphosis 已提交 |
| 蜕变 | 全职虫 | CompleteMetamorphosis 已提交 |
| 脱壳 | 可脱壳个体 | Consequence 已提交脱壳结果 |
| 酸液喷吐 | 喷吐虫 | Ability 实际释放 |
| 骨刺发射 | 对应职虫 | Ability 实际释放 |
| 采集/运回 | 工虫 | Collect/Deliver 活动阶段 |
| 建巢 | 建巢母虫 | 建巢进度和完成 |
| 巢器官施工 | 母巢 | 器官建设进度和完成 |

动画只表现已经提交的模拟状态，不在动画回调中决定资源、伤害或固化结果。

### 步骤 2：UI 与信息呈现

UI 必须遵守 `Prompts/UI.md`，只消费不可变 ReadModel，使用现有滚动容器、分段条、对象池和 Tooltip。

#### 个体详情页

“虫群表现型”页完整展示：

- 所属母巢和生态型。
- 出生基因世代、职虫和固定形态。
- 五个器官槽及来源。
- 体细胞适应。
- 当前 Trial 和分组。
- 当前职责、小队和 Doctrine 影响。
- 模块带来的能力、收益与代价摘要。

#### 母巢观察窗口

| 标签页 | 内容 |
| --- | --- |
| 概览 | 人口、生物质、巢核状态、生态型 |
| 压力 | 主要压力、证据、趋势、最近来源 |
| 基因 | 各职虫形态与五槽模板、巢器官、Doctrine |
| 试验 | 候选原因、分组数量、目标指标、期限和结果 |
| 生产 | 目标比例、效用原因和 BroodQueue |
| 历史 | 最近 16 次固化、淘汰、分巢和危机 |

需要覆盖：空母巢、无压力、无 Trial、未解锁职虫、长模块名、历史满载、目标失效和母巢崩溃状态。正式 UI 不显示 Seed 或未压缩中间公式；开发模式可显示完整评分分解。

#### WorldLog

记录母巢建立、首次 Trial、固化/淘汰、新形态、生态型、分巢和崩溃。文字必须包含主要原因，例如“因长期火焰伤亡，赤脊巢群固化了火元素折射膜”。

所有文本、模块名、原因和日志必须本地化。

### 步骤 3：性能预算

设计负载：

- 32 座活动母巢。
- 4096 个虫族个体。
- 每座母巢最多一个 Trial、24 个压力通道、32 个样本和 16 条历史。
- 每个个体固定五槽，不保存动态 Dictionary。

复杂度目标：

| 操作 | 目标复杂度 |
| --- | --- |
| 一次伤害观察 | O(实际元素数)，常数上限 |
| 个体死亡 | O(1) + 固定槽结算 |
| 成员加入/退出 | O(1) Relation 操作 |
| 月度压力结算 | O(Hive × Channel) |
| 候选评估 | O(EligibleDefinition × Channel)，低频预算 |
| Trial 结算 | O(固定指标数) |
| 单个 ReadModel | O(单巢固定摘要或请求成员集) |

禁止：

- 每帧遍历全部虫族 ActorAsset.units。
- 每次伤害重建母巢成员列表。
- 每个个体保存母巢压力数组。
- 每帧为敌人构建完整 SemanticProfile。
- ECS Query 中修改结构。
- 渲染系统修改模拟状态。
- UI 每次刷新复制整个世界状态。

初始每帧预算：

| 工作 | 数量 |
| --- | ---: |
| 母巢常规 Tick | 8 |
| 候选评估 | 2 |
| 孤虫归巢 | 8 |
| Deposit 维护 | 32 |
| 到期蜕变提交 | 16 |
| Trial 决策 | 2 |

超出预算进入队列，不全量补算。普通伤害记录不得产生托管堆分配；关闭 UI 时不得持续构建 ReadModel。

### 步骤 4：诊断

每次候选评估记录：

```text
HiveSerial
GenomeGeneration
EvaluationSequence
TopPressures
EligibleCandidateCount
TopThreeScores
SelectedCandidate
RejectedReasons
RandomPerturbation
CurrentBiomass
CurrentPopulation
```

每次 Trial 记录两组原始指标、归一化结果、阈值和结果原因。

开发命令：

```text
insect.hive.dump <buildingId>
insect.pressure.add <buildingId> <channel> <value>
insect.evolution.evaluate <buildingId>
insect.trial.resolve <buildingId>
insect.biomass.add <buildingId> <value>
insect.spawn <buildingId> <casteId>
insect.verify
```

维护阶段检查：

1. 每个虫族 Actor 恰好零或一个 Membership。
2. 每个活动 Hive 能解析有效 Building。
3. 每座 Hive 最多一个活动 Trial。
4. 每个 Trial 恰好被一座 Hive 指向。
5. Trial 个体满足同职虫和出生时间条件。
6. 每个职虫模板每槽最多一个模块。
7. 所有模块、形态、Ability 和 Status ID 存在。
8. Biomass 满足非负和容量约束。
9. PopulationState 与 Incoming Membership 一致。
10. 已结束 Trial 没有 Cohort IncomingLinks。
11. 已回收 Hive 没有任何外部引用。

开发构建发现失败时输出完整实体和关系信息，不静默修改权威状态。

### 步骤 5：边界情况

| 场景 | 处理 |
| --- | --- |
| 成年个体少于 8 | 暂停新 Trial，优先恢复工虫和基础兵虫 |
| Trial 期间压力消失 | 等待到截止；交互不足则 Inconclusive |
| Variant 全部早死 | 达最小失败样本可提前 Reject；一般生存低于 60% 可提前结束 |
| Baseline 未遭遇压力 | 延长或 Inconclusive，不与旧历史伪比较 |
| Actor 被力量直接删除 | 处理退出，不伪造死亡遗传证据 |
| Building 被力量删除 | 进入 Collapsing，不伪造敌方伤害压力 |
| 结构定义热重载 | 要求重新开始世界 |
| 纯本地化/视觉重载 | 允许 |
| 平衡数值重载 | 标记相关缓存为脏 |
| 世界暂停 | 所有玩法时间停止 |
| 世界倍速 | 模拟时间加快，每帧预算不变 |

未孵化完成的个体不计入 Trial 适应度。没有敌人的长期存活不能被视为抗性成功。

### 步骤 6：参数基线

所有参数集中在 `InsectBalanceProfile`，不得散落硬编码。

| 参数 | 初始值 |
| --- | ---: |
| 母巢人口上限 | 64 |
| BroodQueue 容量 | 8 |
| 同时活动 Trial | 1 |
| 候选评估间隔 | 1 年 |
| 同槽固化锁定 | 3 年 |
| 普通伤害半衰期 | 3 年 |
| 样本半衰期 | 10 年 |
| 遗传记忆半衰期 | 20 年 |
| Trial 最短/最长时间 | 2/5 年 |
| 每组最低结算个体 | 8 |
| 最低相关交互 | 12 |
| 目标收益最低提高 | 15% |
| 一般生存最低比例 | Baseline 的 90% |
| Variant 占目标职虫 | 50% |
| Variant 占全部新生上限 | 25% |
| 单个个体体细胞适应 | 1 |
| 体细胞相对完整模块强度 | 不超过 40% |
| Sample 条目上限 | 32 |
| 历史摘要上限 | 16 |
| 子巢最短间隔 | 10 年 |

长时间模拟调优必须同时观察压力响应速度、Trial 完成率、母巢崩溃率、职虫分布、资源净增长和模块多样性，不能只提高单位战斗胜率。

### 步骤 7：最终验收

#### 生命周期

- 放置母巢只创建一个 Hive Entity。
- 工虫、兵虫、生物质和 BroodQueue 可长期循环。
- 母巢摧毁和世界清理后无实体、关系、索引或旧请求残留。

#### 压力与 Trial

- 压力按真实伤害类型、人口和半衰期正确结算。
- 没有目标交互不能固化。
- 高目标收益不能掩盖一般生存崩溃。
- 固化只影响后续生产计划。

#### 非数值适应

- 飞行方向实际改变路径和对空追击。
- 酸液方向实际增加新 Ability。
- 撤退方向实际改变活动和位置。
- 生物质不足实际改变后续职虫构成。
- 两栖方向实际改变可达区域。

#### 分化

相同初始巢群在火焰近战与飞行远程环境运行 30 年后，形成不同压力、Trial 历史、模块、职虫比例和生态型，同时受槽位与成本限制。

#### 性能

- 4096 个虫族、32 座母巢下无逐帧全体扫描。
- 普通伤害记录无托管堆分配。
- 候选和 Trial 决策遵守预算。
- UI 关闭时不构建 ReadModel。
- 世界清理后所有清理前的实体、关系、索引和待处理消息归零。
