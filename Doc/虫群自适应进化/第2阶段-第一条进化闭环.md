## 具体说明

### 步骤 1：环境压力

阶段 2 启用固定通道：

| 通道 | 事实来源 | 主要响应 |
| --- | --- | --- |
| Fire | 实际火元素伤害和死亡 | 火元素折射膜 |
| Weapon | 近战/远程武器实际伤害 | 层叠几丁质 |
| Poison | 中毒伤害、状态持续和死亡 | 滤毒表皮 |
| ArmoredTarget | 虫族对高甲目标的低有效伤害 | 酸液囊、喷吐虫 |

单次伤害严重度：

```text
HealthSeverity = clamp(ActualDamage / MaxHealth, 0, 1)
PowerSeverity  = clamp(AttackerPower / max(DefenderPower, 1), 0.5, 3)
RawSeverity    = HealthSeverity * sqrt(PowerSeverity)
```

死亡额外贡献：

```text
DeathSeverity = 3 + clamp(RecentDamageFraction, 0, 1)
```

- 元素按实际 `ElementComposition` 权重分配。
- 零伤害、无效命中和重复死亡不产生压力。
- 每个个体的非致死伤害月度贡献有上限。
- 死亡绕过普通受伤上限，但同一死亡只结算一次。

每月结算：

```text
Observed[k] = AccumulatedSeverity[k] / max(MeanActivePopulation, 1)
Decay       = exp(-ln(2) * DeltaYears / HalfLife[k])
Pressure[k] = Pressure[k] * Decay + Observed[k]
Evidence[k] = Evidence[k] * Decay + AccumulatedEvidence[k]
```

初始半衰期：武器 3 年，火焰 4 年，毒素 4 年，装甲目标 5 年。

虫群只能观察已经发生的交互，不扫描附近敌人的 Trait、装备或未施放 Skill。

### 步骤 2：首批适应内容

| 定义 | 类型 | 响应压力 | 实际变化 | 代价 |
| --- | --- | --- | --- | --- |
| 层叠几丁质 | 甲壳模块 | Weapon | 降低武器伤害通过率、甲壳变厚 | 移速下降、孵化成本提高 |
| 滤毒表皮 | 甲壳模块 | Poison | 缩短毒素层数和持续 | 恢复效率下降 |
| 火元素折射膜 | 甲壳模块 | Fire | 只适应火元素并改变甲壳色调 | 对预定义克制元素产生弱点 |
| 酸液囊 | 武器腺模块 | ArmoredTarget | 获得远程酸液和腐蚀 | 射速低、成本高 |
| 喷吐虫 | 固定形态 | 酸液囊已固化 | 远程压制并使用酸液 Ability | 基础成本 16、分化 3 个月 |

甲壳槽硬互斥，三种甲壳模块不能同时表达。元素折射膜的数据变体共用一套规则，不允许叠加多元素抗性。

### 步骤 3：候选选择

每座母巢每年最多评估一次；每帧最多评估两座母巢。已有 Trial、母巢濒毁、人口不足或资源不足时不开始新 Trial。

候选必须：

1. 对当前前三主要压力至少有一个正响应。
2. 满足证据、世代、职虫和前置要求。
3. 不与锁定结构冲突，且与当前模板不同。
4. 母巢能够承担最低试验成本。
5. 不在抑制期，或压力超过重新尝试阈值。

需求和置信度：

```text
Need[k]       = 1 - exp(-Pressure[k] / Scale[k])
Confidence[k] = 1 - exp(-Evidence[k] / EvidenceScale[k])
```

评分：

```text
FinalScore = PressureBenefit
           + SampleBonus
           + MemoryBonus
           + SynergyBonus
           - RiskPenalty
           - CostPenalty
           - ReplacePenalty
           - SuppressPenalty
```

阶段 2 的 SampleBonus 和 MemoryBonus 可以为 0，但字段和日志合同保持稳定。

- 候选按稳定 ID 排序后评分。
- 低于最低阈值时不启动 Trial。
- 最高三项进入最终池。
- 使用 Hive Seed、GenomeGeneration、EvaluationSequence 产生不超过总分 5% 的确定性微扰。
- 记录前三项分数、收益、代价和落选原因。

### 步骤 4：对照试验

每次 Trial 是独立 ECS 实体，Hive 通过 `HiveActiveTrialRelation` 指向它。个体通过 `TrialCohortRelation` 标记 Baseline 或 Variant。

分组规则：

- 只比较同巢、同职虫、相近出生时间的个体。
- 目标职虫新生个体按稳定轮转 50%/50% 分组。
- Variant 不超过全体新生个体的 25%。
- 两组冻结出生时模板，Trial 期间不被后续变化改写。

最低样本：

| 条件 | 阈值 |
| --- | ---: |
| Baseline 已结算个体 | 8 |
| Variant 已结算个体 | 8 |
| 目标相关交互 | 12 |
| 最短时间 | 2 年 |
| 最长时间 | 5 年 |

适应度维度：目标压力缓解、一般生存、战斗/职责产出、资源效率和行动稳定。

```text
CompositeFitness = TargetWeight * TargetBenefit
                 + GeneralWeight * GeneralFitness
                 + ResourceWeight * ResourceFitness
```

连续指标压缩到 `0..1`，极端值使用截尾均值。

固化必须同时满足：

1. 样本量和目标交互达标。
2. Variant 目标收益至少提高 15%。
3. Variant 一般生存不低于 Baseline 的 90%。
4. 资源效率不低于候选底线。
5. 主要压力仍存在。

结果：

- `Committed`：写入模板，基因世代加一。
- `Rejected`：收益不足或一般生存过低，抑制 5 年。
- `Inconclusive`：目标交互不足或差异过小，冷却 2 年。
- `Interrupted`：母巢摧毁、人口崩溃或世界结束，不产生遗传结论。

### 步骤 5：固化与表现型

BroodQueue 入队时冻结 `BroodPhenotypePlan`：

```text
CasteId
MorphId
GenomeGeneration
GeneModuleIdsBySlot
TrialEntity
TrialGroup
BiomassCost
Signature
```

固化只改变后续创建的计划：

- 已出生个体保持原表现型。
- 已支付成本的卵不被改写。
- Variant 和 Baseline 在 Trial 内保持冻结。
- 完成分化时同步属性贡献、Ability 来源、Status 来源和图形脏标记。
- 可替换器官不写入永久 ActorTrait 或 LearnedSkill。

表现型签名按职虫、形态、五槽模块和 TrialCandidateId 的稳定顺序生成，不包含 Actor ID、名字、出生时间或运行时冷却。

### 步骤 6：观察窗口

通过“观察母巢”工具打开只读窗口，本阶段启用：

| 页面 | 内容 |
| --- | --- |
| 概览 | 人口、生物质、巢核状态 |
| 压力 | 当前值、证据、趋势、最近来源 |
| 基因 | 工虫、兵虫、喷吐虫模板与槽位 |
| 试验 | 候选原因、分组数量、指标和期限 |
| 生产 | 目标比例和孵化队列 |
| 历史 | 最近固化、淘汰和危机摘要 |

正式 UI 不显示 Seed 和完整中间公式；开发模式可以显示评分分解。

### 步骤 7：验收

1. 火伤主要增加 Fire，不平均增加其他通道。
2. 同一高恢复个体不能无限堆高母巢压力。
3. 停止暴露后压力按半衰期衰减。
4. 长期火焰压力提出火元素折射膜候选。
5. 没有足够目标交互时不能固化。
6. Variant 获得目标收益但一般生存崩溃时必须 Reject。
7. 固化只影响后续 BroodPhenotypePlan。
8. Trial 完成后清理全部 Cohort 关系和临时实体。
