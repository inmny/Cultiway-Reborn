## 具体说明

### 步骤 1：环境压力

正文使用中文压力名，程序中的固定编号保留在括号内。

每座母巢只保存一份 `HivePressure`。它同时记录本月伤害与事件证据、衰减后的当前压力和历史峰值，由 `HivePressureService` 统一修改，不再拆成“累计值”和“当前值”两个组件。

阶段 2 启用固定压力类别：

| 压力类别 | 事实来源 | 主要响应 |
| --- | --- | --- |
| 火焰（`Fire`） | 实际火元素伤害和死亡 | 火元素折射膜 |
| 武器（`Weapon`） | 近战/远程武器实际伤害 | 层叠几丁质 |
| 毒素（`Poison`） | 中毒伤害、状态持续和死亡 | 滤毒表皮 |
| 装甲目标（`ArmoredTarget`） | 虫族对高甲目标的低有效伤害 | 酸液囊、喷吐虫 |

单次伤害严重度：

```text
HealthSeverity = clamp(ActualDamage / MaxHealth, 0, 1)
PowerSeverity  = clamp(AttackerPower / max(DefenderPower, 1), 0.5, 3)
RawSeverity    = HealthSeverity * sqrt(PowerSeverity)
```

死亡额外贡献：

```text
DeathSeverity = 3 + clamp(RecentDamageFraction, 0, 1)
```

- 元素按实际 `ElementComposition` 权重分配。
- 零伤害、无效命中和重复死亡不产生压力。
- 每个个体的非致死伤害月度贡献有上限。
- 死亡绕过普通受伤上限，但同一死亡只结算一次。

每月结算：

```text
Observed[k]          = MonthlyEvidence[k].Severity / max(MeanActivePopulation, 1)
Decay               = exp(-ln(2) * DeltaYears / HalfLife[k])
Pressure[k].Value    = Pressure[k].Value * Decay + Observed[k]
Pressure[k].Evidence = Pressure[k].Evidence * Decay + MonthlyEvidence[k].Count
HistoricalPeak[k]    = max(HistoricalPeak[k], Pressure[k].Value)
```

初始半衰期：武器 3 年，火焰 4 年，毒素 4 年，装甲目标 5 年。

虫群只能观察已经发生的交互，不扫描附近敌人的特性（`Trait`）、装备或尚未使用的技能。

### 步骤 2：首批适应内容

| 定义 | 类型 | 响应压力 | 实际变化 | 代价 |
| --- | --- | --- | --- | --- |
| 层叠几丁质 | 共享表被/甲壳器官 | Weapon | 降低武器伤害通过率、甲壳变厚 | 移速下降、孵化成本提高 |
| 滤毒表皮 | 共享表被/甲壳器官 | Poison | 缩短毒素层数和持续 | 恢复效率下降 |
| 火元素折射膜 | 共享表被/甲壳器官 | Fire | 只适应火元素并改变甲壳色调 | 对预定义克制元素产生弱点 |
| 酸液囊 | 共享武器腺器官 | ArmoredTarget | 获得远程酸液和腐蚀 | 射速低、成本高 |
| 喷吐虫 | 共享固定形态 + 虫群职虫定义 | 酸液囊已固化 | 远程压制并使用酸液主动能力 | 基础成本 16、分化 3 个月 |

甲壳槽硬互斥，三种甲壳模块不能同时表达。元素折射膜的数据变体共用一套规则，不允许叠加多元素抗性。

### 步骤 3：候选选择

每座母巢每年最多评估一次；每帧最多评估两座母巢。已有对照试验、母巢濒毁、人口不足或资源不足时不开始新对照试验。

候选必须：

1. 对当前前三主要压力至少有一个正响应。
2. 满足证据、世代、职虫和前置要求。
3. 不与锁定结构冲突，且与当前模板不同。
4. 母巢能够承担最低试验成本。
5. 不在抑制期，或压力超过重新尝试阈值。

需求和置信度：

```text
Need[k]       = 1 - exp(-Pressure[k] / Scale[k])
Confidence[k] = 1 - exp(-Evidence[k] / EvidenceScale[k])
```

评分：

```text
FinalScore = PressureBenefit
           + SampleBonus
           + MemoryBonus
           + SynergyBonus
           - RiskPenalty
           - CostPenalty
           - ReplacePenalty
           - SuppressPenalty
```

阶段 2 的 语义样本Bonus 和 MemoryBonus 可以为 0，但字段和日志合同保持稳定。

- 候选按稳定编号排序后评分。
- 低于最低阈值时不启动对照试验。
- 最高三项进入最终池。
- 使用母巢固定随机种子、遗传代数（`GenomeGeneration`）和评估序号（`EvaluationSequence`）产生不超过总分 5% 的确定性微扰。
- 记录前三项分数、收益、代价和落选原因。

### 步骤 4：对照试验

每次对照试验都有独立运行记录，母巢通过 `HiveActiveTrialRelation` 指向它。个体通过 `TrialCohortRelation` 标记基准组或变异组。

参试虫发生有效伤害、死亡、击杀、采集、运回、护巢等事件时，事件处理器根据 `TrialCohortRelation` 找到所属试验和分组，直接更新该试验的 `TrialCohortMetrics`。普通虫子没有这条关系，不保存也不累计试验成绩。

分组规则：

- 只比较同巢、同职虫、相近出生时间的个体。
- 目标职虫新生个体按稳定轮转 50%/50% 分组。
- 变异组不超过全体新生个体的 25%。
- 两组冻结出生时模板，对照试验期间不被后续变化改写。

最低样本：

| 条件 | 阈值 |
| --- | ---: |
| 基准组已结算个体 | 8 |
| 变异组已结算个体 | 8 |
| 目标相关交互 | 12 |
| 最短时间 | 2 年 |
| 最长时间 | 5 年 |

`TrialCohortMetrics` 分别汇总甲组和乙组的目标压力缓解、一般生存、战斗或职责产出、资源效率和行动稳定。

```text
CompositeFitness = TargetWeight * TargetBenefit
                 + GeneralWeight * GeneralFitness
                 + ResourceWeight * ResourceFitness
```

连续指标压缩到 `0..1`，极端值使用截尾均值。

固化必须同时满足：

1. 样本量和目标交互达标。
2. 变异组目标收益至少提高 15%。
3. 变异组一般生存不低于基准组的 90%。
4. 资源效率不低于候选底线。
5. 主要压力仍存在。

结果：

- 固定（`Committed`）：写入遗传模板，遗传代数加一。
- 淘汰（`Rejected`）：收益不足或一般生存过低，抑制 5 年。
- 无法判断（`Inconclusive`）：目标交互不足或差异过小，冷却 2 年。
- 中断（`Interrupted`）：母巢摧毁、人口崩溃或世界结束，不产生遗传结论。

### 步骤 5：固化与实际身体

孵化队列（`HiveBroodQueue`）入队时冻结虫群生产资料和一份共享身体计划：

```text
BroodPhenotypePlan
  CasteId
  GenomeGeneration
  PhenotypePlan
    BodyPlanId
    MorphId
    Organs[]          // CreatureOrganEntry
    Signature
  TrialEntity
  TrialGroup
  BiomassCost
```

`TrialEntity` 和 `TrialGroup` 属于虫群对照试验附加资料，不进入 `PhenotypePlan.Signature`。基准组与变异组因为实际器官不同而得到不同组合编号。

固化只改变后续创建的计划：

- 已出生个体保持原实际身体。
- 已支付成本的卵不被改写。
- 变异组和基准组在对照试验内保持冻结。
- 完成分化时只调用一次 `CreatureExpressionService`，同步固定形态、属性、语义、主动能力、来源状态和图形脏标记。
- 可替换器官不写入永久出生特性（`ActorTrait`）或已学技能（`LearnedSkill`）。

共享身体组合编号按身体方案、固定形态、五槽器官编号与等级的稳定顺序生成，不包含生物单位编号、名字、出生时间、母巢、遗传代数、候选编号（`TrialCandidateId`）、试验记录（`TrialEntity`）、分组或当前冷却。虫群候选编号和固定原因保存在母巢及对照试验历史中。

### 步骤 6：观察窗口

通过“观察母巢”工具打开只读窗口，本阶段启用：

| 页面 | 内容 |
| --- | --- |
| 概览 | 人口、生物质、巢核状态 |
| 压力 | 当前值、证据、趋势、最近来源 |
| 基因 | 工虫、兵虫、喷吐虫模板与槽位 |
| 试验 | 候选原因、分组数量、指标和期限 |
| 生产 | 目标比例和孵化队列 |
| 历史 | 最近固化、淘汰和危机摘要 |

正式界面不显示固定随机种子和完整中间公式；只显示候选的主要收益和代价。
