# 修仙成就-摘要

- **版本**：v1.0
- **状态**：设计基线
- **当前范围**：仙途里程碑、道果挑战、丹器百艺、宗门传承
- **首批规模**：18 项，其中 14 项明示、4 项隐藏
- **奖励方式**：纯荣誉，不解锁属性、特质、物品或工具
- **明确不包含**：旧世界补判、进度计数器、化神及以后境界、成就专属窗口、Steam 成就提交

## 设计目的

修仙成就用于记录玩家在世界演化中真实见证或促成的修行节点。它不替代人物成长、宗门评价或世界日志，也不要求玩家沿固定任务线推进；只要注册完成后，世界中的角色通过现有玩法完成了对应事件，成就就能被账号永久记录。

首批成就围绕当前已经可玩的内容组织：

1. 修士从灵根初醒走到筑基、金丹、九转与元婴。
2. 高品质道果、混沌灵根和越境击杀形成少量长期挑战。
3. 炼丹、炼器与器灵觉醒让生产玩法进入成就体系。
4. 建宗、收徒、出师与宗门建设记录传承的形成。

成就不为只有本地化名称、尚无完整进阶规则的化神及以后境界预留空条件。后续境界真正可玩后，再以新的阶段扩展，而不是提前注册不可达成就。

## 核心原则

### 只记录新事件

成就系统不扫描载入世界中的既有角色、宗门或物品，也不根据当前状态恢复过去已经发生的经历。世界载入、打开成就窗口、切换地图和 Mod 重载本身都不能触发成就。

注册前已有的角色仍可在注册后的新事件中参与判定。例如，一名已经拥有九转金丹的修士在注册后成功结婴，可以在这次结婴事件中达成“九转功成”和结婴相关成就；如果他不再发生相关进阶，则不会补发过去的九转经历。

### 复用原版成就体验

首批成就直接进入原版成就窗口，复用原版分组、Tooltip、图标按钮、完成计数和解锁弹窗，不增加专属窗口或 prefab。新增一个“修仙”分组，并按仙途、道果、百艺、传承的固定顺序展示 18 项成就。

Mod 成就只写入本地 `GameProgress`。自定义 ID 不提交 Steam，也不写入官方 Analytics，避免把 Mod 内容伪装成官方平台成就。

### 不反向影响玩法

18 项成就全部为纯荣誉：

- 不提供数值加成。
- 不解锁宗门特质。
- 不授予物品或角色特质。
- 不改变 AI、进阶概率、炼制结果或宗门规则。
- 不使用 `unlocks_something`，因此不显示原版奖励型成就背景。

成就负责观察已经提交成功的领域结果，不能成为结果产生的原因。

### 条件可解释且可验证

明示成就的 Tooltip 直接描述达成条件，不使用内部类名、组件名、事件名或概率公式。隐藏成就在解锁前沿用原版隐藏说明，解锁后显示真实条件。

所有条件必须对应当前代码中的稳定状态或成功提交点：

- 境界与道果读取统一进阶事件及形成快照。
- 越境击杀读取实际击杀回调。
- 丹药与法宝读取最终定型后的生产结果。
- 器灵读取未觉醒到觉醒的状态变化。
- 宗门与师徒读取建宗、加入、建筑完工、收徒和出师的成功提交。

## 隐藏成就

首批四项隐藏成就用于保留探索感，但条件仍必须可稳定判定：

| 成就 | 隐藏原因 |
| --- | --- |
| 一脉天成 | 要求四境成果形成连续高品质谱系，属于长期养成结果 |
| 混沌初开 | 依赖稀有混沌灵根与元婴成果，不在普通进阶路线中提前提示 |
| 逆行伐仙 | 由实际战斗中的越境击杀触发，适合作为意外故事节点 |
| 器有真灵 | 器灵觉醒依赖法宝构成，不提前暴露特殊能力结果 |

隐藏只影响解锁前的条件文本，不改变图标槽位、计数方式、判定难度或账号持久化。

## 生命周期与持久化

成就资产在 Mod 内容初始化期间注册，账号进度继续由原版 `GameProgress` 的成就 ID 集合持有。系统不新增 Mod 存档字段、世界级计数、历史事件表或迁移逻辑。

运行时数据流固定为：

```text
领域事件成功提交
  -> 修仙成就条件检查
  -> 本地解锁网关幂等确认
  -> GameProgress 立即持久化
  -> 原版弹窗队列展示
  -> 原版成就窗口读取完成状态
```

同一事件可以解锁多项成就。例如，注册后结成天阶金丹会同时满足“一粒金丹吞入腹”和“金丹天成”。账号进度应立即、逐项写入；展示层按成就表顺序排队，不能因原版弹窗正在播放而丢失后续提示。

原版诅咒世界法则开启时，新的成就事件不解锁，也不缓存等待补发。法则关闭后，玩家必须再次发生新的合格事件。

## 分组与本地化

新增分组 ID 为 `cultiway_cultivation`，本地化键为 `achievement_group_cultiway_cultivation`，标题为“修仙”，标题色为玉青色 `#78D7B2`。

每项成就使用稳定资产 ID `Cultiway.Achievement.<Name>`，并显式声明名称键和描述键，不依赖原版初始化完成后的自动下划线转换。中文文本置于独立成就本地化文件中；未来增加其他语言时沿用相同键集合。

## 资源总览

首批需要 18 张独立的 28×28 RGBA 透明像素图，未来统一放置于：

```text
GameResources/cultiway/icons/achievements/
```

图标不含文字，以单主体和清晰轮廓表达条件。四条路线使用不同色彩重心，避免整个分组成为单一色系：

| 路线 | 主要意象 | 色彩重心 |
| --- | --- | --- |
| 仙途 | 灵根光点、仙基台、金丹、九重丹纹、紫府元婴 | 玉青、金、紫 |
| 道果 | 天阶霞光、四境同心印、混沌胎光、逆阶断剑 | 白金、青绿、黑紫、赤红 |
| 百艺 | 丹炉、丹药、锻锤、法宝、器灵魂火 | 朱红、翠绿、铁灰、天青 |
| 传承 | 山门、师徒谱系、传灯卷轴、三阁宗门 | 青瓦、暖金、朱砂、木色 |

本阶段只登记资源规格和逐项构图，不生成图片，也不修改原版成就 prefab。

## 最终体验

玩家从新世界开始，可以在不进入额外任务界面的情况下逐步点亮修仙分组：先见证灵根与筑基，再观察金丹、元婴、丹器生产和宗门传承。普通成就清楚表达目标，隐藏成就在稀有道果、越境战斗与器灵觉醒发生时揭示。所有结果来自注册后的真实世界事件，不追溯旧世界，也不改变世界为了成就而运行的方式。
