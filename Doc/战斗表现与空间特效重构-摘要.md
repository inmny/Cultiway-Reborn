# 战斗表现与空间特效重构

**历史方案说明**：本页记录此前的技术接通和实现过程，现有画面未达到用户要求。当前转向 [技能系统全面重构](技能系统全面重构-摘要.md)，不以本页的技术完成状态表示新质量目标已经验收。

**状态**：现有能力来源已接入空间表现，但代码核对与录像抽查仍发现主体漏画和演示错误，用户另指出范围不匹配、过度复用和战技烟雾问题；具体待办见[全量演示问题与修正](城域战斗表现/第5阶段-全量演示问题与修正.md)。此前实现范围、验证结果与限制见[全量实施与验收](战斗表现与空间特效重构/全量实施与验收.md)，不代表逐招美术验收完成。<br>
**最后更新**：2026 年 10 月 21 日

## 要解决的问题

当前最直接的问题是技能看起来软、贴图动画质量不统一，许多招式的观感接近“向目标丢出一个东西”。重制需要同时改善主体轮廓、运动、接触反馈，以及一招内部各部分之间的配合。

范围包含修士法术、近身格斗、骑士战技、法宝能力、符箓与卷轴、元婴与元神载体技能、妖兽器官技能，以及治疗、辅助、召唤和地形类能力。飞剑只是其中一种形式，不承担整个框架的定义。

## 已确认的方向

- 优先改善修士斗法与法宝交战，同时把近身格斗和其他法术形态纳入设计与首轮验证。
- 先做好一招内部的组合：起手、运动、作用过程、真实接触和结束；跨技能的元素反应另行讨论。
- 减少依赖整张序列帧，不再把 imagegen 批量生成的动画作为主要制作路线。
- 粒子方便组合，但清楚的主体形状、表面和动作同样必要；制作方式按形态选择。
- 普通交战保持清楚，关键交锋才加强镜头和节奏反馈。
- 将 Worldfall 纳入设计。当前参考包位于 /data/Downloads/S3COND2_WORLDFALL/，版本为 0.9.8。
- 保持正式存档的升级承诺，视觉重制不能使既有技能、法宝或角色进度失效。

## 设计覆盖

| 形式 | 需要表达的差别 |
|---|---|
| 拳掌、踢击、爪击、兵器近战 | 身体或武器真的完成一次接触动作，区分突刺、横扫、重击、格挡和反击 |
| 冲锋、突进、坠击 | 角色实际位移、途中作用和终点作用各有来源 |
| 弹丸、飞刃、御器 | 有明确主体、路径、朝向、加速与命中；不同实体不共用一种光球外形 |
| 光束、喷吐、连锁与牵引 | 连续通道、扇面覆盖、跳跃顺序和两端连接分别表现 |
| 落雷、地刺、陨落物 | 从天空或地面发生，具有落点和方向，不伪装成横向投掷 |
| 浪潮、风暴、毒雾、领域、墙体、阵法 | 边界、厚度、推进和持续状态可辨认 |
| 护盾、招架、反射 | 待机克制，实际受击处发生变化，明确区分承受、挡住、破裂与反射 |
| 附体强化、治疗、净化、诅咒 | 状态施加和持续效果清楚，减少遮挡角色的循环光团 |
| 召唤、分身、神魂及器官能力 | 表现跟随真正行动的载体和作用部位，区别召唤过程与召唤物自身攻击 |
| 非战斗世界能力 | 地形、天气和生长变化与实际修改进度对应，复用同一套空间表达 |

元素、能力来源和上述形式分别描述。例如火可以是拳上附着、喷吐、弹丸、火墙或法宝释放物，不能仅靠换色区别。

## 当前交付范围

已覆盖基础和结丹专属法术共 104 项、164 个旧变体，九项骑士战技、五种御器动作、43 项法宝显示档案，以及符箓、卷轴、神魂、召唤物、现有器官技能、持续状态和世界修改能力。具体稳定编号、主体形式与来源说明见[全能力覆盖清单](战斗表现与空间特效重构/全能力覆盖清单.md)。

模型、路径和局部粒子来自同一份未投影状态；原版统一投影，Worldfall 0.9.8 追加到其实际场景。掌击使用真实单次接触，兵器与剑阵保留实际来源模型；金钟读取实际防御结果，法宝器口使用组合锚点。普通攻击不连续震屏。

正式存档仍为第 1 版。稳定编号和旧变体不重排，临时显示不入档；旧法宝派生尺寸在读取后自动重建，骑士只读战技与失效状态的恢复问题已修复。正常升级无需重新开档。

## 明确的边界

支持的是实测的 Worldfall 0.9.8。兼容通过独立显示补丁完成，不加载或分发参考包；其他版本需要重新核对外部结构。三维显示没有改变原版按高度命中的规则。

身体与器官仍有近似挂点，像素武器、符纸和人物镜像保留真实轮廓及薄厚度；本次没有给全体人物、妖兽补齐立体骨架，也没有新增元素反应、独立爪尾攻击或自动连招玩法。组合效果指一招的动作、主体、路径、实际作用和收尾能协调起来。

本机参考包只用于观察表达方式与兼容验证，没有复制其图片、模型、声音或代码进入发布资源。
