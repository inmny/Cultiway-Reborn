## 目标

本阶段把元神从单一命魂神游扩展为受总心神和神识预算约束的多节点系统。化神修士可以蕴养九层元神、分出多个真实节点、安排任务、从节点位置施法并远程控制本人已经祭炼的法器。

普通分念只有一种：每次固定投入 `15%` 心神。系统没有重分念、附神任务或可调百分比。

## 九层蕴养

化神境使用统一小进阶 `xian.refine_yuanshen`：

- 当前境界必须为化神并拥有有效元神。
- 元神层数低于 `9`。
- 成功后层数加一，并确定性强化已有元神形成。
- 失败不降层、不改名、不重抽形成，只消耗资源并造成神魂创伤。
- 直接授予化神只创建第 `0` 层元神，不默认补满九层。

| 层数 | 当前作用 |
| ---: | --- |
| 0 | 命魂神游、基础神念攻击和无身续存 |
| 1 | 提高牵引、完整度和恢复 |
| 2 | 继续提高元神强度和魂防 |
| 3 | 开放第一道普通分念 |
| 4 | 开放节点位置施法和远程控宝 |
| 5 | 普通分念上限提高到两道，开放守护与跟随任务 |
| 6 | 继续提高强度、完整度和恢复，没有独立能力 |
| 7 | 开放本命法器和设施锚点能力 |
| 8 | 普通分念上限提高到三道，开放战斗法相 |
| 9 | 开放稳定化身和本相肉身重塑 |

形成演化只强化既有原子效果，不新增随机原子。元神名称和品阶保持形成时结果。

## 统一神识预算

预算同时管理连续神识负荷和离散分念槽位：

```text
分念容量 = 1 + floor(log2(1 + 神识 / 16))
```

并行单位规则：

- 人物当前命魂所在的主位置属于主念，不占槽。
- 命魂离体后，肉身无论保留多少心神都可独立行动，占一个槽。
- 每道普通分念占一个槽。
- 法相、化身和显圣各占一个槽并承担对应负荷。
- 非自主法器按现有规则占槽，自主法器只占连续负荷。
- 节点执行追踪、控宝、锁敌或锚点迁移时增加任务负荷。
- 本命法器寄托和本人设施网络承担连续负荷。

没有主动护魂、神识领域或附神负荷。预算不足时，创建节点和开始任务必须在写入状态前失败；已有低优先任务由各自系统停止或归返。

## 普通分念

蕴养第 `3` 层后可从当前命魂位置分出普通分念。

生成条件：

- 每次固定划出 `15%` 心神。
- 划出后命魂必须仍保留至少 `40%`。
- 当前有空余分念槽和连续神识负荷。
- 人物不处于强制归返、肉身死亡提交、夺舍、塑体或锚点迁移等排他状态。
- 支付最大灵气的 `3%`。

数量上限：

- 第 `3～4` 层最多一道。
- 第 `5～7` 层最多两道。
- 第 `8～9` 层最多三道。
- 最终数量仍取层数上限、神识槽位和可用心神三者的最小值。

普通分念不能成为命魂，不能接管人物身份。它可以移动、执行任务、被短时锁定并受到魂系伤害；受损部分转为人物创伤，未受损部分归返时回到主心神。

## 节点任务

每个节点同一时刻只有一个任务：

| 任务 | 目标 | 完成或中止条件 |
| --- | --- | --- |
| 待命 | 当前地点 | 收到新命令、受击或超载 |
| 移动 | 明确地面点 | 抵达目标或目标超出牵引 |
| 定点守护 | 明确地面点 | 一分钟到期、超出牵引或受损归返 |
| 跟随 | 明确友方人物 | 一分钟到期、关系失效或离开牵引 |
| 追踪锁定 | 七秒内仍被锁定的敌方节点 | 锁定到期、目标失效或离开牵引 |
| 控宝 | 已祭炼法器 | 法器失效、主动解除或预算不足 |
| 锁敌 | 明确敌方人物 | 目标失效、节点超时或资源不足 |
| 锚点迁移 | 本人授权锚点 | 引导完成、锚点失效或受击打断 |
| 归返 | 当前主位置 | 汇合后回收 |

任务目标只来自玩家明确点击、人物当前攻击目标、明确友方、本人授权锚点或现存短时节点锁定。任务系统不搜索人物、节点、建筑或世界。

## 节点位置施法

节点只是施法起点，人物仍是唯一能力所有者：

| 职责 | 所属对象 |
| --- | --- |
| 技能掌握、资源、冷却 | 原人物 |
| 阵营、敌我、伤害与击杀归属 | 原人物 |
| 技能出现位置和初始方向 | 当前节点 |
| 技能强度 | 原人物、元神形成与节点份额 |

准备、距离检查、支付和释放使用同一份冻结上下文。提交前再次验证节点句柄；节点已经归返、被击破或代次改变时，在支付资源和设置冷却前失败。

依赖肉身武器、近战动作、血肉碰撞或实际装备挥击的能力不能从分念释放。显圣投影另受非攻击限制。

## 远程控宝

第 `4` 层后，聚焦普通分念可以接管下一件正在运转且由本人完成祭炼的法器：

- 法器保持唯一实体和原祭炼归属。
- 能力显化位置跟随控制节点。
- 人物支付资源并持有冷却。
- 节点和法器共同占用统一神识预算。
- 节点失效、主动解除或预算不足时，法器回到现有调度流程。
- 同一法器不能被多个分念重复控制。

## 玩家操作

玩家可以：

- 分出固定 `15%` 心神的普通分念。
- 点击本人节点进行聚焦。
- 移动聚焦节点。
- 在第 `5` 层后安排定点守护或跟随明确友方。
- 追踪仍有效的短时节点锁定。
- 接管或解除远程法器控制。
- 归返当前分念或全部普通分念。

节点列表、世界选择和能力栏共用同一个聚焦状态，不把节点注册为第二个可控制人物。

## 人工智能

人工智能只在原人物当前有有效战斗目标时创建和调度普通分念：

- 优先保证肉身安全和命魂归返。
- 已经持有敌方节点短时锁定时，令第一道分念追踪该节点。
- 没有锁定时，分念只移动到当前战斗目标附近的合法牵引位置。
- 创建的每道分念固定使用 `15%` 心神。
- 战斗目标消失后召回全部普通分念。
- 法器与分念争夺槽位时使用同一个预算结果。

人工智能不主动侦测节点，不保存目标历史，也不执行人物、宗门或建筑搜索。

## 验收重点

- 第 `0～9` 层均能通过统一进阶流程提升，失败不降层或重抽形成。
- 系统只创建固定 `15%` 普通分念，不存在重分念入口或可变份额参数。
- 分念数量同时受层数、槽位和可用心神限制。
- 每次创建、受损、击破和归返后，全部心神份额严格合计为 `100%`。
- 节点位置决定技能起点，原人物承担资源、冷却和归属。
- 法器保持唯一实体，多个节点不能复制控制收益。
- 锁定追踪只处理仍有效的神魂接触锁定。
- 人工智能没有真实任务时不生成分念，也不主动发现未知节点。
- 世界清理后不存在节点、聚焦或预算残留。
