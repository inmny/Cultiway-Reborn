# 第2阶段-节点完整度与神魂战斗

## 目标

本阶段让普通分念和高阶元神节点承担真实神魂战斗，并让临时命魂人物通过普通人物受击入口结算魂伤。短时锁定只约束模组节点；临时命魂人物是可明确选择的人物目标，不需要节点锁定。

系统没有察神、领域、主动威压、范围扫描、空间索引、痕迹记录、位置历史或长期目标表。节点注册表只负责按稳定句柄找回已经明确接触的节点。

明确不包含：

- 人物、城市或宗门情报。
- 传念、托梦、搜魂或借用感官。
- 对普通人物、节点或建筑的全图与范围扫描。
- 存档、读档、迁移或兼容代码。

## 稳定节点句柄

元神节点不是原版人物，不能直接写入人物攻击目标。每枚节点注册一个稳定句柄，包含：

- 所属人物编号。
- 会话编号。
- 节点逻辑编号。
- 生成代次。

每次使用句柄都重新验证节点实体与身份。节点归返、击破或回收后，旧句柄立即失效；即使实体编号被复用，也不会误中新的节点。

注册表不按位置登记节点，也不提供落点检测。只有已经持有句柄的任务和战斗流程能够解析节点。

## 短时神魂接触锁定

人物通过以下明确事件取得节点锁定：

- 合法神魂攻击命中目标节点。
- 法相、化身或其他明确魂系接触入口提交节点命中。

每项锁定只保存节点句柄和到期时间：

- 基础持续 `7` 秒。
- 同一目标再次发生神魂接触时刷新到期时间。
- 每名人物最多同时持有 `32` 项节点锁定。
- 超过上限时删除最早到期的一项。
- 节点失效、人物死亡、锁定到期或世界切换时立即清理。
- 锁定不保存位置、来源、危险程度或可信度，也不能共享。

因为没有主动侦测能力，对模组节点的基础神念攻击不是发现目标的第一击，而是明确神魂接触后的反击和持续交战手段。临时命魂人物沿用普通人物的局部目标选择。

## 节点完整度

节点拥有独立运行时完整度。它表示这部分心神的当前结构，不是第二个人物生命值。

完整度由以下内容共同决定：

- 原人物最大魂魄。
- 节点投入的心神份额。
- 元神形成强度。
- 元神蕴养层数。
- 节点角色修正。

节点受到魂法伤害时，先由原人物魂防降低伤害，再扣除完整度。完整度损失会按节点份额比例转为人物的神魂创伤锁定，确保所有心神份额仍合计为 `100%`。

普通武器和没有魂系入口的攻击不能直接命中地图节点。

## 基础神念攻击

基础神念攻击共用一套距离、冷却和资源总账，但按目标类型走两个明确入口：

- 临时命魂人物把“神念冲击”作为魂体专属普通主动技能，可以直接攻击明确选中的敌方人物，不要求节点锁定。
- 攻击普通分念或高阶节点时，目标必须仍处于攻击者的七秒节点锁定中。
- 两种入口的攻击起点都取当前命魂位置。
- 距离上限为 `12` 格。
- 冷却为 `2` 秒。
- 每次消耗原人物最大灵气的 `2%`。
- 对人物的纯阴伤害读取攻击者元神强度并按当前命魂份额缩放；对节点的伤害按目标完整度上限和攻击者元神强度计算。

命中节点会刷新攻击者对该节点的锁定。若攻击者的临时命魂人物在外，受击方可把该临时人物作为普通战斗目标直接反击，不需要为它建立节点句柄。

## 牵引干扰

节点受到合法神魂攻击时会累计牵引干扰：

| 累计干扰 | 牵引状态 |
| ---: | --- |
| 少于 `0.75` 秒 | 稳定 |
| `0.75～2` 秒 | 波动 |
| `2～3` 秒 | 受阻 |
| `3` 秒以上 | 切断 |

没有继续受干扰时，累计值会逐步恢复。牵引受阻会妨碍正常归返；牵引切断且没有本命法器备用锚点时，离体命魂被击破会导致真正神魂死亡。

## 节点击破

### 普通分念和高阶节点

- 完整度归零后停止当前任务。
- 未损失份额按正常流程归返或消散。
- 已损失部分继续作为人物创伤锁定。
- 节点句柄和相关战斗锁定立即失效。

### 临时命魂人物

- 牵引仍可用时，命魂进入强制归返。
- 牵引切断但存在本命法器备用锚点时，尝试消耗锚点保命。
- 牵引切断且没有备用锚点时，提交真正神魂死亡。

同一次命中只允许提交一个最终结果，避免人物死亡、命魂死亡和锚点保命重复结算。

## 无身元神受伤

肉身毁灭后，原人物继续以无身元神存在：

- 普通物理、疾病、毒、饥饿和环境伤害直接忽略，即使毒素构成中带有少量阴属性也不例外。
- 明确神魂伤害，或由技能、法器直接提交的含阴攻击，按正常最终伤害流程结算。
- 这类伤害造成的致命命中可以造成真正死亡。
- 魂系攻击统一使用纯阴属性。
- 阴系威力、阴系抗性、魂防和力量层级都会参与最终结果。

这条规则只保护无身元神，不让普通离体节点借人物生命值承受物理伤害。

## 神魂创伤恢复

节点完整度损失形成的锁定份额由统一恢复系统处理：

- 命魂在体内时可以恢复。
- 命魂离体但停止任务时，可以按一半速度恢复。
- 正在执行神游和战斗任务时不恢复。
- 人物魂魄恢复属性越高，恢复越快。
- 元神蕴养层数会提供额外恢复倍率。
- 有效本命法器或设施锚点会提供有限加成。
- 锁定份额归零时移除神魂创伤状态。

## 人工智能

人工智能只使用原版人物当前已有的战斗目标：

1. 收集人物已经因神魂接触取得的有效节点锁定。
2. 对敌方锁定节点使用基础神念攻击。
3. 有普通分念时追踪该锁定节点。
4. 没有锁定时，只令分念前往当前战斗目标附近的合法位置。
5. 战斗目标消失后召回分念。

人工智能不会尝试发现未知节点，也不会因为曾经见过目标而在锁定到期后保存或追踪它。

## 验收重点

- 不存在主动察神、空间位置索引、领域或主动威压入口。
- 锁定中只有句柄和到期时间，不存在长期记录或共享。
- 没有真实神魂接触时，人物不能凭地面点取得未知节点锁定。
- 锁定到期后，神念攻击和追踪停止处理目标。
- 节点回收和代次改变后，旧句柄稳定失效。
- 普通物理伤害不能命中节点，也不能伤害无身元神。
- 纯阴魂伤可以击伤并杀死无身元神。
- 节点完整度损失只形成一次创伤锁定。
- 牵引切断、备用锚点和命魂死亡按唯一顺序结算。
- 世界切换后节点注册表和全部短时锁定均被清空。
