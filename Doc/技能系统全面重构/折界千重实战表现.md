# 9.37 折界千重

从目标附近采下相连的地貌，按相接的带状断面分层。每层有厚度，能看到原来的河岸、山脊和景物轮廓。各层从原位错开，在不同高度停留片刻，再依次对合。真实切割发生在各层回合时扫过的边缘，沿游戏原有的接触和伤害规则结算。

- [x] 分层与闭合。复用同一块真实测试地图，采样相接的地形和景物，按所见表面推进三层。检查错位、厚度、逐层归位，以及取消后没有临时层。
- [x] 实际作用。攻击只在回合时生效，使用与画面同尺寸、同姿态的断面。用同一场地验证断面接触、空隙及仅在开启时接触。检查真实切割，并确认受力者正常留在原世界。结束后仅保留已结算的影响。
- [x] 整项交付。原术与「折径」通过正式存读和实际施放，另用新进程读回同一档。原版和 Worldfall 各有一段覆盖完整过程的原速录像。

| 资源 | 用途 |
| --- | --- |
| 相连的地貌带 | 从原地图取色、高度与确有的景物轮廓，提供带厚度的断面。 |
| 回合边缘 | 使用真实切面尺寸，颜色和亮度交代当前闭合阶段。 |
| 错开及归位的路径 | 复用构造曲线，显示和实际碰撞共享部位姿态。 |

同一片场地实机通过分层、逐段对合与取消。三条分别采到河岸、风车与山脊上的树。切面与实际作用体逐项同尺寸、同姿态。开启时无人受伤，闭合时三名敌人分别失去 139 点生命，带外人物生命未变。

命中段结束后，脚本因两处原版表层草木变化报错。同场只读复核确认原地图高度、底层地块、风车和树都保留，三条临时地貌与施放已清理，原人物均存活且没有被技能控制。原失败记录随复核保存。

正式档保存在首层已造成伤害、另外两层尚未闭合时。读回保留已发生的伤害以及两份完整构造，未完成过程没有重放。「折径」从对侧展开并提前闭合首层，读回后实机按修改过的路径切中。冷启动读取同一份档也通过。

两段原速录像各为 4.22 秒，都包含展开、逐层切割和归位。地表使用原地图的颜色和高度，景物用简化的立体轮廓。首次录像暴露了顶面绘制方向问题，修正后两种视角均已重录。复验结果、正式世界和录像收在开发环境的 `evidence/thousand-fold-937/delivery.json`。
