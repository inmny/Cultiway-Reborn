落实3.04，分批接入。当前连接实际部位、结构、过程、父关系、本地结果、真实碎片集合与逐片流散，以及留置、世界材料转换、回能和导电的真实确认。世界记录编号已能继续作为转换、收束和导电输入；开放水层跨区后的材料身份、原有部位操作输出的统一接入继续在本项推进。完整条目保持未完成。

## 当前资料

能力的`Steps`保存命名步骤，每项包括`Id`、原有`Operation`及按端口名组织的`Inputs`。输入可以直接选择真实展开部位，也可以引用另一项的命名输出。引用在编译边界解析为索引，不在每帧查询名称或解释原JSON。声明可以前后互引；真正循环会在编译时拒绝。

```json
{
  "Id": "launch",
  "Operation": {"Kind": "Fly", "Vector": [4, 0, 0], "WorldVelocity": true},
  "Inputs": {
    "part": {"Step": "expand", "Output": "part"},
    "after": {"Step": "expand", "Output": "growth"}
  }
}
```

这里`part`传递真实身份，`after`等待尺寸过程实际完成。若材料定型使过程暂停，后续投送继续等待；不能按`Seconds`直接倒计时放行。部位或结构输出默认在实际开始后可用，过程和结果默认等待完成；`Stage`可以明确选择`Started`或`Completed`。`part`接受单个部位或完整子结构，其附属子体继续按原父关系随动。

首批复用生长、旋转、飞行、制作动作、本地材料转换、停止、脱离及聚合执行。聚合输出真实父连接，后续脱离可以引用该连接；引用别的部位的父体或连接会被拒绝。后续集合与世界确认实现见下文；尚未接通的输入明确报错，不取集合第一项，也不把本地材料变化当成世界转交。

## 共同运行

世界结果从原来的主线程提交入口返回。步骤运行和请求已发出都不能代替确认；留置等待世界接受，范围转换等待实际选择和转换结束，导电等待每一波真实传播和伤害结算，回能等待原支付通道处理。

| 世界操作 | 回执资料及放行条件 |
|---|---|
| 留置 | 世界接受编号、转交体积及支付份额；源部位结束后仍可读取确认事实 |
| 材料转换 | 实际改变的世界记录及体积；空选择明确返回零结果，不虚构材料 |
| 导电 | 每波序号、实际到达水格、实际进入伤害结算的目标和余力消耗；全部已发波数确认后结束 |
| 回能 | 已转化体积、请求量及原通道实际入账量；整数精度、容量和原支付者有效性仍由原资源入口决定 |

回执仅保存编号、数值及不可变集合，不保存游戏人物或世界材料对象。世界清空或来源取消后不继续放行旧施放。世界材料输出的精确选取与原部位操作输出统一接入仍按3.04后续范围完成。

集合输出使用`Mode`明确选择：`Single`要求一个对象，`Each`按真实部位逐个处理，`All`等待全部来源。`part`集合只允许`Each`；其他集合输入选择`Each`时，必须找到同一真实部位的唯一对应，不能把两组无关对象按数组顺序硬配对。

真实碎解在编译时预留实际分件，输出只有在完成出生及余力交接后才可使用。每片保留自己的身份、材料、体积、作用余量、支付份额和控制归属；可继续投送、改变材料或进入自己的流散。查询集合须使用`AppendStepOutputs`，标量查询不会偷偷返回第一片。分件流散以真实分件边界播种，不借用整物的骨架范围。

集合展开也受128个部位、128个执行实例及单部位16项操作预算限制。流散仍保留原来的水平速度与地表限制；三维曲线路径不能被误用为浅层水格的运动。

步骤只保存等待、运行、完成或中断。开始与完成事实记录真实部位、父体、时刻、位置、材料和同次施放中的控制归属。执行仍调用共同的尺寸、速度、骨架、布局及材料方法；显示和实际作用继续取同一状态。

完成由真实进度决定，替换、停止及来源失效不会冒充动作完整完成。已经发生的开始事实可继续定位仍存在的部位；等待完成的依赖遇到来源中断则一同中断。阶段及事实随已有预测快照回退，不能因寻找更早接触而重复放行后续操作。

每个步骤最多开始和完成一次，最多128步，单部位与原有条件操作合计最多16项。正常无变化帧只读取索引及数值；仅有新事实时继续派发就绪项。没有新步骤的旧构造不分配步骤运行状态。完整跨来源和规模性能仍按第13工作包验证。

没有新增模型、贴图、粒子或界面控件。原有构造输入和显示继续保留；游戏内新步骤编辑与更复杂输出按后续相关条目接入。

## 明确世界记录输入

后续转换或世界材料收束可绑定`worldMaterials`，导电可绑定`water`。来源必须是已经确认的留置或世界改质输出；只发生本地改质的部位不能提供世界材料编号，也不能引用“开始”阶段冒充接受完成。

```json
"Inputs": {
  "part": {"Node": "root/probe"},
  "worldMaterials": {"Step": "chosen", "Output": "material"}
}
```

共同编译器将引用解析为索引。真正提交时读取不可变回执中的世界编号，继续检查真实范围、当前材料、归属和数量限制。空输入、材料到期或没有符合条件的材料，都保持零结果；不会重新选择范围内其他材料。材料输出读取实际转交体积，源部位已经清零时也不会把转交量误报为零。

指定水域的传播只读取这些记录的实际液态水格，不借用原版海面、其他活动施放或同格其他来源。共同世界水格只累计指定记录的水深，伤害回调后再次核对相同来源。独立水格沿用各自的真实分辨率。

世界材料收束仍由原世界维护者启动并沿原支付者入账；本批限定的是它的实际选择，未把独立世界材料的后续入账量混入生成主体的回能回执。

私有游戏93855通过26项专项：两份铁材空间重叠时只冻结指定的6体积；空输出继续传空；过期材料不改选其他记录；明确编号仍受真实范围限制；世界收束只领取指定材料；独立水格及共同水格均验证冻结来源不借用其他水路、液态来源实际到达并消耗余力。编译也拒绝开始阶段、本地材料假冒及缺失实际世界参数。

回执19项、集合30项、原绑定33项、操作27项及正式资料256项回归通过，当前75份构造通过共同编译入口。旧导电回归原先让目标持有魔力护盾，却要求每次命中都扣血；已用实际目标及前后生命记录定位，并将测试目标设为零魔力，仍经过原伤害结算检查真实扣血。SDK0错误、16条已有警告，按项目DotSettings整理。
