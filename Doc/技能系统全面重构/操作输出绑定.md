## 当前资料

能力的`Steps`保存命名步骤，每项包括`Id`、原有`Operation`及按端口名组织的`Inputs`。输入可以直接选择真实展开部位，也可以引用另一项的命名输出。引用在编译边界解析为索引，不在每帧查询名称或解释原JSON。声明可以前后互引；真正循环会在编译时拒绝。

```json
{
  "Id": "launch",
  "Operation": {"Kind": "Fly", "Vector": [4, 0, 0], "WorldVelocity": true},
  "Inputs": {
    "part": {"Step": "expand", "Output": "part"},
    "after": {"Step": "expand", "Output": "growth"}
  }
}
```

这里`part`传递真实身份，`after`等待尺寸过程实际完成。若材料定型使过程暂停，后续投送继续等待；不能按`Seconds`直接倒计时放行。部位或结构输出默认在实际开始后可用，过程和结果默认等待完成；`Stage`可以明确选择`Started`或`Completed`。`part`接受单个部位或完整子结构，其附属子体继续按原父关系随动。

首批复用生长、旋转、飞行、制作动作、本地材料转换、停止、脱离及聚合执行。聚合输出真实父连接，后续脱离可以引用该连接；引用别的部位的父体或连接会被拒绝。未接通的集合与世界输出明确报错，不取集合第一项，也不把本地材料变化当成世界转交。

## 共同运行

步骤只保存等待、运行、完成或中断。开始与完成事实记录真实部位、父体、时刻、位置、材料和同次施放中的控制归属。执行仍调用共同的尺寸、速度、骨架、布局及材料方法；显示和实际作用继续取同一状态。

完成由真实进度决定，替换、停止及来源失效不会冒充动作完整完成。已经发生的开始事实可继续定位仍存在的部位；等待完成的依赖遇到来源中断则一同中断。阶段及事实随已有预测快照回退，不能因寻找更早接触而重复放行后续操作。

每个步骤最多开始和完成一次，最多128步，单部位与原有条件操作合计最多16项。正常无变化帧只读取索引及数值；仅有新事实时继续派发就绪项。没有新步骤的旧构造不分配步骤运行状态。完整跨来源和规模性能仍按第13工作包验证。

没有新增模型、贴图、粒子或界面控件。原有构造输入和显示继续保留；游戏内新步骤编辑与更复杂输出按后续相关条目接入。
