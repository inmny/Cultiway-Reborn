# 姿态约束与体型接合

对应4.08，已完成当前身体动作的姿态约束与双视角接合。保持既有掌击、横拍及持剑动作入口，补齐真实比例、同轮尺寸和固定肢段，不展开后续全身战技制作。

## 共同姿态规则

手路参数是请求点，不是肢长。实际腕点受固定上臂和前臂约束；把手路参数改成一万倍也不会扩大真实手臂或身体选取范围。参考身体保留原有0.24与0.27体高的两段长度，Worldfall使用自身模型的实际比例，两套肩肘共用一个腕点、一个手掌和一个握点。

伸直和完全折叠两端均留出随骨长缩放的余量，弯曲面随前态运输，不在特殊方向突然翻面。每步同时限制腕点速度及两套肩点附近的转向；越靠近肩点，允许的单步位移越小。快慢改变后重新计算运动包络，不另设显示时钟。局部时间、弯曲面和另一套肩肘随预测快照一起恢复。

`BodyReachProjector`在单位体高空间枚举球面、交圆与三球交点，在有限候选中选择共同可达点；同时满足两套臂长的内外界限和本步移动界限。没有逐帧数组分配，不靠迭代次数或镜头推进。

躯干同时满足参考站立及实际三维腿段的支撑。固定两脚后从可站立位置向请求位移推进，以各条腿允许的进度夹紧；深蹲也保留最短折叠距离。实际腿段和手臂不再按腕点或足底距离拉长。

## 实际身体与并行手臂

`BodyFit`仅保留固定肩点、臂长、腿根、支撑距离与完整身体高度比例。在正式开始前由主线程从Worldfall原有模型和个体外观取得，不要求打开三维视角；工作线程不访问人物、图片、网格或外部骨架。

原版人形的头部由原版另行拼接。高度换算读取完整站立人物的实际可见高度，保留原版已有图片缓存，不把裸身体图片当成完整人物。Worldfall的图片缓存允许异步返回空值：此时仅准备资料，不取得控制或支付，下次请求可继续受理。每帧沿用外部已有图片准备预算。

原版观察和Worldfall观察都读取同一套固定比例和同一腕点。三维身体接管时移除外部独立的上身闲坐、呼吸及步态偏移；其他未接管部位保留原有显示。衣甲继续沿用原有模型及姿态数组，接管的两段跟随同一固定肩肘腕。

并行双手共用当前身体朝向，各自路径仍可独立瞄准。局部手臂不带动躯干和转体，不建立两套互相冲突的身体朝向。全身与局部的原有互斥规则不变。

## 同轮位置、尺寸与地表

身体发布同时保留同轮不可变地表。原版投影从该地表换算离地高度，图片变换、变形边界和深度排序共用已确认脚下及尺寸；不修改人物或精灵池缓存。Worldfall身体及相连部件使用同一桥面、水面和跳跃偏移，身体读取共同绝对脚下。

闲置与施法使用同一完整站立人物高度，避免接管时从外部另一套尺寸缓动跳过来。动作中原始人物先变大、移动而共同姿态尚未确认时，身体和手掌一起保持前态；确认后再一起采用新位置和尺寸。
