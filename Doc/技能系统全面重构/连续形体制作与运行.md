## 具体说明

制作交换沿用明确版本的JSON，保留Three.js的索引几何、法向、表面坐标、每顶点四个控制索引及四个权重。发布网格通过Unity资源包加载，控制层级、绑定姿态、动作关键点、挂点及作用形状通过形体说明读取。游戏不临时导入模型，也不逐帧重建或复制顶点。

控制姿态使用父级之前的有序骨架和局部位置、单位四元数。首批最多32个控制点。动作保存世界秒数对应的局部姿态，执行通过普通构造操作选择动作及速度；同一资源可被不同运动、材料与嵌套结构使用。控制骨架使用位移与旋转，主体整体尺寸仍由已有构造缩放控制。

数值运行计算共同控制姿态和蒙皮矩阵，真实挂点及胶囊端点读取相同矩阵。绘制只消费完成状态，顶点在显卡中按相同权重变形。停留、打断、预测回退和固定根继续遵守已有规则，不另外启动一个动画时钟。

骨架影响范围由制作顶点按控制点归集；运行将这些范围随共同姿态变换并取并集，用于保守裁剪。正权重混合后的顶点位于该并集包围范围内，避免用绑定姿态的旧边界裁掉弯曲后的尾部。

原版投影和Worldfall使用同一蒙皮计算。骨架矩阵统一提交固定32项，避免Unity同名矩阵数组首次长度固定后截断后续更长资料；刚性资源保留原有路径。

连续主体仍需要单独制作。骨架、权重和材质能力不等于已经完成天鲸覆城的托举、压落、奔流、各尺度表现或最终用户验收。

首批发布水鲸包含7个材质部件、9个控制、49个游动关键点和13,196个三角形。眼部为随头控制的刚性部件，其余主体通过顶点权重变形；尾部挂点可继续嵌套其他形体。现有剑、枝、肢段及手掌同时切换为版本2说明，稳定资源编号不变。这里的版本2是发布形体说明，世界构造存档仍使用既有正式版本1，没有重开档要求。

`verify_form_rig.script`从真正资源包核对制作资料，41项通过。顶点位置、法向、表面坐标及权重保持制作数值；控制与动作导入最大误差约0.000000204。13帧共107,848个顶点采样没有超出动态边界，最大数值误差约0.000000954。检查也覆盖同一尾部挂点、五个作用形状、发布姿态不被后续推进改写、提前接触、驻留冻结和预测恢复。纯数值顺序／并行比较另包含全部32项发布蒙皮矩阵，结果一致。

翻卷浪体使用`form_curve.mjs`生成封口的厚曲面，表面、控制及作用取样保留同一纵向参数。浪背抬升、卷唇前倾、下落和铺开的控制姿态由目标曲线导出；它使用已有Animate执行，不增加整招运行类。当前是局部浪体资源，尚未完成真实积水、分流、地面承接和完整结束过程，2.07及对应流派制作继续保留。

表面点可指定最多四项命名控制权重，加载时解析为索引，运行使用与顶点相同的加权位置。挂点的朝向也读取混合控制，但重新建立正交朝向，避免骨架混合将附着的刚性器物压短或剪斜。未指定混合时仍使用明确的单控制或所属刚性部件控制。

制作动作支持Markers阶段表，导出器把阶段时点也加入姿态关键点。构造可用ActiveFromMarker、ActiveUntilMarker绑定真实有效窗口，开始时点加上阶段内部时间除以动作速度得到共同世界时点；已明确阶段优先于数字有效时点。缺少动作、未知阶段、结束早于开始及越过施放总时长在编译时报告。数字有效时点继续原有语义，正式世界存档仍为版本1。

水和冰的发布网格通过附加通道保留局部厚度及泡沫覆盖，蒙皮和整体尺寸同时调整表面厚度。水面根据厚薄选择透光与深色层次，冰面保留厚处朦胧、薄处透光的区别。环向接缝使用一致法向与连续扰动，表面坐标跟随形体变形；泡沫覆盖不会增加实际作用范围。当前厚度是制作阶段的局部近似，并非逐像素测量完整光程，尚未实现真实场景折射，最终材质质量继续按2.09验收。

## 资源说明

| 资源 | 制作要求与本轮用途 |
|---|---|
| 水鲸 | 鲸首、腹部、尾柄、成对胸鳍和水平尾鳍有清楚连接；连续脊柱、胸鳍与尾部控制；验证同一姿态驱动网格、挂点和作用区 |
| 翻卷浪体 | 封口厚曲面、七个连续控制、抬升／卷唇／下落／铺开阶段；29条实际作用取样与表面使用相同权重 |
| 权重与动作资料 | 每顶点四项权重，局部姿态和绑定逆矩阵；制作与导入后的数值对照 |
| 表面 | 局部表面坐标、厚度及泡沫覆盖；水、冰等显示可覆盖，实际材料仍由构造独立指定 |
| 边界对照 | 骨架控制范围、真实胶囊及显示姿态的数值与实机检查；调试形状仅用于开发 |
