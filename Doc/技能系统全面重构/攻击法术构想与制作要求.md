# 攻击法术构想与制作要求

**状态：用户已认可这批攻击构想的方向，尚未实现。** 本页记录攻击意象，作为[生成式法术构造方案](生成式法术构造方案.md)的检验用例，不是十三套独立写死的技能。具体强度、代价和制作批次继续随设计收敛，名称不代表无条件必杀。

## 共同设计要求

每招先明确“显化什么、怎样成形、怎样攻击、如何伤敌、结束留下些什么”。 可执行的制作阶段、实际作用与收尾见[技能制作清单](技能制作清单.md#十三项攻击样板)。具体攻击设计用于检验和调整框架；现有几何、动画和判定类别不能成为设计上限。

- 主体有独立轮廓、厚度、材质和内部结构，常用视距下可以辨认。
- 成形、蓄势、运动、接触和收尾有连续关系；近身小术与城域神通各有适合自己的节奏。
- 攻击中的有效部位与时点明确，画面里的托举、压落、冻结、裂击和侵蚀都对应真实作用。
- 近景有材质与动作，中景看得清攻击结构，远景能读懂整体异象和传播过程。
- 原版、Worldfall 三维观察与第一人称共同验证资源细节、空间关系和实际作用。

这些是独立攻击法术的构想。自主施放、词条、跨形态改造与交锋规则沿用总方案，不能把它们编排成玩家必须使用的固定多招配方。

## 十三项攻击构想

### 寸掌葬岳：短促接触后的层层崩裂

手掌贴上敌人，最初只有衣甲轻微凹下；压缩的劲力随后层层展开，裂势越过接触处，敌人身后的地面连续翻起山脊。

动作以肩、肘、掌的短促发力为核心，接触后有短暂停势与收掌。伤敌过程区分最初掌击和随后传播，实际作用沿设定方向展开。收尾保留翻起的岩层、碎屑和受击后的失衡。

近身规模保持简练；高阶扩大的是劲力的纵深和地表响应，人物本身仍只完成一次清楚的掌击。

### 剑冢开天：残兵成剑，断片继续斩过战场

地面露出古兵残柄，整座剑冢逐渐拔起。残剑在空中汇聚、扣合成一柄断口遍布的巨剑，随后沉重斩下，外层剑片沿斩势脱落，继续切过两侧。

汇聚时能看清组成它的兵器和缝隙，斩落时有剑脊、刃面和整体重量。主剑与脱落片分别具有实际攻击阶段和运动；结束后整体解体，残片落下或按明确规则消散。

### 天炉倾海：熔流从天炉中倾泻

青铜天炉在高处显化并缓缓倾斜，赤金熔流越过炉口，拉长、分叉，坠地后沿战场奔涌。冷却边缘形成暗壳，暗壳又被内部炽流顶裂。

攻击来自倾泻、落点和后续流动。炉身、熔流、火焰与凝壳分别运动；收尾表现流势减弱、暗壳凝结及余火退去。留下的火区或凝结物是否继续有效，由对应状态决定。

### 天鲸覆城：完整水体跃起、翻身、覆压

深蓝水鲸从目标下方穿出，托起敌人和碎石。鲸身在空中翻转，腹部垂落瀑布，最后整个水体压落并撞散成奔流。

须完整表现鲸首、背脊、腹部、尾部的连接及翻身重量，表面水流随身体运动。起跃、托举、翻转、压落和奔流分别对应真实位置、高度与有效区域；收尾有水体铺开、碎沫回落和残留水域。

原版俯视与三维侧视都应读得出鲸体，不能只在制作预览中成立。

### 森罗倒生：倒悬古树以根群收拢目标

古树在敌人头顶倒悬，树冠隐入高处，粗壮根系朝大地生长。根尖先钉入地面，随后根群收紧、盘结，形成不断闭合的木质牢腹。

主根有明确的生长方向和承力结构，细根随之展开。刺入、抓持和挤压有各自实际阶段；结束时根系松脱、枯裂或留下对应的真实结构，具体后果随能力版本确定。

### 山河叩首：连片岩层俯压

周围山脊逐渐倾斜，山腹露出层叠岩层，数段山体朝目标接连俯压。每次落下都挤起新的地表褶皱，最终群山向中心合拢。

岩体保持刚性、层理和体积，重点表现抬起、翻转、接地、挤压与断裂。实际攻击跟随移动岩层和接地过程。地貌变化由地形玩法维护；短期岩体与永久地形需要分别定义。

### 霜花葬形：冻结合拢，再反向盛放

细密霜纹爬过兵器、衣甲与脚下，透明冰花从周围逐层合拢。短暂停顿后，包裹目标的冰体向外盛放，随花瓣状冰层一起崩裂。

表现由薄霜过渡到有厚度的冰层，冰面内部有纹理和裂隙。冻结与崩裂读取真实受术对象及过程；收尾表现裂片脱落、冰粉散去和残留寒气。

### 雷神凿世：云中巨神持锤凿地

云腹中逐渐露出巨神的肩背、手臂与重锤，雷霆沿躯体奔走。巨锤砸落，地面先压出下陷锤痕，随后雷霆从破开的岩层中向上喷发。

巨神需有清楚的体块和发力姿态，雷光服务于身体与锤体。锤击和地层喷发分别具有实际作用过程；结束时巨神逐部解散，云层恢复，地面留存相应痕迹。

### 影中葬身：影子反向站起，裹住本体

目标影子逐渐变深，一个与本体形态对应的黑影从地面反向站起，抱住目标向下拖拽。接触地面像黑水一样合拢，留下仍可辨认的挣扎轮廓。

关键是影身与本体的对应、反向运动和包裹过程。伤敌、限制行动及可能的拖入由实际状态驱动；目标仍存活时必须有明确去向和可见状态。结束方式区分挣脱、术式解除与目标死亡。

### 镜中碎身：倒影先裂，裂势翻到现实

古镜照出目标清楚的倒影，镜中衣甲先产生裂痕，裂痕随后逐片翻到真实目标。最终镜中映像碎开，现实中的护持与目标受到对应裂击。

镜面需要深度、目标轮廓和动作对应，裂纹有局部起点与传播。镜中过程与真实结算保持同一时序，结束时碎影退回镜内或剥落散去。双视角中的映照、遮挡和裂纹表现需尽早验证。

### 折界千重：错开的天地层层闭合

目标周围的景物如书页分层错开，天空滑到身侧，远处山体出现在脚边。层层空间随后交错闭合，处于其中的对象承受切断与挤压。

空间层需要可读的厚薄、前后关系和连续错位，保留被折叠景物的辨识度。每层的作用区、闭合过程和受影响对象明确；收尾景物重新对合，实际损坏由相应世界对象保留。

### 刹那千秋：岁月在局部急速经过

目标所在之处草木反复枯荣，兵甲逐渐锈蚀剥落，石墙风化成沙，受术者显出持续加深的衰败痕迹。

攻击的主体是各类对象真实发生的时序损耗。材料、护持、身体与建筑采用各自明确的作用规则，不能只播放一次换色。收尾区分仍存留的腐蚀、风化结果与短暂时序异象；不要求让整个游戏一起快进。

### 归墟开口：形体失序后卷入深处

天地间撕开边缘持续翻卷的深口。附近兵器、术式和岩石失去原本形状，拉长、碎解为混杂物，逐步卷入深处，目标也受到相应侵蚀与牵引。

深口有内外层次、不规则边缘和可见卷入过程。解构、牵引与最终作用分别记录真实结果；结束时开口收拢，未被彻底消解的物件与残留有明确去向。

## 对框架和制作的要求

从上述攻击中提炼实际所需能力：短促接触与后续传播、多个部件组成并解体、连续流体形变、抓持与高低运动、物质生长、真实地形过程、对象关联映照、空间错位和时序损耗。

这些需求需要具体资源、动作和玩法支持。寸掌葬岳可检验身体发力与接触传播，天鲸覆城可检验复杂动态主体与高度阶段，镜中碎身可检验关联对象与镜面表现。它们是候选用例；实际选取需与总方案的功能、城市和世界验证共同推进。

每项还需由同一套资源与操作生成结构或行为明显不同的变体，证明形体、材料、运动、变化和关联确实能够重组。至少一个变体在共用能力冻结后再提出；不能分别写出三套完整技能，就认为框架已经灵活。

十三项构想不是全部流派清单。风、阳、五相、其他法宝及妖兽攻击继续按同样标准展开。每招以独立攻击意象和完整过程为依据，再检查词条、轨迹与跨形态改造需要怎样改变它。

## 资源说明

| 法术 | 主体与材质资源 | 动作、形变与收尾资源 |
|---|---|---|
| 寸掌葬岳 | 身体与掌部、受压衣甲或护持、翻起岩层 | 肩肘掌发力、短暂停势、劲力传播、岩层翻裂与碎屑 |
| 剑冢开天 | 古兵残片、拼合巨剑、断口与金属层次 | 拔起、汇聚、扣合、斩落、逐层脱片与落地 |
| 天炉倾海 | 厚重青铜炉身、熔流、暗壳与外焰 | 炉身倾斜、分流、坠落、地表奔涌、凝壳破裂与冷却 |
| 天鲸覆城 | 完整鲸体、水面流纹、厚薄变化与碎沫 | 出水、托举、翻身、垂流、覆压、撞散与落水 |
| 森罗倒生 | 古树冠、主根、细根、木皮与承力结构 | 倒生、钉地、收紧、盘结、松脱与枯裂 |
| 山河叩首 | 分层山体、断面、岩块与地表褶皱 | 抬起、俯转、接地、挤压、断裂与残骸落稳 |
| 霜花葬形 | 霜纹、透明冰花、厚冰层与内部裂隙 | 爬霜、逐层合拢、停顿、反向盛放、碎裂与冰粉 |
| 雷神凿世 | 巨神体块、持锤手臂、重锤、雷霆与云层 | 显身、举锤、发力、下陷、地层喷发与逐部解散 |
| 影中葬身 | 对应本体的影身、地面深影与包裹表面 | 反向站起、抱持、拖拽、合拢及不同解除过程 |
| 镜中碎身 | 古镜、具有深度的映像、镜内外裂纹 | 映照、裂纹传播、裂势翻出、碎影与收束 |
| 折界千重 | 景物分层、空间断面与错位边缘 | 分层偏移、连续错动、交错闭合与重新对合 |
| 刹那千秋 | 多阶段材料老化、植被枯荣、护持与身体时序痕迹 | 衰败递进、剥落、风化、枯荣循环与异象退去 |
| 归墟开口 | 深口内外层、不规则卷边、可解构主体与混杂物 | 撕开、翻卷、形体拉伸碎解、卷入与收拢 |

以上按意象列出待制作规格；实现时应提炼共用形体、部位、材料和连续动作，供其他构造重用，不能把整招封成不可拆的资源。本页未新增模型、位图、动画或运行代码，也不以已有通用部件作为这些攻击已经完成的证据。
