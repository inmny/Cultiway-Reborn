# 连续发力与站立支撑

对应4.06，本项连续动作链路已完成，已记录并核对原版与Worldfall的实际动作。完整美术及各类战技内容继续按第9工作包制作，本项不代替最终用户验收。

## 本项动作计算

原来每段关键点单独使用起停曲线，即使手掌继续向同一方向经过中间姿态，也先减速到零再启动。现在编译时根据相邻段与实际间隔计算共同切线；同向经过姿态时保留速度，反向及平台处才停下。起势和收尾速度归零，各轴不越出关键点包络，手、躯干和转角使用同一段进度。握持旋转在创建时展开相邻的最短转角，跨过零度不会突然绕远。

`Body.ImpactRecoil`声明真实接触后的收回幅度，按体高计算；缺省为零，旧资料不会凭空新增接触反应。`RecoilSeconds`声明一次回弹的动作秒数，历时改造同时缩放它。掌击、横拍及持剑刺击已制作相应数值。第一次真实身体接触启动连续脉冲，命中当刻不跳位置，回弹结束归回原手路；落空不启动。回弹修改真实肢体姿态，握持器物和命中形状继续读取同一姿态，没有额外的显示回弹计时器。预测回退同时恢复接触时点。

共同身体姿态补入站立的左右落脚点和身体承重点。当前为站立支撑：两脚按实际体高与锁定方向定位，胸肩转体不带脚在地面旋转；承重点随本时刻躯干偏移。可创作的脚路、前进、腾起及地形支撑仍归4.15、4.18和4.19，不能拿固定站立点代替完整步法。

## 显示接入

Worldfall使用真实骨盆、两段腿及模型足底点。共同躯干偏移交给骨盆，腿段连接到共同落脚点；衣甲沿用身体自身姿态数组。该接入只读取已经发布的姿态，不修改实际人物位置，不改变施放时间或玩法作用。具体体型与高速约束继续由4.08验收。

原版身体沿用现有动画图片和原贴图坐标，将每个原三角形分为十六块。脚底保持不动，上身读取同轮共同躯干偏移，手掌与器物继续使用真实姿态；颜色、翻转、透明和场景深度仍走原有共同绘制。没有新建贴图或另设动画时钟。图片池换人及动作结束时回收临时网格，切世界清空。原来的额外整张图片倾斜反馈已移除，避免与共同变形叠加。
