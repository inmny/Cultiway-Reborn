# 6.16 交锋去重与终止

一次真实接触可同时结算主体伤害和招式写明的追加效果。追加伤害、通过映像传回的伤害和分送伤害仍照常扣血、由原施放者负责，但这些后续结果不能再次被法宝、阵法等当成新的主动攻击。反弹后的主体伤害本来就按反应结算，维持这一规则。

接触次数按原目标记账。同一个人的多个映像共享接触次数；真实反弹可改变归属，仍受原施放的总接触次数、反弹次数及寿命限制。导电按实际水路逐波确认，每波对同一目标只结算一次；取消后不补发。关联步骤只启动一次，构造中的循环依赖在编译时拒绝。

验收使用现有世界和招式素材：直接攻击及指定的追加伤害分别结算；通过实际映像或水路作用时，后续伤害不重新触发只认主动攻击的被动，每波每人一次，取消后停止。延用同一原目标的映像和多次反弹的已有实机证据，复验本次改动触及的结算路径。交付可独立运行的复验入口与结果记录。此项不增加新招式、资源或存档字段。

## 实机验收

- 直接接触的主体按主动伤害结算一次。17点追加和7点分送都保留；路径外的旁人只承受一次7点分送。回调确认这几笔派生伤害均为后续反应。这与法宝反射被动读取的是同一类别，本轮没有另配一面法宝。
- 同一原人物的两个映像各发生真实交锋，只向原人物传伤一次，保留施放者归属。用户可设置的接触频率仍生效，没有把合法后续波次一并去掉。
- 原版水路两波分别作用两个实际目标，每波各结算主体和追加，逐人去重。取消后没有补发，也没有多扣血；重新施放从第一波开始。首次验证还纳入了其他场景留下的人物，因其中一波未扣血而失败；移出无关人物后单独复验水路。两段分别通过，均保留实际受击记录。

沿用[实际反射](实施记录.md#实际反射验证)中三次往返、第四次吸收及屏障重叠终止的证据；事件依赖与步骤依赖的循环拒绝分别见[事件驱动的运动变化](事件驱动的运动变化.md)和[操作输出绑定](操作输出绑定.md)。本次未改变这些限制及收尾规则。按既定顺序继续 6.17。
