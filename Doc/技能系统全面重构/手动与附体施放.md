# 手动、附体与第一人称施放

## 10.14 分批结束条件

- A1 原版附体。共同动作持有站姿期间，原版走动、跳跃、冲刺和后撤不能接管同一个角色的移动。动作交还站姿后恢复原控制。只占手臂等局部部位时照常走动。复用同一世界、人物和真实站姿动作，从原版动作按钮和附体更新验证失败、结束归还和再次操作。交付可复验脚本和实际过程。
- A2 第一人称。使用现有 Worldfall 实例验证附体输入、相机与真实身体位置。优先复用已安装的共同移动拦截，实际发现绕过时再修。退出附体或换人物后只归还原对象的控制。
- B 手动施放。能力栏、落点和第一人称目标使用同一实际能力版本。改版后核对费用、作用范围、描述及输入选择，拒绝无效目标和已经失效的准备。
- C 交付。在正式操作入口集中录制两种视角，整理受影响的存读与结束验证，再按完整 10.14 合并。

## 原版输入路径

附体状态每轮会处理移动方向、攻击和附加动作。平滑位移已有占用检查。进入平滑位移前，附体状态还会写入下一步位置和移动标志。跳跃、冲刺与后撤使用自身的原版入口。复验从真实附体输入进入状态更新，检查整个角色结果。

在旧版规则中，从原版跳跃按钮进入附体更新后，持有掌击站姿的人物在约 0.12 个世界秒内离地 0.57 格，站姿同时中断。桌面环境未能将键盘事件稳定送入独立窗口，已用原版游戏内动作按钮复现到相同处理入口。

A1 已通过原版实机。站姿在同一人物的走动、跳跃、冲刺和后撤输入中保持，三次跳闪均无位移和离地。掌击结束后沿同一方向恢复走动，只占右臂的同源动作也可边走边继续。走动从原版热键状态送入方向，跳闪用原版动作按钮。桌面版未启用触屏部件，复验在每次检查后复位其按钮输入，避免前一个按钮持续按下。基线和完整复验入口为 `Scripts/SpellDemos/verify_possession_stance.py`。

## 手动施放的当前规则

原版俯视沿地面光标选取，Worldfall 第一人称沿准星的实际选取对象和落点施放。第一人称不从俯视光标或身后补选目标。人物目标需满足能力所声明的关系和距离，地点能力显示同一个受理落点。

按下施放键时记住当前附体人物、能力来源和实际编译结果。按住时，以这份结果展示选择距离和作用区域。松键时先检查这份准备是否仍有效。换人物、换世界、换到另一项能力或同一构造重新编译后，原准备取消，新的选择从下一次按键开始。只扣正式受理的一次费用。以同一能力的两个实际版本核对预览、受理和余额，另查一个无效或过期的选择。
