# 部位作用形状与持续区域（6.02）

本项结束条件：一个构造的部位能单独声明有限厚度的薄体、体块、扇形、路径带或持续区域，也能把几种形状组合起来。接触以形状本身为准；包围框只用来找候选。实际位置随部位的移动、旋转和变化更新，空隙仍然可躲。区域尚未开始或已经结束时不结算；同目标同时接触同一作用组的多个形状，按原有命中和间隔规则结算一次。形状接入现有的接触、阻挡和反馈入口；显示和判定都能读取同一时刻的形状。

旧资料缺少新声明时继续按原来的胶囊处理，有限水层继续使用真实水深。保留现有形体编号和已存招式的含义。此项交付的是形状和作用时段；高速转向的专项验证留在 6.03，画面逐项对照与尺度误差验收留在 6.18 和 6.19。流派美术、万法阁编辑和自主创法按后续编号接入。

| 本地批次 | 要改变的行为 | 必要验证 |
| --- | --- | --- |
| A：薄体、体块 | 用同一套可随部位转动的有厚度形状接入薄面和厚块；保留已用胶囊及水层形状。 | 同一目标命中面内，越过薄边或高度时无伤；旋转后，命中范围跟着部位转。厚块内仍可接触。另用同一防御形状核对一次拦截。 |
| B：扇形、路径带 | 扇形保留开角、外沿和厚度；路径由有限的相连段组成，弯折的内侧空隙与未启用的段不参与作用。路径区域表示可作用的带状范围，单次移动的经过范围仍由扫掠决定。 | 一个扇面和一段弯路径：内侧命中，角外与转弯空隙无伤；该段启用后能重新命中，切换形状时不沿新旧边界凭空扫过。 |
| C：持续与复合区域 | 部位在声明的时段持续提供作用；多个形状保持各自位置和身份，通过现有作用组共同结算。 | 目标进入、留在重叠处、离开再进入；按声明的间隔或再次进入规则结算，结束后不再结算。保存并读回同一复合声明，再次施放；用原版与 Worldfall 复用同一场景核对实际位置和恢复。 |

各批只复用一个已有测试世界和同一普通目标。子批可单独提交到开发分支；三批通过后合齐资料、复验入口和证据，才勾选 6.02 并合并到 `codex/dev`。

### A．薄板与厚块的制作资料

在形体的 `Contacts` 中指定所属 `Part`、局部中心 `A` 和三轴半宽 `HalfExtents`，并省略胶囊的终点 `B` 和 `Radius`。三个半宽都要大于零；薄板只是某一轴更薄的同种形状。作用范围保留部位的真实位置、方向和各轴尺寸，斜放以后外框的空角不会结算。形体可用 `AControl` 或 `AInfluences` 继承已经登记的部位控制；未声明时继承所属部位的刚性控制。现有胶囊、有限水格、存档版本和正式形体文件不变。

复验使用自带明确尺寸和同尺寸模型的板形、块形试件，确认新定义可以进入正式施放与交锋，不把试件加入正式自主创法目录。这批只交付新作用形状入口；成品形体的选用、扇形、路径带与持久组合继续按本项后续批次推进。

A 在原版独立游戏分两段通过。先确认板内命中、薄边外和斜放空角无伤、离地越过、厚块内部受击，以及来袭物从板的正面反射。随后在同一进程补独立部位动画：板部位移动前无伤，移动后只命中一次，实际作用面与绘制部位中心同在 `y=72.9`；两段都自然结束。证据见 `/home/inmny/.local/state/cultiway-dev/evidence/part-contact-shapes-a/delivery.json`。

### B．扇形、路径带的制作资料

一个作用形状从胶囊、`HalfExtents`、`Sector` 和 `Path` 中选一种。扇形和路径带以 `A` 为原点，沿所属部位的局部 XZ 平面展开，局部 Y 是厚度方向；照常用 `AControl` 或 `AInfluences` 指定随动。扇形声明 `Radius`、开角 `Angle`、朝向 `Direction` 和 `HalfThickness`。朝向从局部正 Z 向正 X 量角，单位是度；外沿使用不超过 5 度一段的内接弧面。

路径带用 `Points` 依次列出局部 `[X, Z]`，另给 `HalfWidth`、`HalfThickness`。`Starts` 可为每段指定 0 到 1 的启用进度，缺省同时启用。网格需要分段出现时，用同一进度制作显示数据。转折处只补外侧接缝，接缝跟后段一起启用。已经存在的段继续按实际运动扫掠；新段只从出现的位置参与作用。两种形状都只在加载时拆片；保留原声明供部位、装备和存档识别。

原版独立实机同一轮通过扇形外沿内外、开角外、离地无伤，以及路径后段启用前后、弯道内侧保持空隙和自然结束。实测成形进度约 `0.322` 时只有前段，约 `0.958` 时包含前段、后段和接缝；后段只命中一次。复验入口是 `Scripts/SpellDemos/verify_part_contact_regions.py`。证据见 `/home/inmny/.local/state/cultiway-dev/evidence/part-contact-regions-b/delivery.json`。

### C．正式剑气与持续复合区域

正式剑气沿现有 V 字折刃生成带厚度的路径，两段刃身和外侧接缝随同一部位运动。构建形体后，发布脚本按原样保留薄板、扇形和路径的数据，包含段的启用进度；只使用胶囊的旧资料不需要改写。此次没改剑气的模型、资源包、编号或收费，也不需要玩家手动迁档。原来已学会的剑气仍可照常支付、命中一次并自然结束。

构造可用现有的 `ActiveFrom`、`ActiveUntil` 和 `ContactGroup` 把多个独立摆放的形状放进同一作用组。实机用两道折刃的重叠区验证：进入和留在重叠处只扣一次血；离开整个作用组再进入才会重算。间隔模式从世界时间 0.24 秒开始，每 0.16 秒结算一次，同一时点不会因重叠多扣血；1.08 秒结束作用，仍可显示收尾，随后主体自然消失。

同一份正式存档分别在原版和 Worldfall 0.9.8 的新进程读回，两项招式定义和学习记录保留，可以直接使用。实际绘制的两片刃身与当时的作用位置一致；重叠、重入和结束行为复现。原版首次读档复验的浮点比较方式、旧剑气复验的人物灵力设置各修正一次，保留失败并仅补对应段。软件渲染结果用于检查玩法与位置；最终画面验收按 6.18 单独做。
