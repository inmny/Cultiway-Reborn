# 身体挂点与刚性投影

对应1.09，仍未完成。本批只修正和验证原版身体显示的两处实际问题；Worldfall真实身体、器官、真实坡地、水面及物理跳起仍须继续，不进入后面的工作。

## 已完成的原版修正

原版人物将走动跳动、受击抖动写进精灵平面，而共同身体模型此前只读取完成的玩法姿态。两者会分开。现在每个身体绑定实例通过实际人物编号读取同一平面偏移，统一加给所属肢体、手和器物；不写回发布姿态、人物位置或实际接触。

原版精灵的纵向跳动沿平面纵轴表达，绑定模型也使用相同的平面平移。实际离地高度仍由共同姿态表达，不把这段显示偏移当作额外物理升高。独立形体没有身体归属，因此不会跟随附近人物跳动。

有地表快照时，原版此前对身体模型的每个顶点分别扣除其脚下高度，同一条刚性手臂会在坡度处被拉歪。现在身体绑定、没有动态流散面且不声明贴地变形的部件，共用已发布身体脚下的承托高度。边界与实际顶点使用同一规则，避免只修画面但仍用整幅地形范围裁剪。原有流散和贴地变形路径保留各顶点采样。

实现落在[原版形体显示](../../Source/Core/Visuals/Forms/FormNativeRenderSystem.cs)和[共用表面](../../Content/ShaderSources/FormSurface.shader)。不新增玩法分支、配置、身体格式或单招专用类。

## 实机证据

使用真实原版人物、实际装备和生产用BodyActionBinding读取已编译的掌击、持剑动作。通过生产用AppendVisuals与共用场景发布，执行实际原版显示系统及着色器，独立图形缓冲读取像素。缓冲只隔离显示，不推进世界或制造伤害。

| 检查 | 修改前 | 修改后 |
|---|---|---|
| 四个朝向的平地／坡度快照对照 | 例如一个朝向有109个像素不同，联合覆盖118个像素 | 四个朝向均0个像素不同 |
| 实际跳动与抖动后的像素平移 | 四个朝向均未跟随人物 | 四个朝向均与参考图的16×16像素平移一致 |
| 身体显示偏移与原版人物 | 肩部仍停在原位置 | 与实际人物的平面偏移相同 |
| 腕点与前臂末端 | 随人物分离 | 四个朝向重合 |
| 手内握点与真实装备握点 | 原有器物几何可重合 | 保持重合，并共同跟随身体 |
| 玩法姿态及独立形体 | 原有规则 | 发布脚下不变，独立形体不被人物带动 |

25项挂点检查通过，原版深度、透明、纹理、真实精灵遮挡及相对／绝对高度等29项回归也通过。检查没有增加伤害球、改变动作时钟或用另一段动画代替原绑定。

装备准备中实测原版刷新装备属性会清掉跳动的竖向分量；工具先完成装备，再设置本次待测姿态。没有为了通过而放宽握点标准。
