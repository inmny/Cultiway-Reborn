# 身体挂点与刚性投影

对应1.09的早期修正与实测记录。1.09已于2026-10-24收尾，最终支持范围、失败记录及后续落点以[挂点核对结论](器官挂点核对与接入缺口.md#核对结论与后续落点)为准，当前进度以[全程TODO](全程实施TODO.md)为准。下文保留各批证据，不再作为本项尚未完成的状态说明。

## 已完成的原版修正

原版人物将走动跳动、受击抖动写进精灵平面，而共同身体模型此前只读取完成的玩法姿态。两者会分开。现在每个身体绑定实例通过实际人物编号读取同一平面偏移，统一加给所属肢体、手和器物；不写回发布姿态、人物位置或实际接触。

原版精灵的纵向跳动沿平面纵轴表达，绑定模型也使用相同的平面平移。实际离地高度仍由共同姿态表达，不把这段显示偏移当作额外物理升高。独立形体没有身体归属，因此不会跟随附近人物跳动。

有地表快照时，原版此前对身体模型的每个顶点分别扣除其脚下高度，同一条刚性手臂会在坡度处被拉歪。现在身体绑定、没有动态流散面且不声明贴地变形的部件，共用已发布身体脚下的承托高度。边界与实际顶点使用同一规则，避免只修画面但仍用整幅地形范围裁剪。原有流散和贴地变形路径保留各顶点采样。

实现落在[原版形体显示](../../Source/Core/Visuals/Forms/FormNativeRenderSystem.cs)和[共用表面](../../Content/ShaderSources/FormSurface.shader)。不新增玩法分支、配置、身体格式或单招专用类。

## Worldfall真实肩腕与连续施放

正式掌击中测到，原来的共同肩点比一个实际三维人物的肩点低约0.17地图单位，约为共同体高的五分之一。Worldfall的人物比例、朝向及闲坐都有自己的处理，隐藏原手臂不能自动保证新的手臂接合。

现为已发布的上臂、前臂和手掌补入左右归属。Worldfall使用自己的完整关节变换取得真实肩点，再连接到共同腕点；两段显示肢体按动作的长度比例和弯肘方向适配。三维接合不把肩点偏差加给手掌、器物或攻击位置。原版仍读取共同肢段。此处只接入当前确实存在的手臂，不算2.04通用身体说明或全部战技部位已经完成。

近景复查发现，只有接合检查通过仍不足够：原共用袖臂和手掌太粗，王国色与固定肤色也不对应三维人物。现于共同绑定缩小袖臂及掌部比例，掌面接触与握持同时读取新的手矩阵；Worldfall从实际人物颜色槽取得袖色和肤色，独立器物保留原材质。检查还直接比较显示宽度与原身体部件宽度，不以配置中的比例常量互相对照来证明合理。

同时修正共同动作左右轴的反向计算，正侧方表示身体右方，并在共同姿态中明确保存出手前方。Worldfall在正式动作期间使用该朝向和转体，解除该人物的闲坐；独立人物卡片不参与世界手臂接管或肩点采集。普通三维仍负责其余身体和穿着。

连续施放还暴露出原版当前倾角没有同步的问题：三维隐藏原版精灵后，结束只清零目标倾角，下一次出手仍会被旧当前倾角拒绝。现于解除身体控制时调用原版姿态同步，正常收势和中断走同一入口。

实现见[身体三维适配](../../Source/Content/Compatibility/Worldfall/BodyWorldfallRenderer.cs)、[共同身体姿态](../../Source/Core/Skills/BodyMotion.cs)和[施放结束](../../Source/Content/Skills/ConstructedAbilityService.cs)。显示肘点及肢长可随身体比例调整；本轮实际作用部位是掌面和器物，没有把显示适配扩称为前臂独立命中已经实现。

实机从正式学习和施放入口执行右掌、持剑刺击、左掌资料改造，覆盖四向平地、真实丘陵坡度、水中及原版受力腾起，共21次施放、63个姿态、809项检查通过。检查实际提交的显示矩阵与外部骨架，不以调用适配函数自身作为通过依据；同时核对左右、身体朝向、真实腕点、掌内握点、器物握点、实际配色、部件宽度、原手臂隐藏及结束释放。闲坐由外部原入口准备，再检查正式首招解除它。受力腾起通过原版addForce和实际高度推进，未手填离地高度当作跳跃通过。

## 衣甲跟随

初测一套真实铁甲时，甲片肘点与共用手臂相差约0.14地图单位，腕点相差约0.23。甲片还在使用原手臂动作，只隐藏身体的旧手臂不能让甲片随动。

Worldfall衣甲与身体原本共用姿态数组。现继续使用这些数组与原甲片模型，只将本次接管的上臂、前臂变换对应到实际提交的肩、肘、腕；先保存两段各自的原姿态，避免伸长上臂时再次放大弯曲前臂的厚度。取点调用在接入时绑定，逐帧不重建甲片几何，不把外部骨架对象传入玩法计算或存档。

皮甲、铁甲、精金甲分别配合不同材质头盔和靴子，验证右掌、持剑与左掌、四个朝向和两个动作时点，共36次正式出手、72个姿态。另验证同一人物卸甲后正式出手与释放，以及两个实际外部骨架副本的伸长弯肘截面，共651项检查通过。实际甲片肩肘腕最坏误差约0.000023地图单位，头盔与靴子仍连接原身体，正常收势恢复原显示规则。

同一实际加载版本的无甲回归809项、63个姿态通过；没有把651项衣甲检查与原有身体检查混成一种覆盖范围。
