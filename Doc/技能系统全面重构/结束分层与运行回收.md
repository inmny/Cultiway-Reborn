## 本项改动

动作事实发布前先检查实际身体过程是否结束，已经完成或中断便归还本次身体凭据。订阅者收到结束事实时能够看到已释放的占用，不必再等整次施放和其他独立主体结束；解除过程不删除原人物或器物。

受力记录改用稳定人物编号和弱引用维护，仍只有一份运动事实。主线程按实际活动运动采集地表范围，移除已经落地、失效或被外部接管的记录；人物更新只访问自己的数值轨迹。即使全部施放已经结束，仍在运动的目标继续收到新地表，运动结束后停止采集。不扫描全体人物、不延长旧施放，也不从人物更新线程访问Worldfall采样器。

世界材料、原版天气、地形和蒸散原来已有各自的维护者。本项实测其移交与结束，没有再加一套统一计时、回收或保存系统。

## 各自的维护者

| 内容 | 维护及结束 |
|---|---|
| 身体与握持 | 本次身体凭据，动作完成或中断即解除，原人物和物品继续由原玩法维护 |
| 临时形体 | 本次施放按寿命、损耗、接触和取消结束，清理自身运行与未用额度 |
| 已确认的受力 | 人物自身的运动记录，施放结束不提前拉回地面或停止运动 |
| 已转交的世界材料 | `WorldMaterialService`独立维护，按自身期限、回收或世界切换结束 |
| 原版天气 | 原版云推进，模组只保存实际身份和当前状态，不能随短施放一起删掉 |
| 永久结果 | 原版世界或对应玩法保存，取消原施放不回滚已经确认的改变 |
| 无害蒸散 | 真实反应后的短暂显示，不产生伤害、阻挡、供能或条件作用 |

## 验证结果

独立游戏197921由NML加载当前代码，共182项通过：

| 专项 | 项数 | 实际范围 |
|---|---:|---|
| verify_cast_cleanup | 29 | 完成通知前解除身体、短施放后的实际受力、停止无用采集、材料到期及额度释放、来源死亡后的移交材料、水火蒸散期限、真实地形和天气、正式保存恢复及换世界 |
| verify_source_loss | 27 | 各类来源失效和独立存续回归 |
| verify_actor_impulses | 79 | 原有受力、平坡地、不同更新频率与正常、五倍速度 |
| verify_action_events | 47 | 共同阶段与单次事实、身体、模型标记及中断回归 |

第一轮在旧代码中复现：身体完成通知内仍读到占用；没有施放后地表采集次数停在2。修正后，同一完成检查读到已释放，受力期间采集次数从9增加到21；运动落地后不再增加。测试没有延长短施放的0.12秒寿命，也没有提前结束目标运动。

材料专项先经正式入口移交并建立真实空间筛选，再验证0.4秒期限到达后只有一次结束通知、记录与筛选引用清空、未用额度归零。持续材料在来源死亡及原施放结束后仍存在。两份真实水火主体接触后蒸散正体积，0.15秒施放结束后只剩无害反馈，之后按自身0.9秒期限消失，不保留身体占用。

永久结果经正式世界原理实际抬升地形；天气原理生成一朵2秒原版雨云。短施放结束后，材料、已改变地形及雨云继续存在；正式存读档恢复这三类事实，不恢复旧瞬时施放。继续推进后雨云自行消散，持续材料及地形保留，切到另一个世界时旧记录、天气、蒸散全部清空。首次场景把人物身体高度作为地点高度，导致世界作用面没有触地；已将地点输入改为真实地面零离地高度，未扩大作用形状或放宽接触要求。
