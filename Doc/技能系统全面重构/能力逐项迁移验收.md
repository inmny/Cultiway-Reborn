# 能力逐项迁移验收

## 10.16 结束条件

- 对照第 0 章冻结的登记、旧索引、主动来源及实际过程，核对当前游戏真正提供的入口。改名、被替换、内部执行及无独立施放的记录保留可追踪关系。
- 每项有效能力都能追溯到当前实现、真实作用和正式存读证据。源技能保存属于原持有者时，引用该持有者的正式恢复和再次使用。各自的原受理、支付和结束仍由原玩法掌握。
- 逐批归档已具备的证据，补上真正缺失或受新改动影响的行为。既有影像继续作为功能证据，最终美术、性能及用户验收按各自条目执行。
- 交付第 0 章原编号与当前能力的对应关系、逐项证据和确实保留的例外。全部批次和必要复验完成后，合并 10.16。

## 实施顺序

1. 基础法术与旧变体。用当前游戏登记、旧索引和 10.01 正式档的实际复验结果核对能使用的全部旧术。新旧资料与实际记录缺一项就列出具体编号。
2. 修炼专属、战技及御器。按已学、原主来源、器物与派生关系核对真实作用与保存。
3. 法宝、消耗物、器官及妖丹。核对原件、持有者、能力及撤下后的失效，按原能力说明保存归属。
4. 元神、天劫、状态、丹药、宗门设施及旧功能法术。核对各自正式入口、长期结果和保存关系。
5. 对照第 0 章余项。处理当前登记比冻结清单新增、合并或删除的记录，关闭仍对应到有效能力的缺口。

## 基础法术与旧变体

当前游戏从原编号提供全部 67 种基础法术，学习入口和每招的旧索引数与冻结清单一致。原版与 Worldfall 的原始报告分别确认每个旧索引确实从共同执行发起。真实敌我、作用范围、接触和地块结果以[基础法术分组实测](基础法术及旧变体迁移.md)为准。旧档校验值与交付时相同，实际跨进程冷读的 127 个索引逐项吻合。制作表同步补录原来空白的 67 条登记，保留原先已填写的旧变体结果。

复验分两步。先在独立游戏里读取当前登记，再离线核对原录像报告和正式存读结果。两个命令分别使用同一次导出的清单：

```bash
dev.py exec --timeout 105 -- python3 Scripts/SpellDemos/demo_all.py --inventory --output 当前登记目录
python3 Scripts/SpellDemos/verify_base_spell_evidence.py --inventory 当前登记目录/inventory.json --delivery 10.01实机交付目录/delivery.json --output 逐项复验结果.json
```

本机索引为 `~/.local/state/cultiway-dev/evidence/ability-audit-1016/base-spells/delivery.json`，包含每个旧索引的双视角原始报告、对应作用记录及正式档。功能术在 10.13 修改发射后有[另行取得的复验](旧功能法术的共同执行接入.md)。本轮直接读取当前登记，并复用已有的实际施放和冷读记录。原登记导出中的“待实施”仍是旧清单标注，共同执行以实际日志中的发射记录为依据。

这一批也发现原煞风劫心和旧风波两个技能登记已从当前清单移除。它们的替代入口及正式恢复证据留在对应的天劫批次核实。当前导出来自刚完成实测的独立世界，含测试用的暂停状态，正式能力对照会排除该状态。

## 修炼专属、战技及御器

- 修炼专属的原子、效果族和内部派生逐项对应当前登记，原授予条件、等级和事件来源可回查。[修炼来源与实测索引](修炼来源与实测索引.md)关联七种主动和二十八种派生的真实结果。共同的保存恢复使用金丹、元婴、化神三名代表人物，三个境界均有读取后的实际生效记录。
- 精元回生原先把每小段不足一点的恢复都记为一点，实机损失 90 点、储备约 36 点时，错误返还了 90 点。现在根据剩余储备的整数变化兑现实际生命。三秒等待内未恢复，写档前实际到账 6 点。沿用同一份中途正式档，恢复后共到账 36 点，储备耗尽后停止。首次读回后的取样还算进了月度回血，保留该记录，在同一份未改动的正式档只补受到影响的尾段。灵渊储备沿游戏实际地块蓄积约 1.918 真元，主真元降到不足后原量返还，随后停止。首次整体余额采样还包含环境回气，复验按资金来源分别记载。
- 原地掌击的身体入口和共同构造仍指向同一招，沿用[原掌击、跨形态和正式冷读记录](旧战技迁移.md#追踪飞掌与跨进程读档)。九项骑士战技经原流派入口正式学习，写入同一世界，换世界加载后逐项核对各自的执行编号、人物等级和原流派，恢复没有丢弃资料。实际出手继续使用[原十招的双视角连贯实录及玩法证据](旧战技迁移.md#整项交付)。迁移前的枪骑正式档另有独立进程的恢复和再次施展记录。
- 普通御器和飞剑、剑阵及其单刃沿原器物或原法宝能力运行。[逐项实机与存读](御器飞剑与投射物迁移.md#整项验收范围)记录原持有者、真实装备、实际费用、命中、回收及原件再次使用。长期资料保存在原人物及器物上，写档时还在飞行的临时箭、单刃和占用根据共用规则退出。

以本页基础法术命令导出的当前登记为准。本机索引 `~/.local/state/cultiway-dev/evidence/ability-audit-1016/formation-martial-weapon/delivery.json` 保存逐项对应关系、原档、受影响部分的复验和原失败。
