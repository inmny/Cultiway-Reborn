# 高速运动与转动的连续接触（6.03）

结束条件：高速经过的人物、攻击及防御形状按同一时间段的真实姿态找首次接触。剑刃和飞掌即使在一步内越过人物也能命中；快速转向时，刃尖经过的弧面能命中，弧内的空隙不能因为首尾连线而受击。出现、瞬移及仅在新位置接触仍保留各自断点，不把不曾经过的空间算作攻击。保留按接触时点确认、实际费用及命中次数的原规则。

| 本地批次 | 游戏行为与必要验证 |
| --- | --- |
| A：高速直飞 | 用现有折刃、飞掌形体及普通施放入口，确认前后形体已越过受击边界，途中只扣一次血。另选一个高度错开或偏离的对照，确认无伤、自然结束及可再施放。优先复用现有直线接触，不为高速平移另加机制。 |
| B：快速转向 | 先固定纯数值反例：固定轴的薄刃外端转弯，弧上有接触、弧内有空隙。修正影响候选范围、接触时点和作用面的共用路径，再用同一受击者实机核对。已有拐点和瞬移规则只验证与本次改动紧邻的断点。 |

各批复用已有世界和同一个普通受击者。交付实际输入和结果、可复验命令与文档。两批合齐才关闭 6.03，并合并及推送至 `codex/dev`。美术及整体性能仍在原定条目验收。

### A．高速直飞已验证

正式入口施放现有折刃与飞掌形体。速度为每世界秒 780 格，最长模拟步走 13 格，前后形体分处同一狼的受击边界两侧。折刃在约 0.00575 秒、飞掌在约 0.00782 秒实际命中，各扣血一次，两次按输入费用支付并自然结束。把同一个目标移开三格时飞掌无伤，结束后用同一招再次施放仍能命中。现有直线扫掠已能处理，无需另加高速直飞机制。

首轮攻击者未完成属性初始化，记录到实际接触但没有扣血。复用同一夹具初始化流程后，折刃和飞掌分别验证通过。原始失败、两段成功及快速转向的修前对照见 `/home/inmny/.local/state/cultiway-dev/evidence/high-speed-contacts-a/delivery.json`。

### B．已复现的转向缺口

在同一采样入口用真实旋转姿态做参考：一步仅转六度，长刃及长轴外沿已能越过首尾包围范围，两种形状都漏判；较大转角还会使首尾连线扫进实际没有经过的内侧空隙。修正前的结果收在 A 的证据索引中。后续修正在同一对照和实际施放验证。

### B．按同一转动姿态计算

薄体和胶囊保留实际部位的转心及朝向。每步先移动转心，再把局部形变放回同步转过的坐标。找候选时根据转角和端点离转轴的距离留出弧面余量；确认时仍按同一时刻的形体求距离。切取剩余路径、对三角面查询和计算接触处速度共用这一姿态。无转角的胶囊继续走原来的直移和补算路径。

连续转动和立即改向经过的空间不同。定时立即改向复用间隔转移的断点：改向前保留已经实际经过的一段，改向后只检查新姿态。间隔转移也仍只在真实落点发生新接触。两种断点都没有把空隙变成伤害区。未增加招式、设置项或存档字段。

独立数值参考确认，转六度时薄刃外沿和胶囊长轴都能命中原来漏掉的位置，内弦空隙不再误判。正式实机用每世界秒 7200 度的折刃在 0.00560 秒命中，静止姿态参考为 0.00561 秒；环内空隙在转过一整周后仍无伤。相同受击者验证两种断点：中途无伤，真实落点或新角度均在 0.04 秒命中一次。验证使用原版独立游戏，不代替 6.18 的画面对照或性能验收。

换用新判定后重新验证高速直飞、偏开和再次施放，行为保持。纯数值的直移及候选筛选也通过；实机准备时漏采剑气绑定姿态、旧脚本误用空间索引无参构造的失败都保留，分别修正测试后补齐。A、B 全部关闭，6.03 完成，证据索引见 `/home/inmny/.local/state/cultiway-dev/evidence/high-speed-contacts-b/delivery.json`。
