# 9.27 寸掌葬岳

这项的结束条件：真实掌击、方向传播、分层岩脊和收尾都完成，至少有一份用相同规则重组的结构变体。原版和 Worldfall 各录一段连续常速实机画面。全部通过才勾选 9.27 并合并到 `codex/dev`。

| 分段 | 玩法和画面 | 必要验证 |
| --- | --- | --- |
| A · 掌击与传力 | 基于现有掌击。肩肘带掌短促发力，确认掌面命中时才从真实触点出发，沿当时方向把劲力传到目标身后。掌击和后段各有时点，首个目标不会只因身处起点而重复承伤。 | 复用一个人形和现成平地：首击先到，后方两处按路程到达，侧面和入口外不受击；空掌没有后段。收掌归还控制，传播独立结束，之后可再次施放。 |
| B · 岩层与回落 | 接触姿态在受击面略停再收掌；岩片随着真正到达的前沿依次翻开，厚度、方向、推压与画面对应。受断路限制时前沿和岩面同时停下。成块岩片回落，碎片只表现已经翻裂的位置，不额外扩大伤害。 | 复用同一场地做一次断路和一次完整回落；比较有效前沿、实际受击和画面，确认结束后没有残留碰撞。地表在这招只产生短时翻起，由原地面负责恢复。 |
| C · 重组与交付 | 从通用动作、触点和传播规则构成可编辑原招。共用规则冻结后，再做一份改变后段结构的变体；不能只换颜色或范围。 | 原招与变体各用正式入口跑一次；核对原资料保留及同一世界重开后的可编辑性。只在整项交付录两种视角，并把原构造、变体、复验和影片编入索引。 |

优先复用「掌触凝枝」的命中启动和已有地表传播；只有现有规则无法保持真实触点、发力方向或作用与画面同步时，才改共同接口。永久地貌、其他体型和武器样本、城市档扩大分别留在后续条目。
