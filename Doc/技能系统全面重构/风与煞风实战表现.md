# 9.19 风与煞风实战表现

先验收小规模风场和实际煞风劫。9.40 再验收城域风槽、不同来源和跨形态改造；本项不把规模放大当成质感达标，也不重复跑已通过的全套天劫存读。

- [x] A 挟砂风垒：低处风面画出有效范围，内外宽面分别卷动，能看到空隙和旋向。风体按实际中心推进，内侧牵引人物，外侧无作用；停止后余风散掉。用已登记、未被持有的地面原物作携物验收：能卷起有限物件、沿卷动方向移动，失风后带着余速落地，原编号、耐久和拾取能力不变。空地不能冒出假砂叶；只改能被卷起的原物，不能从人物手里偷装备。附一份走现有传承和学习入口的构造资料。旧龙卷的命中芯、费用和轨迹不因换外观改变。
- [x] B 赑风：真实煞风劫的中央风柱与来袭风股用两套有缝隙的暗色剪切层，保留原环境来源、劫心、接触范围和伤害结算；命中前看不到贴身侵蚀，打完自然退出。可独立学习的「赑风削甲」另走既有装备侵蚀规则，实际接触后反复损耗，贴身余痕只来自已经提交的耐久变化，范围外不掉耐久。验证正常命中、空落或未触到装备，以及结束后效果清除。

## 实机结果

- 挟砂风垒的风心从 `(67.08, 72.00)` 移到 `(67.80, 72.00)`，高度保持不变。圈内人物被拉向风心，圈外人物原地不动，风压没有造成接触伤害。实测用原兵器：风起时离地并沿卷动移动，风停后同一件兵器落稳、耐久不变，两种视角录制后均成功拾回。旧龙卷的 30 段接触形状、方向和挂点保持原样。
- 赑风削甲每次实扣 8 法力。分段核对时，同一件护甲从 100 掉到 98、再到 96；拉出有效范围后停在 96，再次施放全程落空也无余痕。完整常速录像里两种视角的护甲都从 100 掉到 88。原煞风劫从正式入口产生风柱和无主风股，只命中渡劫者；从原结束入口撤除后，风柱、风股与贴身余痕均已清除。
- 独立实机分段核对；初次拾取失败用的是未按人物比例缩放的测试轮廓，已在两段录像中用实际持物表面补验。原版和 Worldfall 的各两段常速原片、运行结果与构建记录统一索引在 `~/.local/state/cultiway-dev/evidence/wind-combat-919/delivery.json`。未修改存档区段版本，不需要手动迁移。
