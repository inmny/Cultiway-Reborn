# 9.21 阴与影实战表现

本项结束条件：阴流和立影都能从蓄起看到退场；画面能指出发生了什么、作用在哪个对象上、存活人物最后在哪。复用已有小场景和人物，不扩大测试样本。

- [x] 「玄阴汲流」：改进阴域厚度、卷入和收束。旧阴域保留接触面、动作与结算。新增可学构造，持续接触时在受术者余量和收受者空位内实际转移灵气；每次确认转移后才显示裹住受术者、流向收受者的阴质。验证两边余额、离场停止、一次被防住的接触或已满拒绝、来源中断和自然退场。
- [x] 「潜影牵身」：用人物实有的身体部位做映照，让脚下的薄影抬起，再沿地收回。只有对应关系和接触成立时才牵引或短暂限制原人物；联系断开后不再施加，存活人物在当时合法落点恢复行动。验证一个有效牵引与退出、一次断开，以及正常退场。
- [x] 交付两招各两段原版与 Worldfall 的常速录像、构建记录、可复验脚本、对应资源和规则实测记录。所有条件满足后关闭 9.21，再合并推送。

影中关押、营救以及死亡分支留给 9.35；厚镜及裂纹传递留给 9.36。本项不替换旧阴阵的玩法，也不另建人物副本或灵气账户。

可在万法阁导入[玄阴汲流](构造输入/玄阴汲流.json)和[潜影牵身](构造输入/潜影牵身.json)。`WakanTransfer` 是每次接触可归给当前施术者的灵气上限，计入构造报价；不声明该项的旧招仍按原方式结算。`OriginalContactOnly` 可以把主动接触限定到仍有效的原身；`ShowBody` 让实际推拉或行动限制出现后显示原身部位。立影只取形，不加入受击、占位或存档，接触与牵引继续使用构造原有的规则。

实机核对了来源与受术者的实际入账。汲流前两次共转移 8 点；离开、收受者已满或来源失效后没有再扣账。受术者只剩 1.5 点时，另一端也实际只收 1.5 点。两段常速录像各录到 16 点转移，并保留实际修炼与法术入账的分开记录。

潜影在真实接触后才出现并随原身移动。原人物在作用时段内从横坐标 69 拉到约 66.53，生命未被该术扣除，相邻人物不被牵引。到期和施术者死亡两种退出都没有留下行动限制。初版影身在两个视角中太像竖线，调整了离身方向、投影宽度和暗色层次，只重录这两段。

构建通过，旧阴域接触面、挂点、原动作和控制位置一致。这次不需要手动迁移存档。四段原片、复验结果、三平台资源校验与初版失败记录见 `~/.local/state/cultiway-dev/evidence/yin-and-shadow-921/delivery.json`。本项使用独立游戏和软件渲染，未作性能验收。
