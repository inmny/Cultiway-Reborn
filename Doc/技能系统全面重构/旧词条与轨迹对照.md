# 旧词条与轨迹对照（8.01）

本项的交付是一份能查到每个旧编号的对照。范围包括本模组登记的玩家选项、后台词条、隐藏及停用轨迹、法宝和兵器专用轨迹。逐项写明应保留的游戏行为、新构造的落点，以及何时能退掉旧入口。验收对照实际游戏登记，无遗漏和重号；不为这份资料重跑已验证的施放，也不在本项切换旧档或删除登记。

**保留**表示保留玩家可感知的原意，换用新资料也算保留。**改写**表示拆成通用部位、步骤、条件或费用；旧来源要按原值转换，不能拿新编辑器默认值替换。**移除**表示不进入新构造的独立选项，旧编号何时退役仍按迁移验收决定。表内“基础转换”指已经有的原逐发执行转换，只对受理的来源和参数组合成立；它不等于旧蓝图、学习关系及前后版本已经自动升级。

词条登记来自[玩法词条](../../Source/Content/SkillModifiers.cs)、[辅助词条](../../Source/Content/SkillModifiers.Support.cs)、[功能词条](../../Source/Content/SkillModifiers.Utility.cs)和[共用词条](../../Source/Core/SkillLibV3/SkillModifierLibrary.cs)。轨迹来自[普通轨迹](../../Source/Content/SkillTrajectories.cs)、[法宝轨迹](../../Source/Content/Artifacts/ArtifactSkillTrajectories.cs)和[真实兵器轨迹](../../Source/Content/Combat/EquippedWeaponTrajectories.cs)。下表编号与旧登记一致。

| `Cultiway.Huge` 巨大 | 保留 | 部位尺寸同时改变形体和共享作用面；若原词条另影响接触分送、吸引等半径，保留各自的数值换算。既不凭尺寸增加选敌距离，也不修改身体本身大小。 |

| `Cultiway.Combo` 合击 | 改写 | 保留重复选主目标的倾向、原出手步数、各发时点和单发倍率，用同一招式的分批显现表达。 |
| `Cultiway.SalvoCount` 连续施法倾向 | 移除 | 旧登记停用且菜单隐藏，仍可能存在于旧资料。保留它对重复选主目标、出手步数及旧费用的影响。单次地块来源的明确设值可参与计算步数；退役后不保留独立倾向开关。 |
| `Cultiway.BurstCount` 分散施法倾向 | 移除 | 同为遗留输入。保留它对分散选目标、搜索半径、地块来源步数及旧费用的影响，再移除独立开关；原值不是固定散射数。 |
| `Cultiway.SkillModifier.PlaceholderAggregator` 附魔占位 | 移除 | 旧汇总容器没有独立作用。已落实到实际组件的附魔按各自资料转换；只留编号而欠缺必要旧数据时报告受影响部分，不凭编号猜等级、重复附加或重新抽取。 |

## 接触与控制词条

原来源经识别后由[接触转换](../../Source/Content/Skills/ContactEffectMigration.cs)展开；其它来源仍要通过第10工作包的真实接入。作用挂在实际接触部位上：零伤害的弹体带着落地爆发时，不会在飞行中提前发放后段作用。

| 旧编号 | 决定 | 新构造中的对应与迁移边界 |
|---|---|---|
| `Cultiway.Slow` 减速 | 保留 | 接触附加减速状态，保留持续时间、速度降低比例和原叠加规则；不是减慢招式自身。 |
| `Cultiway.Burn` 灼烧 | 保留 | 接触附加火性周期伤害。旧总量按持续时间换成每秒量，同类刷新，保留原来源。 |
| `Cultiway.Freeze` 冰冻 | 保留 | 接触附加原冻结状态及时长；不会因此把地表或任意物质冻结。物态转换独立走 8.07。 |
| `Cultiway.Poison` 剧毒 | 保留 | 接触附加毒性周期伤害，保留同源上限、层数和每层伤害；不把刷新改成无限叠层。 |
| `Cultiway.Explosion` 爆炸 | 改写 | 接触分送，按原半径、伤害比例和目标关系从接触点产生额外范围伤害。区别于主体的落地爆发；不要把整个爆炸范围绑定到飞行主体全程。 |
| `Cultiway.Knockback` 击退 | 保留 | 接触后按出手方向推离，保留距离与抛起高度，实际去向由移动规则决定。 |
| `Cultiway.Weaken` 衰弱 | 保留 | 接触后按目标当时属性降低攻击，保留原比例、时长和刷新；不改施放者强度。 |
| `Cultiway.ArmorBreak` 破甲 | 保留 | 接触后降低目标护甲，保留时长及同类刷新；和实际击破屏障容量是两种作用。 |
| `Cultiway.Gravity` 引力 | 改写 | 在部位范围内按原半径和速度牵引，基于原范围成长；移动随真实位置推进，不靠命中伤害或画面拖尾模拟。 |
| `Cultiway.Daze` 硬直 | 保留 | 接触刷新短硬直状态并使目标等待，保留实际时长。 |
| `Cultiway.Mercy` 怜悯 | 改写 | 先应用原单发伤害倍率，接触再按实际作用强度回复空间来源。与终结规则的互斥不能在改写时丢失；不从总伤害另抽一次。 |
| `Cultiway.Chaos` 混乱 | 改写 | 旧发射转换在逐发准备时一次抽取伤害、初始偏角与速度，传入已确定的资料；并行和预测不重抽。新编辑若要提供等价的每发变化，需显式描述抽取位置和三个范围，接触随机不能替代它。 |
| `Cultiway.Swap` 颠倒 | 改写 | 实际接触后以原概率交换自身与目标，落点、承托、有效性沿共用搬运规则，拒绝非法终点；不能改成无条件瞬移。 |
| `Cultiway.RandomAffix` 随机 | 改写 | 接触概率和候选结果表。保留原硬直、灼烧、毒伤、附伤、破甲和击退的各自量；一次只取一个，区别于每发混乱。 |
| `Cultiway.Burnout` 燃尽 | 改写 | 独立的火性附伤和灼烧状态分别配置，保留各自伤害和时长，主伤害仍用原属性。 |
| `Cultiway.Silence` 封印 | 保留 | 附加共用封印状态，保留攻击削弱与模板中的施法限制；只改攻击数值不等价。 |
| `Cultiway.DeathSentence` 终焉死亡 | 改写 | 真实接触挂标记并判断血量比例；低血走原终结伤害，高血走原附伤。不得把条件拍平为加强普通伤害。 |
| `Cultiway.ReincarnationTrial` 轮回试练 | 改写 | 先结算试练附伤，再根据该结果是否真正击杀进行来源回复或反噬；反噬归属来自原受击者。保留实际伤害结果，不按预测或预计击杀触发。 |
| `Cultiway.EternalCurse` 永世诅咒 | 改写 | 同一状态保留长时、阴与混沌的周期伤害，同时降低目标攻防；保留刷新及实际抗性。 |

作用、费用及冲突的游戏内接入继续由 8.06、8.08 和 8.09 验收。上表说明作用资料的去向，不把现有每个兼容转换都当成已开放的编辑选项。

## 普通和专用轨迹

普通轨迹以 [5.05 C16 的实际登记及基础来源覆盖](可编辑曲线与轨迹接入.md#旧登记的接入清单)为原参数依据。保留方向、距离、时点和真实接触；新构造不依靠旧轨迹名字分派。同一条轨迹可用于不同主体，主体自身的治疗、冲击、防御、落地等作用仍独立。法宝和兵器的隐藏专用登记单列：对应资料已经能表达其中的部分运动，尚未判定旧来源完成迁移。

|---|---|---|
| `Cultiway.TowardsDirection` 朝向指定方向 | 保留 | 沿起手方向的持续飞行，可有初始偏角回正，掠过所选点时不会自动结束。 |
| `Cultiway.TowardsDirectionNoRot` 朝向指定方向（不转体） | 改写 | 同方向运动，加固定姿态，保留初始偏角。旧菜单隐藏但允许旧档保留，独立名字可退掉，不能默认为沿切线转动。 |
| `Cultiway.TowardsPosition` 朝向指定坐标 | 保留 | 发起时冻结实际坐标；按原到达规则结束。辅助来源保留对指定友方的作用。 |
| `Cultiway.TowardsTarget` 朝向指定目标 | 保留 | 随真人或实际目标位置转向，保留追踪、失效处理和到达结束。不能改成锁死初始坐标。 |
| `Cultiway.DriftHoming` 偏航归心 | 改写 | 在真实方向上叠加初始横偏，按行程消退；到达判定仍用真正目标。 |
