# 视角切换与共同遮挡

对应1.08，已完成。原版29项与三视角50项实机检查通过，覆盖位置、相对／绝对高度、前后遮挡、近裁剪、两轮实际往返、渐变合成及退出旧帧引用。下一项按顺序为1.09；不将本项显示检查计作挂点、最终美术或规模性能完成。

## 原版场景接入

原先共用模型放在最上层，原版人物、树木则按精灵层级绘制，两套前后关系并不相通。现在在实际相机的一次绘制中收集原版可见物件，使用精灵的地面位置和每个像素的竖向位置生成共同深度。形体继续读取已完成的姿态，不修改实际伤害、位置、动作时钟或存档。

绘制顺序为：原版物件的不透明像素写深度、实体形体、原版不透明颜色、按共同远近排序的半透明颜色。孔洞不写深度，淡出和半透明边缘不会变成硬壳。原版上层提示、动画、拖尾及粒子在最后继续使用原材质绘制，并保留原版排序层与层内次序；夜色等MapOverlay覆盖层仍在EffectsTop提示之上。这里只在相机提交期间隐藏自动副本，绘制结束立即恢复，不把隐藏状态带到下一台相机。

原版精灵池登记新对象，已有显示器只在首次接入时收集。本模组的动画、拖尾、境界表现和世界标记在创建处登记；运行时模板的复制品通过小组件自动登记。没有每帧扫描整个场景，也没有修改原版共享材质。

原版物件和可见精灵的完整前后范围共同决定映射，边界与实际相机一致；不沿用精灵旧屏幕高度去提前裁剪。无形体时恢复原版路径并清空本帧命令。

## 保留树木与建筑的专用效果

实机发现人物使用`Sprites/Default`，树木则使用带风动等效果的`WorldBox/Building`，只检查前一种不能代表树木已接入。不能简单替换树木着色器后声称保留原效果。

专用建筑材质继续由原着色器在本帧生成画面，实际贴图、颜色、风动、时间及透明度保持。可见区域放入复用图集，再以四角平面参与共同深度。平面的索引在命令提交前一次固定，不在录制中更改已引用的几何。实体深度和实体颜色各批量提交一次；透明平面按共同排序连续分批，不逐对象增加整套颜色绘制。

图集按当前画面的像素需求分配，保留到相机实际峰值；达到平台面积边界时降低采样密度，保留物件。世界或相机清理时释放图集和批量网格，生成材质继续由所属资源版本负责，原版材质不被写入。

实现见[相机共同绘制](../../Source/Core/Visuals/Forms/FormNativeScenePass.cs)、[原版专用画面图集](../../Source/Core/Visuals/Forms/FormNativeSpriteAtlas.cs)、[原版物件表面](../../Content/ShaderSources/NativeObject.shader)及[新精灵登记](../../Source/Patch/PatchNativeSceneSprites.cs)。[原版形体显示](../../Source/Core/Visuals/Forms/FormNativeRenderSystem.cs)保留姿态和视图准备，相机阶段负责共同提交。

## 三视角切换与原版副本

同一份完整剑形姿态在原版、Worldfall普通三维、真实附身第一人称之间往返两轮。显示端只读取发布状态；原版矩阵不被视角改写，三维相对高度只增加一次实际地面，绝对高度保留原坐标。实际颜色目标中的三个位置样本分别验证平移和升高，不只比较内存矩阵。

实际相机图层隐藏后，原版共同绘制入口也停止提交模型。此前四次三维／第一人称切换都仍留有原版命令，现按每部件的真实相机图层处理，完全隐藏时本帧命令为空。原版也有独立的图层隐藏／恢复像素回归。

Worldfall的过渡画面使用原DLL建立的`FirstPersonGodScreen`及原材质。建立时登记到共同绘制入口，保留其透明度、覆盖队列和最后合成次序。否则原版人物、树木和模型会在已绘制的过渡画面上重新出现，破坏渐变。修正前半透明对照中14,201／36,864像素超出0.035误差；修正后该数为0，最大误差约0.0157。对照来自同一帧的原版、纯三维、半透明三次真实相机绘制，逐像素与两端各一半的参考值比较。

真正回到原版并完成过渡后，兼容入口清空旧三维帧中的实体、透明列表和提交计数。清理依据实际附身、普通三维、飞行观察与过渡状态，不按任意时间猜测。原版仍发布当前形体时，退出的三维列表也归零，避免继续持有旧模型资源；实际飞行操作不在本轮验收范围内。

## 三视角实机证据

`verify_view_switch.py`使用独立的私有游戏、NML缓存、配置和调试会话，依次加载Cultiway、DebugToolbox与下载包原Worldfall DLL。下载包声明为0.9.8，实际程序集版本1.0.0.0；未修改原下载目录。附带的译文包装源码曾在程序集通知中重入补丁，因此测试副本直接使用原DLL自带的NML入口，不代表修复第三方包装脚本。
