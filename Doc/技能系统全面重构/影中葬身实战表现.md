# 9.35 影中葬身

影从所选人物脚下反向站起。合臂时左右接触面必须同时碰到该人物的真实躯干，才能取得控制。路过的人不会被替换成目标。

- [x] 影身与抱持。借用原人物的身体轮廓，显示升起、合臂、放手。复用现成世界，验证双侧真实接触、原人物在合臂前离开时落空、结束归还控制。
- [x] 拖入与解除。抱持后才开始拖拽。足下深影标明实际入口和出口，仍能看到活人的挣扎。自然解除、挣脱、救援与死亡分别收尾，换世界不残留占用。用同一场地复验。
- [ ] 整项交付。原版招式及改造各验证一次真实作用，核对正式存读与冷启动，录制原版与 Worldfall 各一段原速连续画面，归档脚本和证据后合并到 `codex/dev`。

第一段用 `Scripts/SpellDemos/verify_shadow_burial.py` 复验。两侧接触各自来自原身的真实表面，站姿控制在抱持约 0.93 世界秒后归还。原身提前离开时，仍站在原位置的旁人不受影响。

第二段分开运行 `--section drag` 和 `--section release`。原招将同一活体沿地面带动约 1.44 格，挣扎用原身的真实表面显示。深水中断行程，人物留在岸边。自然松抱、援术命中、挣脱、死亡和换世界都已分别验证。
