# 主体轮廓、材质与视距（9.02）

本项先打磨已有主体中明确记录的五处问题，最后检查使用这些主体的其他招式在常用距离是否仍能辨认。后续流派和复杂攻击有新主体时，按同一标准验收。这里不补动作、声音、通用反馈或第 9 章的其他玩法。

| 子批 | 本次要改的行为 | 必要验证 |
|---|---|---|
| A 近距光束 | 灵光从亮芯到半透边逐渐变弱，阳光保留较紧的金色分脊，避免近处像硬柱。短段、常用长度和词条放大时，能分清亮芯、有效外缘与无伤余光。 | 复用 `verify_beams.py` 的修士、近处点和侧边对象。在一个短段上查有效区内外和自然结束，对比正常长度与放大截图。确认过去正式保存的构造不因替换同名接触资源而改变作用范围。 |
| B 连锁雷 | 雷体有错开的亮段、少量粗细不同的支梢和可看清的击中端点。支梢是否接触由同一份范围决定；纯装饰支梢收在真实范围内。 | 复用 `verify_chain.py` 的短链，确认只有实际命中才有下一段，一名分支旁的对象保持原状态。比较近处接点与远处链路，检查结束后无残存雷段。 |
| C 土墙 | 主墙有厚断面、叠层与承重岩块，边缘凸出量可读；临时土墙的实际阻挡边界随主体。详细碎裂动作归 9.03 和土系制作。 | 复用 `verify_wall_migration.py --section earth`，核对挡住正面、边缘外能绕过和结束撤墙。近景看岩层，拉远时确认墙的宽度和缺口仍能看清。 |
| D 龙卷和玄阴 | 龙卷从地面进风、腰部卷动、顶部泄流，避免整张风壳；玄阴用可辨认的包裹边与内层阴影，保留开口、深浅和对象轮廓。二者不能只靠改色区分。 | 复用 `verify_remaining_fields.py` 对应外观与实际作用段：各选一处明确边界及自然结束，比较两种主体在同一环境中的近、中、远景。 |

近景检查主体截面、材质过渡和端部接缝；常用战斗距离检查能分清攻击、护持和空隙；远处检查整体方向及开口，不要求保留微细纹理。凡外观改变会改变有效边界的，要在实机确认至少一个区内结果和一个刚好区外的对象，不用看起来差不多的代理体代替。对同一规则已通过的用例不再铺开身体、装备或多个世界。

A 的现状已核对：目前灵光和阳光都用封闭圆端网格，阳光有三道重叠的光脊。射线的最短生效长度直接跟接触半径走，节点放大也会放大横截面。所以缩窄外壳若不跟作用同步，会留下不可见的厚伤害圈；动到作用资料又要保留旧正式构造的结果。A 先用现有端点与作用观测把两种情况分开。若需要新接触范围，给新形体稳定标识，旧名和旧费用保留。

每个子批交付制作源、发布资源、一个可复验入口和实际截图，改接触时附边界结果。制作预览用来快速看形体，数值与视觉一致性以实机为准。原版与 Worldfall 的连续取景集中到 9.10，最终验收视频按总表第 16 章交付。等本表及视距检查都通过，再关闭 9.02 并合并到 `codex/dev`。
