# 事件驱动的成形与动作

## 本批规则

继续4.09及8.06，在现有同主体条件操作中接入生长、动作切换和材料改变，不生成替代主体，不重新支付或重置接触次数。

- 条件生长以该部位原始尺寸为1，从真实当前倍率到明确目标倍率，使用自己的历时；允许继续长大或收缩，尺寸与实际作用区同时变化。
- 条件动作使用形体已经提供的动作，从当前完整局部骨架姿态连续过渡，挂点、显示和作用形状共用相同结果。动作和过渡时间均服从暂停、材料保持及正式历时改造。
- 停止分别保持尺寸、内部动作和整体运动。重新生长只恢复尺寸，重新播放只恢复内部动作；飞行仍由飞行操作恢复。
- 明确数字有效窗口继续使用部位时间；制作阶段窗口在动作切换后使用当前动作的对应标记，缺少标记在编译入口报告，不套用另一动作的时间。
- 条件材料改变沿用真实材料规则，并产生同一材料变化事件。每项操作只接受一次，循环引用不能无限执行。
- 过渡姿态和操作状态随预测快照恢复。运行中只读取已经编译的数值资料，复用独占姿态缓冲，不按帧创建新的骨架或模型。
- 旧正式资料的默认行为保留；新增参数可省略。完整长期过程、损耗与成长阈值、网络传播和地形结果仍继续按全程TODO推进。

## 验证

`verify_shape_events.script`通过32项，覆盖连续生长与收缩、实际胶囊和显示同步、材料冻结及解冻续行、从真实起姿过渡、阶段窗口切换、分别恢复、快照回退、材料链事实、无效资料、历时改造、真实接触、一次支付及修士创法。

正式记录中，同一把剑由施放编号1、部位0在约0.897及1.518秒分别命中两个人物；回卷厚浪由施放编号2、部位0在0.98秒真实接触后开始后续过程。主体、归属和原命中记录保留。

`verify_shape_events_parallel.script`使用正式工作池，128及512个主体分别核对生长、持续过渡和冻结，共六组；姿态、速度、材料、实际胶囊及两次回退重跑误差均为0。该检查不包含原版人物、实际伤害确认和整场绘制性能。

旧同主体运动34项、身体动作42项、曲线35项、材料状态47项、事件部位生成46项和独立维持27项，共231项检查通过。旧保存场景仅运行保存前的验证段，没有覆写历史冷启动证据。开发构建0错误、16项已有警告，录像工具3项测试通过。

实机发现生长完成前可能产生极小余步：旧实现中5.96046448×10⁻⁸秒加到1.5秒后，真正写回仍为1.5秒，造成重复计算。现在新增过程均在共同世界时间上拆分边界，专门验证写回后的时钟确实前进。

停止中的尺寸和动作有独立开关。只恢复生长时，动作阶段窗口读取停止中的实际动作时间，避免共用形变时钟恢复后提前进入有效阶段。

## 剩余范围

- 接触、交锋、结束和材料事件后续已扩展[损耗及尺寸条件](损耗与成长条件.md)，每项只接受一次；通用过程进度、条件组合及网络传播继续实现。
- 动作切换需要形体提供明确动作及必要阶段标记，不能从任意静态模型自动编造骨架或动作。全身体技、兵器握持及非人部位仍按原TODO推进。
- 条件尺寸过程服从材料保持；原始生成生长保留旧规则，初始凝形与后续材料内部变化是不同过程。
- 过渡使用实际局部姿态与当前动作混合，尚未实现自动纠正支撑、地形穿透、双方抓持或运动匹配。
- 浪面在三维远景仍偏薄，透明点阵和附身近景遮挡明显；本批验证结构过程，不作为最终美术、城市级场面或完整世界作用验收。
- 4.09已由后续损耗和尺寸条件完成明确场景验证；8.06其余范围仍待办，当前总表54/328，不以几个输入替代全量迁移与最终验收。
