# 分枝曲面与逐段成形

对应2.07。原有Grow仍负责整件缩放；根、藤、浪面和流路另由共同动作的成形进度逐段建立。成形进度与控制姿态一并采样、停止、预测恢复和发布，不增加招式专用时钟。

## 制作与资料

形体发布格式升级为第4版。制作网格附加通道保留每个顶点的收拢中心及成形顺序，动作关键点保留0至1的成形进度；挂点和作用形状声明所需进度。旧资源整体重建为当前格式，世界存档继续保存稳定资源编号。

| 资源 | 制作内容 | 逐段建立和形变 |
|---|---|---|
| 分枝根 | 有体积的主根、侧根及实际分枝连接，保留截面和根尖 | 主根前端推进，抵达分枝处后侧根逐段伸出；同一控制结构可摆动 |
| 藤 | 封闭、渐细的藤体，保留接触段和末端挂点 | 从根部延伸并弯曲，不靠放大整条藤替代；成形后可以盘卷 |
| 浪面 | 复用现有厚水层、卷唇和局部泡沫 | 新增沿纵向建立的动作，其他已有翻卷动作保持原用途 |
| 流路 | 复用现有闭合后流水层、表面权重和地表适应 | 前沿沿流路铺开，未铺到的部分不产生显示或作用 |

顶点先向自身截面中心收拢，再使用共同控制姿态。前端在连续截面间逐渐收尖或收薄，尚未建立的段不提交有效片元，避免收拢后的曲面留下线条。运行继续共享固定网格，不每帧重新造整份模型。

作用形状按相同进度启用，正在形成的前端不向未形成部分延伸判定；挂点所需部位尚未建立时，附着子体等待，已经脱离的独立物件保持原规则。已经转交世界的固定形体保留成形进度及同一内部姿态，不在读取后突然变成完整外形。

复现：`python3 Scripts/SpellDemos/verify_form_formation.py --record`。脚本使用独立游戏配置，原版与Worldfall共用同一组资源和动作相位。

## 实机结果与范围

正式资源编号为`root_network`、`spirit_vine`、`water_wave`及`water_flow`。根使用27个控制、3个实际部件、6090个三角形；藤使用9个控制、2030个三角形。水面沿用原资源，新动作名为`form`；根藤另有`bend`，原翻卷、退浪和流水动作仍保持完整形体。

游戏进程3989891中82项检查通过，覆盖20个形成阶段取样、真正发布网格的成形通道、未形成时的隐藏和接触、共同边界、动作调速、接触预测回退、驻留及维持、延迟开始、半成形材料的正式数值序列化恢复，以及旧资料缺省完整形体。旧翻浪、退浪、流水、水鲸和整件缩放同时通过。有效顶点最大边界偏差约0.00000048地图单位。

原先无事件构造的快速启动会令子体提前开始计时。现在需要等待成形挂点的构造采用正常启动；子体在挂点满足要求后的数值取样开始自己的时钟。未承诺跨数值步解析精确阈值时刻。首轮失败的两项检查与被底栏遮住的旧取景留在`before-anchor-start-fix/`，没有用那一轮冒充通过。

[检查、来源及录像入口](../../artifacts/skill_rebuild/form-formation/index.html)包含原版与Worldfall共12秒、1280×720、12帧每秒的实际游戏录像。原版和三维各先建立四种主体，再展示完整姿态变化；世界暂停，构造使用同一制作动作相位推进，未冒称自然角色战斗录像。

SDK构建0错误、16条原有警告，经NML真实编译加载；C#按仓库DotSettings格式整理，Python与JavaScript语法、差异空白检查通过。Linux、Windows、macOS资源包均完成构建，只有Linux实际运行。新增两项资源标签，无GameResources图片及玩家设置。

固定世界材料新增数值`BuildProgress`，缺省1，正式旧资料继续恢复完整形体；当前通过同一正式材料保存接口的数值往返，没有重复整套世界冷启动验收。作用胶囊仍是有限分段近似，不等于逐像素碰撞。该实现建立制作与运行路径，完整水量、世界流域、植物玩法、美术与规模性能继续按相应任务验收。
