# 身体与兵器接触的批量实测（13.18）

复用原锤盾对练的两个人物、正式铁锤和铁盾，以及原有狼足动作。18、72 个动作批次都冻结同样的身体比例、实际器物和非人骨段输入，再分别走顺序与工作池。两种方式按相同次序得到身体姿态、真实作用范围、碰到或落空的结果、首次接触时点、接触位置及朝向。

每个批次交替测七次。以下是含 13.17 工作分支改动的诊断结果，单位为毫秒：

| 动作数 | 作用形状 | 候选 / 接触 | 推进顺序 / 并行 | 求交顺序 / 并行 |
| ---: | ---: | ---: | ---: | ---: |
| 18 | 414 | 74,385 / 6,429 | 1.37 / 1.55 | 65.83 / 40.75 |
| 72 | 1,656 | 1,325,916 / 118,956 | 6.10 / 7.02 | 1,655.71 / 2,039.27 |

这是对已经取得的数值姿态和候选计时，最大批次包含全配对，用来测压力上限；游戏实际会先做空间筛选。这些数字不代表整场帧率，最大批次也没有显示并行一定更快。

复用狼足抓持用例。384 个正向、反向及空隙查询中有 256 次实际接触，两种方式的接触时点、朝向、原三角面抓点及输出次序相同，实测由 14.58 到 6.50 毫秒，含测试反射调用；游戏中的关系确认仍在主线程。正式出手建立抓持，跨步保持原抓点，遇已有控制时拒绝，结束后双方归还控制并恢复行走。

原锤盾对练按旧条件再查，锤击显示被挡，目标生命未变，但没有盾面交锋及对双方余量的结算事件。保留失败记录，不把这场计作盾面通过；本项的真实关系由狼足抓持用例核对。未更改玩法和线程设置。

将本项单独移到远端 13.16 基线后，完整复验再次通过，补查了实际轮廓变换和旋转信息。18 个动作的求交中位耗时为顺序 92.03、并行 108.38 毫秒；72 个为 1,549.96、1,428.45 毫秒。双向有限面样本为 9.46、2.19 毫秒。两次运行的耗时有波动，结果一致。本次发布不包含 13.17 的调优改动。
