# 事件驱动的部位生成

## 本批范围

继续8.06，接入由真实事件开始的部位过程：人物接触、形体交锋、部位结束、材料实际变化，以及真实身体的接触和自然收势。条件开始后继续使用共用生长、动作、旋转、脱离、轨迹和实际接触，不增加整招专用执行类型。

## 共同规则

- 部位可以等待指定来源的事件。来源采用父体、身体或明确部位引用；相对引用跟随结构复制，不能产生没有起点的等待循环。
- 等待期间不显示、不产生作用形状、不提前播放动作。触发一次后，该分支以自己的零时点执行已有操作；未单独指定条件的子体继承分支时钟。
- 可在触发后延迟开始。整次施放的寿命仍是总上限，不因事件晚到而无限延长。
- 放置可继续附着，或从真实事件处独立生成。从事件处生成采用来源当时朝向、实际事件位置和明确的地图尺寸；保留节点本身的局部偏移及转角，不从画面反查。
- 事件处生成的部位在条件确认时解除父体的结束牵连，因而可以在命中者消失后开始。继续附着的部位随真实连接结束。
- 人物接触包括实际格挡等接触结果，不以选取目标或播放到某个动画时点代替。材料条件只在实际材料变化后满足，可明确筛选输出材料及物态。
- 事件只触发过程，不凭通知改变归属。附着子体沿用已有反射交接规则；反射后发出的独立子体保留已交接的归属。
- 每部位每次施放最多开始一次；触发事件本身不重置接触次数、剩余作用量、支付或恢复。显式分配不同接触组，才代表独立作用。
- 自然结束和接触、耗尽导致的结束可以带动后续部位；整次取消不继续生成新作用。身体被中断时不会冒充自然收势。
- 编译阶段检查引用、来源能力、等待循环及预算。预测中产生的开始、结束和材料变化随同一快照回退，不能在回退后留下未来事件。

## 使用入口

万法阁当前部位的“接触与作用”页增加普通条件参数，不使用节点连线或多招配方。修士创法和外部资料使用同一条件定义及正式施放入口。

## 已接入的资料

| 字段 | 保存的含义 |
|---|---|
| Source | 父体使用`..`、身体使用`body`，也支持相对引用及`root`开头的完整部位路径 |
| Trigger | 1人物接触、2实际交锋、3部位结束或身体自然收势、4实际材料变化 |
| Delay | 确认事件后再等待的世界秒数，非负且小于整次上限 |
| Placement | 0继续真实附着，1事件处独立开始 |
| Matter／State | 材料事件的可选实际输出筛选，不接受仅改颜色冒充材料变化 |

`ConstructionNode.Activation`缺省为null，不写入原正式资料；普通后代继承最近开始分支的时钟。条件、实际起点、结束通知及排队状态随同一数值快照恢复。监听按来源与事件预先建立索引，队列每部位每次最多开始一次，复用原有工作池。

数量复制及环绕包装会重绑绝对引用，相对关系仍指向各自分支；首批出手延迟不会再次加进后段的局部时间。巨大同时改变独立事件主体，随动明确转换该主体的放置并保留身体来源的朝向约定。完整历时缩放包含事件延迟，费用和接触预算沿用各自原规则。

## 已知边界及后续

- 本批实现部位开始条件；后续已接入[同主体运动](事件驱动的运动变化.md)及[条件成形、动作和材料变化](事件驱动的成形与动作.md)。损耗、成长、网络到达、关系变化、持续过程控制及事件间组合条件继续按4.09、5.18及8.06推进。
- 每部位每次只能开始一次。频率和重复作用继续由真实接触规则管理，不允许事件回调重置次数、费用或恢复。
- 材料变化筛选实际输出，不保证某个合法筛选一定会在本次战斗满足。没有收到事件时按来源和整次结束规则清理，不保留无上限的等待。
- 事件处生成采用当时位置，仍附着则依赖实际父体。来源结束后不能要求同一来源链继续支撑新部位；整次取消和身体中断不冒充自然收势。
- 各种开始时间仍受整次寿命约束；耗尽上限时不继续生成新作用。临时形体结束与长期世界结果分别处理，长期结果和网络传播尚未完成。
- 录像沿用现有模型及表面，枝体在原版远景仍偏细弱，附身近战仍有目标遮挡。材质体积、近战镜头和Worldfall角色尺度还须完善，不能作为最终宏大战斗或美术验收。
