# 9.25 五相周流

同一术式把一次支付形成的材料依次传下去。起手岩壳有实际挡击面，岩壳挡到来招且仍有余力才从接触处开出木相；木相接触目标后开出真正贴地的水流，水相完成实际接触后才出现火相，火相经实际碰触后收成金相刃面。每一相独立制作或使用有完整接触资料的实体模型。触发条件、位置、材料、余量和形体由同一推进结果决定。

| 固定行为 | 必要验证 |
| --- | --- |
| 只有满足明确条件时才传到下一相。允许改次序，不按元素名字猜反应。 | 用已学入口跑完五相，记录实际挡击、作用、转换顺序、接触点以及五种真实形体。将一段在资料里调换次序，再实际施放。 |
| 同一份材料和未耗支付份额分流。已转用的份额不留在上一相；一小部分岩壳留在原处。木相首次实际命中消耗其可回收灵力，后续继续传递剩余体积和作用力。 | 确认每次过渡前后的力、体积和支付份额，实际触水灭火沿用共同反应。 |
| 岩壳未挡到来招时不启动；途中耗尽或中断时，尚未完成的阶段不显示，已经落地的岩片保留。 | 复用同一世界与两名角色，核对未触发、两处截断，以及原有世界材质还能读回。不扩大身体、装备覆盖。 |

交付可编辑的主资料、一份改序资料、复验脚本，以及原版和 Worldfall 的常速实机录像。本项做到局部完整过程；9.40 再验证城市尺度与多来源调度。原修炼成果「五相轮转」保留自身减伤规则。

[五相周流](构造输入/五相周流.json)按土、木、水、火、金推进；[五相换序](构造输入/五相换序.json)改为土、木、水、金、火。改序使用同一个交接操作。岩壳被打穿或木冠打空时，后面的模型不会提前出现。岩壳成功分出的落地支座独立留在世界里。

编辑器里，先在旧部位的「接触作用」页添加「交接剩余材料」，指定何时执行；再给新部位添加「实际交接完成」条件，选择旧部位为来源。新部位从真实作用点独立开始，旧部位退出；可明确决定是否重新计算接触次数。缺少交接操作时，编辑器不给保存。

实机中，12 体积的岩壳真实接刃后，约 2.98 留作落地岩片，约 9.02 随木相往下传。外来火与实际水层接触时蒸散约 2.23，后续收到约 6.80。木、水、火、金分别造成实际扣血。没挡到来刃、被重刃打穿、木枝打空分别停止在对应阶段；第三种情况下已经分出的岩片经正式写档、读档后仍保留原编号、体积和灵力份额。读档不会恢复旧施放。

复验入口见 [演示脚本说明](../../Scripts/SpellDemos/README.md#925-五相周流)。本机证据索引为 `~/.local/state/cultiway-dev/evidence/five-phases-925/delivery.json`，包括原版主方案、Worldfall 主方案、原版换序各一段约 6.4 秒的常速原片，以及中英文编辑器截图和分段日志。验证使用同一独立测试世界和同一对人类，软件渲染不用于判断游戏帧率。
