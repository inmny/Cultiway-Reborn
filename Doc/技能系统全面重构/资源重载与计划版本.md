# 资源重载与计划版本

## 范围

补齐3.12和2.15：同一构造及资源版本共用编译计划，资源或定义变化后新施放取得新计划，已经运行的施放保留开始版本。重载、结束、切世界及退出均不得继续使用已经销毁的模型或材质。

## 约定

- 资源按版本分组，模型、动作、材质及纹理属于同一组；实例通过自己的形体资源取得对应材质，不能让旧模型混用新版本材质。
- 重载先读取并检查新一组全部资源及已登记构造，全部通过才发布。失败保留当前资源和正式定义，不破坏正在施放的内容。
- 编译缓存包含资源版本和完整构造资料。正式登记和编辑仍复制定义；同编号、同修订但实际内容改变也不得复用旧计划。
- 当前资料更新后，新的目录、预览、准入及施放使用新计划。运行中施放与身体绑定保留原计划和资源，不在中途替换骨架或作用形状。
- 旧组不再供新请求加载。卸下资源包时保留已加载对象；仍有施放、身体绑定、预览或发布帧引用时保留旧对象，引用回收后在主线程释放。
- 切世界清理施放、预览和绘制视图，共享当前资源继续复用。退出释放当前及旧组的模型、材质、纹理、着色器和资源包。
- 版本只描述本次运行的资源，不写进世界存档；正式存档继续保存构造和学习关系，读档按已安装资源重新编译。

资源包卸载行为按[Unity 2022.3说明](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AssetBundle.Unload.html)核对：保留已加载对象与同时销毁已加载对象分别处理。

## 资源

本批不新增模型、贴图或动作。验证临时修改既有资源说明，检查后恢复原文件；正式发布资源保持原内容。

### 边界

首次请求和重载均在主线程完整读取资源组，只在加载边界读取文件。Unity不能同时打开同名资源包，故完整保留旧对象后用`Unload(false)`关闭旧包，再读取新组；失败时旧组不再从已修改的磁盘补读。资源目录也取已发布集合，失败内容不会进入界面选择。

旧组通过弱引用观察施放、身体绑定、预览及发布资料的实际使用者；原版停用视图解除模型和材质引用，Worldfall绘制暂存保留形体引用直到清空。正常更新每秒检查一次可回收旧组，不强制触发托管回收；测试单独强制回收以核对最终释放结果。引擎可能共享的原生对象按组计数，最后一个所属组释放时才销毁。

本批完成加载、版本和释放规则，不代表水体美术、透明重叠、城市规模表现或所有来源迁移已完成；相关待办保持原状。
