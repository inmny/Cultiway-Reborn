# 共用发力动作与距离适配

4.17实现共用动作生成，而非增加七个固定技能。创建输入交给`BodyActionGenerator.Create`，输出普通`BodyActionDefinition`和五个实际姿态关键点；内容层`BodyActionCatalog.Create`将其接到现有学习、施放、自由编辑及世界保存。运行不再读取生成请求，也不按招式名字执行另一套逻辑。

## 可调整的输入

| 输入 | 实际作用 |
|---|---|
| 动作种类 | 刺、扫、劈、挑、拍、挡、拨，生成不同路径 |
| 实际部位 | 已接入的左右手、肘、肩、膝、足及头，共11个选择 |
| 历时与速度 | 同时调整起势、出手、有效窗口和收势，不单独加快命中 |
| 幅度 | 改变实际动作行程，固定骨长、共同腕点及站立支撑继续约束 |
| 扫角与动作面 | 改变侧向行程及其绕前方轴的倾斜 |
| 器物与握点 | 手部可使用已有实际握持路径；不把其他部位当作握点 |

生成结果仍可逐个改写关键点，不要求保留原来的种类名称。脚下、当前体高和方向由真实身体提供；左右侧使用各自肩点及弯曲方向。肘部收拢手路、肩部带动躯干、腿部生成自己的足底路径、头部生成关节转角，不将一条手路复制给所有部位。当前独立器官仍保留4.16的实际根部转角构造；完整非人动作轴及支撑按4.29接入，不静默套用人形。

## 距离与共同取样

新生成动作打开`Body/MatchDistance`。受理时锁定实际目标点，主线程采集本步脚下到该点的距离；工作计算只接收数值。共同取样调整前向行程，固定骨长约束最终姿态，不能靠目标很远就伸长手脚。手部和足部可展开到实际允许范围；肘、肩、膝、头仍保留近身行程，膝击不会被展开成足部远踢。足部高低调整仍保持在地面以上。

近、有效与收势共用原有动作时间和连续曲线。姿态、实际接触形状及两种显示读取同一结果；距离适配不改碰撞半径。手部候选范围包含适配后的可达包络，足部拆步预算包含前向展开；实际是否命中仍取决于真实作用形状。内容创建入口不写死零范围，以免覆盖自动得到的身体范围。

旧资料缺省`MatchDistance=false`，保留原路径。新字段及生成关键点通过现有世界资料保存，没有另存生成器对象或运行中的人物、图形引用，也不要求用户手工迁移。既有速度改造仍缩放完整关键点及作用时段。

## 动作资料

本批没有新增模型、贴图或玩家设置，复用已有身体、掌面、关节及器物资源。

| 生成动作 | 路径特征 | 本项边界 |
|---|---|---|
| 刺 | 收拢后向前送出，再收回 | 不改变真实肢长 |
| 扫 | 从一侧经过前方到另一侧 | 侧向行程与转体共同变化 |
| 劈 | 高处准备、向下经过 | 兵器接触部位进一步适配归4.20 |
| 挑 | 低处准备、向上经过 | 发力及传导规则继续4.21、4.22 |
| 拍 | 短促侧向拍出、回收 | 与长横扫保留不同路径及掌面方向 |
| 挡 | 抬起接触面并保持一段架势 | 默认不造成伤害；实际架挡规则归4.25及工作包6 |
| 拨 | 短程侧向经过 | 默认不造成伤害；拨压和脱手规则归4.25 |

这次不增加固定多招配方，不做新的动作编辑器。自主创法选择这些动作的完整接入仍按7.20、7.21推进。
