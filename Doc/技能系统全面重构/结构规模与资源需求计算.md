# 结构规模与资源需求计算

3.09第二批：从实际展开结构计算资源需求，接入新创法和明确的数值改造。本批原始记录不包含最终数值平衡、完整维持改造或最终画面验收；后续收尾见[动作维持与实际选取范围](动作维持与实际选取范围.md)。

## 计算时机与明确填写的数值

编译后的同一计划提供`ConstructionMeasure`，统计材料、存在时间、作用组、运动和世界过程。统计在编译时完成，施放过程中不逐帧重新定价，也不从网格三角形数量推断强弱。

默认值合成后仍缺少费用或冷却时，只计算缺少的那一项。作者明确填写的零费用、零冷却和其他数值保留。正式登记、读取存档及重新打开完整构造均不会自动改价。

尺寸、急速、整段历时、独立维持和数量改造命令，依据改造前后实际需求之比调整费用，冷却按该比值的平方根调整。明确免费或零冷却继续为零。数量复制只生成一份真实身体动作，因此身体部分不会随材料份数重复收费。直接填写单个原始字段仍保留作者费用，不冒称每一种任意编辑都已自动计价。

新创法使用第三版生成规则：先生成完整结果，再计算需求。已保存的第一、二版请求保留原有生成和费用规则，不能因为读档或继续未完成请求而得到不同结果。

## 当前统一尺度

以定义中的体高为一，费用表达结构需求，并非承诺真实命中次数或已完成玩法平衡。人物实际体型仍影响运行时尺寸，本批没有按每次施放者的身高动态改价。

| 项目 | 当前计算 |
| --- | --- |
| 身体动作 | 一次基础需求0.5，加动作秒数×0.25 |
| 初始材料 | 实际定义体积×父子缩放；预留已声明生长的最大尺度；加体积×存在秒数×0.25 |
| 空组织中心 | 不算材料，不把无网格支点当作生成实体收费 |
| 碎片与余量后段 | 不重复计初始材料；碎片运动仍携带原材料的相应份额 |
| 无材料功能区域 | 共同参考姿态下的平面包围面积×（0.1＋存在秒数×0.025） |
| 运动控制 | 携带体积或区域预算×（速度×秒数＋加速度×秒数²÷2）×0.1 |
| 曲线运动 | 只截取实际可能采用的时长，以曲线控制折线长度上界计预算；循环按可运行圈数及余段计算，不按曲段数收费 |
| 旋转 | 携带预算×角速度×有效秒数÷360 |
| 接触作用 | 整招倍率×部位强度×（伤害倍率＋推力绝对值×0.1），再计重复规则；共享接触组只算一次 |
| 格挡 | 整招倍率×部位强度 |
| 传导 | 脉冲数×（传播范围×0.1＋目标上限×单目标作用量×0.1） |
| 世界材料转换 | 明确体积上限×0.1 |
| 攻击附带世界作用 | 地块预算×0.001×（1＋效果秒数×0.1）×重复规则；功能区域还受参考面积预算限制 |
| 投送距离 | 合计需求乘（1＋定义选取距离÷120）；选取距离与实际作用形状分别维护 |
| 新创法默认冷却 | 需求平方根×0.25与身体动作时长取较大值 |

这些系数是当前统一规则的明确起点，最终平衡仍须后续实战确认。无材料区域采用参考包围面积，不能用这个估计值代替真实接触形状或宣称精确面积。

单次作用计一次；间隔作用按有效时段和世界秒间隔预留，并受明确次数上限限制。没有上限的离开后重入，按维持负担计预算；真实是否重入仍由接触确认决定。共享组在实际运行中继续去重，费用统计不能创造额外命中。

## 整数资源与保存

整数资源在最终支付边界向上取整，短名和正式资源编号遵守同一资源声明。构造另存资源通道、未取整需求和未降精度的恢复时间，连续放大再缩小不会把每一步取整误差累积成额外费用。微小正费用也不会被当作免费。

实际扣款继续使用正式`Cost`，退款继续使用实际已付本金；计算基准不能充当支付凭据。作者手改正式费用后，下一次明确改造会以新费用建立基准。

世界部分`ability_constructions`升至第六版。第五版到第六版只保留既有内容，不回头重算旧法术；旧构造在首次明确改造时才建立计算基准。原档不回写，不需要玩家手动迁移。
