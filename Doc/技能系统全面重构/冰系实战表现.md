# 9.17 冰系实战表现

验收一段从接触起霜、增厚合拢到受击开裂的冰体，以及一段真实冻结、保形和重新解冻的厚水体。两段共用独立游戏里现成的演示世界和对手，用现有的接触、部位生长、交锋、碎解与物态规则。两段均通过后再关闭、合并并推送 9.17。

- [x] A 触生冰壳：从真实接触点长出霜缘，冰片由根部变厚、左右合拢。未长到的区域留空，合拢后才有有效阻挡。一次真正交锋使冰体沿内部裂面分开；没有交锋时不凭空画出受击裂缝。沿用 `接触后生长冰枝` 的触发结构和已有分件碎解入口，使用独立构造资料，不改旧术。最低复验：落空不生长；实际接触后，合拢前空隙可过、合拢处能挡；受击分离后不保留完整墙面的阻挡，脱落部分按各自寿命退出。交付原版和 Worldfall 各一段有真实交锋的常速原片，连同实际接触、阻挡和分离时点。
- [x] B 冻结与解冻：复用 `厚浪凝冰与解冻`，同一水体在真实冻结时保留当时轮廓，固定冰内纹理和厚截面，解冻时才恢复水面流动。记录真实材料没有转换时冰层不出现，以及解冻后原过程恢复、不生成第二份水量；末尾区分已解冻水体和仍保有实际冰材的部分。交付原版和 Worldfall 各一段常速原片，附实际材料、形变与退出时点。若用到留在世界里的冰，沿用已有留置与融化资料，保存这部分状态按受影响路径单独复验。

冰壳长成和已冻结水体的形状锁定要分开处理：已冻结水体不能为了画面继续长大；生长、裂面和残留也不能只按屏幕时间播放。薄霜和碎屑不另加伤害。先用现成对照验证关键时点，完整录像集中在两部分通过之后。不扩展境界、装备、城市规模或永久地貌样本。

## 实测记录

- 冰壳：实机已确认落空不生长，碰到对手后才形成薄霜；生长时不封路，结成厚冰后实际阻挡。独立支付的石弹触发交锋，原壳拆成九个无伤的实物部件；墙的阻挡立即解除，碎片自然退净。原版与 Worldfall 的常速原片都拍到真实命中与交锋。
- 冻融：实机已确认落空保持水态；命中后同一水体保持当时的骨架形状，整体仍向前，三秒后从冻结进度继续，体量不变，最后无残留。首轮原片中液态浪身缺失，只剩泡沫边。封闭水体改为使用真实曲面的方向和厚度受光；液态时有流动反光，凝冰时改为固定的冰纹和内雾。两种视角的最终原片都能读出浪背、卷唇和冻融前后，旧潮浪在抽查中仍保有浪身及命中。
