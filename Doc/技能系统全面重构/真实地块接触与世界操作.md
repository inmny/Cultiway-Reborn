# 真实地块接触与世界操作

## 本批范围

继续11.03及7.11的基础实现。先让任意普通构造的真实部位直接调用净化、植被生长、农田成熟等地块操作；后续再迁移原技能取得、词条和组织项目入口。本批不把地块操作登记成新的整招类型，不用额外圆形范围代替部位。

## 使用规则

`Impact.WorldEffects`可以声明至多八种已登记操作，每项有地块接触规则及不同地块上限。根部、后代、脱落形体或真实身体都使用自身实际作用面，沿用当前控制者和施放时间。普通战斗未声明世界操作时不会遍历附近地块。

查询先以作用面的真实扫掠范围找候选地块，再用共同胶囊和箱体算法确认实际表面接触。地块操作与相撞、材料反应和人物接触共同排序，回到真实最早时点后才改变世界；悬空投影不会触及下方地面，出现前和有效阶段以外也不提前作用。

每块一次、固定世界秒间隔及真正离开后再进入，复用现有接触规则和区间合并方法。世界接触与人物接触分别记忆编号，分件仍对同一部位、操作及地块去重。符合条件后的失败尝试也记录频率，避免原版随机生长的成功率被画面帧数放大。

世界产生实际收益后消耗本部位原支付份额，不能先催生真实植物、再把该份费用当作未用资源返还。没有改变世界的尝试保留未用份额。已经支付的总费用、自身冷却、材料和显示仍由共同构造执行维护。

## 实际世界规则

| 稳定操作 | 实际作用 |
|---|---|
| `land.cleanse` | 调用原有净土规则，清除火、灼烧、暂时冻结、热量及可移除荒地表层，保留道路和建筑 |
| `nature.grow` | 在原版允许的空地调用原有生物群系植被生成，不凭显示创建收益 |
| `crop.mature` | 调用原版麦田组件，实际达到成熟状态，后续仍由原版收获维护 |

旧世界功能法术与新接触调用同一实际地块实现。旧技能的完整迁移、地形操作、日常需求匹配及美术制作继续推进，11.03和7.11保持未完成。

## 资料与扩展入口

以下是一个实际作用面的地块操作，和普通材料、形体、部位、运动及有效阶段一起组成构造；无需新增整招执行类。

```json
"WorldEffects": [
  {
    "Action": "land.cleanse",
    "Contact": { "Mode": 1, "Interval": 0.5, "MaximumPerTarget": 6 },
    "MaximumTiles": 256
  }
]
```

该字段放在整招或部位的`Impact`里。整招规则作为缺省，部位可以覆盖。`Mode`的0表示一次、1表示间隔、2表示真正离开后再次进入。`MaximumTiles`限制这一部位及操作所接受的不同地块数量，`MaximumTotal`另限制总尝试次数，不把人物接触与地块接触的编号混在一起。装饰部位不执行世界操作。

操作的目标单位是原版地块：作用面触及地块表面后，操作规则处理其中的热量、植被或麦田。这不代表已经实现建筑顶部、器物、区域网络等全部对象的三维接触；那些对象仍按原待办推进。

`ConstructionWorldActions.Register`登记一种实际原理，提供地块预检与主线程提交。任意普通构造均可组合它；八种操作上限按单个作用面声明检查。未知编号和错误容量在构造资料边界拒绝，运行计划保存只读规则副本。`WorldContactConfirmed`发布实际时点、部位、地块、归属、尝试次数和真实结果，不将失败尝试计作收益。

本批调用净化时还修正了原有实现的一处问题：`MapAction.terraformTile`即使重设相同地形也会检查已有建筑与地形是否适配，因而可能误删麦田。瞬时清理现改为调用原版灭火、解冻、移除灼烧和清热接口；仅确实需要去掉荒地表层时才改变地形，且事先排除道路和建筑。旧净土法术与新世界接触共同受益。

## 后续范围

接着将旧功能法术的学习、资源报价、词条、轨迹及城市项目入口接到这些普通构造，继续补地形和日常需求。地块条件触发新部位、完整建筑接触、大范围候选批量处理与性能，以及各流派视觉仍在原待办中。当前小范围验证不能代替城域、世界范围或多修士并行的性能验收。

验证用麦田采用原版`field`表层、城市归属及风车维护，城市扩建在独立测试场景中关闭，避免测试中铺路覆盖麦田；普通草地上的调试麦田不能用于证明原版收益能保存。另保留一处人工调试麦田只检查净化不会主动删除现有建筑，不把这处不规范摆放计入冷启动保持。

原版`Wheat.growFull()`只改变当前成熟等级，不更新保存资料。催熟现在同时写入原版`BuildingData.grow_time`，重新加载后由原组件恢复可收获状态，不另建农田进度存档。
