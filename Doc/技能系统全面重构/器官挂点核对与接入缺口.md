## 实测范围

在私有Worldfall游戏中为九种实际动物启灵，设置一阶基础鳞片和二阶雷角，读取实际原版帧、已发布器官图片、正式技能起点解析及三维主体。世界暂停，没有释放攻击，也没有用标记代替器官模型。

原版图片采用实际帧枢轴、缩放和翻转，将角的可见像素换到同一原版投影中，与SkillCastPlanner.TryResolveSourcePosition返回的雷链起点比较。下表单位为地图单位。“角顶”只是最高可见像素的辅助测量，不是所有器官都应使用最高点的设计规则。

| 物种 | 到最近角像素中心的偏差 | 到角顶像素的偏差 | 三维主体顶点与加角前相同 |
|---|---:|---:|---|
| 狼 | 0.290 | 0.366 | 是 |
| 熊 | 0.361 | 0.510 | 是 |
| 龟 | 0.261 | 0.261 | 是 |
| 狐 | 0.112 | 0.304 | 是 |
| 鳄鱼 | 0.482 | 0.763 | 是 |
| 兔 | 0.250 | 0.403 | 是 |
| 鼠 | 0.305 | 0.404 | 是 |
| 羊 | 0.358 | 0.486 | 是 |
| 蛇 | 0.333 | 0.446 | 是 |

九种动物最近像素偏差为0.112至0.482。现有起点按整张身体帧的宽高取比例，没有读取对应器官的实际位置；图集留白、体型和部位变化都会影响结果。因此，不能把这些通用近似点算作实际器官挂点。

加角后三维主体仍使用原模型和原顶点，实际部件列表中没有新增雷角，属于这些动物的共同形体实例也为0。原版已经合成角图，不代表Worldfall已经显示相应三维结构。这里只证明本次实际模型与提交情况，没有把它扩大成所有器官、所有绘制入口的完整验收。

## 按顺序继续1.09

1. 在现有身体与器官资料中明确命名的安装点和施放出口。已有图像的出口由实际制作资料给出；吐息等没有外部图像的器官，也须在身体资料中明确口部等出口，不能继续仅按槽位估算。
2. 原版合成、技能出生位置与三维接入读取同一出口。还要验证朝向、换帧、缩放、移动和延迟释放，避免只在计划建立时保存一个随后过期的点。
3. 先用本次已测量的雷角接通实际三维结构和头部挂点，使用器官自己的结构和材质；再核对背部、四肢与尾部等不同安装关系所需的最小接入。外观竞争后以实际显示结构为准，不能从已经隐藏的图片中取一个假想出口。
4. 正式施法与原版、普通三维及施法者第一人称分别实测，记录真实地形、水面、腾起及移除器官后的恢复，再判断1.09是否通过。缺少实际结构、共同出口或必要视角证据时，本项保持未完成。

必要依赖是2.04中身体/器官挂点资料、2.05至2.07中现有器官实际需要的资源段，以及10.09的组合身体接入段；只提前补当前验证确实缺少的部分，完整范围仍按总TODO顺序推进。资料只存稳定名称和制作坐标，外部骨架引用留在兼容层；绘制不推进施法，也不按镜头模式改写玩法出生位置。

这不是在1.09提前完成全部器官制作与迁移。下面的十三类资源表保留后期制作要求；先解决当前核对所缺的实际结构和出口，完整模型、动作、材质与能力迁移仍分别归入第2、第9、第10工作包。

## 资源说明

以下是后续接入时应保留的资源含义和挂点，不代表这些三维资源已经制作。继续复用已有原版逐帧图片；三维结构按现有资源发布链接入。测量点不等于新增主动技能，是否用来出手仍由实际器官能力声明。

| 当前图层 | 三维制作要求 | 安装与测量点 |
|---|---|---|
| 雷角 | 有截面和渐细弯曲的角体，保留角质或金属感及局部雷光 | 颅顶安装、实际角尖出口 |
| 辟邪角 | 具有独立尖端的暗色角体，轮廓与雷角不同 | 颅顶安装、尖端测量；不凭外观新增技能 |
| 扶鹏翼 | 成对羽翼，羽片有层次、厚度及展开方向 | 两侧肩背安装、翼端测量 |
| 凶翼 | 与羽翼不同的分节或翼膜结构，保留折叠和展开 | 两侧肩背安装、翼端测量 |
| 单尾 | 连续渐细体积，连接尾根，不用拖尾线替代 | 尾根、尾端 |
| 三尾 | 三个能区分的尾体，保留独立尖端 | 共同尾根、各自尾端 |
| 六尾 | 六个独立尾体与有限展开，不能缩成一团 | 共同尾根、各自尾端 |
| 背甲 | 有厚度和分片曲率的壳体，贴合实际背部 | 背部安装、壳面测量 |
| 普通鳞纹 | 映射到真实身体表面，保留鳞片方向 | 表面区域；没有独立外部出口 |
| 寒鳞纹 | 冷色、层次和反光与普通鳞纹区分 | 表面区域；没有独立外部出口 |
| 火纹 | 保留图案分布与局部发光，不用整只身体均值染色替代 | 表面区域；没有独立外部出口 |
| 月纹 | 低强度柔光及清楚的局部纹样 | 表面区域；没有独立外部出口 |
| 发光眼 | 绑定真实眼部，只改变局部显示 | 眼部中心；是否出手由能力资料决定 |

表面材质和完整动作的最终质量仍按第2、第9工作包制作；1.09须先具备足以核对实际安装和出口的结构与资料，不能用标记或单纯改色代替立体器官接合。
