# 9.14 水系实战表现

本项复用现有施放、地形和水量规则。两批都通过后关闭 9.14，一起合并到 `codex/dev`。

- [x] A 潮浪：由厚浪背托起前卷水唇，水唇越过波峰后下泻，最后只余低矮水脚。泡沫成零散片，跟着同一段水面走；浪身和接触共用姿态。沿用原学会的招式、费用、寿命、轨迹和伤害倍率。复验真实扫中过浪人物、足够偏离的目标无伤、自然结束；留原版和 Worldfall 常速实战各一段。
- [x] B 贴地后流：在现有有限水量和坡面场景里，能看出落地后沿坡奔流、前沿分开和余水衰减。贴地显示与实际有水的位置一致；浅薄和干涸的位置不靠泡沫制造假边界。复验实水命中及干处无伤、接续与退出；留原版和 Worldfall 常速过程。

潮浪不另造持久水域。真实流散沿用原世界规则；屏障、冰、蒸散及其他元素交互留各自条目。分两批验证，只重跑受此次改变影响的场景。

A 使用 `Scripts/SpellDemos/verify_ground_waves.py --section tidal`，只加载原潮浪。B 沿用[缓坡守恒流](构造输入/缓坡守恒流.json)作为正式输入，沿真实水深和流向显示水脚及碎沫；以相同的干湿判定裁切画面，不改水量或推进规则。

潮浪仍由原 `travel` 动作和贴地轨迹驱动，沿用 0.9 秒寿命、原接触编号和半径。截面在浪背更厚、卷唇收薄，横向不再整齐同步；碎沫附着同一骨架，不参加伤害。实机水唇从约 0.50 格抬至 0.81 格，再降到 0.29、0.18 格。三段姿态的真实接触皆贴合；正式施放支付 1.3 灵力，正面人物只结算一次，轨迹外对照不掉血，到期清除显示与接触。

保留两轮早期记录：原复验的固定半秒到达条件不适用于这次取景；正侧的旧对照位于潮浪的实际转弯路线上，实机确实命中。最终对照移到轨迹外，没有改变施法或命中规则。

原版和 Worldfall 的补拍均录到正式支付、真实扣血、低水脚及完整退场。第一版落下后仍像方形硬片，作为未验收对照保留；最终版收薄两端和侧缘，使用弯曲水脚和错开的前沿。三维录制在保存完整视频后中断清理，已检查全过程帧和视频解码并正常关闭独立游戏。证据见 `~/.local/state/cultiway-dev/evidence/water-combat-914a/delivery.json`。本批没有更改已有存档格式或增加配置。

## B 的实机记录

贴地后流只调整有限水层的画面：反光顺着实际水流移动，泡沫出现在够深且向前变浅或减速的位置，最薄的边缘自然淡掉。仍用同一份水深裁切，水量和命中规则维持现有行为。验收沿用缓坡与已有分流场景，观察有水处命中、干处无伤、后流变薄和到期退场。

同一缓坡下正式施放支付 6 灵力，湿区目标扣血 32，干区未接触也未扣血。水深峰值从约 0.48 格降到 0.36 格，到期后没有残留水面。沿用已有高地绕流场景核对，两侧水面均出现，高地格中心依然无水；实际流动方向写入水面，裁切使用共同干湿阈值。原潮浪网格继续走原材质分支。

第一段原版试拍能接续和命中，但后流看起来像均匀的蓝色薄片，保留为对照。加强随实际流向移动的宽水纹后，以同一个[鲸散守恒后流](构造输入/鲸散守恒后流.json)场景补拍。两段均录到约 1.1 秒由水鲸接成贴地后流、正面实际扣血和完整退场，首个后流画面约有 6 立方格水量，最后可见时约为 3.6 立方格，之后按原规则结束。录像使用软件渲染，供画面确认，不作为性能结论。
