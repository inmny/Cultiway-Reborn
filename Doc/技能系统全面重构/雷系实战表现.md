# 9.18 雷系实战表现

本项做两组普通战斗用例。已有四段连锁雷保留；城域的雷神与重锤另归 9.34。

- [x] 落雷：旧落雷换成有厚度的折面主干和短岔枝，保留原接触芯、轨迹和费用。新构造用共用动作让雷团收束、主雷下击；只有人物真实接触才裂开余电，空落不出现命中反馈。
- [x] 水路：只在传导实际到达的水面铺有高低面的雷脊，按实际来路与距离分批出现，退散后释放网格。保留水路、伤害和网格预算上限。
- [x] 复验与交付：复用现成世界。一轮落雷验证蓄力无伤、实际命中与空落、结束；水路复用原版池塘验证真实传导、冻断停传与自然退场。两组分别留原版和 Worldfall 常速原片，三平台资源由共用脚本重建。全部通过后，整项合并并推送 `codex/dev`。

## 实测记录

- 聚雷下击实际支付 8 点灵力。蓄力和落空都无伤，只有一次真实接触时才展开余电，随后干净退出。试拍时发现雷尖已到地面、作用面却未触到小目标；新术把作用面延伸到雷尖。旧落雷保留原作用面，从原入口抽查扣费、范围命中与友方无伤均通过。
- 两种视角都记录了同一池塘水道冻断前后的传导：结冰前连通 105 格，冻断后只达 55 格，断点后的目标停止受击。雷脊沿实际连通的水边铺开，退场后清除。主动生成的水面也通过传导抽查。
