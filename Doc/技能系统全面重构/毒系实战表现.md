# 9.20 毒系实战表现

本项结束条件：毒息、染毒、传播、腐蚀和消退五种变化能从画面分开辨认，且能从真实接触和状态追查原因。只用现有小场景，本项不做城市规模、混沌场外观或新的毒物规则。

- [x] 毒雾改为带方向的贴地厚流，前端卷起、两侧变薄。保留旧毒雾的接触体、动作和结算。新增可学构造「拂地毒息」：先推进、再稀薄；首次真实接触才染毒、触发一次局部传播。验证一个直接接触者、一个只吃传播者和一个范围外对象，以及主体散去后持续毒伤、解毒或自然结束时清掉附着。
- [x] 毒潭改为暗色黏膜和厚薄不均的积液。保留旧毒潭资料和结算。新增可学构造「蚀甲毒潭」：按真实留在作用面内的时段腐蚀护甲；先掉耐久，才出现局部蚀斑。验证同一护甲重复损耗、离开后不再掉耐久、无装备不产生蚀斑，以及结束后可以重放。
- [x] 复用现成世界验证原版和 Worldfall。交付两招各两段常速录像、规则实测记录、可重跑脚本和三平台模型资源；不增加新存档字段。核对完成后再关闭 9.20 并合并。

## 已验证行为

- 「拂地毒息」实扣 7 法力，毒息从横坐标 64.00 推进至 67.28 时直接打中前方人物，直接伤害为 7。另一人在侧面 3.25 格处，没有被主体命中，只收到第一次接触产生的 4 格范围传播；场外人物未中毒。主体散去后毒伤仍继续，解毒及自然到期分别清理各自的黏斑。
- 「蚀甲毒潭」实扣 8 法力。潭内同一件铁甲耐久从 100 降到 98、再到 96；离开后停在 96。再次施放确实命中无甲人物，只造成原本的命中结果，不出现腐蚀痕迹，也不凭空附毒。
- 独立对照旧毒雾的 3 个接触体、旧毒潭的 25 段接触面、挂点、局部方向、控制位置和原 `run` 动作。旧资料的默认淡出仍为零。没有变更存档格式。
