# 9.44 长兵战技实战表现

沿用现有长枪的尖叶、套管、长杆和尾鐏，首轮用同一对人形单位及原版实际长枪对练。原版铁枪和石枪都是九像素长，铁枪尖叶更宽，两种器物的原握柄高度相同。改变握法和器形时同步使用对应的实际端点、距离与承力位置。

先完成滑握的共同姿态与一条正式枪刺。资源继续使用现有长枪，沿用储存格式及旧动作的静态握法。

## 滑握与直刺

引杆送锋以靠前握点起势，右手沿同一段直杆滑到后握，再向前送尖。枪尖收回时右手沿杆返回前握。滑握只接受朝向一致且都位于同一可握杆段的真实握点，中间位置沿既有动作曲线连续取样。正常路径和受阻后的收势都读取同一滑握数值。

同一条手路固定前握时，可选距离为体高的约 1.97 倍。有效时段滑到后握后约为 2.31 倍。实机三处取样中，实际握点与画面的手内坐标重合，实际枪尖端点也与显示对齐。铁枪在 0.350 秒命中一次，消耗体力 6，目标扣血 40。贴身目标用同一招正常出手，枪杆经过时未受伤。结束后均正常归还身体控制和同一件原铁枪。

专项结果见 `~/.local/state/cultiway-dev/evidence/long-weapons-944/grip-thrust/checks.json`。

## 杆身横扫

压杆横摆以靠前握点把长枪收向身侧，转胯带动枪杆两端横过身前，再把长杆送回持械姿态。有效阶段只启用木杆的实际作用形状。枪尖那一段仍为铁质，铁枪刺实际使用的就是这处表面。

同一对人物实测中，横扫取样期间杆尾移动约 0.76 格，靠枪头的杆端移动约 1.02 格，两个作用端点与渲染位置对齐。实际木杆在约 0.469 秒命中一次，扣血 26，随后对目标施力。收势归还实际控制和原铁枪。新增杆身材料后，另行复验了原铁枪刺的尖端和铁质接触。
