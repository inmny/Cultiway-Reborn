# 构造法术的城市工作

## 本批范围

继续7.11、10.13和11.21。复用原有城市工程的需求、规划、认领、移动、额度和验收，让正式已学构造进入这条流程；不添加另一套城市工作服务，不按整招名字登记功能。

城市的净化、植被、催熟、住房和农田地形需求分别识别实际原理。候选使用自身资源，修士不需要转成法师或持有法杖。不同构造以来源和能力编号区分；同一构造的不同持有者也保留，因为来源挂点和运动会影响实际足迹。

## 完整足迹与评价

预估从正式共享计划创建独立的 `AbilityCast`，使用真实来源、目标地块中心、离地高度和当前地表，复用共同步长、连续扫掠、首次接触、间隔、重入及次数规则。按每项世界原理保存实际接触地块。预估不调用世界修改，不支付、不发布施放或结果，不向正式施放列表登记。

每次完整预估限制8192轮、两百万数值工作量和65536次地块操作查询。超出即拒绝这份不完整结果；不能把已遍历的小部分当成全部范围。一次城市目标搜索或个人选招最多完整预估八项，轮换能力与落点，使后面的候选也能得到评价。旧容器继续使用原评价。

全部世界足迹必须处于城市合法空间；收益只统计当前需求对应的原理。净化和催熟可以一起存在，分别按污染和未成熟麦田评价；生成植被仍保护实际与预留农田。地形沿用一步升降与排水预测，以及不损失原有有效地块的规则。重复地形操作暂不投入城市工作，除非每块最多一次。

城市候选限定为零攻击力量、无推拉、无身体动作、屏障、收束和独立材料副作用的纯世界用途。未知世界原理、附带注水或相反地形作用的候选不投入当前工程；先补对应用途和副作用评价。正常手动使用不受这些城市选择条件限制。

预估读取当前世界，不模拟尚未发生的其他角色行动，也不把地形改变后的未来世界复制为另一套地图。正式执行前会从当前位置重新计算，施放期间仍以实际地形和保护条件为准。敌人干扰、地形变化或新农田可能使实际完成少于预估，最终按真实结果验收。

## 实际执行与结束

准备和到位时重新选择当前可用能力并冻结明确足迹。执行前保存主作用的真实地块及收益基线，统一入口负责原资源支付和冷却。新构造的包围半径仅供原有历史空间规则使用，不再用于扩大作用或统计收益。

本次 `ConstructionWorldScope` 同时检查当前城市归属、实际与预留农田、已评价足迹，以及工程仍处于执行中且持有当前执行记录。角色死亡、离城、工程超时或被替换后取消尚未提交的世界作用。已经提交的永久结果保留。

开始事实将本次施放编号连接到工程令牌；地块事实只统计所需原理、冻结主足迹中的实际改变；真实结束后才进入已有验收。相关作用没有改变世界时重新规划，不能拿别的副作用、预计寿命或总世界变化次数代替任务结果。有部分真实收益而结束取消的行动仍交由既有验收规则判断。

原版只在行为明确请求时进行效用决策。实测发现，长闭关等工作始终不请求决策，已有应急工程因此无法打断。城市现在按原有低频规划节奏唤醒可执行者，再交回原版决策选择和原工程认领；不重置已经认领者的行走，不打断冻结或正在战斗的人物。没有从脚本直接指定工程或逐帧强制施法。

## 存档

沿用正式城市工程区段第一版，新增可选的全部足迹和主作用地块数组。旧工程没有这两个字段时保持旧半径路径；新资料读取时检查地图编号、长度和包含关系，损坏部分进入原有局部丢弃报告。

保存的是构造、已学关系、工程目标和实际基线，不保存委托、运行对象或旧施放编号。原工程恢复规则把认领改回待处理，把执行中改为验收已有结果；未结束的法术不重播，未达到目标则按当前需求重新规划。无需玩家手动迁移。

## 11.03 城市功能效果的结束条件

- 沿用真实已学功能术和城市任务。净化复用 10.13 的实际任务、净化、失效、再用与冷读。其他用途先用同一座已有城市和一名已有施术者，分别验证植被催生、麦田催熟及地形整理从原有工程规划、认领、施放到实际验收。
- 催生只统计真实植被，实际和预留农田受保护。催熟只在确有饥饿与未熟作物时计划，验收读取实际原版生长。住房和农田整理共用地形施工，只在真实新增可用格且原有效用地没有损失时完成。用一条实际施工和另一用途的候选判定核对共用路径。
- 只处理妨碍上述真实收益的缺陷。复用同一城市和原施术入口。新地形、统一工程调度和自动工作全套交付继续各自条目。
- 交付可按用途复验的脚本与结果。已有正式地块保存和城市任务冷读作为共用存档证据；新改动涉及长久结果时补受影响的正式存读。整项条件齐备后合并 11.03。

## 11.03 城市功能实测

复用正式档中的城市 1 和修士 56。准备对应需求，使用原规划器和常规职工入口请求一次工作。任务自行取得真实目标、选择已学法术并在到位后才施放。完工以原城市历史和实际世界结果为准。

| 用途 | 实际结果 |
| --- | --- |
| 净化 | 复用 10.13 的净土实测。原版及 Worldfall 从同一档冷读后重新认领，分别净化 46 和 43 格，两发先后结束，工程随后验收。提前取消与再次认领也已经通过。 |
| 催生 | 仓库木材为零，城市规划催生工程。施放自然结束，确认 5 格确实长出植被，原工程验收通过。同一游戏、同一城市另核对施放用的实时保护，挡住新麦田和新预留地，允许普通地生长。 |
| 催熟 | 由原档另一名居民的实际饥饿更新城市需求。城市选择 (68, 74) 的原版未熟麦田，修士施放后同一株作物成熟，工程验收通过。 |
| 地形整理 | 用同一个已学降地术分别预估住房和农田，两边各识别出 16 格新增用地。原规划实际选择农田整理，整片共改变 32 格，其中 22 格由不可建变为可建。原验收同时核对既有可用地没有损失。 |

复验按用途分段。早期试验保留需求未满足、等待不足、职工尚在原任务和测试麦田被世界更新移除的现场结果。保护规则在催生已经结束的同一世界单独采样，未重复净化。正式地块保存与城市任务冷读沿用既有记录。自然工作频率和城市级过程分别留在 11.21 及 11.14。
