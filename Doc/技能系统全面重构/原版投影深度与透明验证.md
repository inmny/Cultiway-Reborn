# 原版投影深度与透明验证

对应1.05，验证共用形体在原版画面中的前后顺序、表面细节、透明叠加及主体内部遮挡。已修正内部深度精度和实例透明材质，保留实际绘制读回及完整模型录像。本项不代表各流派最终美术和全部视角已经验收。

## 问题与修改

旧绘制把深度压成`(地图纵向－相对高度)×0.0001－0.5`。原版相机的观察范围较大，16位深度无法区分其中相距很近的表面。真实像素读回确认：同一主体的近面和远面交换三角形顺序后，中央颜色改变，远面会盖到近面上。只检查材质有深度开关、或者只看凸形轮廓，不能发现这一问题。

现在先取得所有已发布姿态的保守投影边界，再把共同前后范围线性映射到相机可用深度的80%，留出边界余量。所有部件共用同一映射；显示边界同步映射，地表高度同时修正平面和前后范围，不能只改着色器却使用旧边界裁剪。没有逐帧复制网格或排序三角形。

实体先写深度，水、冰及实例半透明色随后按实际投影边界的前后中心由远到近叠加，同深度保留发布顺序。实例透明色现在选取所属资源版本中复用的透明材质，关闭深度写入；不修改其他实例共用的实体材质。视图缓存网格入口和参数块，按显示峰值复用，世界清理时释放。

代码见[原版绘制](../../Source/Core/Visuals/Forms/FormNativeRenderSystem.cs)、[同版本表面](../../Source/Core/Visuals/Forms/FormResource.cs)和[着色器](../../Content/ShaderSources/FormSurface.shader)。原版与Worldfall继续共用几何及完成姿态，两个视角的绘制通道各自执行。

## 实际检查

在Linux、RTX 3050 Ti Laptop、OpenGLCore和Unity 2022.3.60f1上运行。测试通过共同发布入口和实际`FormNativeRenderSystem`生成视图，再由真实相机绘制；缓冲的实际深度格式为D16_UNorm，观察范围为－40至281.6。不是离线重画一张“正确示意图”。

| 核对内容 | 实际结果 |
|---|---|
| 同一主体的两面，交换三角形顺序 | 两种顺序均与近面独立绘制颜色一致，旧实现此项失败 |
| 不同实体，交换发布顺序 | 近处实体保持遮挡远处实体 |
| 两层实例半透明金属 | 两层均有贡献，合成透明度约0.75；交换发布顺序结果一致 |
| 同一半透明主体内部的远面 | 保留远面贡献，不被实体深度写入提前吞掉 |
| 木纹与表面坐标 | 内部区域的实际颜色变化超过阈值，纹理参与绘制 |
| 远处透明体与近处实体 | 透明体不能透过近处实体 |
| 斜穿实体的透明面 | 前半面可见、后半面被挡，按像素判定 |
| 地图坐标移到1200、1200 | 内部遮挡结果保持一致 |
| 绝对高度减去地表 | 形态、遮挡及裁剪与平地对应结果一致 |
| 发布着色器 | 实际支持并带有新深度映射参数 |
| 真正游戏窗口的模型部件 | 所有活动部件均在主相机可见图层 |

以上11项通过。鲸体重新执行实际发布网格、权重、骨架、挂点和作用区等41项回归，也全部通过。完整来源、读回颜色与图形设备见[检查结果](../../artifacts/skill_rebuild/native-projection/checks.json)、[来源记录](../../artifacts/skill_rebuild/native-projection/metadata.json)和[骨架回归](../../artifacts/skill_rebuild/native-projection/form-rig-checks.json)。旧失败画面及结果保留在`before/`。

[原版投影技术录像](../../artifacts/skill_rebuild/native-projection/native-projection.mp4)为1280×720、12帧/秒、72帧、6秒。画面包含完整实体剑、半透明剑、木体和连续变形水体；已查看动作中段及前后画面。世界暂停，动作使用单独的显示时间，不发生伤害；不冒称战斗或最终内容验收。木体细节、鲸体轮廓和尾部衔接等美术继续在资源及流派工作包制作。

录制时曾发现隔离检查留下的图层使主相机漏掉剑刃和护手，已还原图层、增加主相机可见性检查并重录；没有用部分模型可见的旧录像通过本项。

## 构建中一并修正的必要问题

完整重建发现导出器没有保留制作资料的前向和上向，会丢掉鲸体、浪面和流体已经声明的轴向。[构建器](../../Scripts/ShaderBuild/BuildFormBundles.cs.txt)现明确保留两者，缺省值沿用正式格式。九份发布说明的有效方向、动作、控制和单精度数值与原先等价，见[发布说明核对](../../artifacts/skill_rebuild/native-projection/manifest-equivalence.json)。生成文本的浮点写法及默认字段有所归一，没有将这种文本变化当成新模型制作。

三平台资源包均重新构建；只有Linux实机验证，不声称Windows或macOS已经实跑。新增资源为现有三个`Content/AssetBundles/cultiway_forms_*`的更新，没有新增`GameResources/`贴图。正式存档格式及稳定编号未变，无需人工迁移。

开发构建原先会从`artifacts/`内测试游戏和调试工具副本选到错误程序集，出现大量无关访问权限错误。现将测试产物排除出默认项目文件候选，开发构建恢复0错误、原有16项警告。这是本项验证的构建依赖修复，没有修改其他玩法来绕过错误。

## 下一项与边界

下一项严格为1.08，检查原版、Worldfall、第一人称和切换过程的实际位置、高度、遮挡与近裁剪。本轮保持既有最上层特效层；与原版人物、建筑、树木等精灵的共同层级和相互遮挡尚未因此解决，需在1.08中落实。交叉、自交的透明曲面仍受按部件排序的限制，本项未实现逐像素多层透明排序。
