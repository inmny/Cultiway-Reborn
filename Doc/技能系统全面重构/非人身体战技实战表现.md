# 9.49 非人身体战技实战表现

伏首雷角刺和伏地扑已有正式编号，以及 9.40 的实战、双视角录像和正式读档。用原来的狼、狐和已有器官补足尾与翼的独立战技，并检查同身不同部位如何一起出手。各招可独立学习、改造与施展。

| 部分 | 游戏行为 | 验收条件 |
| --- | --- | --- |
| 角、爪 | 伏首雷角刺由真实头部承接角尖，伏地扑由后足承重、左前爪接触并落地。 | 延续 9.40 已通过的实际支撑、作用、失去雷角时拒绝及归还。使用原正式资料在本项双视角展示中各重放一次。 |
| 尾、翼 | 卷尾横扫先逆卷蓄劲，再用整条尾扫过身体侧前方，越过接触点后收回。敛翼斜切先合翼蓄势，沿斜向展开，用实际翼缘切入后折回。 | 正式目录中的两招用原身体、真实部位和体力执行。存在接触才有伤害，按真实部位自然收势。 |
| 同身分别出手 | 既有狐形的尾与翼可分别受理、占用和结束。同一多尾器官也能改用两条实际命名尾，保留其余尾的原姿势。 | 尾与翼的两招各自支付、作用和结束。编辑尾扫副本选择真实命名尾，与另一条尾各自施展。另在出手途中撤去翼，核对旧翼不再接触、可用部位及控制归还，并演示恢复后可再出手。 |
| 改造、保存和录像 | 可在现有编辑器选择具体尾部并保留原招。 | 新游戏进程读回狐、真实器官和招式副本，核对实际出手。原版和 Worldfall 交付常速近景，各覆盖角、爪、尾及尾翼同身。 |
