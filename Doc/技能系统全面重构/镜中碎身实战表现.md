# 9.36 镜中碎身

镜框、背板与镜面形成有厚度的古镜。镜中人来自这次施放选定的原人物，保留身体、衣甲和当前姿态。裂纹从镜内真实触点向外发展，镜面和原人物分别给出所发生的反馈。

- [x] 立镜与映照。用现有铜框、背板和镜面。映像缩放到镜口，随原人物姿态更新，人物失效时退去。复用原测试世界，验证正式施放、原人物变化与旁人不串接、失去目标和自然结束。
- [x] 裂纹与传递。用同一次施放生成的实际攻击面打到镜面。裂纹从碰撞处逐片传播，只有映到允许的原身体表面时才交给正常伤害结算。验证伤害或护持反馈、打偏和镜碎停止未抵达的裂势。碎片使用已经到达的裂纹边界。
- [x] 整项交付。完成原术和改造各一次真实施放、正式存读及冷启动，录制原版和 Worldfall 各一段原速录像。归档脚本、关键证据和视频后，整项合并推送到 `codex/dev`。

第一段只核对镜框与映像的真实身份、动作和退出。同一场地、同一身体用于后续的镜面击中与裂纹传播。

第一段用 `Scripts/SpellDemos/verify_mirror_shatter.py` 复验。铜框、背板和镜面的实际总厚度约 0.58 格。原人物移动并换上钢甲后，映像更新了轮廓和服装层，旁人留在原位置也不会接替。原人物失效时映像立即撤掉，镜框按自己的时段收尾。

第二段用 `--section travel` 与 `--section interrupt` 分段验证。同一次施放实际击镜后，躯干和头部先后在各自的表面结算 42 点伤害，撞镜当下无扣血，旁人无伤。实际打偏时不起裂。护盾路径接入一份固定额度的测试护盾，使用游戏原有吸收入口，反馈来自实际消耗。外来攻击耗尽镜面时，尚未抵达的裂势停止，已形成的裂片下落并退场。

第三段在已有实际扣血且镜面仍在时正式存档。恢复完整原术、裂冠、学习关系和原身生命，未完成过程没有重放。用同一档等保留的冷却走完后实际复施，原术作用于躯干和头部，裂冠只作用于头部。另用重启后的独立进程验证了同一份档。

原版与 Worldfall 各交付一段约 3.45 秒原速连续录像，均可看到镜内外反馈和退场。录像中的实际表面各承接一次裂势，两个许可部位的实放另有正式读回记录。原版录像保留第一次结果，用未剪接的原始帧和时间记录补核。见开发环境 `evidence/mirror-shatter-936/delivery.json`。
