# 数量、尺寸、速度与历时改造

对应总 TODO 8.05。数量、尺寸、急速及整段历时伸缩已接入；后续已补齐保留出手与收势速度的[独立维持延长](独立维持阶段.md)。玩家、修士创法及开发工具共用 `ConstructionMagnitudeEdits`，将变化写进实际构造；运行期不再叠一套仅影响外观的词条参数。

## 实际含义

| 改造 | 改变的资料 | 保留的资料 |
| --- | --- | --- |
| 巨大／缩小 | 根生成体尺寸；子结构、挂点、实际胶囊与显示随父变换缩放 | 放置中心、真实身体、单次作用量、速度参数 |
| 急速 | 飞行速度、旋转角速度、追踪速度与曲线路径的时间；纯身体动作改为更短的完整动作 | 生成体尺寸、单次作用量；有生成体时保留准备及制作动作的原时点 |
| 历时伸缩 | 完整过程的寿命、阶段、姿态时点、制作动作、存在窗口、飞行及曲线时钟一起伸缩，同一进度仍到达相同位置 | 接触间隔、次数上限、基础作用量 |
| 数量 | 原主体的多份独立结构、横向布局及显现间隔；每份各有完整存在时段和接触去重 | 单份的材料、阶段、内部连接与操作、每份接触规则；真实身体只发力一次 |

“历时伸缩”明确表示整段过程的时间伸缩，不表示凭空追加持续伤害。这个能力不能代替独立的维持延长。整段变慢时静态领域也会存在更久；已有间隔规则仍按世界秒计数，次数上限不会自动解除。需要维持运动速度时，可继续使用急速、普通速度或路径参数修改。仅想延长外层容器可直接修改总寿命，但不会因此延长原来明确结束的作用或制作阶段。

后续3.09已接入[结构规模与资源需求计算](结构规模与资源需求计算.md)：上述命令依据实际结构需求变化调整费用和冷却，真实身体只计一次，正式施放一次支付总额。作者明确免费或零冷却仍保留，正式登记及读档不重算。旧第一、二版生成请求保持原有结果，下方早期录像和费用记录属于当时规则。旧齐射的单份伤害系数可以用现有整法强度表达，完整旧词条逐项迁移仍由8.01跟踪。

## 结构、存在窗口与身体

数量使用现有空支点承载多份原结构。相邻显现间隔为零就是齐射，正数就是同一生成构造分批显现，仍然是一个法术，不是多招组合或固定连招。各份显现前不绘制、不产生接触；早生成的一份到自己的寿命便退出，不会等最后一份才消失。全部主体已经结束且没有后续份时，空组织支点不会继续占用施放计算；真实身体尚未收势则仍完成原动作。

`ConstructionNode.AppearAt`、`DisappearAt` 是正式资料中的两个可选世界时点，缺省分别为零和整次结束。它们同时约束显示与实际接触；预备姿态仍可在窗外更新。结束边界保留最后一段真实扫掠，不继续绘制已消失的主体。普通编译检查时段，模拟在时段边界拆步。旧正式格式不含这两个字段时按原行为恢复，缺省字段不写入 JSON，不需要重开档或手动迁移。

原来直接从根飞行的结构改为子结构时，会补上相同释放时点的连接解除。已有明确接触组在每份中独立命名，组内关系继续保留。身体显化的第一份继续与真实掌击共用去重，其余份独立；实际身体动作不复制、不延长占用。手部连接在原离手时解除，之后显化从同一次释放过程继续运动。未提供生成主体的纯身体不能凭空复制肢体或放大身体，界面会指明先显化或改变实际体型。

总份数沿用 1 至 64，最终展开仍遵守整个编译器的 128 部位预算；嵌套预算在复制前检查，超限不修改草稿。其他参数仍受现有路径、时长和旋转预算约束。

## 游戏内与开发接入

性质页新增四行普通改造命令。输入框只填写本次参数，点击“应用”后才生成候选、完整编译、加入一次撤销并替换草稿。数量一行依次填写总份数、横向间距、显现间隔。失败给出实际原因并保留原草稿和历史。部位参数还可直接调整各自显现及消失时点。

修士创作已有枝上凝锋后，使用同一命令生成不同尺寸、速度、历时和份数，并直接学会、保存；不另设按法术编号运行的专用表现分支。完整创法规则仍按第 7 节继续推进。

| 资源 | 用途 |

| 现有 `sword`、`hand`、`water_wave`、`branch` | 原有几何、动作和作用形状，未新增代替判定的装饰 |
