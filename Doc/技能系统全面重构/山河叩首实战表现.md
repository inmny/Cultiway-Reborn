# 9.32 山河叩首

整项完成条件：分层岩片依次抬起，绕各自的轴刚性翻落，朝同一战场中心合拢。压中人物和地面都要以实际岩面接触为准。压地后出现与落点相连的褶皱，断块依据真实地形落稳。临时岩体退出后恢复通行；若留下持久地貌，由正式地形规则确认并保存。原招与一个可编辑派生完成存读，原版和 Worldfall 各留一段常速录像。全部齐备才勾选并合并。

| 分段 | 要改变的游戏行为 | 必要验证与交付 |
| --- | --- | --- |
| A · 层岩抬起与俯压 | 先复用现有分层岩壁、断面模型。几段岩片错时抬起、向内翻落，转轴和岩面共用实际姿态。抬起与翻落时不拉伸岩层，也不在岩片之间补一整块伤害。 | 复用已有世界、一段高低地和现有施术者与目标。检查两片岩体真实转轴、挂点距离和接触形状；只落在翻动空隙的目标不被作用。留下可实放构造与代表画面。 |
| B · 压地、褶皱与断块 | 落到地面才启动接地挤压，实际碰到的地块决定褶皱位置。断块沿真实方向脱落、受重力并在地表停住；来源中断后，未压落的岩片不再继续，已脱落的碎块正常收尾。 | 一个场地覆盖命中、未接地和来源中断。对照压地时点、地表褶皱范围和真实伤害，检查高低地的断块落点与术后通行。 |
| C · 材料交接、派生与录像 | 临时岩体和持久地貌分别交接；没有地形写入许可时仍可完成临时效果，同一份岩量不同时留为碎块和地貌。改变一片的转轴或落向，实际落点随之变化。 | 检查许可与拒绝各一次；原招、派生与已确认的地形结果走正式存读。集中录制原版、Worldfall 常速实机，覆盖抬起、俯压、断裂和落稳。 |

本项只复用一个场地，不扩人物和装备样本。城市及世界规模验证留给对应条目。开工先让 A 在实际场景里成立，再接入 B 的地表结果。

A 已实机通过。用[山河叩首构造](构造输入/山河叩首.json)正式施放，近片先抬，远片随后，底边各自固定，显示与接触共用同一姿态。抬升无伤，近片扫中的目标扣血，片间的目标全程未被触碰，到期岩片消失。复验入口在 [SpellDemos](../../Scripts/SpellDemos/README.md#山河叩首932)，先留原版两帧作为过程证据。A 用旧岩层验证运动；B 的正式模型改为四块有裂面、可拆开的连续岩层。

B 已实机通过。新的分层岩片用同一轮廓提供可见断面和分块接触，砸地时从真实接触点翻起褶皱和短时阻路的岩唇。普通场地里两片分别约在第 1.37、1.69 秒接地；岩面直击和后续褶皱分别扣血 57、13，片间目标无伤。断块保留实际横向速度，由下压速度产生短促弹离，再各自贴合高低地面停住。临时岩唇退出后，同一段移动恢复通行。

分开复验两个边界：保持同一转动但整体抬高，悬空时没有褶皱和碎块；近片压地后令施术者真实死亡，远片停止，已脱落的近片仍落稳。首轮资源未打包，之后的落地段发现断块瞬停，均保留原记录。修正后正常、悬空、中断三个分段各自通过。

## C · 材料交接、偏脊与正式存读

普通施放没有地块许可时，两片照常翻落、起褶和碎裂。即使明确拒绝，也不会写入永久地形或扣掉岩量。许可只放行近片实际接触的 `(67, 72)` 格时，该格正式抬升一级且只发生一次：扣除近片 `0.625` 岩量和约 `0.06025` 的原支付份额，无许可的远片保留原岩量。已有地形法术未指定许可要求时，仍沿用原来的条件。

[偏脊派生](构造输入/山河叩首·偏脊.json)只转动近片的底轴与俯压方向。实放近片从 `(67, 72)` 改落到 `(70, 71)`，远片的实际接触点保持不变。正式存档重开后，两份完整构造、派生来历、人物学习和抬升后的地块均恢复，临时岩体不入档。重开的派生仍可独立改动并编译。原版按地块类型重建高度，因此重开验证以持久化的地形层及其规定高度为准，无需手动迁移。

原版和 Worldfall 各有一段约 3.93 秒的常速录像，依次显示抬起、俯压、接地起褶、碎块落稳和清场。两段画面和实测索引位于本机 `~/.local/state/cultiway-dev/evidence/bowing-mountains-932/c/`，分别为 `native.mp4`、`worldfall.mp4` 和 `delivery.json`。录像使用固定场地和软件渲染，供查看招式和双视角表现；城市尺度和性能另有验收项。

验证按分段记录：地貌写入和材料交接在正式存档前通过，重开直接用了该份存档。初次断块检查和存读检查的失败记录均保留。
