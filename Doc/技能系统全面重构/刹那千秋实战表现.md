# 9.38 刹那千秋

以一处战场为中心，分几轮推进已经接触的对象。护持先承担一次实际冲击，之后的部位按各自接触次数侵蚀原装备、推进原人物年龄。相邻植被先枯后荣，再重复一轮。石造建筑从受损进入废墟，继续风化才清去废墟，在适用的原地块留沙。世界总时钟照常推进。

- [x] 地物规则。枯萎、复生和石造建筑风化均为可组合的世界作用。复生跳过自然发芽的随机等待，仍按原种群、占地和数量限制生长。实机通过两轮枯荣、受损、废墟、留沙和带外对象保持。
- [x] 组合与画面。原术的护持、甲衣、人物、植被和石屋随实际变化给出反馈。中断后停下尚未施加的阶段，已有改变保留。停荣改造按不同节奏实放，保留原资料。
- [x] 整项交付。原术和派生分别实放，正式存档读回两招、原人物年龄和耐久、生长结果及建筑残留。重启验证未完成阶段没有重放，原版和 Worldfall 各有一段完整原速录像。

| 画面 | 对应的实际结果 |
| --- | --- |
| 错开的石质印片 | 交代各轮作用的位置和先后，与当前部位一起进入及退去。 |
| 枯叶与抽芽 | 原植被失去生命或真正长出新的植被后出现。 |
| 甲片上的旧痕 | 只在选中装备的原耐久确实下降时出现剥落。 |
| 人物衰败 | 随实际增加的年龄逐轮出现，人物年龄由原版保留。 |
| 砂砾与废墟 | 真实受损后有剥落，确认废墟消失且底层可用时留下一格沙。 |

原术实机中，护持先吸收约 132 点伤害，目标尚未掉血或老化。之后原人物年龄从 18 增至 54，原铁甲耐久逐步由 100 到 76。同一根部两次枯死并长出新植被。石屋交由原版切入废墟，继续风化时原址留下沙。首次脚本取样跨到了下一阶段，修正取样后通过，初次记录保留。

中途撤销终止了尚未兑现的阶段，先前改变的年龄和耐久保留。正式档保留原术与「停荣」。读回后实际施放「停荣」，它少一次复生和终末风化，场地因此留下空根部与真实废墟。

同一次原术在进行中和完成后各存了一份正式档。重新启动游戏读回时，进行中的档保留第一轮变化并停在当时的结果。完成后的档保留原人物、铁甲、长出的原版植被和石屋原址的沙地，两份档都保留原术和改造。

两段实战录像各约 6.05 秒。Worldfall 首次开场房屋尚未全部显示，补录等场景就绪后开始施放，原石屋、废墟与原地沙都可见。初次记录、复验、原始帧和正式世界收在开发环境的 `evidence/moment-of-ages-938/delivery.json`。
