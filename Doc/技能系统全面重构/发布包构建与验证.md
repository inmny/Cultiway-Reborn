# 发布包构建与验证

## 发布内容核对（15.09）

从已推送的 `codex/dev` 已知提交构建候选包。只加入现有打包入口规定的源码、正式资源、语言、依赖、许可和发布声明。验证包内文件与提交逐一对应，排除调试工具、测试世界、临时生成输出及本机配置。保留包、文件清单、校验值以及形体和着色器的制作来源。支持平台的构建、目标游戏实际加载和干净安装将在后续条目验证。

PowerShell 可用时沿用 `pack.ps1`。Linux 环境可按同一根目录清单从指定提交生成压缩包，输入为 Git 中已提交的文件。

```sh
git archive --format=zip -9 --output="$archive_path" "$revision" -- \
  Assemblies Content GameResources Licenses Locales Source \
  mod.json icon.png default_config.json LICENSE
```

形体制作源见[制作入口](../../Scripts/CombatModelStudio/README.md)。三平台形体和着色器资源由 [ShaderBuild](../../Scripts/ShaderBuild) 内的构建入口发布。音画资料仍采用各资源目录中已有的原始数据、许可和制作程序。

本次候选包来自 `codex/dev` 的 `5359c7f9`。压缩包内的文件与该次提交逐字节一致，清点六个三平台资源文件及七个正式依赖。验证没有大小写冲突、测试世界、调试连接工具或临时依赖，默认配置中的 API 密钥留空。首次清单误把正式法宝目录当作本地输出目录，核对打包根目录规则后重新检查，同一个包通过。这个候选包用于发布阶段验证。[候选包](/home/inmny/.local/state/cultiway-dev/evidence/release-package-1509/Cultiway-0.0.29.zip) · [校验结果与来源](/home/inmny/.local/state/cultiway-dev/evidence/release-package-1509/delivery.json)

## 三平台资源（15.10）

用发布分支上相同的制作源，在单独的 Unity 工程构建 Linux、Windows 和 macOS 的形体与着色器资源。保留构建日志、各资源的校验值及游戏加载路径。复用一份独立 WorldBox 安装验证实际读取 Linux 资源。Windows、macOS 实机或其他模组兼容组合的范围以实测记录为准。

Unity 2022.3.60f1 已构建六份资源。Linux 原版 WorldBox 0.51.2 在独立游戏目录中由 NML 加载重建资料，实际形体清单通过。Windows 和 macOS 本轮已构建，实机仅覆盖 Linux 原版。Worldfall 的视角与画面验收见后续条目。

重建形体描述的差异包括默认值、数字写法，以及少数部件按现有制作源导出的额外远景网格。重建结果用于本项加载检查。后续正式安装使用 15.09 已核对的候选包及其形体描述。[三平台指纹与加载结果](/home/inmny/.local/state/cultiway-dev/evidence/release-platforms-1510/runtime/resources/bundles.json) · [形体对照及构建日志](/home/inmny/.local/state/cultiway-dev/evidence/release-platforms-1510/form-compare.json) · [实机结果](/home/inmny/.local/state/cultiway-dev/evidence/release-platforms-1510/runtime/resources/result.json)

### 安装和继续使用

1. 将 [Cultiway-0.0.29.zip](/home/inmny/.local/state/cultiway-dev/evidence/release-package-1509/Cultiway-0.0.29.zip) 解压到 NML 的模组目录。本次实机路径为 `WorldBox/Mods/Cultiway`，该目录直接包含 `mod.json`、`Source`、`Content` 和 `GameResources`。
2. 使用 NML 启动并启用修仙模组。本次通过的是 Linux 原版 WorldBox 0.51.2 与 NML `10c5577` 的组合。Windows 与 macOS 提供已构建的资源，其实机范围见上文。
3. 在游戏中正常打开受支持的正式旧世界，查看恢复提示。需要转换或局部恢复时会保留原档副本。确认世界后可另存并继续游戏。现有预览旧档与正式版本的支持边界见[正式样板说明](../../Scripts/WorldSaveTests/Fixtures/README.md)。
