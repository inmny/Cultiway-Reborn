# 技能接入手册

新增法术先确定实际来源、支付、目标和作用。玩家与修士自主使用都经过主动能力入口。同一份构造可配不同形体、材料、词条、轨迹和触发条件，修士也能通过已有创法规则保存自己的成品。

## 新增通用操作

可参照已经发布的「转折」操作。它让正在飞行的部位转向，再由成功结果驱动后续改质。

1. 给操作种类追加稳定编号。转折在 `ConstructionOperationKind` 中使用 `Deflect = 13`。已有编号保留原含义。
2. 在 `ConstructionOperations` 为该种类登记真实参数、输入、输出及需求。转折输入一个实际部位，读取三轴 `Vector` 和坐标约定，输出同一部位和 `deflected`。
3. 在 `AbilityCast` 的操作注册入口加入对应实现。转折由 [AbilityCast.Deflection.cs](../../Source/Core/Skills/AbilityCast.Deflection.cs) 编译为固定转角并应用到当前位置、速度和朝向。失败时返回中断。操作需要地形写入、伤害或资源改动时，走正式提交接口。
4. 用构造复现作用和停止情况。[折向续行](构造输入/折向续行.json)保存真实飞行、延迟 0.5 秒转折和依赖结果的改质。以一次成功、一次拒绝及结束作为基础检查。涉及余力、费用、控制或正式资料时，同时验证这些结果。

现有可用操作从 `ConstructionOperations.All` 读取。操作字段、输出和状态约定详见[操作输入输出](操作输入输出与需求.md)及[共用操作登记](共用操作登记与转折.md)。

## 接入有厚度的有限射线形体

制作例子从 [forms_ray.mjs](../../Scripts/CombatModelStudio/forms_ray.mjs) 的 `makeRay` 开始。`energy_ray` 使用一个封闭胶囊主体，制作轴 `+Z` 指向末端，半径为 0.12。起点和末端分别由 `origin`、`extent` 控制，网格权重和真实作用段都使用这两个控制。结构声明提供 `span.length`、`span.radius` 与 `span` 伸展能力，因此可随距离伸缩，同时保留厚度。

新形体使用新编号并标明部位、表面和控制来源。将制作函数接到 [forms.mjs](../../Scripts/CombatModelStudio/forms.mjs)，先生成制作资料，再按[现有资源构建入口](../../Scripts/CombatModelStudio/README.md)发布形体说明和三平台资源。确认 `FormResources.Load` 能读取新编号，再用构造选中该资源。现有射线的最小输入如下。

```json
{
  "Version": 1,
  "Id": "Cultiway.Guide.BoundedRay",
  "Name": "有限射线",
  "Lifetime": 1.4,
  "Resource": "wakan",
  "Cost": 7,
  "Power": 8,
  "Use": { "Channels": "World", "Target": "Point" },
  "Binding": { "Anchor": "Source", "Follow": true, "Height": 0.4 },
  "Root": {
    "Id": "channel",
    "Form": "energy_ray",
    "Matter": "physical",
    "Operations": [{ "Kind": "Ray", "Ray": { "Length": 8, "TurnRate": 90 } }]
  }
}
```

检查近端、末端、8 格最大距离和半径外的安全区。验证目标更近时实际长度缩短，改变材料和转向时两端视角共享作用位置。将 `Form` 换成缺少伸展声明的 `sword` 可复验编译拒绝。[已有射线复验](../../Scripts/SpellDemos/verify_ray.py)

## 升级既有资料

构造成品使用稳定编号，修士的学习关系引用实际成品。资料结构变化时，在对应区段登记相邻版本转换，并给新定义明确默认值。存档内已经受理的创法请求继续沿用冻结的生成规则、种子、费用和结果。临时施放由世界生命周期管理，存档保留已确认的世界结果和长期进度。

升级时先保留原档，再转换副本。无法恢复的部分写明原因，其余内容继续加载。用原存档或固定旧格式夹具验证转换、原档校验值、继续使用和改版后重新保存，涉及跨进程恢复时用新的游戏进程读回。[资料升级与恢复示例](构造编号与资料版本.md#相邻格式转换1210) · [正式存档复验](../../Scripts/WorldSaveTests/README.md)

## 在独立游戏演示

复用 [develop 的独立游戏入口](../../.agents/skills/develop/SKILL.md)运行命令。先导出能力清单，再按编号选一个。录像与资料应保留同一次实际施放的来源、费用、有效区、结算和结束。

```sh
dev.py exec -- python3 Scripts/SpellDemos/demo_all.py --inventory --output /tmp/cultiway-inventory
python3 Scripts/SpellDemos/build_ability_inventory.py /tmp/cultiway-inventory/inventory.json
python3 Scripts/SpellDemos/build_ability_inventory.py /tmp/cultiway-inventory/inventory.json --entrypoints

dev.py exec -- python3 Scripts/SpellDemos/demo_spell.py Cultiway.Fireball --variant 0 --cases base --view native
dev.py exec -- python3 Scripts/SpellDemos/demo_all.py --scope base --cases base,modifiers,trajectory --view native
dev.py exec -- python3 Scripts/SpellDemos/check_skill_changes.py resources
```

把有限射线的输入存为 JSON 后，可用 `demo_spell.py --construction <文件> --aim-offset 8 0` 验证。多文件使用 `demo_all.py --construction <目录>`。需要对照三维或第一人称时选择已经安装 Worldfall 的独立环境，并分别使用 `--view worldfall` 或 `--view firstperson`。[演示参数与复验选项](../../Scripts/SpellDemos/README.md) · [演示入口和记录说明](演示入口与能力目录.md)
