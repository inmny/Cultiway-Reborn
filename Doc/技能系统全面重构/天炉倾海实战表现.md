# 9.29 天炉倾海

整项交付条件：有内壁、厚口沿和真实出口的青铜炉先升起，再倾倒。实际口沿朝下时才释放已计量的熔融材料；材料从炉口沿真实路径落下，触地后才铺开并随地势分流。高温、推压、暗壳、破裂和余火分别对应实际作用。炉身扶正、被打断或被破坏时停止供料，已经流出的材料按自己的状态继续冷却和收束。原招与一种改变出口布局的派生都可保存重开，原版和 Worldfall 各交付一段常速实机录像，整项通过后合并推送。

## 第一段实机结果

- 已通过：青铜炉先抬高，口沿朝下后，三处出口在约 1.32、1.51 和 1.66 秒各出一股。出流点和方向与当前炉沿对应，空中各自坠落，三次实际触地后才铺成薄层。中间一股流向两侧，侧股分别沿各自低处前进。总量从约 3.92206 到 3.92206。
- 已通过：保持直立不出流，可自然结束并再次正式施放；无法证明先飞后落的三维投送仍会被拒绝。正式施放每次只扣一次真元。
- 开发截图能看到抬炉、倾倒和铺地。原版俯视里青铜炉偏暗，三个流头偏像分开的团块；接下来随热度、凝壳和余火一起打磨，最终仍以两段连续录像验收。此次使用软件渲染，没有验证帧率。

## 第二段开工条件

先做可验证的材料变化：较早落地的熔料从薄边散热并形成铁壳，未冷完的部分仍能推进。晚到的热料与壳体有真实接触才可能推破；同一处熔料和壳的体积须能对上。只在有余热或实际燃料的位置显示余火。再验证一组断供：原炉受真实阻挡或销毁时截断后续出口，已离口的一股继续落地和冷却。复用第一段场地，现有直立、正常抬升不重复整套验证。双视角录像及原招和改造版的正式存读集中到第三段。

## 第二段实机结果

- 先落地的一股在约 2.25 秒已形成固定铁壳。下一股实际触地后，在约 2.45 秒于两股重合的低处打开缺口。破壳消耗后续热流的热量和推力，核对了液态熔料、铁壳与散失热量的合计。全部凝固后余火熄灭，冷壳保留至招式结束，不再造成熔流伤害。
- 空中的流束和落地后的液层分别在实际接触时扣了 36 点生命。施术者在约 1.54 秒死亡后，炉身和待释放的两股一同消失；已离炉的一股正常落地、凝固、撤去。直立不出流沿用第一段的验证。
- 本地证据：`~/.local/state/cultiway-dev/evidence/sky-furnace-929/b/progress.json`。断供单独通过；调整破壳时的推力交接后，复验了冷却破壳、三口出流和实际伤害。软件渲染仅用于核对行为和画面。

## 第三段开工条件

用同一炉、人物和场地做一份偏口构造：保留中央口作为对照，把第二股改从一侧炉口离开，核对两次真实落点和冷却覆盖与原招的区别。通过正式存读保留两份构造的完整材料设置、学习记录和改造来源；读回后改动偏口构造并再次正式施放。存读沿用共同规则，保留可施放的构造；施放中的流体和铁壳随招式回收，不在读档后重新生成。

最后打磨炉身和流束的辨识度，检查两套画面中的实际出口、触地、结壳、破裂和收尾，原版与 Worldfall 各录一段按实际游戏时间播放的视频。前两段的验证只补受本段改动影响的部分。正式存读、录像和证据索引齐备后才勾选 9.29，整项合并推送。
