# 9.09：共用形体的组合质量

整项验收按三批进行，一起完成才合并推送。复用已有地图、人物和模型，不新增身体或装备矩阵。先从游戏实际发布的目录取形体全集；无网格资源单列真实用途，不以空画面通过。已有同一规则的有效证据直接引用，只有受改动影响的场景重测。

| 批次 | 要保持的游戏行为 | 必要验证及交付 |
|---|---|---|
| A 换材与分层 | 换回原材质应保留制作时的亮芯、深层、边缘等细节。换成另一材质，真实材料部件跟随；原来没有材料槽的形体仍可换材，多表面主体只替换主体外观，保留独立层次。手柄、泡沫、镜面等带独立用途的表面不被统一染掉。显式旧表面、作用范围和原保存不变。 | 全部发布形体读取部件与表面；对有槽及无槽的分层主体各用一个游戏场景，看原材料、异材料和换回。取相同视点画面、实际提交表面与材质，核对实际形体未变。留复验及结论。 |
| B 布局和轨迹 | 用同一个共用形体重复布置、贴地或循不同轨迹，部件不能散架、压成片，真实作用和图上形体仍共用同一结构。 | 发布全集按刚体、带骨架、贴地、逐段、流体和射线登记实际使用的变更路径。用已有输入，在每条共用路径上检查至少一个常见用法和一个最易失真的变体；体积和质感有疑问的具体资源进入现场对照。 |
| C 尺度与流派差异 | 近、常用及远景保留主体厚度、辨识轮廓及本流派特征，远景简化不把不同流派画成同一个外形换色。 | 逐个核对发布形体的近远形体和已有取景证据，补缺失对照；分组留原版和 Worldfall 的代表帧。此项完成后关闭 9.09；连续录像和第一人称联合验收仍归 9.10，流派造型制作归之后相应条目。 |

## A：换材选择共同表面

绘制按部件选择表面。旧资料的明确整件覆盖仍有优先权。主动随材料时，先辨别制作表面是否是同一材料的细分；同材的亮芯、暖边、暗层、层理保持原样。有材料槽的形体只替换已声明的部件；没有槽的形体沿用第一种制作表面作为可替换的主体表面，同表面的分件一起换，其他表面保留。独立材料保留同一个选择，流层分组按实际绘制的表面比较。两端读取同一份结果，玩法的材料、伤害和作用范围仍独立由原规则确定。

模型目录提供 101 个数据文件，游戏另发布一份运行时生成的火体；其中 `pivot` 和 `world_domain` 各自只有锚点或范围用途。`catalog.json` 记录每个形体的部件用途、表面、尺寸、动作、作用区和支持的变化。目录记录用来核对覆盖及选取相同路径，不代表画面或玩法已逐一验收。

实机分段验证已通过：阳法同材时保留亮芯和发光外层，换为土质时材料槽跟随，换回即恢复；毒雾只换外层，内部毒芯保留；剑刃随材质变化，皮革手柄保持。另复验实际水体凝冰，法术退出后独立冰体仍保持冰面，到期清除。普通表面覆盖和自然结束同样通过；本批未更改网格、伤害、作用范围或存档格式。

独立游戏的实际发布目录有 102 个形体，其中 100 个包含可绘制网格。目录核对、三种换材、独立冰体为分别通过的三段。首次目录检查漏计运行时火体；首次换材脚本因 C# 元组命名未启动。两次结果均保留，修正后只补跑对应段。原版及 Worldfall 代表帧、运行输入和结果收录于本机 `~/.local/state/cultiway-dev/evidence/form-combinations-909a/delivery.json`。开发构建通过；代表帧用于确认换材，整体造型质量仍待后续核对。

## B：排布、轨迹和共同作用区

以 A 的实机全集登记每件资源采用的路径，100 件可见主体都能做整体变换。其中 47 件还使用骨架或制作动作，12 件声明贴地挠曲，4 件支持逐段成形，6 件支持射线纵向伸展。同一资源可以落在多个组。普通刚性承托由构造选择地面响应，真正流层由构造的液态材料和实际流散操作决定，因此这两种运行方式不从模型名字猜测。两个无网格资源继续只登记锚点和实际范围。

| 共用路径 | 常见及易失真场景的证据 |
|---|---|
| 整体、排布 | [六种分布](选择与子结构分布.md#c3交付六种来源的双视图连续画面)已有两端正式录像。补验三剑成列后共同折返，保留每件的全部作用段。 |
| 骨架 | [连续控制](连续形体制作与运行.md#具体说明)有水鲸原地游动、尾部挂点与作用端点记录。补验三鲸成列、游动不停止且同时随父体转弯。 |
| 承托和挠曲 | [地表承托](地表承托与贴地水层.md#当前验证)已有刚性枝体沿地和坡面柔性水层首尾共同承托；[沿地与混合曲线](可编辑曲线与轨迹接入.md#b11交付沿地追踪与地面游剑)另验证途中转向、显示底面与作用底面。 |
| 逐段成形 | [逐段成形](分枝曲面与逐段成形.md)已核对四种实际资源、半成形和缩放。未形成的段不提前出现或作用，部分及完整形体同用一个边界。 |
| 真实流层 | [贴地后流](地表承托与贴地水层.md#实机画面与继续推进)有真实受理和接触；另引用原流散的分流、高障碍绕行、薄层高度内外和[延迟投送](可编辑曲线与轨迹接入.md)的实际继续及移交结果。 |
| 射线 | 原固定与随动光束已有沿线扣血、外侧无伤、相同次数结算；[短束与放大](主体轮廓与视距.md)确认保留亮芯和真实外缘。 |

补验实机沿用同一地图和人物。剑和水鲸各经正式入口施放一次，三份排布共用局部坐标；转向约 81° 后，两侧各距中间格 2 格，各轴保留原设倍率。逐件用发布姿态和资源原端点重算作用位置，最大误差不到十万分之一格。中间作用面内各确认一次实际扣血，场外目标无伤，整列按原时长自然退出。原版保留转弯前画面，Worldfall 保留转弯后画面；用于核对组合形体的功能和轮廓。证据索引为本机 `~/.local/state/cultiway-dev/evidence/form-combinations-909b/delivery.json`，包含发布路线清单、切换画面和上表的实际结果文件。没有修改游戏代码或资源。

B 完成，9.09 仍开放。C 将逐件核对近、中、远显示的外轮廓和厚度。旧细节级验证仅记录当时发布的 16 件，不能代替现在的 100 件：先复用其边缘、权重和两端取景办法，再按流派在同一场景分组补拍，直接比较相邻距离下的主体轮廓。形体有缺口就在 9.09 修正，招式独立演出仍按各流派后项打磨。连续录像和第一人称的联合验收留给 9.10。
