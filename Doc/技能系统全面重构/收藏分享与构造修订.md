# 收藏、分享与构造修订（8.11）

开工前固定以下结束条件。8.11 在同一个已有测试世界中复用水剑；只有本项的完整路径跑通、文档和复验入口齐备后，才合并到 `codex/dev`。

- **副本和替换：** 沿用正式的“学会独立副本”和“替换此人原法术”。副本取得新编号，修订从 1 开始；替换取得新的构造编号，修订在原术上加 1，并只换选中修士的掌握关系。两者都要保存依据的旧编号和修订。其他修士仍用原术；重新打开改造以当前修订为起点，不能串改旧资料或绕过冷却。
- **收藏：** 万法阁提供构造收藏入口，保存完整、已经确认的修订，以编号和修订识别。反复收藏同一修订不产生重复；编辑后明确收藏的新修订不改写旧收藏。不收藏未保存的草稿，不因点击收藏或取消收藏改变人物掌握。收藏复用万法阁的本机长期保存入口，换世界仍可查看；取消收藏不删除世界法术。
- **导入导出：** 通过万法阁复制或粘贴带明确格式版本的构造文本。同一份文本往返保留编号、资料版本、修订、原术关系及完整施放规则。导入走正式编译及资源检查；完全相同的构造可以重复导入，编号相同而结构不同、版本不支持或缺依赖时说明原因，保留原目录与收藏。导入只使构造可供使用或编辑，不自动授予人物，也不把外部作者的数字编号当做当前世界的人物。导出的构造文本只包含定义，不包含运行、掌握、资源余额或装备状态。
- **必要验证：** 从万法阁复制并收藏同一水剑，导出后走一次有效导入、一次编号冲突拒绝；关闭再打开构造窗口，替换并再次编辑，检查原术和修订关系。正式保存后结束游戏，用同一份世界档及本机收藏重新启动，核对编号、修订、掌握和收藏原件。留存中英文实际窗口与复验入口，完整录像和极端窗口尺寸留给对应后项。

本项只接通已经确认的构造资料。旧蓝图迁移、以后新增的格式迁移、批量导入及外部资源分发各沿其原条目处理。本项无需创建更多世界、身体、兵器或法术样本。

## 资料边界

- 改造窗口的“收藏或分享已保存修订”读正式构造副本；人物的当前草稿、施放状态和余额都不会进入输出。万法阁“新建 → 构造收藏与分享”可重新载入任一收藏，也可从剪贴板读取并确认导入。
- 本机收藏文件 `Saves/global/wanfa_construction_favorites.json` 由现有保存管理器负责，独立资料版本为 1。旧万法阁蓝图库不换版本。收藏保存的是完整修订，不是指向当前世界某个法术的快捷方式。
- 分享格式 `Cultiway.Construction` 独立使用版本 1；其中的构造资料版本与作者修订各自保留。导入只登记经正式检查的原样资料，不触发补全、重新计价或自动学习。同编号冲突不以修订更大为由覆盖。外来作者编号保留为来源事实，不映射到本世界人物；后来明确另创或替换时，新的修订记下实际改造者。


## 实机验证

- 保存段：用同一份水剑经万法阁按钮完成收藏、独立副本、两次替换、重新打开及剪贴板往返。确认导入前目录不变；相同内容重复导入复用原件；同一编号改动消耗后拒绝覆盖，不改原收藏。保存世界前确认其他修士仍掌握原术。
- 冷启动段：退出保存进程，使用同一份测试世界档和本机收藏启动。读档前已能读本机收藏；读档后五份完整构造、两位修士的掌握关系和剩余冷却保留。重复收藏没有新增条目，取消收藏后世界仍能读取第二修订。构造和掌握保存区段没有跳过；旧测试世界的状态与物件引用另有恢复提示，原样保存在 `save-skipped.json`。
