# 9.31 森罗倒生

整项交付条件：倒悬树体先落定，主根和细根分批向下长出。根尖必须接触实际地面并建立支撑，才允许相关根群抓持并收拢目标；伤害来自实际根形接触和挤压。断开承力根、目标挣脱、来源消失及自然收尾，都解除相应抓持。原招和一个改分枝或支撑布局的派生能通过正式存读；原版与 Worldfall 各有一段常速录像。三个分段可以各自提交，以上齐备才勾选本项并合并推送。

| 分段 | 要改变的行为 | 必要验证与交付 |
| --- | --- | --- |
| A · 倒悬、生长和钉地 | 先看清完整树冠和倒悬树芯，再从树芯向下长出承力主根，侧根从对应枝节展开；未长到的部位没有接触形状。实际碰到地面的根尖建立支撑，收势时释放。 | 复用一个场地和现有人狼样本。核对生长中段的模型和实际接触范围、同场高低两处地面的接触时点，以及够不到地面的根尖不钉地。此段不做抓持。留下可施放构造、复验入口和代表画面。 |
| B · 抓持、收拢和解除 | 只有已取得支撑、又实际接触目标的根群才能抓持。根形逐渐收拢，沿实际接触推挤。切断某条承力根只解除它维系的抓持；挣脱和来源失效也能明确归还控制。 | 用同一场地看一次完整抓持与自然解除，并分别检查断根、挣脱及来源失效。未接地的根或没有进入作用面的旁侧目标不会受控。核对结束后能恢复移动和再次施放。 |
| C · 改造、存读与录像 | 以同一套树形、分枝和支撑规则做一个派生，让改造真正改变哪边先接地和能抓到谁。正常结束后根体松脱回收，本项采用临时根系。 | 正式保存重开保留两份构造和人物学习状态，改回一个参数再施放。集中录制两种视角的倒悬、生长、钉地、收拢、断根或自然松脱。交付录像和实测索引，齐备后合并推送。 |

城市与世界尺度、永久木结构和新的场地样本留给对应条目。本项先用已有场地核对同一根形能否从视觉生长一路驱动实际支撑、作用和收尾。

## A 已完成：倒悬、生长和钉地

树冠独立落定，三条承力根从各自树节生长。模型和接触形状一起伸长；每条根可指定自己的「地块接触事件的形状」，本招只接受根尖。根身先碰到地面时不会提前定住，根尖接地后根身保持该次接触的实际长度和位置。旧构造未指定时仍使用全部作用面。

复用同一场地分别实测原招和短根：原招主根与两侧根约在第 1.56、1.90、2.07 秒钉住，两侧接触高度相差约 0.25 个世界单位；短根够不到地面，另外两条照常钉住。两次均正常退出，未对人物造成作用。保留了三维旁观的生长和钉地截图、实际接触记录及初次脚本和场地检查的失败记录。独立游戏的证据索引是 `~/.local/state/cultiway-dev/evidence/hanging-tree-931/a/progress.json`，复验命令见 [演示入口](../../Scripts/SpellDemos/README.md#森罗倒生931)。

本段不接管目标；B 的抓持、收拢和解除，以及 C 的派生、正式存读和双视角常速录像仍须完成。
