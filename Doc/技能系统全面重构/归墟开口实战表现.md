# 9.39 归墟开口

地面上方撕开有厚边和深度的裂口。外沿先和实际碰到的术式交锋，并侵蚀已落在地上的材料。裂口张开后，里面的涡流把获准移动、已经受蚀的散件拉长并绕向喉口。只有真正到达喉口且能通过的材料才消解。人物与落地兵器沿普通受力规则移动，继续使用原版各自的身份和归属。

- [x] 外沿和人物。共同交锋里，敌术前片受蚀，未触支撑保留承力。人物受伤并被拉近，原版铁剑经过真实卷起和落稳，保留同一身份及耐久。
- [x] 内层和退场。实际受蚀的生成散件沿同一身份位移和拉伸。小块抵达后消解，大块和生成剑保留余量。敌方材料受蚀后保持位置，范围外材料完整。撤销后已发生的位移和损耗保留。
- [x] 整项交付。原术与狭喉均经正式入口使用。两份档分别读回卷动中与退场后的真实材料，冷启动还原当时姿态和余量。原版和 Worldfall 均有完整原速录像。

| 画面 | 对应的实际结果 |
| --- | --- |
| 不规则外唇 | 刻出攻击面所在的边缘和张开位置。 |
| 暗腔与旋转内层 | 深口有可读厚度，内层先收窄，外唇随后闭合。 |
| 拉长的破片 | 同一原材料被移动和变形，画面、接触与保存沿用该姿态。 |
| 倒卷或滞留 | 有余量的对象继续由原世界维护，喉口内成功消解的份额结清。 |

实机看到裂口三层先张开，闭合时喉口先收窄。小石块在实际抵达后消解，较大的受蚀石块和生成铁剑继续作为原材料存在。全程核对原体积及原支付份额，余量与已经发生的损耗之和保持，消解没有产生回能。撤销试验在散件已经移动时结束，随后原位置和控制正常交还世界。

第一轮场景中大块按实际尺寸折算为约 72 格，超过归墟本次容量。保留该轮检查和当场读取。补验保持大块外形，使用容量内的实际体积，确认接纳后仍会受喉口尺寸约束。复验见开发环境 `evidence/returning-abyss-939`。

两边术式使用正常受理和支付。敌术前片被外沿消耗，未触支撑仍承力。人物经过实际碰撞受伤，并由范围受力拉近。铁剑走原版物品的落地、起飞和落稳流程，卷动期间仍是同一件无主原物。外沿首轮实际交锋通过但未触及人物，调整外唇实体高度后复验。

一次正式施放分别保存了卷动中的姿态和消解后留下的世界。读回两招及退场后的余料，原身份、姿态、体积、归属和支付份额都保留。「狭喉」读回后实放，同样尺度的小石块受蚀和移动，最终作为真实余料保留。

原版和 Worldfall 录到同一场战斗的外缘交锋、散件卷动、到达消解和外唇闭合。每段原速成片约 6.02 秒，时间记录列出了对应的交锋、命中、消解和余料。

新进程读回卷动中的档，散件从保存位置继续原本独立侵蚀。深口与临时牵引关系已清空，余料保持原来的身份和位置。读回退场后的档时，实际消解的小块仍然缺席。两种录像、正式档、冷读和先前失败保留在开发环境的 `evidence/returning-abyss-939/delivery.json`。
