# 条件与传播（5.18）

5.18 让同一份法术在实际接触、损耗、成长或传播到达后，继续同主体操作或展开后续部位。沿用[部位事件](事件驱动的部位生成.md)、[损耗与成长](损耗与成长条件.md)、[地表传播](接触发力与宏观传播.md)和[讯号的真实收件](施加与解除作用.md#d-真实送达与可查询条件开工前固定)，不另建一套只用于演示的触发器。

| 批次 | 结束条件 |
| --- | --- |
| A 地波到达 | 能以波面实际抵达的地面路程开启部位及后续操作；验证到达时点和位置、途中断路、回退后的同一结果、结束再用。 |
| B 介质与送达 | 补齐已有传播路径中可复用的确认结果，至少覆盖水域传导和实际人物送达。采用对应的真实结果、归属及原有去重，不把搜索候选、可视范围或发出意图当作到达。 |
| C 顺序与终止 | 用普通构造串联接触、损耗或成长、传播到达和后续结果；核对同刻顺序、取消、上游失效和自然结束。实测缺口才改共同规则。更广泛的关联、反射和重复事件矩阵留在 6.16。 |
| D 编辑、创作与交付 | 接入现有条件窗口及可用的独立创作和派生；正式存读保留完整新旧结果，旧请求不重抽，临时传播在读档时不重放。交付原版与 Worldfall 连续实机、正式保存结果和索引，整项完成才合并。 |

## A：地波到达（开工前固定）

- 要改变的行为：指定一个确实能开启普通地表传播的部位，并填写正的地图格路程。传力真正到达第一个达到路程的可作用地块时，按同一运行时点、地块中心和表面高度通知。起点、仍在入口安静区的格子、只是计划会经过的格子和随后断路的分支不通知。距离取已走的地面路程；同刻顺序沿用地表路线已有的稳定格子顺序。先记实际花费与损耗，再接受到达，最后处理来源归零结束。完整动作和新部位各用原有一次执行规则。取消后不补发，到整招上限后也不发。
- 必要验证：只复用已有平地、一次地波和一组友方人物。检查两段不同距离按先后开启、事件位置落在实际地块、条件操作只执行一次，等待期间无早到；在途中切断路径，已发生的近段保留、远段不出现；再施放恢复。另用同一场景的数值快照核对回退重跑，及编译拒绝不能传播的来源。只检查新触发路径，不重跑大地图或身体装备样本。
- 交付：共用正式执行、限定复验入口、实际记录和中文本地提交。窗口、创作、正式新旧存档和连续录像集中到 D，不单独合并。

A 已完成。一个真实足底入口确认第 3、7 格路程在施放后 0.825、1.325 秒开出对应部位；近段同时换材，后续地块不重复触发。预测回退重跑保留同一时点、位置、扣力和操作，正式运行独立确认结果。实际水隙保留近段并截断远段；接回后同编号重新支付并到达，提前取消和自然结束都不补发。不能实际传播的来源在编译时拒绝。

首次实机发现同一部位混用定时与条件操作会在正式登记中用错索引；改为按已编译的声明条件对应。修正后 `all` 一次通过，首次失败仍保留。入口与结果见[复验说明](../../Scripts/SpellDemos/README.md#518-a-地波实际到达)及 `/home/inmny/.local/state/cultiway-dev/evidence/ground-route-a/delivery.json`。5.18 继续 B，不在 A 单独合并。

## B：水路与人物送达（开工前固定）

- 水路：本次实际扣力、核实连通并完成结算后，只在确有有效水格时，按已确认次序的最后一格水面通知一次。脉冲未到时、空水路、未通过校验的分支不通知。不同脉冲仍按原规则结算，后续部位或操作各按原一次执行规则接收。旧导电步骤的输出与报价保持。
- 讯号：只有在真实收件人身上首次有效登记，或登记的发信人确实变更时通知，事件位置取实际收件人脚下。同一发信人刷新、接触落空以及仅发出意图不触发。身体、持物及普通部位复用原有实际作用，选择一个现成普通部位验证；本批不增加收件人查询字段、组队目标或新的讯号类型。两个事件均只回到当前有效施放，不能把结束或取消的来源重新开启。
- 必要验证：复用已有示例中的一条水路和一处收件位置，检查真实水路时点和位置、空水路、重复脉冲去重；检查真实送达、落空、同来源刷新及结束恢复。各选一个普通部位和一个操作验证接入；不重验旧水域和讯号的全部功能。
- 交付：共用正式执行、限定复验入口、实际记录和中文本地提交；复杂同刻串联留在 C，窗口与正式冷读及连续录像留在 D。

B 已完成。首轮实际导电与部位、换材同在施放后 0.26 秒，位置吻合最后一格水面；空水路没有事实，第二轮实际到达不重复开启。讯号只有登记到指定收件人才从脚下开启并换材；落空及同一发信人再次释放只保留原规则，同源刷新不触发，到期后可重新送达并自然结束。来源不具备对应作用时编译拒绝。现有导电结果及步骤的输出坐标保持不变。

首次缺少示例文件，第二次旧样例的人物入口未受理；改用显式输入和正式选点入口后，水路和讯号 `all` 同次通过，两次原失败仍保留。入口与结果见[复验说明](../../Scripts/SpellDemos/README.md#518-b-水路与人物实际送达)及 `/home/inmny/.local/state/cultiway-dev/evidence/network-arrival-b/delivery.json`。

## C：顺序与终止（开工前固定）

- 复用 A 的足底地波和一位友方人物，串起真实触地、已确认的近段到达、独立部位成形、同刻两次依声明顺序换材、最后对人物产生一次实际恢复。换材分别让不同的材料监听者认领，以核对同刻保留各自材料快照，最终材料必须来自后写的操作。用既有构造字段组合；只有实测不符才修共用规则。
- 正常使用要证明后续不早到、不重复，到整招结束时回收。再用同一输入缩短波源寿命：尚未确认的远段应取消；先前确认、独立且正在等待的近段可继续。主动取消整招则还未生效的近段与远段都不能再产生作用。验证采用原有正式施放、世界时间和结算，保留失败记录。
- 交付限定复验入口、真实事件及恢复前后记录、中文本地提交。只做这一个串联场景；反射、跨来源及更广的重复事件矩阵留给 6.16。编辑、创作、跨进程存读和双端连续录像继续 D。

C 已完成，一次实机覆盖全部三种情况。足底先触地，地波第 0.825 秒实际到近段，独立分支第 0.945 秒开始生长；第 1.135 秒同刻通知冰和铁两个监听者，最后保留铁，对实际接触的人物恢复 20 点生命且只做一次。波源缩短寿命时，已经接收的独立近段仍完成，远段没有补发。整招主动取消时，即使近段已收到事件，仍等待执行的分支也没有恢复人物。既有执行能满足这次组合，不改生产规则。实机结果见 `/home/inmny/.local/state/cultiway-dev/evidence/propagation-chain-c/delivery.json`，复验用 `verify_ground_route.py --section chain`。
