# 事件驱动的运动变化

## 本批范围

在同一实际部位上响应事件，接入停止、脱离、改变飞行及旋转。与上一批“事件后开始新部位”分别使用：本批不复制主体，不重置接触次数或作用量。进行中的生长、动作改写及其他世界过程继续按完整TODO推进。

## 规则

- 操作可以提供可选事件条件，使用与部位开始相同的来源、事件、延迟和材料筛选。只作用于已经存在的部位；同一事件刚确认开始的分支可以接收操作。
- 每项操作每次施放最多确认一次，延迟使用世界时间；At仍是该分支最早接受事件的时点。运行状态及待执行操作随同一快照恢复。
- 飞行改变使用实际当前姿态和速度，重新设置平移、追踪或已有曲线，不生成第二个形体；可以保留原速度，也可明确替换。
- 停止保持当前姿态、生长尺寸和内部形变。后续改变飞行只恢复整体运动；旋转可以使保持形状的物体在原地转动。
- 脱离保留实际位置、朝向和脱落点运动。父体结束时要立即解除连接；需要延迟飞行时，可以同一事件立即脱离，再延迟改变飞行。
- 飞行可提供加速度及明确的地图方向，支持真正的下落。可选地面停止由实际作用形状接触地图高度零平面决定，不以模型原点冒充着地。
- 操作执行前先保证该部位已推进到共同事件时点；事件来源和目标部位在编译顺序上的先后不改变结果。
- 数量复制及环绕重绑事件来源；完整历时同步修改事件延迟和加速度，急速同时修改速度和加速度。
- 旧正式资料的默认行为保留。材料变化的旧触发继续按原规则执行，新增条件与旧触发不得同时指定。

## 数据形式与兼容

`ConstructionOperation.When` 使用共用条件：`Source`、`Trigger`、`Delay`、`Matter`、`State`。开始新部位仍用 `Activation`，它另有放置方式。两者使用同一来源解析及监听索引，运行时按索引直接找到订阅对象。条件飞行使用编译后的独立参数，运行时不会再读取或修改原始资料。

`Stop` 追加为操作编号6，旧编号不变；新增条件、加速度和地面选项均可省略，正式资料版本仍为1。已有法术按原默认规则运行，用户无需手动迁移。瞬时施放依然不跨读档续行，保存的是构造、学习关系及既有支付和冷却规则；长期过程另行推进。

## 本批边界

- 本批接入停止、脱离、飞行和旋转；后续已接入[条件生长、动作切换和材料改变](事件驱动的成形与动作.md)，其余过程仍按全程TODO推进。
- 每项条件最多接受一次，不提供循环、条件组合、损耗阈值、成长进度或网络传播。未满足来源能力及无效引用在共同编译入口拒绝。
- 地面停止检查实际胶囊底部。稳定形状的直线加速下落拆到解析触地时点；旋转、曲线及持续形变使用受限小步中的形状接触近似，完整连续地形碰撞尚未完成。
- 地面暂为逻辑地图高度零平面，未实现坡地、水面、台阶、地形阻挡、反弹、滚动或永久残留。
- 并行对照只核对纯数值推进及回退一致性，不代表包含原版人物、伤害确认和绘制的整场性能。
- 沿用已有形体，本批录像用于核对过程，不作为城市级画面及最终美术验收。4.09及8.06保留待办，不能用几个成功示例替代整项范围。
