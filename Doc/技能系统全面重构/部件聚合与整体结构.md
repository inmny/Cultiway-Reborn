# 部件聚合与整体结构

## 范围

推进5.07：分散部件沿实际路径汇入父体布局，完成后随父结构整体运动，原有材料、作用量、身份和子结构保留。再次脱落继续使用已有解除连接及速度继承，不为剑阵或木甲建立专用执行类。

## 共同规则

- 新增`Gather`共用操作。节点的`Offset`及`Rotation`是散布起姿，操作的`Vector`是汇入父挂点坐标中的最终位置；可选`GatherRotation`指定最终局部朝向，缺省沿用节点原朝向。
- 操作须有实际父结构。父结构可以是无形组织支点，也可以是有真实模型、骨架和挂点的主体。汇入位置持续随父体及挂点运动，不在开始时复制一份随后失联的目标。
- 聚合保留部件真实大小，用连续平移和转动形成结构；不会把部件缩成点后换成另一模型。显示、挂点、作用形状和脱落速度读取相同姿态。
- 支持初始定时聚合，以及共同事件条件开始的聚合。条件操作从当时局部姿态继续，不退回出生位置；多个条件过程按已有资料顺序覆盖，仍只接受一次事件。
- 聚合是整体布局运动，与内部动作、材料定型、生长及形变维持分别计时。冻结可以保持形状，聚合仍可搬动这块形体；真正停止、脱落或结束后停止汇入，不暗中重新取得已经解除的连接和控制归属。
- 聚合途中有实际作用区，可受击及损耗；有效时段与聚合分别定义，不能用模型汇齐冒充已经命中。父体运动、汇入和脱落共享数值时钟与预测快照。
- 普通表单可增删聚合过程并修改目标位置、朝向、时长和条件；修士创作直接生成同一资料。正式格式1以可选字段和追加操作编号扩展，旧操作编号保持不变。

### 实现边界

节点的组织连接在构造中明确指定，聚合只改变这段连接中的实际布局，不猜测周围散兵或从世界中夺取器物。以真实世界物件为输入的回收与借用仍由对应来源玩法接入。

计划含聚合时才分配局部布局及预测前态；普通施放不增加聚合状态数组。每次汇入只保存起姿、目标和开始时点，运行不解释原始资料，也不逐帧访问Unity资源。位置与朝向采用同一平滑进度，关键开始、结束和转动速度进入现有时间拆步；实际挂点速度继续由同一姿态差取得。

初始聚合必须在计划脱落前完成。真实事件可提前停止或解除连接，之后不再自动汇入；条件聚合在仍连接时从当前位置继续，不能越过来源与控制归属合同重新接管已脱落部件。分裂、拾取真实物件、宏观地形后果及最终流派美术仍按对应任务继续。
