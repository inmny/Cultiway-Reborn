# 9.47 步法战技实战表现

沿用防御战技存下的两名人物和对练世界。使用现有根点、脚底承托、持物和动作收势。每招可以从正式入口单独学习和使用。

| 交付段 | 固定的游戏行为 | 必要验证 |
| --- | --- | --- |
| 斜撤转身 | 抬足后先退、再横移，踩稳后带动整身转向。收势保留实际位置和朝向。 | 选点施展，核对两段真实位移、固定承托脚、转向交回和再次移动。走过的人物无接触伤害。 |

| 越坎落步 | 蹬离地面后向指定方向跨出，经过地形变化仍以同一实际高度过程落脚。落稳时屈膝卸下重心。 | 复用这片地形验证起跳、越过低坎、实际落地。一次空中受力中断验证旧位移停止、人物最终回到实际承托。 |

步法和作用分别声明。斜撤转身和越坎落步只移动人物，沉步撞肩只由真实肩面结算。承托、碰撞和外力沿用共用规则。场景使用同一对人物，抓投与非人身体继续各自条目。

## 已通过的实机行为

- 斜撤转身先后撤约 0.192 格，随后侧移约 0.232 格。后撤期间承重脚的世界位置保持不动，换足后整身转过 78 度，收势方向交回普通人物。近旁的人物没有受到接触伤害。
- 沉步撞肩在向前移动约 0.318 格之后由实际肩面接触一次，目标受到伤害和推力。命中后从接触点收势。将原路线前方设为真实阻挡地块，再用同一人物和目标复验，根点停在墙前，目标生命值保持原样。
- 越坎落步先蹬地再越过低坎入口，实测最高离地约 0.336 格，向前到达约 0.712 格外的实际地面。落地后双足重新承托，归还人物控制。

改造窗口允许提高抬脚高度和改变侧程，原人物已学会改造副本。原人物、原招、副本、原铁锤和原铁盾已写入同一份正式世界档。

新进程正式读回两份完整招式和原装备。副本的抬脚高度为 0.103 倍体高，侧程改为 0.21 倍体高。实际后撤仍为约 0.192 格，侧移缩短为约 0.168 格。

同一把铁锤在跃落动作约 0.368 秒、人物实际离地约 0.237 格时命中。旧步法当场退出。人物承受实际余力，最后回到地面并保留原铁盾和普通控制。

## 验证记录

首次加载指出收势脚底不符合站姿，随后发现已有接地关键点不能直接换足底位置。改造姿态资料后继续使用共用检查。退步首轮取样在左足换起之后，空中受击首轮取样在刚离地时。最终分别以换脚前和实际命中时点核对，保留前次观测。

中英文截图取自正式副本的路线页，显示同一组编辑后的路径值。空白的早期截图保留在验证记录中，后续使用正常滚动位置重新取景。

原版与 Worldfall 各交付一段常速录像，顺序为斜撤换足、撞肩命中、墙前止步、越坎落地。各段用正式对练世界分别拍摄后拼接。拍摄时对练者收起铁盾以露出脚步和接触处。原版首次录像的测试墙缺少原版地图贴图，补拍改用实际原版山体，只在独立对练中临时启用阻挡。正式档、复验结果、截图和录像见 `~/.local/state/cultiway-dev/evidence/footwork-947/delivery.json`。
