# 创法重复控制与长期开销

本批完成7.06、7.07。比较的对象是生成结果的实际结构、作用和参数，名称或颜色不能作为新能力的依据。保存、玩家明确改造与自主创法的登记政策分别说明。

## 比较什么

先走同一正式编译入口，再建立一份小型比较资料。保留实际形体、材料、物态、嵌套结构、挂点、操作、动作、连接、条件、目标、作用、接触规则、资源、时间及连续参数；资料中新增加的字段默认继续进入比较，不能因为比较器没有手工列出而被忽略。

名字、作者、种子、修订号、直接来源、部位的局部别名、显示表面和染色不作为新的实际作用。部位改名时同步归一事件引用；真正改变来源、连接或接触组关系仍是不同能力。编译计划保留原资料部位路径，使挂点集合展开与名字中的`@`分隔符不混淆。缺省物态、缺省作用和接触组实际规则按编译结果补齐。

所有离散规则、整数次数与类型保持精确比较。自身已学的至多128项，逐项比较全部连续参数：每项都在百分之五以内才视作近似，零与非零、正与负始终不同。例如零伤害与实际攻击、推与拉、独立接触与共用接触不会被微小数值阈值合并。

世界目录使用结构与百分之五对数阶梯索引，只查询同阶梯的已有记录，避免每次遍历十万项目录。同阶梯中的必要参数变化不超过百分之五；跨阶梯即使很接近也可能保留。自身已学逐项比较不受这个边界影响。比较资料只用于控制增长，不作为能力身份，也不写入长期存档。

## 重复时怎样处理

正式自主创法在完整检查后、登记和学习前比较。重复时记录具体已有编号，结束本次请求，不登记半成品、不占新的掌握位置、不反复重抽，也不把另一人的名称、作者或近似参数冒充本次创作结果。

明确的玩家复制、改造、开发登记和历史恢复仍可保留重复版本。已有存档不做破坏性合并；每个人的来源和版本保持。登记同编号的新内容时移除旧索引，换世界清空，载入及资源成功重载时从实际定义重建。没有新增世界存档版本、mod.json开关或长期比较缓存区段。

## 工作量与缓存

现有创建预算继续生效：每共同周期处理一项、最多256项等待、每人128项掌握、世界100000项定义；展开最多128个部位及16层嵌套，条件操作和材料变化各最多16项，路径最多65个关键点，身体动作最多128个关键点。一次衍生固定选择一个实际改变，失败有原因并结束，不在同一次机会里持续搜索。

原共用改造会将每个中间阶段交给长期编译缓存，失败或重复结果也可能留下计划。新增`Compile(definition,cache:false)`继续完整验证，但不保存临时计划；数量、速度、历时、随动、身体显化、衍生和比较均使用它。正式登记、资源版本和已开始施放仍保留共同计划，不改变旧施放的执行资料。

## 验证入口

- `verify_similarity_math.script`：别名与显示、真实结构差异、参数边界、共享接触、集合挂点和草稿缓存。
- `verify_similarity.script`：正式重复拒绝、请求原因、目录更新移除旧索引和正式保存。
- `verify_similarity_restart.script`：真正退出重启后重建索引，保留所有旧定义和掌握，拒绝重复后仍可创出不同结果。
- `benchmark_creation.script`：同一512人世界的活动基线、24个月机会和512份草稿；记录真实世界速度、请求、成功、失败、目录、缓存和托管内存。这里的活动测量不包含密集战斗或绘制，不替代第13包完整性能验收。

原始结果位于`artifacts/skill_rebuild/similarity/`。没有新增模型和材质；可复用既有正式演示入口检查保留的新术。
