# 5.16 过程速度与延期

过程的主人继续结算自己的实际进度与代价。法术传入选中的过程、何时生效、以几倍速度推进；时间倍率只改变该过程收到的有效秒数。其他部位、施放总寿命、冷却、世界时间和镜头继续按原规则运行。延期期间不结算，恢复后从剩余进度接续；分期允许一段暂缓、另一段加速，已经发生的结果不退回也不补发。真正到达原完成条件后，才公布完成结果。

按三个交付推进：

- **A：生成材料的可分段局部时间。** 在选中的实际侵蚀操作上声明有限的时间窗，可加速、减速、暂停及分期。窗口相对这一操作的真实启动，在未指定的时段恢复常速；互相覆盖的窗口拒绝编译。实际余量、付出的本金和缩小后的碰撞形状共用侵蚀进度，依赖等待实际完成。比较同一次施放中的普通与变速部位，覆盖暂停无损耗、完成后余量相同、非法重叠拒绝和结束后再用。交付编译及执行、复验与证据；不为延长过程自动延长整招寿命。
- **B：独立过程与真实存档。** 把同一分段规则接到已经交回世界的材料侵蚀，由原材料记录拥有时间进度。支持给正在持续的明确过程施加或替换有限时间影响；阶段转换、失效和结束都按实际结果确认。验证原样保留已耗份额、新旧正式存读和中途恢复、换世界无旧结果。其他生活过程的玩法按 11.12 扩展；直接作用入口按 6.17 衔接。
- **C：组合、编辑与创作。** 把可用过程和实际时间窗接进万法阁、规则说明、自主创作与报价。新旧冻结规则各保存、各授予一次。用原版和 Worldfall 展示同一场内两个独立节奏、暂停、恢复及真实结束；镜头不会接管时序。
