## 5．可嵌套结构与通用变化操作

- [x] 5.01 构形：由固定资源或生成器建立形体、部位、控制结构及可用作用形状。
- [ ] 5.02 选择与分布：按部位、表面、路径、空间或集合放置子结构，分布规则可供不同主体使用。

- [ ] 5.05 轨迹：接入直行、追踪、弧线、螺旋及现有登记轨迹，统一实际路径、朝向与结束；已接入可编辑曲线，完整旧登记映射继续按[曲线与轨迹接入](可编辑曲线与轨迹接入.md)完成。
- [ ] 5.06 生长：沿枝体、曲面或过程逐段建立部位，未长出的部分不提前生效。
- [x] 5.07 聚合：让分散部件按目标结构汇集、连接并整体运动，保留部件的独立身份及材料，见[部件聚合与整体结构](部件聚合与整体结构.md)。
- [x] 5.08 解体与脱落：解除真实连接，继承位置、朝向及脱落点运动，后续可独立交互。
- [ ] 5.09 压缩、展开与形变：使用对应控制结构改变主体和作用区，区分刚性体与可变主体。
- [x] 5.10 分裂与碎裂：按真实状态产生有限部件，明确哪些继续攻击、哪些是装饰以及何时结束，见[按部件碎解与余力继承](按部件碎解与余力继承.md)。

- [x] 5.12 材料与物态转换：冻结、熔化、凝壳等变化同时改变实际状态、表面和后续变化规则，见[验证依据](材料与物态变化.md#验证依据)。
- [ ] 5.13 侵蚀与老化：依对象材料或生命过程推进实际损耗，并产生对应阶段及残留。
- [ ] 5.14 映照与关联：建立目标与映像、影身或副本的对应，明确允许传递的作用、时序和结束。
- [ ] 5.15 空间映射与转移：支持局部对应、出口、搬运和连接，实际位置、归属与显示同步。

- [ ] 5.17 施加与解除作用：覆盖损伤恢复、推拉、抓持、修复转化、信息到达及条件登记等实际需求。

- [ ] 5.20 验证复合变化：嵌套部件、材料转换和关联能继续参与其他操作，来源和结果不丢失。
