# 能力版图与尺度设计

**状态：创意与架构讨论稿，尚未实现。** 本页扩展全面重构的目标，用具体能力检查框架的表达范围。能力名称是创意储备，不代表每一项都已列入首批制作。

## 设计出发点

技能是修士、法宝、生灵对世界施加变化的能力。战斗、生活、修炼、生产、探索、交通、救灾与改造天地都属于它的用途。

个人、局部战场、城市和世界是不同作用尺度。世界级指当前游戏世界的广泛影响或规则改变，不要求每帧为全图制造海量执行体。设想中包含顶尖个体直接施展的世界级神通，也包含法宝、阵法、自然现象和长期维持的形式。

境界提高能力上限，不强迫每招都放大。顶尖修士同样可以只修一盏灯、稳住一道伤口，或把巨大力量压进极小范围。威力、范围、精细程度、持续时间与永久程度分别设计。

## 八类作用，打开技能的用途

| 方向 | 能做的事 | 可同时产生的功能与战斗用途 |
|---|---|---|
| 物质与形态 | 塑形、分解、凝结、修复、转化 | 修桥炼器、改变武器、重塑地面、构筑城防 |
| 能量与流动 | 聚集、传导、封存、抽取、转换 | 供能照明、输送灵气、截断术式、迁移灵脉 |
| 生命与生态 | 催生、抑制、修复、寄生、形态改变 | 育种疗伤、活木建筑、缠缚侵蚀、改造栖居环境 |
| 运动与空间 | 搬运、牵引、易位、收纳、建立连接 | 运货救援、牵制敌人、疏散城市、建立门户网络 |
| 感知与信息 | 观察、传讯、显影、隐匿、制造感知差异 | 探路寻物、警报通信、诱敌破幻、远距离共享观测 |
| 魂魄与契约 | 寄托、召回、替代、约束、共享负担 | 留存传承、护送魂魄、替身承伤、建立有条件的联系 |
| 时间与过程 | 加速、延缓、暂停某个过程、延迟兑现 | 催熟生产、缓解伤势、延缓来袭、借取未来资源 |
| 条件与法则 | 给区域、对象或连接施加运行条件 | 镇火安居、禁空封渡、改变通行或施术条件、影响天地灵流 |

这些是内容方向，不是八个封死的职业。同一能力可以涉及多个方向。不能把所有新作用重新简化为增加或减少属性。

## 多尺度能力谱系

表中各尺度可以成为同一术法的不同用法，也可以分别成为独立能力；不要求低阶技能仅凭数值变大就直接变成世界神通。

| 谱系 | 个人与生活 | 局部交战 | 城市与地域 | 世界尺度 |
|---|---|---|---|---|
| 行云布雨 | 掌中取水、灌溉一畦、清洗器物 | 水流改向、雨幕散火、用水团搬开伤员或阻碍来袭 | 引河入城、调蓄水位、扑灭连片火灾、围城水幕 | 组织跨地域雨带、迁移旱涝、让天河落地并留下真实水系变化 |
| 万木生息 | 接枝育种、稳住伤口、催生可用木材 | 枝条抓握兵器、木甲替伤、根系感知附近震动 | 活木桥、会修复的城墙、根网输送养分与警报 | 让荒原演替为新生态，建立跨地域林海与灵木节点 |
| 地脉搬山 | 塑石成器、补路架桥、探查地层 | 抬岩承击、移动掩体、改变脚下落脚点 | 挪山护城、疏通峡口、迁移聚灵地势 | 海陆更替、山脉迁徙、浮陆升起，改变地理与通行格局 |
| 天工化物 | 修补工具、分离矿料、收拢散落材料 | 扭转器形、凝土为甲、把战场残骸改为障碍 | 以真实材料修缮街区、建立持续工作的炼造设施 | 改变资源分布或材料循环，让一片世界获得新的生产条件 |
| 袖里乾坤 | 收纳材料、搬运物资、携带救援对象 | 收摄来袭后再释放、短距离易位、困住局部空间 | 折叠道路、迁移居民、把城区暂时安置进承载空间 | 连接遥远地域或洞天，让世界形成新的空间交通网络 |
| 借时春秋 | 延缓伤势恶化、加快一段生产过程 | 拖慢来袭过程、把一次冲击分期兑现、短暂冻结特定对象 | 借来一季收成、让工程渡过短暂窗口、维持灾后的恢复过程 | 改变四时运行次序，或让某类过程进入一段有明确规则的世界时段 |
| 照影传心 | 留声传讯、显出物体痕迹、观测已到达之处 | 幻身诱导、遮断感知、识别伪装与实际来袭 | 建立观测与报警网络，共享真实观测到的信息 | 构建覆盖世界的传讯或梦境联系，影响交流与集体应灾 |
| 镇界敕令 | 镇住炉火、封好容器、稳定危险物件 | 封住器口、限制局部位移、让敌我术式遵守区域条件 | 禁空、封渡、护城、维持区域安全条件 | 改变天地灵气的输送或某类施术条件，使世界进入特殊时期 |

空间容纳、真实幻觉、世界季节和完整地理演变等需要各自的玩法支持；本页没有把它们写成现有模块已经具备的能力。

## 各流派也要有自己的生活与天地用途

| 流派方向 | 功能、交锋与宏观变化的设想 |
|---|---|
| 火 | 温炉、照明、炼造、驱寒；局部熔断或焚除；城域供热与炼造网络；世界尺度改变火脉或焚除大范围侵蚀 |
| 金 | 修器、分矿、磁引收物；操控与干扰兵器、凝金护持；城域器物维修和材料流转；世界尺度改变金属或矿脉的分布与联系 |
| 风雷 | 通风、除尘、传音、输能；改变运动与电流路径；城域风道、运输和警报；连接地域的天风通路或雷能网络 |
| 阴阳 | 寄影传讯、护持生命过程与魂魄；借影易位、替身与负担转移；城域镇魂或生息维护；世界尺度的魂魄归渡、阴阳流动与生命条件变化 |
| 混沌 | 分解废料、回收散逸、净除异质；让接触的术式失去结构或退回游离能量；从废墟中重新组织材料；世界尺度修复或重塑失衡环境 |
| 五相 | 让材料、能量和过程形成可用循环，服务农作、炼造和修炼；交锋中在明确作用之间转换；城域设施互相供给；世界尺度改变约定的生态或灵气循环 |

流派保留各自的形体、运动与材料语言，同一种功能也可以有不同做法，例如木桥生长、石桥塑形、空间连通都能解决跨越问题，但实际后果与视觉应清楚区分。

## 六项值得展开的具体设想

### 引河：同一条水路连接民生与交战

修士先确定取水处与去向，水沿实际路径聚集、推进，最后留下水域或散去。平时把河水引向农田，救灾时排出城区积水，交战时截流成墙、绕过阻挡或卷走来袭。

城域表现应有来水、分流、堤岸承压、缺口与落水。世界级发动时可以看见云带和河网逐段响应；地面实际哪里改变，哪里才出现相应水体。术式结束后，已改变的地形与水系按其自身规则继续。

### 活城：木系能力创造能工作的环境

一株小树先成为可以跨越沟渠的活木桥；继续生长后，根系连接城墙与街区，形成传递震动、修补破损、输送养分的网络。

交锋时不是整片绿色光圈持续扣血：前沿枝体抓握或阻挡，受力处开裂，燃烧沿可燃部分蔓延。功能节点被破坏后，对应能力真实中断。更高尺度可以改变荒原的生态与居民通行方式。

### 乾坤袖：留下新的空间关系

小规模用于收纳和搬运，战斗时收摄真实对象或术式，再从明确出口释放。城域用于疏散居民、临时迁移街区，世界尺度用于建立遥远地区间的新通道。

必须真实记录对象在哪里、归谁管理、何时能进入或离开。表现应让人看到边界、入口、内部承载和释放过程；不能只让对象消失再闪现。

### 借来一季：时间能力改变过程

农田、炼造、伤势和术式各有自己的过程。技能可以加速其中一项，暂停另一项，或把某种变化延期兑现。战斗中延缓一股火焰，与生活中延缓伤口恶化，可以共用过程控制能力，但采用不同条件。

城域施术可以让一季生长在短时间内完成，实际消耗、衰老或其他代价必须明确。世界级的“四时易序”会影响约定的生产与生态过程。完整回溯整个世界需要历史资料，属于额外设计，不能拿重设生命值冒充。

### 一声镇界：世界级也可以有安静的威严

钟声传开后，水面、云层、器物与术式依次响应。一城之内，可以稳定暴动灵气、封住某类危险作用；世界尺度则建立一段真实持续的天地条件。

画面不必处处同时爆炸。宏观云流改变、区域逐一安定、正在运行的法术作出一致响应，才能让人读懂世界确实受到了影响。普通人的行动与不受影响的能力仍按自身规则运行。

### 照影成网：功能能力也能构成交锋

小术留下可追溯的声音或身影，节点之间传递观测，城区因此得到预警。交战时敌人可以切断节点、制造假象或破除遮蔽，信息能力因此有实际争夺。

世界级网络扩大的是联系范围，传播的信息仍来自真实观测和明确的感知规则。它需要影响接收者的实际行为或可用信息；只播放一圈扫描光不能算功能完成。

## 对自由改造的进一步要求

词条不止改变数量、大小与速度，也应能改变目标、条件、过程和结果：

| 改造方向 | 例子 |
|---|---|
| 目标与筛选 | 只作用于带标记对象、指定材料、受伤者、某条水路或网络节点 |
| 路径与连接 | 把直达改为沿水系传播，把单个出口改为多个分流出口 |
| 时间与触发 | 接触才生效、经过者触发、受击后启动、延迟释放、持续维持 |
| 作用方式 | 推动改为牵引、散失改为回收、单向转移改为交换 |
| 保留与结束 | 留下可用桥体、维持空间入口、解除后归还收纳对象 |
| 尺度与精度 | 扩大覆盖、集中作用、缩小目标但加强精细控制 |
| 来源与归属 | 由人物维持、交给法宝承载、依托节点网络运行 |

每项改造需要明确语义与所需资源，不承诺一句任意文字就能自动成为完整玩法。游戏内仍使用容易理解的改造选择，不要求玩家制作多招配方或编排节点程序。

## 框架必须因此扩大什么

1. **对象**：除人物、地块和坐标，还要表达器物、区域、过程、连接与世界条件。
2. **发生方式**：接触、主动指定、事件触发、生活需求、持续维护都能启动作用。
3. **过程**：支持展开、传播、维持、转化、衰减与完成；施法动作结束不等于结果消失。
4. **结果**：损伤之外，还包括物件改变、地形推进、连接建立、过程速度变化和规则生效。
5. **资料归属**：永久地形由地形系统保存，门户与收纳由对应空间玩法保存；技能保存必要的来源、条件和进度，不把所有世界事实塞进技能实体。
6. **运行尺度**：近身接触精确更新，地域按分区推进，世界条件按事件和实际查询参与；它们共用时间和结果，不必共用每帧扫描方式。
7. **自主使用**：战斗之外还要接入工作、救灾、旅行和修炼需求。现有城市功能法术工程已有净化、催生、催熟与地形用途，可作为迁移入口，不能停在这些既有六项。
8. **显示尺度**：近处展示接触与材质，中景展示作用结构和传播，远景展示区域和天地变化；在 Worldfall 中保持真实空间关系。

## 后续设计顺序

先把个人功能、局部战斗、城市过程、世界条件放进同一份能力合同，再验证资源和执行方式。初期实现可以分批，但框架验收从一开始就包含这些尺度；不能等全部攻击法术重做以后再尝试给“辅助”留一个接口。

具体能力逐项确定作用、过程、结果、视觉、触发入口和保存方式。哪些进入首批内容，随讨论收敛；本页不直接修改游戏数值或玩法。
