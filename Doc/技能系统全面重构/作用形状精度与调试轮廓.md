# 作用形状精度与调试轮廓（6.19）

开工条件：本项确定有效区简化的容差、量出实际偏差、交付能复验的调试轮廓。沿用 6.18 的世界、人物和已有形状；不调整模型美术、不按镜头远近改变能否命中、不改存档格式。

- [x] 对共用圆弧简化采用向内的误差，最大为实际半径的千分之一。半径不超过 16 格时应小于 0.016 格，64 格时不超过 0.064 格，512 格时不超过 0.512 格。用实际判定分别核对弦内、仅落在数学圆弧内、真实圆弧外；证明形状没有因简化扩大，不在两处尖角或厚度上放宽判定。明确独立的路径折角、圆柱胶囊、箱体、水层采样和镜头模型细节哪些有近似、哪些没有。
- [x] 调试轮廓默认关闭。按实际施放编号开启，读取同一轮判定用的形状和已确认姿态，显示真实厚度、箱体和胶囊；不借模型包围盒重算。形状结束、关闭调试或换世界后清除。原版与 Worldfall 读取同一份发布结果。
- [x] 交付可分段复验的脚本、三档边界的实战扣血记录、同一次实际施放的调试轮廓画面及关闭或结束后的清理记录。旧边界已核对的部分直接引用，不重跑全部 6.18。

扇形每段圆弧最多跨 5°，用弦连接两端。最大内缩为 `R × (1 − cos(2.5°))`，约为半径的 0.0952%；不会把判定扩到理想圆弧外。扇形直边、折刃各片的转角和厚度使用所声明的几何。圆球和胶囊的判定使用原半径和轴，只有绘出的线把圆弧折成短线；箱体保留实际长宽高。镜头级别只改变表现细节，不改变碰撞。

三档沿用同一地图和角色，用同一角度的扇形圆弧边缘实测。每次弦内命中只扣一次血，另外两处无命中、无扣血。既有五类正式模型和高度、擦边、反射的实战依据见[画面与实际作用边界](画面与实际作用边界.md)。

流散水面有自己的格子尺度：实际作用是每个湿格从地面到水面的箱体，画面在格中心之间插值并按同一干湿阈值裁切。本次实际施放的一帧，水格边长约 0.478 地图格，曲面四侧较有效区分别向外约 0.194、0.188、0.237、0.236 格，均小于半个水格。每个调试箱体的八角与实测有效形状的坐标一致。四侧数据只描述这帧沿地图两轴的最远边缘，不代表整张曲面逐点重合，也不包括离开施放后独立存在的世界材料。

从 `ConstructedAbilityService.CastStarted` 取实际施放编号。调用 `SetContactDebug(castId)` 叠加有效区；正式形体可能遮住内侧线条，可用 `SetContactDebug(castId, true)` 暂时单独看有效区。调用 `SetContactDebug()` 立即关闭，正式形体在下一轮显示时恢复。显示取一轮确认结束时的有效体积，移动过程中扫过的位置不叠在这一帧上。原版平面与 Worldfall 使用同一份线网格。已实测默认关闭、暂停关闭、同一次施放重新开启、自然结束和换世界清理。

复验脚本见[演示脚本说明](../../Scripts/SpellDemos/README.md#619实际判定误差与有效区调试)。第一轮检查扇形边缘、叠加轮廓及清理；第二轮补验隔离显示和流散水面。两轮均在独立游戏里用软件渲染，画面用于核对有效区，不作为美术或帧率结论。
