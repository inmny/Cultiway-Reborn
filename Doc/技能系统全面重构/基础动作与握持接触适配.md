# 基础动作与握持接触适配

对应2.17。沿用共同骨架、动作时钟、挂点及作用区，制作能够声明适用条件和调整范围的资料。

## 实施顺序与完成条件

1. 握持资料先提供完整方向、柄粗及允许尺寸；真实持剑使用同一对齐结果生成显示和作用形状，以剑、镜、双柄炉及不同尺寸验证。
2. 基础动作声明实际部位、支撑点、阶段及允许的速度、距离、方向和体型调整，原地发力、持物动作及非人部位分别提供输入。
3. 双方接触资料提供对应部位、接触阶段及解除点，结合支撑和握持验证同一姿态与作用。完整抓投与双方运行控制继续按4.23至4.26接入。

三部分资料均有实际取样及两种显示证据后才完成2.17。资源制作与完整人物玩法分开记录，不将单次对齐当成完整抓持或全部身体适配。

## 第一部分资源设计

| 资源 | 握持资料及用途 |
|---|---|
| 剑 | 原握点、柄长轴与柄粗；允许相对身体尺寸范围，接入真实持剑 |
| 铜镜 | 原握柄及柄长轴；柄粗和可用尺寸独立于剑，不按模型名称猜方向 |
| 双柄炉 | 左右把手分别提供握持帧和柄粗；单点对齐可复用，双手共同约束留在后续接触资料 |
| 掌形 | 原腕点和掌内握点继续使用；内容适配明确手部尺寸和可闭合范围，接合与碰撞读取同一矩阵 |

握点的前向沿柄长轴，另一个方向确定绕轴朝向。原有挂点的方向可能表示施法出口，握持资料只补自己的绕轴方向，不改变其他附着语义。尺寸范围按器物缩放与身体高度之比声明；柄粗随器物真实缩放，不能通过忽略柄粗让物件穿过手掌。

制作源保留资料，经过原有Unity导入和发布格式加载。运行只使用已经解析的数值和索引。新的资源字段不加入mod.json，正式存档仍保存稳定形体和握持编号。


## 握持部分实现与证据

发布格式6新增`Grips`，剑、镜及炉的左右把手共四项资料经过制作源、Unity导入与正式资源加载。每项保存原挂点、绕柄方向、实际最大柄粗与允许的模型缩放/体高范围；运行只保留复制的数值和已经解析的控制。分件保留自己的握持，刃部不会借用握柄资料。

`FormGrip.Align`同时对齐握点、柄轴和绕轴方向，并支持随同一骨架姿态变化的握点。真实持剑由`BodyActionBinding`使用该矩阵，显示和胶囊作用继续共用。内容适配当前使用手模型缩放/体高0.7、剑0.42，手部模型可闭合范围0.035至0.08；剑柄实际最大直径0.13。原手缩放0.4导致掌部尺寸不足，现连同手指及真实作用一起修正，腕点仍准确连接前臂。
