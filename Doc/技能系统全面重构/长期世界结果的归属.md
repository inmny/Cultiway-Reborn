## 哪个系统保存什么

| 世界事实 | 保存归属和实际恢复 |
| --- | --- |
| 永久地貌与生态变化 | 原版地图地块记录真实地形和地表。一次地形抬升已在冷读后保留，相邻地块保持原类型。[精细小术的地貌实测](顶尖修士的精细小术.md#同一施术者的实际控制) |
| 修好的器物和设施 | 原物件保存耐久、装配和所有者。原版房屋继续保存建筑、生命、入住和可用状态。曾受损的房屋冷读后仍有原住户和 125 点生命。[实际设施修缮](实际物件与设施修缮.md#建筑修缮实机结果) |
| 已交付世界的材料与天气 | 世界材料区段保存稳定编号、形体、剩余时间、原支付者和正在收束的份额。模组雨云区段保存原云龄、位置和消散进度，降雨仍由原版推进。[固态材料](固态材料留置与定形保存.md#保存与升级) · [持续雨云](持续雨云与世界原理参数.md#保存及清理) |
| 设施来源和宗门供奉 | 原版保存实际阵台或建筑。物件和宗门区段保存供奉原件及所属关系，护持从当前有效场所重建。原阵的短时充能读档时收尾，旅客可以再次正常请求。[设施与冷读](宗门节点与设施来源.md#d-整项交付) |
| 城市工程与元神网络 | 城市工程保存实际分区、连接、已验收轮次和后续需求。断开时保留已完成部分，接通后只做余下工作。元神网络在物件区段保存实际节点、双向连接、驻留和已经付费的在途进度；原节点有效时按剩余时长抵达，断开则回到原驻留点。[城市工程](城市分区净化工程.md#原版实机) · [元神设施与网络](宗门节点与设施来源.md#d-整项交付) |
| 有限世界条件 | 新的世界条件区段只持有已付、有效且明确允许读档续存的范围、维持者和剩余时间。动态工程的任务边界由工程自己恢复。原术定义与学习关系仍由构造和人物区段保存。 |

世界条件区段从第一版开始。旧档没有此区段时按原方式读取，旧术缺省在正常读档时结束正在维持的防火。新区段按原人物编号接回已付条件，无需玩家手动迁移。

## 实机验证

万法阁的防火规则增加「读档后维持剩余时长」。同一位修士用实际表单开启，撤销后恢复普通规则，重新开启并替换所学。中英表单的原始截图已归档。正式使用两份区域条件和一份全图条件共扣 22 真元，原修士从 100 变为 78。存档时只写入明确允许恢复的区域及全图条件，剩余时长分别约 7.76 秒与 2.76 秒。

进程 216770 保存，退出后由原版进程 220538 读取。真实点火仍受两份已付条件限制，角色余额保持 78，原施放未重播。区域标记与保存的原圆心和 4 格半径一致。全图到期后，只有实际区域继续保护，原普通区域及远处都能正常点火。区域到期后原保护点也能点火。另一次读取同一份原档后，真实维持者死亡，两处立即恢复点火，下一次世界推进清除旧登记。

准备段保留人物容量未刷新的首次失败。首次窗口验证已通过，此后在同一人物上继续付费和保存。冷读段完整通过，原正式档校验值保持一致。
