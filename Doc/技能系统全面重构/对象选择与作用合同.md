# 对象选择与作用合同

对应 TODO **0.06**。本页确定八类对象的完整选择与作用规则，并记录当前接入范围；不把这些规则已经写明等同于通用选择器已经实现。资料身份遵守[稳定编号合同](资料边界与稳定编号.md)，控制、维护及结果保存遵守[归属与结束合同](控制归属与结束合同.md)。

## 选择、放置和作用分开

一次能力可以同时选择人物、器物、某段过程及一组地块，分别作为瞄准、定位、借用、读取或改变的输入。这些角色必须明确，不能只传一个“目标”让执行器猜。

| 环节 | 确定什么 | 必须保留的区别 |
|---|---|---|
| 查找与选择 | 对象类型、来源、筛选、范围、数量及选择时点 | 选到一个敌人不等于已命中；选中一件器物不等于获得其控制权 |
| 绑定与放置 | 采用哪个对象的位置、部位、表面或过程输出；是否跟随 | 以友方位置放置攻击区域，与只允许作用友方是两条规则 |
| 确认作用 | 当前对象仍满足条件，且实际接触、有效关联、区域过程或领域操作成立 | 不能仅凭动画触达或预估候选提交伤害和世界变化 |
| 提交与结果 | 具体改变、实际数量、失败或抵抗、来源及确认时点 | 请求值、尝试次数、已变化次数和工程完成分别记录 |

施法距离、选择区域、真实作用形状、任务边界和纯显示范围分别存在。城市级或世界级能力改变的是实际作用与处理范围，不是把同一个半径同时用于瞄准、碰撞、筛选和镜头。

## 统一的选择规则

所有对象类型都遵循下列规则，具体资料及执行在3—6、10—12包按相应条目接入。本页不新建空接口、空枚举或另一套编辑器。

1. **类型和用途明确。** 选择资料写明人物、器物等类别，以及读取、定位、借用、攻击、改变、断开或传播用途。攻击敌方法宝不要求先拥有它；借用其出招、支配或接管则经过相应控制规则。
2. **条件是可编译资料。** 关系、状态、材料、阶段、来源和范围采用明确参数或已登记原理，不能把任意回调、人物对象或界面选择状态写入长期定义。创建、编辑和正式恢复共用检查。
3. **主目标和集合分别处理。** 明确点选的主目标失效时，按本条资料的停留、取消或继续规则处理，不隐式换成另一敌人。明确声明的“每次在附近重新选择”可以产生新集合，但要保留选择频率、范围、次序及上限。
4. **集合有确定顺序和预算。** 原有明确指定顺序优先；动态选择明确采用距离、用途评分或稳定编号等规则，不能依赖字典顺序。数量、扫描量、路径跨度、传播深度及每批工作都受预算约束，截断或未完成的预估不能冒充完整结果。
5. **身份稳定，空间可变。** 锁定对象身份不冻结它的位置和阵营；地面位置锁定也不凭后来经过的人物自动变成跟踪目标。集合成员可以明确选择固定或动态，但提交前仍检查当前有效性和实际作用条件。
6. **先取数值，再确认事实。** 主线程解析对象并采集统一世界时间上的资料；工作线程只计算不可变快照、路径和候选。提交前核对世界轮次、对象身份、权限或对抗规则及当前事实，过期结果不写入另一个对象或世界。
7. **逐个目标报告实际结果。** 某个集合成员消失通常只跳过该成员；主目标、必要输入或维持来源失效则执行本过程声明的中断规则。必要输入与可选输入在编译时明确，不由运行临时猜测。
8. **支付和重复确认有明确归属。** 不因查询、预览、分批或多层显示重复收费。作用次数由施放、作用、部位或接触组、当前归属及目标身份共同确定；多次独立出手仍是不同事实，不把全部并发能力去重成一次。

### 对象身份与运行引用

长期引用限定在所属世界及玩法内，并保留类别和稳定编号。当前世界保存已经区分 `actor:`、`book:`、`city:`、`sect:` 及 `object:`；器物、状态、元神节点等普通对象由保存器统一分配身份，详见[世界引用导出](../../Source/Content/Persistence/WorldObjectSaveService.cs)。

选择阶段可保留本世界有效的运行引用，写存档时由对应保存器导出；不能直接把临时实体编号当成 `object:` 编号，也不能因为只是查询一次就生成一份新的世界事实。跨世界或小世界引用须由真实世界及所属玩法提供身份，当前没有开放的跨世界目标不通过“同编号”碰巧命中。

运行引用再附当前世界轮次与必要版本。物件池复用、对象删除、区域重划、载体更换及重新加载都会触发重新解析或失效处理。显示网格、Worldfall代理身体和屏幕位置均不承担长期身份。

## 八类对象分别怎样选择与作用

下表是完整合同。后面的“当前实现”单独说明哪些路径已经存在，不能仅凭下表生成新资料就认定可运行。

| 类别 | 选择身份、范围和条件 | 允许怎样作用 | 确认及失效处理 |
|---|---|---|---|
| 人物 | 实际人物/载体身份；活体、尸体或魂体等状态明确；按关系、身体部位、位置或所属组织筛选 | 接触攻击、治疗、推拉、状态、精神或有明确规则的关联作用；身体部位及资源归对应玩法 | 核对实际身份、当前身体、位置及关系。死亡、脱体或换载体不默认为另一实体；尸体用途不能继续使用“必须活着”的筛选 |
| 器物 | 实际武器、法宝、物品、建筑器具或世界材料；注明所属玩法与持有、装备、材料、部位等条件 | 借用、移动、卸下、破坏、修复、炼化、封禁或转移；各自走器物或材料所属规则 | 核对原物件仍存在、占用及当前所有权/控制。伤敌器与借敌器分开；没有器物耐久或转移机制时，不扣持有者生命或只换模型代替 |
| 地块 | 当前世界中的坐标及地表；按地形、水、植被、作物、污染等事实筛选 | 明确原理改变地形、净化、催生、催熟或创建天气/材料；实际结果交原版或所属玩法 | 查询时可预检，提交时复查地块状态、任务约束、容量及接触。地形已变不继续沿旧快照解释；地图变更后重新解析 |
| 区域 | 几何区域或有身份的城市、地理区、领域；分别记录空间形状与所属组织/过程 | 对区域自身的规则或成员集合施加作用；成员作用仍按人物、器物、地块等本类规则 | 明确固定成员、固定足迹或动态边界；提交前执行相应当前归属/保护条件。组织转属不把旧工程权限带给新领主 |
| 过程 | 本次施放中的明确过程、具名输出，或已经交接给世界维护的持续过程；可按阶段、状态或来源选择 | 推进、延迟、维持、中断、改变输入/输出或读取结果；例如冻结一个流散过程或收束其残留 | 核对实际过程、修订及拥有者。短时过程引用不跨读档复活；过程结束的真实结果保留，中断和自然完成按各自规则发出事实 |
| 连接 | 已存在且类型明确的父子附着、握持、控制、供能、映像对应、通路等两端关系 | 建立、维护、转接、切断或按明确规则传递作用；方向和传递量单独描述 | 核对两端身份、连接本身、承载/维持及作用传递规则。一个端点失效不自动指向同位置新对象；切断连接不重复复制两端材料 |
| 网络 | 指定网络，或从明确入口沿合格连接可达的节点与连接；有路径、方向、材料/状态和通量条件 | 传播冲击、导电、输运、供能、封锁或断路；每跳实际消费和后果明确 | 动态复查连通、节点、连接及剩余容量，有限搜索并防止环路无限传播。使用己方网络的授权不能被误用为“无法攻击敌方网络”的筛选 |
| 世界条件 | 当前世界/小世界的具体条件源、字段和时段；例如天气、时令、灵气、世界事件或组织规则 | 作为输入或触发条件读取；改变世界状态时使用对应明确原理及维护者，声明影响域、历时与成本 | 记录采样时点、世界和事实版本；所属玩法提交时复查必要条件。不能将“条件成立”当作“已经改变条件”，长期变化也不由一段视觉循环拥有 |

### 人物、所有者和实际载体

完整合同分别指明**资源与知识所有者**、**当前控制者**、**实际施放载体**以及**被选中的人物**。从命魂发出的盾可以保护命魂，也可以明确关联远处肉身，这需要两种不同目标引用；不能通过同一个模糊的“自己”推断。

新选择资料中的载体自身与所有者必须可明确区分，创作补全也要写明所选角色。正式第一版已有 `Self` 继续按原 `caster.Base` 解释；升级到明确角色引用时，转换保留该旧含义，不能在旧档中静默切成远端命魂。当前[载体上下文](../../Source/Core/SkillLibV3/ActiveAbilities/SkillCasterContext.cs)已有Owner/Carrier区分，而[共同目标解析](../../Source/Content/Skills/ConstructedAbilityUse.cs)仍直接使用传入的 `caster.Base`；各来源的完整对齐须在4.12、10.10及10.14继续验证与接入。

人物选择条件与接触关系分别存在：瞄准A不能证明碰到A，瞄准A的位置也不天然禁止该作用体接触B。单目标、仅指定目标或允许范围作用必须由实际作用规则明确。反射后使用新的当前控制者判断敌我及后续推拉中心，原创造者、支付本金及历史来路不随之抹掉。

### 器物与世界材料

借用、持有与攻击是三件事。借用实际武器发力要保留物件身份、握持及占用；攻击敌方法宝可以进入破坏或对抗规则，但并不因此获得使用权限。原物件离手、被夺取、收入库存或毁坏时，分别按对应关系处理，不能继续用旧模型当作仍被握住的兵器。

目前世界材料有独立的身份、数量、物态、原支付者与控制事实。`ConstructionWorldMatter.OwnedOnly` 当前比较的是原支付者与当前控制者，不是“附近所有友军物品”；转换不会转移原支付本金。选择按真实作用形状及材料/物态过滤，并通过容量限制确认，详见[材料转换](../../Source/Content/Skills/WorldMaterialConversion.cs)。完整的器物、建筑及任意材料目标不能仅靠这个现有入口替代。

### 区域、成员和后续过程

区域首先说明自己是什么：一块固定几何空间、一座城市的动态领地，或由实际过程维持的领域。选择区域不自动获得其所有居民、法宝、地块和连接的写入权限；每种作用明确展开哪些成员、使用何种关系或对抗规则。攻击城市可以按战斗规则作用，不要求先拥有城市；城市日常工程则按自身组织及农田保护条件执行。

固定足迹可以和动态权限同时存在。现有城市工程采用预估足迹与当前城市约束的交集；领地转属、新农田规划和任务失效在实际提交时重新检查。几何作用区仍来自真实构造，不能把城市边界重新包成一个圆。

原理产生独立天气、材料或长期设施时，还要声明哪些约束继续维持，哪些仅用于创建时选址。结果交接之后的移动、传播及副作用由相应维护者处理；没有传递过去的城市边界，不能声称会自动限制雨云、人物伤害或材料转换。预估完整副作用及适用性属于城市候选与长期过程接入。

### 过程、连接及网络的引用

短时过程以当前施放、构造修订、声明路径及明确过程定位；长期过程改用所属玩法提供的持久身份。当前内联操作序号只属于固定资料或编译计划，具名过程及跨输出引用仍按0.04合同在后续工作实现。

连接自身有身份、类型及两端引用。镜像到真身的作用传递要明确允许的作用、方向、倍率、抵抗与终止条件；镜面显示了某个人，不能直接成为伤害真身的证据。握持连接、供能连接及伤害传递也不能因为都连接两个点就共用一条隐含规则。

网络的默认范围是从明确入口沿合格连接能够到达的部分，不是全地图同材质对象。应记录每跳消耗、方向、可达距离、访问上限及波次去重；允许多次脉冲时各波仍有自己的事实。支路断裂、液体冻结、节点转属或容量耗尽后，后续传播按当前事实停止、改道或降额，不能沿旧图继续发放效果。

当前导电已有真实水体入口、传播距离、导电状态复查及有界波次；元神锚点也有自身的连接、归属及通行授权。它们属于不同网络原理，不能仅因“都是网络”就互相连通，或把通行授权检查拿来限制战斗破坏敌方节点。

### 世界级条件与作用

条件读取和状态修改分别声明。例如“下雨时生长加快”读取当前天气；“令全域降雨”调用可维持的天气原理，具有覆盖范围、存在时长和实际费用。时令、灵气、时间进程、组织规则及特殊空间同理，不借一个虚拟人物代替整个世界状态。

世界尺度选择必须有分批方式及时间约定：明确快照还是随执行时点更新，按空间/网络分批保留进度和预算，不能宣称一次扫描就是同一时刻改变了全世界。若原理要求一次整体生效，则先由对应玩法提供这种提交能力；不把逐帧动画包装为同一时刻的全域变化。需要跨存档延续的过程先交给唯一维护者保存，再由它恢复必要联系。

## 提交、来源和保存约定

同一接触或传播可能先改变世界，再使下一个候选失效。确认每项作用时重新检查它实际依赖的条件；观察回调导致换世界、删目标或断路后，不继续消费旧候选。既有事实保留，未确认工作停止或按规则重选。

默认结果记录包含实际目标、来源与当前控制者、能力及作用身份、共同世界时点、尝试/成功及真实数量；需要继续驱动过程时引用这份结果。未造成变化、被抵抗、对象失效和预算未完成分开表达，不能全部写作“命中成功”。逻辑作用不依赖截图次数、显示距离或是否启用Worldfall。

原人物和器物关系仍由原保存体系拥有。短时施放、工作快照、任务回调及其目标引用不自动保存；能继续存在的天气、材料、连接和网络由各自长期资料恢复。恢复先建对象再解析关系，不重放启动伤害、不重复扣费，也不把失效引用接到同名新对象。

## 后续实现与验收用例

这些用例给后续任务提供明确通过条件，本项只完成合同及源码核对。

| 类别 | 必须实现并验证的用例 | 需要证明的结果 |
|---|---|---|
| 人物 | 已选敌人离开作用区；另一个合格目标进入；阵营在接触前改变 | 区分瞄准与实际作用，按显式单体/范围规则处理并使用确认时关系 |
| 人物/载体 | 远处肉身、命魂或节点分别施放自身护持和护本体能力 | 来源位置、受益身体及资源所有者明确，旧`Self`解释经版本转换保持 |
| 器物 | 选择敌方法宝破坏，再对自持法宝借用；过程中换器或被夺取 | 对抗与控制权限分别判断，始终指向原物件，不扣角色血冒充破器 |
| 地块 | 高空模型经过，随后实际触地；期间地块被其他能力改变 | 高空投影不改地，确认时依据真实表面和当前地形；不重复提交 |
| 区域 | 固定足迹内领地转属、农田新规划；带材料/人物副作用的区域术 | 直接地块与其他副作用各自遵守明确边界，未评价内容不能被当成无害 |
| 过程 | 冻结流散、结束维持、改变聚合输出；过程中读档 | 作用于明确过程而非临时数组位置；真实结果保留，短时过程不复活 |
| 连接 | 斩断握持或供能；镜像关系限制某些作用传向真身 | 两端与连接身份不混用，断开后果和允许传递内容成立，不凭视觉直接伤人 |
| 网络 | 从局部水路或阵法节点传播，中途冻结/断边/转属，连接中存在环 | 范围为当前真正可达的部分，动态复查、消耗、次数及上限成立，不沿旧连接无限重复 |
| 世界条件 | 读取时令/天气触发；另有能力改变并保存持续天气或世界规则 | 读取与写入分开；预算、时间、维护和恢复成立，不以动画代替全域事实 |
| 并发及切世界 | 多能力同一时点命中、回调删除目标或切换世界 | 独立出手分别计入，重复候选不重复结算，旧结果不写入新世界 |

现有接触、城市范围、世界材料和导电测试可继续复用，但这些历史结果不自动覆盖未实现的器物目标、过程图、关系传递或世界条件。下一项按顺序为0.09，将全部流派、来源、十三项攻击及功能尺度落实到具体制作和验证条目。
