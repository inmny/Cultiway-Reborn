# 9.15 火系实战表现

- [x] A 移动火体：让新构造共用的火身在飞行中保持连续。能看清较亮的内焰、红橙外焰和向焰尖流动的层次；焰尖起伏留在原轮廓内。复用「离体炎流」正式施放，核对费用、实际命中、偏离目标不受伤、原时限退场。留原版和 Worldfall 常速原片。
- [x] B 附着燃烧：让同一火身在真实着火点上随余热和燃料变化，冷却后退去，燃尽后不留假火。复用「点木流火」「可燃分枝」和既有冷却场景，验证真实点燃、烧损、冷却后的剩余木体，以及自然退出。留原版和 Worldfall 常速原片；冷却用原场景复验。

保留当前火系的橙红色、炎陨落地翻卷和火球已通过的轮廓。两批沿用同一块演示地图、角色和构造入口；不增火系配置、材料规则、伤害范围或存档字段。原版森林火灾及城域火灾留在其对应条目。两个批次的完整结果与录像齐备后才关闭 9.15，随后合并并推送。

| 资源 | 改动 | 保留的实际作用 |
| --- | --- | --- |
| 有限火身 `fire_body` | 在同一个有厚度的火身上做亮热芯、半透外皮和沿高处回卷的焰尖 | 原主体、接触芯、取地范围与染色/换材入口 |
| 燃烧木体上的火身 | 共用火身读已确认的点火位置、余热和余料；无有效燃烧则不发布火身 | 原燃料损耗、传播、木体缩损、熄灭及原资源去向 |

用「离体炎流」核对了原接触芯和作用范围。正式施放支付 8 灵力，正面目标扣血 73，侧外目标无接触、未扣血。原版和 Worldfall 都拍到亮内焰、红橙外焰和自然退场；两段正式演示各产生一次真实接触，末帧没有火身。

「点木流火」与「可燃分枝」在两个视角都从实际接触点起火，火传到三个木质部位，约 4.6 秒后不再显示附着焰，末帧无残留。另用已有场景单独核对冷却：木料先烧损约 0.43 单位，被水冷却后留下约 3.57 单位，火焰消失，后续不再烧损。这个变化没有调整燃烧规则和存档格式。
