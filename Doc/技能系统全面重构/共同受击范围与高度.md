# 共同受击范围与高度（6.01）

完成条件：旧执行和新构造的人物受击统一使用从脚底到头顶的竖直胶囊，宽度与站立体高一起缩放，普通招式保留自己申明的厚度。水平擦过和上下越过都不算击中；在真正的相交位置仍能造成原来的作用。体型大的目标靠自己实际覆盖的范围参与候选，不能靠固定扫描垫宽。新构造已有的身体偏移和建筑原有的范围不变。

原版以地图平面为高度原点；接入 Worldfall 后，旧轨迹的相对高度在相交计算前换算到与新构造同一地表。目标的真实离地高度参与判定，二维绘制投影与切换相机不会改变判定。旧招自带的可接触高度限制仍可进一步缩小作用。此项不增加局部器官受击、模型表面的细分或新的形状；后续高速转动、画面边界矩阵分别归 6.03、6.18、6.19。

复用已用验证世界和一个普通受击者。验收原执行与新构造的实际命中、略微偏开、同一平面但不同高度，以及结束后重新施放。几何边界、大小比例和斜向换算用少量数值检查，Worldfall 只复用同样场景核对高度来源。交付规则说明、正式复验入口及实机记录；全项通过才合并 `codex/dev`。

人物站姿的外边界从脚底延伸到头顶，水平半径取体高的 24%。例如，体高 0.5 格的目标，身体半宽为 0.12 格；轨迹半径 0.35 格的招式，与身体轴线的横向距离在 0.47 格以内才有可能打中，还须满足同一处的高度条件。旧执行不再给人物额外垫一格；选敌距离、招式另行声明的区域作用，以及建筑自己的平面判定保持独立。原版人物真实离地时，也不会因为投影重合就受击。

原版实机分段通过。第一次的水平边界结果有效：同一个狼目标距招式轴线 0.425 格时受击，0.515 格时无伤。第一次高度布置时狼已落回作用区；保留这次记录，修正布置后仅补旧执行的离地和斜向来袭，再完成新构造段。两种执行都在目标实际离地时不命中、归地后能再命中，新构造每次自然结束。Worldfall 0.9.8 用同一个场景从头通过，目标处的真实地表高度是 1.6655 格。另一个安装包启动超时也保留在证据里，正式复验使用 5.18 已通过的副本。验收证据：`/home/inmny/.local/state/cultiway-dev/evidence/actor-hit-boundary/delivery.json`。
