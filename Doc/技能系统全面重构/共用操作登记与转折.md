# 共用操作登记与转折

对应3.13。已有输入输出约定与实际执行现在成对登记；新增的是共用原理，不按某个法术编号选择执行代码。

## 接入方式

新增操作需要三处明确资料：

1. 为`ConstructionOperationKind`追加未使用的固定数字，不修改已发布数字。
2. 在`ConstructionOperations`登记输入、输出、参数、状态、资源和作用约定。参数只能引用真实保存字段；新增专用参数时也须提供实际资料类型和编译检查。
3. 登记一次`Register<T>`：提供具体参数编译、纯数值应用，以及需要的完成读取、即时完成或完整目标检查。新的操作缺省使用共用时点、真实条件和步骤绑定；已有专用定时实现明确声明`direct: true`。

本次13类原操作的条件和命名执行均已接入同一登记，不只为新增类型建立旁路。其参数编译、实际派发、即时完成及过程完成不再各维护一份总开关。原定时过程继续使用已经直接编译的部位资料，输出观察也使用同一登记中的完成规则。

`T`保存该类不可变数值或已解析资源，不能保留原始构造、人物、地块或可变游戏对象。编译为每类一段`T[]`和实际执行函数，24字节指令记录计划内的分组及参数索引；实际编号不作为参数数组下标。调度保持原资料的同刻次序，执行时不反射、不解释描述，也不为每个操作增加游戏对象。

登记拒绝重复编号和缺少实际编译或执行的实现。计划保存已取得的实现与参数，不因另一次施放或原始描述改动而改变。结构规模、输入绑定、真实世界确认及快照仍使用已有共同规则。

共用调度负责时点、事件、步骤和状态交接。一个新原理若需要新的世界事实、状态、作用几何或资源需求，仍须实现对应数值和所属玩法的真实提交；登记名称本身不会赋予这些作用。原有共用输入种类及目标约束继续有效。

## 本次新增的实际原理

`Deflect = 13`为转折，原0至12保留。`Vector`是明确的三轴转角，`WorldVelocity`为真时按地图方向，否则按执行当时主体朝向解释。它作用于正在自由运动的同一个完整主体：

- 转动当前速度、加速度和朝向，速度大小保持；位置不跳回发射点。
- 已有曲线的参照、中心速度一起转动，并以当前位置重新固定中心；曲线时钟不重启。
- 显示、实际作用形状和仍附着的子结构使用改变后的同一姿态，已经独立脱离者不受影响。
- 不重置反射次数、控制归属、材料、实际余力或支付份额，不重新生成另一施放。
- 成功后提供`part`与`deflected`结果；没有自由运动或已经停止时如实中断，不发布成功结果。

流散水格的各格动量不能由完整刚体转角代替，因此完整结构编译会拒绝这两种操作占用同一部位。水格转流继续由实际流动规则实现，不以全体平均速度掩盖各格状态。

新例子[折向续行](构造输入/折向续行.json)在原飞行部位0.5秒时转90度，再由真实转折结果触发改质。它是同一个主体的过程连接，可以改为实际接触后转向、独立命名步骤、其他角度或其他形体；没有新增固定多招配方。
