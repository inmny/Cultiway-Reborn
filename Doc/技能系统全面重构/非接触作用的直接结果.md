# 6.17 非接触作用的直接结果

开工范围：用现有命名步骤和实际世界回执接通指定传讯。对同一套入口已有的指定物件、过程和规则结果，复用实际法宝搬运、世界材料处理及侵蚀变速的验收依据。只补当前不存在的结果路径，不新增一套执行器。

- `SendSignal` 读取本次明确选中的人物或本人；到了声明时点，检查实际人、身份、关系和距离，通过后才登记讯号。主体可为无攻击作用的形体。没有路径扫描，没有命中、受伤或交锋事件。
- 实际首次收到讯号或发信人变更后，按现有规则登记收件，输出 `delivered`，向后续步骤提供实际收件人、内容、发信人及时点。同源刷新保留原规则，不伪造新送达；收件人失效、越界或取消时不输出，也不放行等待此结果的步骤。
- 复用现有世界与人物，验收指定对象独收、无接触、实际送达才展开后续，失败后不触发后续，恢复后可重用。验证新声明能正式存读且不重放旧结果。交付可单独运行的复验与文档；不加新讯号种类、新素材或新用途的创法选项。

## 实际结果的入口

| 用法 | 何时产生结果 | 后续拿到什么 |
| --- | --- | --- |
| 指定原法宝搬运 | 原物件通过出口占地检查并实际移到出口 | `transferred`：原物件编号和实际落点，见[空间映射与转移](空间映射与转移.md) |
| 世界材料与过程 | 实际材料转换、侵蚀或转交由世界确认 | 实际材料身份、份额和确认进度，见[操作输出绑定](操作输出绑定.md) |
| 指定传讯 | 告警或集结确实登记到本次选中的人物 | `delivered`：发信人、收件人、内容、地点、时点，也可用既有送达条件开启后续 |
| 调整正在运行的规则 | 世界确认选中的活动侵蚀确实改变节奏 | `retimed`：受影响材料的身份，已发生成果继续保留，见[过程速度与延期](过程速度与延期.md) |

## 实机验收

同一世界用无攻击作用的形体送达告警。旁人夹在中间仍未收到，生命及接触记录不变。正式扣费一次；施放开始后收件人越界时，送达步骤和依赖它的步骤都中断。回到范围内再施放，收件状态、步骤结果和从脚下开启的到达效果一致。新声明与人物知识正式保存读回，保留已有告警与发信人，不重放结果；同源仅刷新，到期后可以新送达。地点输入和缺少讯号内容的声明均在编译时拒绝。

法宝原物件搬运、实际材料处理和侵蚀规则改动使用已有实机记录，复用同一个确认入口。本轮未更改旧档区段或旧创法规则。复验命令见[演示脚本](../../Scripts/SpellDemos/README.md#非接触结果617)。
