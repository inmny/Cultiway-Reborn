- [x] 沿用上一批的对练，选择一项飞行攻击和链雷对照实际地块、触发位置和次数，另检查一次落空或取消后可再次施放。保留原支付及现行人物伤害，地块操作原来附带的世界伤害按实际旧规则核对。

## 旧攻击把建筑作为接触对象

- [x] 首先接回原本允许接触建筑的飞行攻击。沿实际飞行形体查询敌方建筑，和人物、屏障共享先后顺序。直击照原伤害及穿透规则，范围攻击从真实拦截点爆发一次。
- [x] 复用墟隙已经验证过的完工房屋和同一对练。比较一发普通投射和一发范围投射，核对房屋独自接触、房后人物，以及移走建筑后同一入口可再次施放。保存发生接触的位置、费用、建筑结果和人物实伤。
- [ ] 另对照链雷和持续作用原本能选建筑的路径，避免第一段的飞行规则变成所有法术都能拦截。该段随整项一并验收。

新旧水矢都以 85 点来源伤害击毁房屋，并继续命中屋后人物。火球在实际建筑接触点爆发一次，半径保持 2 格，原版爆炸毁坏房屋，屋后人物无伤。移除房屋后，同一火球可以重新打到屋后。旧飞石实测在弧顶仍打中下方房屋，当时没有启用高度限制。共同执行按轨迹高度约束接触，飞石越过房屋后命中目标。三项费用沿用原发射。完整结果与前几轮试验保存在 `~/.local/state/cultiway-dev/evidence/base-spells-1001/building-flight/delivery.json`。
