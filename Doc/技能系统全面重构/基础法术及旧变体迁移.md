## 火刃的四个索引

| 旧索引 | 主体 | 仍应成立的行为 |
| --- | --- | --- |
| 0 | 沿用五舌焰锋，厚刃沿前缘出力 | 原来有成形和余焰消散。成形期间不移动、不接触，随后按原轨迹推进。 |
| 1 | 两道分开的窄焰锋，各有实体厚度与实际锋口 | 同 0 保留首尾阶段。两道锋共用原术的接触次数，间隙保留。 |
| 2 | 紧凑的亮刃，蓄火集中在较厚的短脊 | 原变体直接运行，结束后立即退出。 |
| 3 | 回钩焰锋，偏弯的一侧提前出锋 | 原变体直接运行，结束后立即退出。 |

第一段的必要验证是在正式入口逐一施放四个索引，确认费用、形体、真实接触、成形时无伤、正常结束及再次施放。用同场景复验改轨迹保持原索引。火系批次集中做新进程读档及连续画面。新形体从共同三维制作脚本发布，原版与 Worldfall 共用。

四个索引均已在原学习入口实测。同一场景中，双锋只伤侧边接触者，中央人物无伤。回钩变体改为折线路线后仍使用原形体，并按改造后原价支付。余焰固定在实际结束点后，索引 0 和 1 单独复验通过。构建、原始实测与收势补验汇总在 `~/.local/state/cultiway-dev/evidence/base-spells-1001/fire-blade/delivery.json`。火系的正式读档和连续画面仍待交付。

## 火球的十八个索引

| 旧索引 | 需要看得出的区别 |
| --- | --- |
| 0–4 | 0 圆核厚焰，1 小而尖的白热火矢，2 多层燃核，3 蓝火向上翻卷，4 短而亮的日盘 |
| 5–9 | 5 小型火种，6 扁而宽的贴行火舌，7 体积更大的厚焰，8 窄核长焰，9 有角的多层折面 |

0–4 保留原成形和消散时长。成形时在起点聚合，命中后在真正的结束点消散。5–17 直接运行。十八个索引共用原火球的触发、爆发半径、伤害及支付。换形体时让飞行接触跟随真实主体，爆发取得完整余力，收束不产生新伤害或移动。

在同一场景逐索引检查正式施放、主体和真实命中。原成形和消散按同一规则验证，选一个落空和一次改轨迹验证爆发边界。将火刃和火球代表索引放进一份正式世界，重新启动后读回并施放，再集中录下两种视角的连续画面。
