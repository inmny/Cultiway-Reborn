# 10.01 基础法术及旧变体迁移

## 火刃的四个索引

| 旧索引 | 主体 | 仍应成立的行为 |
| --- | --- | --- |
| 0 | 沿用五舌焰锋，厚刃沿前缘出力 | 原来有成形和余焰消散。成形期间不移动、不接触，随后按原轨迹推进。 |
| 1 | 两道分开的窄焰锋，各有实体厚度与实际锋口 | 同 0 保留首尾阶段。两道锋共用原术的接触次数，间隙保留。 |
| 2 | 紧凑的亮刃，蓄火集中在较厚的短脊 | 原变体直接运行，结束后立即退出。 |
| 3 | 回钩焰锋，偏弯的一侧提前出锋 | 原变体直接运行，结束后立即退出。 |

第一段的必要验证是在正式入口逐一施放四个索引，确认费用、形体、真实接触、成形时无伤、正常结束及再次施放。用同场景复验改轨迹保持原索引。火系批次集中做新进程读档及连续画面。新形体从共同三维制作脚本发布，原版与 Worldfall 共用。

四个索引均已在原学习入口实测。同一场景中，双锋只伤侧边接触者，中央人物无伤。回钩变体改为折线路线后仍使用原形体，并按改造后原价支付。余焰固定在实际结束点后，索引 0 和 1 单独复验通过。构建、原始实测与收势补验汇总在 `~/.local/state/cultiway-dev/evidence/base-spells-1001/fire-blade/delivery.json`。

0–4 保留原成形和消散时长。成形时在起点聚合，命中后在真正的结束点消散。5–17 直接运行。十八个索引共用原火球的触发、爆发半径、伤害及支付。换形体时让飞行接触跟随真实主体，爆发取得完整余力，收束不产生新伤害或移动。

在同一场景逐索引检查正式施放、主体和真实命中。原成形和消散按同一规则验证，选一个落空和一次改轨迹验证爆发边界。将火刃和火球的全部索引放进一份正式世界，重新启动后读回并施放两个代表索引，再集中录下两种视角的连续画面。

十八个索引已在同一场景分两段验证实际命中。双股火焰可先碰到侧面的敌人，爆发仍从真实接触点取得完整余力，范围内每人只结算一次。落空到期只收束。改成追踪的蓝色交叉焰命中移动后的目标，保留原索引和支付。成形阶段没有人物接触，附加引力也等到进入飞行阶段才开始。默认火焰配色作为同材表面存放，改换材料仍走共同表面规则。

## 火系飞行批次交付

换游戏进程后，二十二份学习资料及交叉蓝焰的追踪轨迹完整读回。双锋火刃和交叉蓝焰均从读回的原入口重新施放，实际命中及费用保持。首轮冷读的对练阵营按原版种族恢复，沿用现有对练入口设回敌对后，以同一正式档补验施放。

原版与 Worldfall 共用逐部位火焰配色和透明收势，本批为飞行火焰增加沿实际形体卷动的亮部。两部总览各含二十二段连续施放，每段约 1.4 世界秒。火刃用广角保留结束点，火球用近景看形体。索引 10、12、17 的影片保留瞄准中轴时的实际落空，相应命中由同一场地的独立功能实测证明。

录像分别为 `火系飞行旧变体-原版.mp4` 和 `火系飞行旧变体-Worldfall.mp4`。逐索引结果、正式世界、复验过程与录像路径汇总在 `~/.local/state/cultiway-dev/evidence/base-spells-1001/fireball/delivery.json`。画面使用独立游戏软件渲染。10.01 继续处理其他基础法术。

## 水箭、水球和水刃的十三个索引

| 原术 | 各旧索引的轮廓 | 仍应成立的行为 |
| --- | --- | --- |
| 水箭 0–3 | 展开的箭尖、螺合水锥、扁平水梭、断续水层围出的短矢 | 沿各自带厚度的箭体贯穿，沿途真实碰到的目标各结算一次。 |
| 水球 0–4 | 卷入的整团水、深核与卷唇、厚实矮水珠、短尾重水滴、有间隙的回旋水团 | 仍用原抛弧与单次命中，落空及改成支持的轨迹时按原规则结束。 |
| 水刃 0–3 | 宽卷水锋、单翼上挑、短窄弧面、带厚度的扇尖 | 水刃沿真正可见的锋面扫过，侧外和水锋空处无伤。 |

三种来源各自的索引 0 和 1 都有原成形与消散，其他索引直接运行。优先复用火系已经验证的首尾处理。用同一场景逐索引核对实际形体与命中，每类只追加其独有的贯穿、抛弧或横扫边界。保存这十三份学习关系并换进程读回，再用双视角录像检查水体厚度、翻卷方向与实际接触面。水幕和潮浪属于各自接入批次。

十三个索引已从原学习入口施放。水箭与水刃沿实在的水体各命中两名接触者，水球在首个实际接触处结束，范围外无伤。成形时水流留在起点，余水在结束点变淡。回旋水团的中心保留空处。基础形体的部位、挂点和接触编号继续可用，新增水箭的箭尖挂点从实际表面的最前端取样。

在落空复验中，发现旧抛弧会越过指定点。现由实际出生和落点共同确定有限弧线，保留原四格抬升和半秒飞行上限。水球落空时在指定点收束，五个水球索引均已复验命中。共用路径的飞石也验证了真实首击。水球改追踪后继续保留原形体，能够命中移动后的目标。

正式档换进程完整读回十三个索引及追踪改造，三类代表变体重新施放成功。原版与 Worldfall 总览各含十三段施放。水箭和水刃用广角保留完整飞行，水球用近景展示卷动的内外水层。原版水箭、水刃沿用修正抛弧前已经录好的直射画面。两套录像都保留水球索引 4 从中轴落空的实际表现，对应的命中在独立实测中通过。逐索引、存档、测试与录像路径汇总于 `~/.local/state/cultiway-dev/evidence/base-spells-1001/water/delivery.json`。

九个索引已通过原学习和付费入口实测。飞剑与风弹各在首个接触处结束，金针和两种刃波沿途接触两名目标并各自只结算一次。索引 0 成形时留在起点，收势在实际结束点变淡。金针落空无伤，改追踪的第二种风弹命中移动后的目标。两种飞剑形体只用于已学飞剑，持握兵器仍用原兵器资源。

正式世界档另起游戏进程后完整读回九份学习资料，其中保留风弹的追踪改造。飞剑、剑气、金针、风弹和风刃各有一个代表索引在读回后重新付费施放。原版与 Worldfall 总览各有九段连续施放，近景展示剑身和翻卷风核，广角保留刃波和金针的完整飞行。原版录像保留短剑气的一次落空，独立实测已验证该索引可扫中两名接触者。

正式档、逐索引实测结果和两部总览汇总于 `~/.local/state/cultiway-dev/evidence/base-spells-1001/metal-wind/delivery.json`。火、水、金和风的这三批共覆盖 10 种法术、44 个旧索引，10.01 继续处理其余基础法术。
