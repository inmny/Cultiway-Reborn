# 动作维持与实际选取范围

3.09收尾，补齐[结构规模与资源需求计算](结构规模与资源需求计算.md)中的命名动作维持和实际选取距离。

## 维持跟随实际启动的动作

制作动作可以在自身操作中声明`Hold`，沿用已有的`At`和`Seconds`。这里的时点相对本次真实动作开始，沿用该动作自身的原时钟；等待接触、身体收势或前一步输出时，不会提前消耗维持秒数。

同一节点原有`Hold`继续按原含义工作。直接定时动作也接受操作内维持；同一原动作不能同时声明两处维持，创建时报告实际字段。超过动作长度、总寿命或没有实际动作的维持仍会被拒绝。

动作维持只暂停当前制作动作及其姿态过渡。独立飞行、旋转、生长和其他世界过程继续按各自时钟推进。显示骨架、随动作用形状和动作阶段读取同一进度；没有实际启动制作动作之前，不能把阶段作用区提前打开。正常完成、中断和后续输出继续根据真实动作状态确认。

明确的维持改造会处理原部位动作、条件动作及命名步骤。每段动作各增加所填的维持秒数，依次等待前一步完成的过程会按最长依赖链延后整次截止，不能只延长一次总寿命而截断后一段。静态区域延长存在及作用窗口，真实身体继续只发力一次。实际接触仍受原来的间隔和次数上限限制。

复制只推迟动作启动，不再把同样延迟加到动作内部的维持时点；完整历时伸缩同时调整动作内部时点与维持秒数。已用维持量属于单次施放状态，随共同数值快照回退，切换到另一次实际动作时重新开始。

## 选取距离与真实作用分别维护

`ConstructionReach`从同一编译计划生成候选包络。它用于决定目标是否可以作为出手候选，不制造额外作用区，也不承诺范围内任何位置都会命中。

- 作者明确填写`TargetRange`时保留该选择，包括比实际接触区更远的观察、投送或地点用途。
- 在目标处生成的构造和目标相对路径，缺省沿用12格控制距离；这种距离无法从零飞行速度反推出，明确填写后采用作者数值。
- 来源处或手部出手的构造，从实际接触端点、父子布局、挂点、制作动作控制链、生长上限、原操作及命名投送推导保守范围。运动包含加速度、使用时长、曲线路程、继承速度和真实碎片分散；没有显示的准备时间仍可能在推进运动，不能漏掉。
- 原版人物的手路、躯干和实际掌面或握持器物共同决定身体包络。模型比例、肩点和骨长与真实身体绑定共用常量，实际体高及目标身体半径参与候选距离。
- 体高只缩放相应布局和形状，独立飞行采用世界速度，不能因为人物更高而再把速度乘一次体高。

骨架端点的界限由实际控制父链、绑定点和所用动作推导，包含旋转中间姿态；不把某张画面里的姿态半径当作全程最大值。该包络可以偏宽，命中仍必须通过共同胶囊及实际时间窗口。精确路径与目标的交点、追踪成功率及复杂战术选择不是本条的范围。

当前距离用于候选建议，不能当作所有动态结果的绝对运行上限。后续3.10已补齐旋转脱落、曲线瞬时速度继承、事件后段及动作维持截止等声明预算，见[结构展开与执行预算](结构展开与执行预算.md)；以下保留3.09原始记录，不将它替代后续预算证据。

需求计算采用同一个定义层选取约定，数量、持续、尺寸、运动、冷却和重复作用仍按前一批的统一规则处理。不会因为扩大候选距离而扩大真实接触几何。

## 保存与复现

新增操作内维持为可选纯资料；没有该字段的正式构造沿用原行为。读取和登记不会重新定价；未取整需求基准、明确费用、阶段、引用和维持一起保存。复用已有第六版构造世界部分，不增加玩家配置、图片、模型或运行对象保存字段。

运行`python3 Scripts/SpellDemos/verify_range_and_motion_hold.py`。它复用独立游戏，检查动作、候选范围、真实远距离支付命中及相关回归，然后复用需求保存脚本完成真正重启。专项结果位于`artifacts/skill_rebuild/range-motion-hold/`，重启结果位于`artifacts/skill_rebuild/construction-pricing/`。

本批是构造数值与共同执行的验收，不代替最终战斗美术、所有流派或城市及世界规模性能验收。
