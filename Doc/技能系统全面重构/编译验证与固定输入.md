# 编译验证与固定输入

对应3.16。构造编译、改造优先级、资源缺失和版本重建使用统一命令，按变更范围选择。现有专项检查继续保留各自实际作用及保存范围，本入口直接执行选中的脚本，不再嵌套调用它们的整套回归。

## 命令与范围

```bash
python3 Scripts/SpellDemos/verify_compilation.py --list
python3 Scripts/SpellDemos/verify_compilation.py --suite compile
python3 Scripts/SpellDemos/verify_compilation.py --suite layers missing
python3 Scripts/SpellDemos/verify_compilation.py --suite versions
python3 Scripts/SpellDemos/verify_compilation.py
```

| 范围 | 实际检查 |
| --- | --- |
| `compile` | 全部正式构造与可复现输入的操作约定，命名输出依赖、真实执行与共同预算 |
| `layers` | 基础、来源、玩家与默认合成，零值、关闭、清空、真实编辑、支付和正式恢复 |
| `missing` | 形体、材料、表面、挂点、动作、阶段、身体、握持、资源通道及实际目标缺项；局部恢复隔离 |
| `versions` | 真实资源更新、定义变化、编译缓存重建、旧施放保持，以及缺失网格或动作时整次拒绝发布 |

多个范围按表中顺序运行，每个脚本只执行一次。第一项失败后停止并保留已执行结果，后续没有执行的项目不计为通过。只修改某个范围时运行对应命令；本入口不附带无关录像、窗口检查或整世界冷启动。

复用现有Worldfall私有游戏配置，启动与会话检查仍由已有工具负责；代码或资源晚于已运行游戏时，先退出该私有游戏再运行。结束后可用`python3 Scripts/SpellDemos/verify_view_switch.py --quit`关闭本配置游戏。普通玩家世界不会被载入或覆盖。

## 每轮记录

缺省结果目录是`artifacts/skill_rebuild/compilation-checks/日期与时间/`。可用`--output`指定项目内一个尚不存在的目录；已有目录直接拒绝，不覆盖历史失败。

- `metadata.json`记录代码及资源内容指纹、提交、选中范围、计划执行脚本与实际游戏进程。
- `inputs/`保留本轮定义、合成资料、版本变化输入、形体说明和固定世界；`inputs.json`逐文件记录内容摘要。
- 每项保留原脚本摘要、改写后的实际执行脚本和返回结果。定义与固定世界读取本轮副本，后来的文件变化不会静默混入当前场景。
- `summary.json`汇总实际完成项、断言数、成功或失败；通道编译及运行异常另存`error.txt`，不丢掉具体行号及原因。
- 全部结束后重新核对原代码、资源和输入内容。期间发生变化则本轮不计为同版本通过。

程序式生成的无效结构、错误依赖和数值边界保留在对应执行脚本内；固定构造见[构造输入](构造输入/README.md)，层级合成见[明确选择覆盖来源](合成输入/明确选择覆盖来源.json)，版本变化见[资源与定义重建](编译验证输入/资源与定义重建.json)。

## 版本检查的隔离

版本场景从本轮形体说明快照再建立可修改副本，资源包及其他内容通过链接读取。游戏暂停并等待共同计算完成后，脚本仅在不让出主线程的一段中临时选择该副本根，调用真正的`FormResources.Reload`；退出时始终恢复正式根并重载。

它实际抬高波浪动作的控制位置，比较旧、新真实接触高度；再改变同编号同修订的尺寸和费用，检查当前目录及旧施放。随后分别设置不存在的网格、删除正式构造正在使用的动作，确认失败不发布、不覆盖正式定义和有效缓存。最后核对正式资源与新尺寸共同重建，旧施放仍可继续读取旧资源。

这个场景不写正式`Content/Forms/`，也不为测试增加游戏设置或产品接口。原资源生命周期、窗口草稿和完整世界冷启动仍使用已有专项及相应工作包的验证。

## 资源说明

没有新增模型、贴图、动画或玩家界面。新增一份版本变化输入和一份调试脚本，复用当前厚浪形体和资源发布流程；测试副本及结果不进入模组发布包。

## 实机结果

Linux私有游戏197880由NML加载当前实现，统一入口最终完整运行六份脚本：操作约定27项、输出绑定33项、共同预算34项、改造顺序21项、实际缺项44项、版本重建16项，共175项通过。记录位于`artifacts/skill_rebuild/compilation-checks/final/`；结束核对`sameContent`与`sameInputs`均为真，原代码、资源和输入没有被测试修改。

本轮保存102份输入。版本场景的真实作用高度从约0.999775变为1.499775，原施放保持旧高度，旧模型和材质继续有效；同编号同修订改为尺寸1.4、费用6后目录采用新定义，旧施放本金保持4。缺失网格和删除正式动作都拒绝发布，当前缓存与正式定义保持有效。恢复正式资源后，真实作用高度按新定义尺寸重建。

首次版本脚本误把费用作为编译计划字段，调试编译如实失败；首轮汇总为失败并保留具体行号。改为检查施放实例的实际本金后，先单独运行版本范围16项，再通过最终四类运行。旧失败目录没有覆盖；对已有输出目录的再次调用也确实被拒绝，原失败汇总字节保持一致。

本批只修改开发工具、固定输入及文档，使用实际游戏通道编译执行脚本，没有重复无关SDK构建、资源包制作或画面验收。3.16收尾，第3工作包已按本页范围完成；统一进度108/328，下一项严格为4.01。
