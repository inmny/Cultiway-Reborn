# 可复用变化资料与缺失提示

对应2.11。已有操作继续共用构造、姿态、作用形状和材料状态；本批补齐真实裂纹资源及明确的缺失提示，不建立固定招式配方。

## 资料与资源

| 变化 | 实际资料与输入 | 支持范围 |
|---|---|---|
| 聚合 | 原有Gather的父挂点、目标布局、朝向及历时；新增裂片板assemble制作动作 | 保留部件身份；不同材料的独立子体仍使用原Gather，板内分件聚形使用共同控制 |
| 解体 | 已有真实部件、可分离连接、作用形状及Fracture参数；新增板体真实分件 | 继承当前完整姿态与运动，攻击碎片须明确指定 |
| 冻结 | 已有实际材料及物态、当前姿态与水层 | 同一形体原地定形，沿用已制作水冰厚度及层次 |
| 流散 | 已有有限格网、实际体积、动量、地表及水面资料 | 从真实材料开始；不把绘制泡沫当作新增水量 |
| 裂纹 | 新增fracture_slab：不规则轮廓、真实分区切面、独立控制、crack动作、作用与挂点 | 几何缝隙随同一动作建立，不用凭空的黑线代替；是否继续碎解由构造决定 |
| 生长 | 已有分枝根、藤、浪面及流路的截面中心、顺序与form动作；旧Grow整件缩放 | 两种用途明确区分；不把缺少截面资料的整件缩放冒充逐段建立 |

裂片板按确定的二维种子分区生成闭合薄体，各片保留原模型坐标及材料厚度。相邻片记录真实接合边，动作改变各片控制，接触、挂点、碎解继承同一姿态。材料可以由构造替换，不限制为一招或一种元素。

缺少模型、制作动作、分离结构或有效作用区时，在加载或编译边界报告具体资源、部位和所需资料；不退回默认投掷物，不在运行中反复查找补丁资源。

## 实机验证

复现：`python3 Scripts/SpellDemos/verify_form_changes.py --record`。使用独立游戏配置，录像和数值来自同一进程4016267；[实际结果与录像入口](../../artifacts/skill_rebuild/form-changes/index.html)。

发布资源`fracture_slab`有8片、8个独立控制、140个三角形，保留真实相邻边、闭合切面、每片接触段及表面挂点。`assemble`使原片聚合，`crack`使原接合边逐渐分离。`FormStructure.Supports("crack")`读取已发布动作声明；单独碎片移除整件开裂声明，普通动作仍可按原控制读取。

33项专项通过，覆盖聚形和开裂各五个阶段、作用矩阵、两种真实材料、冻结定形与解冻、两类模型的解体及流散、原Gather接入、两种生长资料、开裂材料数值保存恢复，以及三类缺失提示。两个动作的作用端点与真实片体矩阵误差均为0；聚形平均接合间距从约2.44降到0.00000051，开裂从约0.00000051到0.659。碎解前后取样相隔0.01秒，新板体姿态差约0.00586、铜镜为0，保留了原片运动；不是把这段正常推进宣称为零误差。

原版与Worldfall共12秒、1280×720、12帧每秒、144帧，分别展示金属板聚形碎解、水板开裂后冻结定形及解冻、同一板体进入实际水层。世界暂停，只推进验证构造；它们是开发验证输入，不是新增固定招式配方或自然交战验收。已查看聚形、实际冰态和流散阶段。

另有63项结构回归通过，检查18项当前资源（包括运行中登记的火体）、制作参数、语义、连接、实际分件、错误格式回退和旧资源保持。旧脚本曾因JSON成员顺序不同误报资料丢失；现在按字段名递归比较，数组顺序及数值容差仍保留，失败脚本留在`structure-regression/before-property-order-fix.script`。

原流散路径直接读取骨架边界，无骨架器物不能复用。现在使用加载时保存的绑定边界，不在工作线程读取网格；有控制的裂片板与无控制的铜镜均实际进入流散，10单位材料体积保持。其余流动规律沿用既有实现。

缺失提示实测包括请求的未知模型及当前可用模型、剑所缺的`crack`动作及可用动作列表、灵臂没有可分离真实结构；没有改用默认投掷物。新增中英文资源标签，中文经实际本地化入口读为“裂片板”。

SDK0错误、16条原有警告；C#按仓库DotSettings整理，Python、JavaScript语法及差异空白检查通过。三平台资源包已构建，仅Linux实跑。没有GameResources图片、新玩家设置或存档格式变化；本轮保存检查是正式材料数值往返，不冒称完整世界冷启动。

## 保留边界

裂纹由构造明确启动制作动作，不从染色或一般余力自动猜测损伤；冻结继续保留当前内部姿态。作用区使用有限接触条带近似，不是逐三角形碰撞。碎片的体积和预算分配沿用既有等份规则，没有宣称按几何体积推算密度。固定分件碎解与动态格网流散仍不能同时声明在同一部位，需要不同结构或明确后段交接；完整复合变化继续按5.20等任务完成。

2.11至此完成六类变化所需的可复用资料与缺失报告。完整流派美术、任意材料混合、来源迁移和所有复合过程仍在对应任务中完成。
