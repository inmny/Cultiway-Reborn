# 9.13 木系实战表现

沿用现有对靶和正式施放入口。完成条件是木体有可辨认的结构，成形、承力和失效能从原版及 Worldfall 常速录像看懂，同时有对应的实际接触证据。两批都通过后才关闭 9.13 并合并。

- [x] A 灵藤：主根先长，侧枝随后展开，细梗接到真实枝条上，叶面在梗尖展开。受击由已成形的根芯决定；根尖未到和侧面叶片不先造成伤害。复验正常命中、作用区外无伤、整株退场；保留原施放入口、寿命、费用和连续推进，记录原版及 Worldfall。
- [x] B 木壁：粗根落地，几根横向枝条盘结出真正的墙面，松枝和叶面保持可分辨。已有容量承担来弹；普通迎击只在命中位置反馈，真实打穿才断开，不让碎枝继续拦截。复验真实挡弹、打穿后通行、自然结束，记录两种视角。

| 资源 | 制作重点 | 作用对应 |
| --- | --- | --- |
| `creeping_vine` | 三条有主次的根芯、较细侧枝、折面叶、分阶段伸展 | 成形进度、骨架和接触面共用；叶面无接触 |
| `wood_wall` | 粗根受力、横枝盘结、局部折断 | 真实屏障与破坏事件决定受力及失效 |

木矛与落木保留各自的材料与稳定形体。本项复用现有换材、世界时间和碰撞规则；额外地形、天气和新的元素交互不插进这一项。若制作品质在任一视角过不了，保留原片作为对照，只补受影响的画面与行为。

灵藤采用三根不同厚度的根芯。主根先探出，侧根张开时细梗与折叶跟着母枝一起动；叶面换材仍读现有材料槽。原寿命、费用和完整姿态下的 24 段接触轴及半径保留。根芯成形进度由共同动作提供，查询也从同一姿态读取，未展开处不会提前命中。

灵藤的独立实机复验使用原学会的施放入口。初段仅有主根的 1 段接触，侧枝生长后达到 22 段，完全展开为 24 段。正前对靶实扣 80 点，侧外人物无伤；一次扣除 1.3 灵力，原时限结束后实例移除。两种视角先留有同一动作的空挥对照片；对靶过远不计为实战录像命中。补拍时复用相同人物和战斗规则，只把主目标放到六格处。原版和 Worldfall 的常速成片均有一次真实命中、一名人物受伤及正常退场。证据目录为 `~/.local/state/cultiway-dev/evidence/wood-combat-913a/delivery.json`。

木壁由十一根粗根、两条横向盘结枝及四组带叶的嫩枝组成。枝叶跟着同一套骨架展开；原有 33 段接触仍取根芯，半径不变。落根、站稳和退场共用一条动作，默认四秒寿命、原容量和费用沿用正式施放规则。

实机用两枚石锥验证了承力与破坏。第一枚消耗 13 点容量，墙还剩 487 点，只在实际撞点落下两片木屑；第二枚耗尽剩余容量，墙立刻停止作用并裂成 21 个无作用的分件。重弹越过原墙面，碎枝到期撤除。游戏寻路使用的共同屏障查询能阻止贴地敌人穿过站稳的墙面。自然退场分段复验：约 3.95 秒时仍阻挡，约 4 秒时解除；自然结束不生成碎枝。最初三维录像发现坡地的高度差被重复带入碎枝速度；共同碎解改用上一帧已贴地的实际姿态，最终实机最快碎枝约 2.12 格／秒。

在独立游戏的 `dev.py exec --timeout 225 --` 后运行 `python3 Scripts/SpellDemos/verify_wood_growth.py` 可复验。录像用以下入口；Worldfall 改为 `--view worldfall --zoom 10.5`，并使用独立的输出目录。

```bash
python3 Scripts/SpellDemos/demo_spell.py SpiritVine --cases base --scene single --realm 0 --speed 1 --view native --zoom 9.5 --duration 1.55 --fps 24 --target-offset 6 0 --motion-trace --keep-frames --output <原版输出目录>
```

木壁使用 `python3 Scripts/SpellDemos/verify_wood_wall.py`；`--section break` 只查两次交锋，`--section exit` 只查自然结束。录像用 `demo_spell.py WoodWall --cases base --scene shield --realm 2 --speed 1 --view native --zoom 12.5 --target-offset 8 -5 --duration 2.8 --fps 22 --shield-break --motion-trace --keep-frames --output <原版输出目录>`。自然退场录像去掉 `--shield-break`，把时间改为 4.85 秒；三维录像改 `--view worldfall --zoom 16.5` 并用独立输出目录。

原版和 Worldfall 各保存一段打穿、一段自然退场的常速录像。两段打穿片均录到 13 点轻击、487 点剩余容量耗尽及 21 个碎件撤场；自然退场片录到来弹被挡、墙体回落且无碎枝。行为与录像分段验证；两种视角的碎解画面已查看，碎枝速度由独立实机复验读取。录像、关键帧和先前失败都可从 `~/.local/state/cultiway-dev/evidence/wood-combat-913b/delivery.json` 查到。
