# 表面受光与自发光

本批完成全程TODO的1.07所需绘制能力验证。它验证表面资料能够进入Worldfall，不代表各流派美术已经通过最终验收。

## 实际受光

旧表面读取了主光方向，却没有使用Worldfall提供的主光颜色和环境光颜色，因而夜景仍保留白天的固定底色和反光。

当前金属、木、皮肤、水、冰、泡沫读取同一帧的`_FP_LightCol`和`_FP_AmbCol`。基础受光、表面反光及近似天空反射随实际光色变化。完全无光时普通材料不凭空发亮；光照不改变厚度和透明度。原版投影仍使用自己的受光约定，不读取三维端的光色，切换后不会沿用上个视角的夜景。

熔铁与火体沿用明确材料表面类别，保留自身辐亮，并在实体场景资料中提交发光份额。普通金属、木材等不提交该份额。它是表面自发光及外部后处理可使用的发光资料，不等同于已经向附近人物和建筑投射局部灯光。

| 内容 | 资料与表现 |
|---|---|
| 普通实体 | 实际主光和环境光，受光方向与反光颜色对应 |
| 水、冰和泡沫 | 同样受场景光色影响，厚薄与透明度保持原值 |
| 熔铁和火体 | 无外部光仍发亮，实体资料提供发光份额 |
| 纹理与骨架 | 仍由原网格表面坐标、细节纹理、权重及共同姿态驱动 |
| 制作源与发布 | `FormSurface.shader`及现有三平台形体资源包 |

## 开发入口

演示工具新增`--lighting day|night`，默认日光。夜景仅接受Worldfall观察和第一人称，避免给原版画面错误贴上夜景标签。条件进入录像清单与版本对照；结果同时保存实际外部昼夜模式、主光色与环境光色。

```bash
python3 Scripts/SpellDemos/demo_all.py --construction Doc/技能系统全面重构/构造输入/厚浪凝冰与解冻.json --view firstperson --lighting night --duration 4.5 --output artifacts/skill_rebuild/lighting-example
```

`verify_surface_depth.script`现在覆盖31项真实绘制检查：前批的遮挡与透明、水冰厚薄18项，普通材料昼夜、无光、透明度、主光色、主光方向、熔铁／火体发光、原版独立受光，以及实际纹理采样和顶点骨架变换。后两项实际比较不同纹理的绘制颜色与骨架移动后的几何覆盖，不能仅靠资源字段存在冒充已绘制。

资源、动作与接触共同姿态的41项检查通过，工具版本的3项回归通过。三平台资源离线构建通过，Linux经游戏加载，Windows及macOS未作当地实机验证。

## 已知边界

还没有接入Worldfall全部局部灯、投射阴影或真实环境反射图。近似反射只随实际光色变化；透明体与外部精灵的共同排序、完整折射、原版完整遮挡和近裁剪仍按原TODO继续推进。夜景视频用于验证受光，不因画面暗而擅改用户全局画风或提高所有材料自身亮度。
