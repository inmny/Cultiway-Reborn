# 能力演示入口（14.01）

继续使用 `demo_all.py` 遍历和 `demo_spell.py` 指定单项。两者从独立游戏读取同一份目录，保留旧来源的正式入口。已登记的构造和当前世界内保存的自创构造按原编号选择。录制前冻结整份资料，切到测试世界后才学习和出手；录制结果附上实际采用的资料和正式施放记录。文件方式 `--construction` 继续保留。

目录中暂缺场景的构造会说明需要哪些输入。已有器官、库存物项或特定资源的资料保持原样，不能通过删掉原条件、换成人形或用假伤害来录制。借用真兵器时从游戏登记匹配原器形的装备规则。原法术的变体、词条及轨迹选项继续沿用原入口；构造原式使用完整构造资料，构造改造的入口归 14.03。

本批先核对构造接入：同一批原版录像混合旧火球与已登记横拍，并验证切换和收尾；用 13.13 已保存的自创战技核对 Worldfall 的点名和原资料恢复。无法满足的器官场景必须能从目录查到并明确拒绝。14.01 完整交付还需接通按实际目标模式准备地块、自身及其他来源专属场景。种子再创作、搜索维度、长期效果及详细记录仍按第 14 组对应条目验收。

## 首批实测

原版遍历同批录了火球与横拍。火球生成一次实际执行，横拍正式施放一次、实扣 83 点生命，随后恢复测试世界。Worldfall 从 13.13 的正式世界数据读回「击劲诀」，指定原编号，送入运行器的完整资料与读回资料一致。原站位受理并扣费但落空；保留这段失败，复用同一招并按实际短掌范围设置测试对手位置后，正式支付 23 点体力、命中一次并实扣 200 点生命。结束后恢复测试世界。「卷尾横扫」可列出，直接指定时明确报告需要原器官场景，不产生空录像。

```sh
python3 .agents/skills/develop/scripts/dev.py exec --timeout 145 -- \
  python3 Scripts/SpellDemos/demo_all.py --filter Cultiway.Fireball,Cultiway.Body.SweepingPalm \
    --cases base --view native --duration 2 --zoom 8
```
