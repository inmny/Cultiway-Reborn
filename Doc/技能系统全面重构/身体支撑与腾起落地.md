# 身体支撑与腾起落地

对应4.18。足底路径、本体离地高度与手脚头部、躯干转体共用身体关键点和世界时间；进退、侧移、冲撞及水平障碍处理继续4.19。

## 共同资料与实际执行

`BodyMotionKey.Support`可选。采用时须覆盖全部关键点，分别提供`LeftFoot`、`RightFoot`和`Rise`，均按实际体高缩放。左右足位置相对本体脚下，`Rise`为本体相对实际地表的高度，躯干前压及屈伸仍由原有`Torso`、`Turn`描述。起势和收势回到已声明的双足站姿，避免结束时突然落地或脚底跳回。

两足与离地高度在相邻关键点间平滑连接，不超出制作高度。足底和本体均在地面时才提供支撑；接地足底不能在两关键点之间平移，换落点须先抬足。单足支撑只约束实际接地的一侧，腾空时不再把双脚钉在地面。参考身体及Worldfall实际身体分别按固定腿骨求出髋、膝、足；手部、头部动作也携带同刻双腿，不再仅驱动上身。

实际人物的离地高度在共同接触步骤确认后提交，预测和回退只计算数字。施法源、目标选取、身体接触和生成形体读取同一时间的脚下位置，绘制继续只读完整发布状态。原版下落仅在确实取得高度控制时让位，普通旧动作保留原下落。完整调速、维持和暂停共同影响足底及离地过程。

正常触地走原版落地通知；空中取消时保留高度及竖直速度，交给已有世界时间受力下落。外部受力接管时不覆盖其速度，切世界释放高度控制。

腿部动作已有的`Foot`与该侧支撑足底须一致，避免两份资料宣称不同的位置；距离改造仍作用于同一实际足底。独立器官不套用人形支撑，非人支撑继续4.29。没有新增玩家设置、模型、贴图或独立运动维护器。保存沿用完整构造资料，旧资料缺省保留固定站姿。
