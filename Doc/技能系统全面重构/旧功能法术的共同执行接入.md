# 旧功能法术的共同执行接入

## 本批范围

推进4.01、10.13和12.04。八种既有功能法术的默认形态，以及已经能够完整解释的范围、熟练、多发和显现轨迹改造，现在从真实来源的发射步骤进入共同构造执行。旧学习与来源仍是正式知识，不额外授予另一份测试构造；原法杖条件、资源报价、任选或同时支付、发射次数及间隔继续由原来源维护。

| 原能力 | 共同世界原理 | 实际结果 |
|---|---|---|
| 抬升地形 | `terrain.raise` | 改变原版主地形层级 |
| 降低地形 | `terrain.lower` | 改变原版主地形层级 |
| 注水 | `water.fill` | 把原版允许注水的干海床填为对应海水 |
| 排水 | `water.drain` | 把原版海水还原为同层干海床 |
| 自然生长区域 | `nature.grow` | 周期调用原版植被生成 |
| 净土区域 | `land.cleanse` | 周期清除污染，保留原有道路和建筑保护 |
| 雨云 | `weather.rain` | 生成由正式天气拥有者保存的原版云 |
| 催熟 | `crop.mature` | 让原版麦田真正成熟并保存生长进度 |

这一批切换的是实际执行，不是播放一个新外观样板。没有在旧效果之外再执行一遍世界操作，也不在新执行入口重复扣费。旧容器、全局蓝图及书籍仍待正式资料转换；未接入的状态类词条、其他轨迹、无人物来源和直接旧生成接口继续留在原路径，不能据此宣布所有来源迁移完成。

## 收费与每次实际发射

`SkillEmission`保留已经安排好的真实步骤、归属、空间载体、目标、强度、关联及本次世界边界。旧来源仍负责受理和收费；共同执行接受一份不含旧实体和委托的当前资料，不把外部来源混入已学构造目录。

脚本、玩家或自主方式从原能力入口传到共同开始事实，任务关联编号保持。边界已经失效时在收费前拒绝；已受理步骤到达发射时边界失效，则结束该步骤，不能回落旧执行再制造副作用。

世界模板默认仍只发射一次。原系统曾把世界模板强制单发，使明确添加的连发或齐射只改变费用；现在这两类词条形成真实步骤，合计最多64步，并由实际计划一次收费。多次发射产生多个真实过程，可以同时存在。实际范围由当前容器词条、设置和施法者成长共同计算，不能把原范围缩小成固定测试半径。推进领域沿用原速度配置和加速词条。起步至巡航的曲线通过八个速度更新时点进入共同运动，收势时停止推进。涡旋复用按经过距离展开的公共曲线。

## 区域与显示分开

新增`world_domain`资料，只有明确的区域作用形状，没有显示网格。形体的作用区可以绑定根部，`FormContactDescription.Part = -1`表示不依附某个可见部件。它适用于区域规则，不把每次抬地、净化或催熟都伪装成飞剑、水团或烟雾。

各操作使用普通子结构，分别声明生效开始和频率；复合世界效果不因共享一个区域而提前触发较慢的原理。实际变化由原版地形、植被、农田和天气展示。这里没有制作最终施法动作、区域表面和流派美术，也不以没有网格的区域冒充完成视觉重制。

普通实体接触地块边沿仍可生效。区域规则新增可选的`TileCentreOnly`，只按地块中心决定成员；转换时对齐原版地块坐标，使旧法术不会因为接触了边沿而多改一圈地。共同几何、连续扫掠、频率、重入及任务边界照常执行，目标高度来自同一地表。

## 原资料与保存

原有已学关系、具体词条数值、改造轨迹与收费规则仍随正式存档保存。瞬时功能模板同时声明已经实现的显现与地面显现兼容域，使合法转换也能通过正式保存恢复校验；不能只在发射时接受、读档时再丢弃。读档不重放已结束的发射，之后新的实际使用重新编译为共同计划。转换结果只作可重建的运行资料，不保存旧对象引用，也不根据随机数重新创作技能。

原有指定与遍历演示也统计共同开始和实际地块结果，使用脚本来源标记；每段结束后边界失效，清理本测试施法者的独立雨云，避免前一段改变下一段。

此批未更改正式区段格式，不需要手工迁移。原型来源的完整格式转换、万法阁及书籍引用、全部状态词条与所有轨迹仍在后续范围内。

指定演示的唤雨，以及遍历入口的净土和唤雨共三段通过，记录`Script`来源、真实施放次数和地块结果。各工具目录保留自身录制时的版本；总览不回写其历史指纹。

## 10.13 分批结束条件

- A1 世界来源。已经受理的无施法者序列使用共同地块执行，保留实际发射时点、固定坐标、原范围和同容器并存规则。复用现成世界，检查真实瞬时和持续地块结果、任务失效后的停止、再用及资源归属。提交代码、复验入口及结果。需要实际跟随对象的世界步骤在轨迹批处理。
- A2 轨迹和词条。按旧法术实际允许的改造收齐不同轨迹、状态、触发时点与范围，保留世界步骤和对象步骤的各自条件。验收改造效果和结束后再用。
  - A2a 落地状态。减速、冰冻、硬直、衰弱、破甲和封印在原落地时点按单位中心与原敌对关系结算。持续区域保留地块周期，原来未触发的对象状态不新增触发。复用现成场景，检查正式学习、实际落地、边界与同阵营、状态期限、地块效果和再次付费使用。交付可指定本段的复验入口及实际结果。
  - A2b1 落地伤害词条。接入燃烧、中毒、长时诅咒和燃尽，按原每发强度计算，保留同源毒层上限、同类燃烧刷新、直接附加伤害的对象及后续周期。沿用同一场地，检查首发数值、实际扣血、边界、超层刷新、效果到期和再次使用，并保留真实地块结果与逐发扣费。换位、推力、随机、范围及条件类词条属后续接触批次。
  - A2b2 击退、换位和回生。落地后按原地面范围选定对象，保留两种位移的原组合作用顺序；用共同受力和身体归还处理两端。换位和回生作用于实际施法载体，学会与付费仍属于原人物。复用抬地场地，验收真实击退和落地、代施者换位与恢复、空中不换位、地块结果及再次施放。

  - A2c1 移动领域与混沌。实际发射保留推进的起步和巡航、涡旋的沿程偏移、跟随人物和建筑及对象失效后的原坐标。混沌只在每发实际开始时抽取，沿用原强度、速度和方向规则。保留领域成形、地块周期和收势时点，以及原编辑许可。复用净土和现成地图，检查推进和涡旋实际位置、跟随转移与失效、地块变化、结束及再次发射。交付分段复验入口与实测记录。

### A1 世界来源实测

世界事件可沿无施法者序列发出已接入轨迹的功能法术。调度人物只负责发射前的序列有效性。发射后保留世界归属和原容器的并存限制，地块操作根据实际任务边界提交。任务失效会停止已经运行的过程。跟随实际对象的世界步骤见 A2c1。

原版独立游戏分段复验通过。抬地在延时后实际改变九格，保留被任务排除的地块、范围外地块和范围内的稻田。净土连续发出三处，第三处替换最早的一处，保留的两处按周期生效。失效后实际停止，新任务可以再用并自然结束。共同发射路径的独立复验记录排队与发射时均未扣调度人物的法力，且无旧执行体。

原脚本的地图路径、词条初始化、占用稻田的预期及临时容器引用问题均保留失败记录。净土段的行为通过后，末尾跨多帧法力读数受原版回蓝影响；用同一发射入口在实际操作前后取样补验。结果来自多个分段。录像和正式资料冷读集中到 10.13 整项。 [本机实机记录](/home/inmny/.local/state/cultiway-dev/evidence/utility-migration-1013/world-source/delivery.json)

### A2a 落地状态实测

原落地轨迹按实际落点、单位中心和敌对阵营施加六类状态。状态仍沿共享的强度、期限与来源规则结算。持续净土地块保留原周期，原版没有触发对象词条的持续区域维持这个行为。落地状态不增加伤害，不改变地块可施工条件。

原版独立游戏通过一轮完整复验。六种词条与地面升起轨迹从正式蓝图学习，抬地有真实地块结果，实际敌人收到六种状态且生命值保持。同阵营和范围外敌人均未受状态；冰冻、硬直按原效果倍率持续 1.5 秒，其他四项为 2 秒。状态到期后再次施放，同一个用法重新付费并生效；净土在真实地块继续生效。三次均由共同执行受理，实际发射前后法力相等，原入口在发射前已扣费。

保留测试脚本的首次编译失败，以及根节点路径错误导致未触发落地状态的实机结果。修复后另起进程完整复验。其他接触词条和轨迹继续 A2。 [本机实机记录](/home/inmny/.local/state/cultiway-dev/evidence/utility-migration-1013/landing-status/delivery.json)

### A2b1 落地伤害词条实测

燃烧、中毒、长时诅咒和燃尽使用同一份每发强度，保留蓝图威力、强化、逐发倍率和原状态刷新顺序。功能法术的地块作用区本身不携带这份攻击强度。燃尽先让原地块作用走完，再提交人物火伤和建筑受击，避免同一发摧毁建筑后补改原受保护的地块。

原版独立游戏分段通过伤害词条和六种控制状态的回归。伤害样例每发强度为 150，燃烧、中毒和诅咒分别记录每秒量 13.5、12 和 9。燃尽首发使敌方人物生命由 5302 降到 5286，摧毁受击建筑，原建筑下地块未补做抬升。之后周期伤害继续扣血。第三次施放保留原两份毒层并刷新，附加状态到期后再次施放可重新产生真实地块和状态。逐发扣费与共同执行均已核对。

首次复验用省略整数位的小数字符串，正式蓝图校验拒绝。改用规范数值后通过，失败记录保留。换位、推力、随机、传播与条件类词条以及轨迹继续 A2。 [本机实机记录](/home/inmny/.local/state/cultiway-dev/evidence/utility-migration-1013/landing-damage/delivery.json)

### A2b2 击退、换位和回生实测

击退沿共同受力推进，实际落地后归还受力。换位按原地块交换，先归还双方旧的动作与受力。实施换位前固定本次对象，避免同一个人移到另一块地后重复成为对象。两种位移同时存在时按旧容器实际排列执行。换位和回生使用实际施法载体，回生保留原威力折减及恢复比例，命魂载体仍恢复其完整度。

使用同一原版独立场景分段验收。真实敌人从横坐标 69 被击退至 71，腾起后正常落地，抬地结果成立。通过实际代施入口时，代施身体和目标交换地块，代施身体恢复 20 点，原人物独立付费。目标在实际结算时处于空中，换位未发生，抬地继续，目标正常落地后再次施放可以换位。组合作用样例先击退后换位，换位归还受力，目标留在换位地块。

首次空中检查在结算之后取值，当时目标已经落地。保留该记录，并用实际持续腾起及结算时高度补验。其他词条与轨迹仍按 A2 推进。 [本机实机记录](/home/inmny/.local/state/cultiway-dev/evidence/utility-migration-1013/landing-movement/delivery.json)

### A2b3 随机、爆炸与条件词条实测

随机附加复用六个已有候选，每个实际对象按原概率取至多一个。爆炸按实际对象所在位置和原水平半径传递自己的伤害，同时提交本发地面元素。终焉在原阈值两边分别提交普通附伤和斩杀。轮回仍按结算前目标生命与本发试练伤害比较，真实受击继续走原队列，恢复或反噬分别交给实际载体。位移及以上作用依原容器的实际顺序提交。

原版独立场景分段确认随机抽到一份中毒。爆炸只把自身伤害传给附近对象，原范围外的敌人实际受伤，硬直仍留在原对象上，友方和远处对象无此次伤害。逐发选择土元素时，原落地范围外的沙地实际变为土壤。轮回两次分别使代施身体损失 24 点、恢复 15 点，原归属人物生命保持。终焉高生命分支挂标记并扣血，低生命分支实际斩杀。原地块效果、逐发支付和击退换位顺序一并复核。

保留跨帧生命读数误判、默认地面元素预期错误，以及不兼容性质材质被校验拒绝的初次记录。正式复验使用带来源的实际伤害结算和已有逐发元素入口。剩余轨迹及随动词条继续 A2。 [本机实机记录](/home/inmny/.local/state/cultiway-dev/evidence/utility-migration-1013/landing-affixes/delivery.json)

### A2c1 移动领域和混沌实测

净土成形时停在出生点，初段推进快于巡航，之后每秒推进约 3.5 格，在实际移到范围内的地块上净化。两发混沌各自确定方向和速度，同一发的巡航读数稳定。无施法者的涡旋产生了实际前进与横摆，也净化了经过的地块。试验使用原容器和真实发射队列，现有编辑许可照常。

无施法者领域从人物实际位置开始。人物从 64 格移到 74 格后，新位置净化，间隙地块没有变化。人物死亡后回到原提交的 60 格并继续净化。人物发出的领域也可绑定建筑，拆除后同样返回原坐标。所有分段的自然结束已核对。

推进与混沌在首轮的前段通过，后续分段补齐涡旋、人物和建筑。保留原脚本问题，以及修复前无人物涡旋异常和随动漏算地块周期的记录。引力继续在 A2c2 验收。 [本机实机记录](/home/inmny/.local/state/cultiway-dev/evidence/utility-migration-1013/field-motion/delivery.json)

### A2c2 引力实测

成形期间没有受力和净化。净土开始后，范围内敌人离地并向中心移动，同阵营人物和范围外敌人都留在原处。移到新中心再施放，敌人的水平移动换向，净化继续照常，结束后两次均恢复普通运动。瞬时抬地也实际完成引力、地形变化与落地恢复。该段由原发射队列连续完成，没有旧执行体接着施力。 [本机实机记录](/home/inmny/.local/state/cultiway-dev/evidence/utility-migration-1013/gravity/delivery.json)
