# 旧功能法术的共同执行接入

## 本批范围

推进4.01、10.13和12.04。八种既有功能法术的默认形态，以及已经能够完整解释的范围、熟练、多发和显现轨迹改造，现在从真实来源的发射步骤进入共同构造执行。旧学习与来源仍是正式知识，不额外授予另一份测试构造；原法杖条件、资源报价、任选或同时支付、发射次数及间隔继续由原来源维护。

| 原能力 | 共同世界原理 | 实际结果 |
|---|---|---|
| 抬升地形 | `terrain.raise` | 改变原版主地形层级 |
| 降低地形 | `terrain.lower` | 改变原版主地形层级 |
| 注水 | `water.fill` | 把原版允许注水的干海床填为对应海水 |
| 排水 | `water.drain` | 把原版海水还原为同层干海床 |
| 自然生长区域 | `nature.grow` | 周期调用原版植被生成 |
| 净土区域 | `land.cleanse` | 周期清除污染，保留原有道路和建筑保护 |
| 雨云 | `weather.rain` | 生成由正式天气拥有者保存的原版云 |
| 催熟 | `crop.mature` | 让原版麦田真正成熟并保存生长进度 |

这一批切换的是实际执行，不是播放一个新外观样板。没有在旧效果之外再执行一遍世界操作，也不在新执行入口重复扣费。旧容器、全局蓝图及书籍仍待正式资料转换；未接入的状态类词条、其他轨迹、无人物来源和直接旧生成接口继续留在原路径，不能据此宣布所有来源迁移完成。

## 收费与每次实际发射

`SkillEmission`保留已经安排好的真实步骤、归属、空间载体、目标、强度、关联及本次世界边界。旧来源仍负责受理和收费；共同执行接受一份不含旧实体和委托的当前资料，不把外部来源混入已学构造目录。

脚本、玩家或自主方式从原能力入口传到共同开始事实，任务关联编号保持。边界已经失效时在收费前拒绝；已受理步骤到达发射时边界失效，则结束该步骤，不能回落旧执行再制造副作用。

世界模板默认仍只发射一次。原系统曾把世界模板强制单发，使明确添加的连发或齐射只改变费用；现在这两类词条形成真实步骤，合计最多64步，并由实际计划一次收费。多次发射产生多个真实过程，可以同时存在。实际范围由当前容器词条、设置和施法者成长共同计算，不能把原范围缩小成固定测试半径。当前移动区域按原运动配置的巡航速度和加速词条转换，启动冲量仍需后续完整统一；显现和定点区域没有这项差异。

## 区域与显示分开

新增`world_domain`资料，只有明确的区域作用形状，没有显示网格。形体的作用区可以绑定根部，`FormContactDescription.Part = -1`表示不依附某个可见部件。它适用于区域规则，不把每次抬地、净化或催熟都伪装成飞剑、水团或烟雾。

各操作使用普通子结构，分别声明生效开始和频率；复合世界效果不因共享一个区域而提前触发较慢的原理。实际变化由原版地形、植被、农田和天气展示。这里没有制作最终施法动作、区域表面和流派美术，也不以没有网格的区域冒充完成视觉重制。

普通实体接触地块边沿仍可生效。区域规则新增可选的`TileCentreOnly`，只按地块中心决定成员；转换时对齐原版地块坐标，使旧法术不会因为接触了边沿而多改一圈地。共同几何、连续扫掠、频率、重入及任务边界照常执行，目标高度来自同一地表。

## 原资料与保存

原有已学关系、具体词条数值、改造轨迹与收费规则仍随正式存档保存。瞬时功能模板同时声明已经实现的显现与地面显现兼容域，使合法转换也能通过正式保存恢复校验；不能只在发射时接受、读档时再丢弃。读档不重放已结束的发射，之后新的实际使用重新编译为共同计划。转换结果只作可重建的运行资料，不保存旧对象引用，也不根据随机数重新创作技能。

原有指定与遍历演示也统计共同开始和实际地块结果，使用脚本来源标记；每段结束后边界失效，清理本测试施法者的独立雨云，避免前一段改变下一段。

此批未更改正式区段格式，不需要手工迁移。原型来源的完整格式转换、万法阁及书籍引用、全部状态词条与所有轨迹仍在后续范围内。

## 验证入口

- `Scripts/SpellDemos/verify_utility_migration.script`：通过原已学能力入口遍历八种真实能力，检查实际收费、共同开始与结束、地块成员、真实原版结果、范围与多发改造、替换轨迹和失效任务；录制过程并保存。
- `Scripts/SpellDemos/verify_utility_migration_restart.script`：真正退出重启后比较原已学关系与改造，重新施放并核对只有共同执行，重复保存不遗失或复制技能。
- 原地块接触回归：检查默认整块接触、频率、重入与收益，防止区域中心规则改变实体语义。

## 实测结果

首次运行58项、真正重启11项、原地块接触回归43项，共112项通过。3483365保存、3488775恢复；十项原术及改造按原顺序和签名恢复，实际多发重新产生两个共同过程，未创建旧执行体，正式恢复和再次保存没有丢弃项或备份错误。连发改造使用正常可保存的词条及其派生发射参数，未把派生缓存伪装为独立永久词条。

八个默认来源均真实进入共同执行。抬地、降地、注水和排水各实际修改69块地，净土实际清理117块，生长实际生成32项植被，雨云及催熟各产生一次真实结果；范围分别为本场人物成长后的4.6格、6.9格或单块地。麦田在真正提交时直接核对原版成熟组件，后续正常维护或收获不冒充法术结果。原地块回归另核对正常农田的持续存在和保存。

指定演示的唤雨，以及遍历入口的净土和唤雨共三段通过，记录`Script`来源、真实施放次数和地块结果。各工具目录保留自身录制时的版本；总览不回写其历史指纹。

[录像与完整结果](../../artifacts/skill_rebuild/utility-migration/index.html)保留八项功能顺序展示的122帧、约14.56世界秒，以及指定和遍历入口录像。代码、资源与当前工具内容指纹为`4a98c5f1ed747f6ceb5d64638e88f0b1c06b6f34496ee533abbe9f57b087ed67`。开发构建0错误、原有16条警告，游戏内NML实际编译加载，提交前使用仓库配置格式化。没有计作最终战斗美术或Worldfall验收。
