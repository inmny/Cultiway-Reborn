# 5.15 空间映射与转移

## A：同一法术形体穿过双门

- [x] 在命名步骤选定一个生成形体及两个实际存在的入口、出口部位。形体在入口半径内才转移；出口保留它相对入口的位移和朝向，飞行中的方向、速度一起旋转。两个门的视觉大小不拉伸形体。已经脱离的部位不随它转移。
- [x] 保留同一形体、材料、剩余力量、寿命和命中记录。只在离开前的真实移动和出口落点计算接触，门间空隙不伤人。门未启用时等待；门已结束或形体不在入口时不会产生完成结果。配置自连、同一门或用随主体移动的下属部位作门时，编译拒绝。
- [x] 复用现有测试世界与剑形资源，验证出口位置和飞行、无空隙伤害、到达后命中、非法关系和未入门时的后续步骤。交付代码、复验入口和证据。本批只覆盖独立的生成形体，人物、持物和动态曲面另做。

实机完整复验通过：门间目标生命保持 12726，出口目标由 12726 降至 12588，伤害仍归原施法者。飞行距离触发也验证：不把门间空隙算作行程，出口继续飞行后仍能触发。首次试验的场景失败保留；最终在独立环境中执行 `verify_spatial_mapping.py --section all` 通过，构建零错误、16 条既有警告。完整证据在 `~/.local/state/cultiway-dev/evidence/spatial-mapping-a/delivery.json`。

## B1：同一生灵经短程双门移动（下一批）

先接通一个在入口被真实接触且符合关系规则的生灵，出口用实际地表和占位判断是否可落脚。出口确认后才解除旧身体动作和受力，更新原人物的地块、坐标与显示；失败时保留人和旧控制，不能假报搬运成功。只复用一个人物与现有地面：验证正常抵达、出口不可用时无位移，以及结束后能正常移动和再次使用。本段交付代码与复验入口，持物、多人承载、保存和录像按照后续分批。
