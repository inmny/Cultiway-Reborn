# 9.23 阴阳双端转移：开工前固定

「两仪渡气」把施术者和选定的一名同道连起来。实际接触时，比较两人各自灵气占上限的比例，每段只把有限的灵气从较满的一端渡向较空的一端，最多到两边比例相等。战斗中任一端另有消耗，下一段会按当时的余额重新决定方向。两端比例已平、失去接触或对象已失效时停止转移；已入账的灵气保留。

以同一条可改造的接触词条承接这种转移，复用灵气的扣收规则。原来的单向汲取保留原行为。暗端的内壁随实际送出而压拢，明端的层片随实际收受而展开；中间有可看清前后方向的实体渡流。每段的两端和流向来自已经入账的结果，等量时没有渡流，流向反转时两端各自换相。画面退去不继续结算。

| 必要验收 | 可观察结果 |
| --- | --- |
| 正常渡气并跨过反转 | 同一施放记录两端一扣一收；对照两边消耗改变后，下一段的实际流向和画面反转。 |
| 持平及选中限制 | 真实接触时两边已持平就不扣收，邻近人物不承接。 |
| 中断与恢复 | 一端失效或离开实际作用区，下一段停止；已结算余额保留，余流退净。结束后可重新付费施放。 |
| 兼容与交付 | 旧单向汲取抽查；可编辑构造资料与限定复验入口；原版与 Worldfall 用同两人、同场地录常速完整过程。通过后整项合并并推送。 |

## 形体资源

| 资源 | 可见过程 | 实际作用 |
| --- | --- | --- |
| 暗端 | 沉色翻边和内壁沿人物收拢，朝出流方向让出开口。 | 随本段已经实际送出的原人物移动。 |
| 明端 | 珠色外瓣和暖色内瓤在人物身上展开。 | 随本段实际收受的人物移动。 |
| 渡流 | 包片裹住明芯，前厚后薄，沿两端之间移动并淡出。 | 由已入账的数量和方向触发，途中没有再结算。 |
| 接触印 | 小片地面印标出这份样例的接触位置。 | 只有这一形体提供实际接触；词条能换用其他合法形体、范围和轨迹。 |

## 交付与实测

- [两仪渡气构造资料](构造输入/两仪渡气.json)在整招、身体和部位的接触作用页共用 `WakanTransfer`（上限）与 `WakanTransferMode`（方向）；只改一个部位不影响其他部位的规则。原资料省略方向时继续单向汲取。实机可改额度和方向，无效额度不能覆盖，撤销后保存再打开读回。
- 常速实机同一施放先两次正向交付，在施术者实扣另一笔灵气后反向交付；接近持平时只再转约 0.86 点。持平后确实还有一次接触但没有扣收，旁人无变化。对象离开时仍有一次预定接触机会，因此停止可以归因于离场；再次付费后恢复正常。旧玄阴汲流抽查仍单向实际转移 8 点。
- 原版及 Worldfall 常速录像、中英编辑画面、完整复验记录和首轮失败见 `~/.local/state/cultiway-dev/evidence/polarity-923/delivery.json`。
