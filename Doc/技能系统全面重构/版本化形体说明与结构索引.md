## 资料与加载

| 资料 | 含义 | 运行中怎样读取 |
|---|---|---|
| `Version` | 发布说明格式版本，当前为6 | 加载边界拒绝未知或过时格式；资源构建器与发布说明同步升级 |
| `Forward`、`Up`、`Structure.UnitInTiles` | 原模型前向、上向及制作单位对应地图长度；当前制作资源均为1 | 保留原三轴，实例继续使用共同变换，不从镜头或二维图片推断比例 |
| `Parts[].Roles` | 制作时明确声明的一个或多个用途，如刃部、剑脊、握柄、鳍、手指、泡沫 | `resource.Structure.Parts("blade.edge")`取得真实部件索引；同用途可以对应多个部件；不存在的用途为空，不退回整物 |
| `Parts[].DetailMeshes` | 中景、远景共享网格路径；低面数部件可不提供 | 和完整网格一起加载及验证，使用相同骨架、表面和成形通道；不改变真实作用与挂点 |
| `Controls`、`Motions` | 实际控制层次、绑定范围、权重、关键点和阶段 | 保持已有`FormRig`加载、共同时间取样、作用与显示绑定 |
| `Anchors`、`Contacts` | 真实部件的挂点和作用形状，保留控制或混合权重 | 加载时解析一次；分件描述保留原绑定并重映射所属部件索引 |
| `Grips` | 完整握持编号、实际挂点、绕轴方向、柄粗和相对体高尺寸范围 | 加载时解析为纯数值，按同一坐标对齐器物显示和作用；真实分件只保留自身握持 |
| `Structure.Connections` | 父、子真实部位的稳定编号、绑定模型空间连接位置及可分离声明 | 加载时解析部件索引，复制为只读数值连接；不使用图片的竖向像素代替三维接合位置 |
| `Structure.Generation` | 相对仓库的制作源、函数或制作段、关键尺寸、路径和采样参数 | 源与参数完整经制作JSON、Unity导入及发布说明保留；运行中不执行制作脚本 |
| `Structure.Changes` | 当前实际存在的变化资料 | 通过`Supports`查询；加载时核对实际资源；正式碎解编译读取`separate`声明 |

`FormDescription.Version`是发布文件格式；`FormResources.Version`仍是本次运行内完整资源组编号，两者用途不同。旧施放保持原资源组，新重载先检查整组；资料有误时保留当前资源和旧施放，不把一半新资料发布出去。

共同`FormStructure`只持有字符串、索引、向量和只读数值集合。参数、用途和连接均在加载时复制，不引用可编辑数组或Unity资源；不会为每个施放重复解析名称。实际生成输入仍保存在制作说明中；这些资料不等于已经实现任意形体的游戏内生成器。

## 当前变化声明

| 名称 | 实际含义与前提 |
|---|---|
| `transform` | 共同整体位移、旋转和尺寸变化；没有凭空提供局部弯曲 |
| `material` | 存在明确允许主体材料覆盖的真实部件；握柄、眼部或泡沫可以保留自身表面 |
| `separate` | 当前整件按真实部件碎解的路径，需要多个实际部件、明确连接且连接均允许分离；固定连接不能声明为现有整件碎解。局部解除某一连接仍需后续对应操作，不能冒称已由此完成 |
| `motion` | 具备实际控制结构和制作动作，运行中由共同姿态驱动 |
| `ground` | 形体已声明并具备共同控制下的地表适应路径 |
| `build` | 部件具有真实成形通道，动作有逐段建立的进度；显示、接触和挂点共同读取 |
| `crack` | 具备两个以上真实部位及非循环crack制作动作，实际控制姿态能形成裂片间距；单分件不保留整件开裂声明 |

缺少的裂纹等不会仅凭文字声明成为能力；当前未知变化在加载时给出具体错误。六类共用变化资料及缺失提示已由[2.11](可复用变化资料与缺失提示.md)补齐；完整流派制作仍按第9工作包完成。单分件保留自身用途、原动作和作用绑定，移除已不适用的整件拆解、地表及材料声明。

连接位置目前描述同一绑定模型空间中的接合关系；连续姿态仍由实际骨架、权重或已发布部件矩阵驱动。这一批没有实现新的通用关节求解器，也没有用该静止连接点替代运动中的真实作用位置。

## 地面涌出的原版遮挡

`earth_spikes`明确声明可选的`HideBelowGround=true`。原版投影按共同地表高度图逐像素隐藏地下表面，避免升起、收回时把地下石体投影成向下拖长的黑柱；实际模型动作和作用区仍使用同一控制。三维继续由真实场景地形深度遮挡，不另外套用原版裁切。未声明的资源保持原显示，格式仍为版本8，不新增世界存档字段。制作源通过现有说明出口保留该字段；三平台资源和原版逐件/批量绘制使用同一声明。验证入口为`Scripts/SpellDemos/verify_ground_spike.py`，完整来源及作用记录见[曲线与轨迹接入](可编辑曲线与轨迹接入.md)。


`rift_opening`提供连续暗腔、左右厚裂唇及普通`open`动作，制作源为`Scripts/CombatModelStudio/forms_rift.mjs`。左右控制共同改变网格，静止作用轴保持固定落点并声明完整范围；接触只在`opened`至`closing`标记之间启用，不把闭合中的细缝继续当成完整伤害体。三个部件保留内部或裂唇自身的表面，实际混沌成分由构造的`entropy/energy`材料单独决定，表面染色不改变伤害。没有新增说明格式或存档格式；该伤害材料不自动附带空间解构、传送或牵引规则。
