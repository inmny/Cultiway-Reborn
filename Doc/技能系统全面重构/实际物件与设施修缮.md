# 实际物件与设施修缮（11.04）

## 结束条件

- 增加一项可添加到普通构造的建筑修缮。实际接触已建成、尚在使用且受损的城市建筑时，恢复同一座建筑的原版生命。一次按生命上限八分之一取整，至少可修补一点，原所有者和建筑功能保留。满额、废墟、拆除中或尚未建成的对象不产生修缮结果。多格建筑只认原生根部。
- 复用现成城市档和同一施术者。用一次原版受损过程、一发正式修缮和一次不适用的接触核对结果、正常结束和后续正常使用。用正式保存及另一进程读回检查同一建筑、修复量和原功能，确认修缮不会在读档时再执行。
- 塑形、碎解、换材及随后的实际作用，核对现有同一主体改形命中、分件接触和独立材料转交的正式记录。原装备修补沿用实际付费、归还及耐久保存。新增场景只验证建筑修缮。
- 交付可复验入口、原始结果和文档。城市全自动派工、活木承托及跨区域维护继续各自编号。达到上述条件后合并 11.04。

## 在万法阁组合

在构造的「地块作用」中选择「修缮受损建筑」。部位的真实落点、触及范围、次数和间隔继续使用一般构造规则。可要求每次成功交出一定体积的实际材料，只有修补成功才扣去这部分体积。测试用石印每次交出一份，原公用领域没有实体材料可交。

恢复量写入原版建筑生命。房屋、住户与城镇归属使用原版存档字段，无需玩家迁移。
