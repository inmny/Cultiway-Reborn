# 独立维持阶段

继续完成 8.05 的持续改造，并接入 8.06 的维持能力。它与整段历时伸缩分开：原来的出手、飞行、转向、生长和收势速度保留，只增加明确的维持秒数。

## 同一份过程与判定

`ConstructionHold` 保存原动作时钟中的 `At` 和额外世界秒数 `Seconds`。身体和生成形体共用这份小资料及只读编译检查，不保存游戏对象。缺省不含此字段的正式存档继续按原行为恢复。

- 真实身体在有效阶段指定姿态停留，之后从同一姿态继续原收势；实际手、肘、躯干、握持和作用形状仍读取同一次身体取样。自动改造选原有效结束姿态，起势和首次发力不变。
- 有制作动作的形体在有效阶段中点维持当前形变。飞行、旋转、生长和定时材料变化仍按原世界时间执行；形变恢复后按原速度完成后续动作。标记作用时段读取同一形变进度，所以维持期间不会先停止实际作用。
- 静态领域直接延长原存在与明确作用结束时点，不新增无用的形变暂停。
- 接触间隔、每人次数、总次数、单次作用量、消耗和冷却均保留。延长维持不是解除去重；原规则允许的迟到目标和间隔作用才会生效。

`ConstructionMagnitudeEdits.Sustain` 同时增加总寿命、已有明确存在终点、必要的作用终点和维持资料。已释放的显化不会重新占用身体；没有离手安排、持续依赖实际手部的主体会同时延长实际身体姿态，避免借用已经结束的手。身体显化投送读取包含维持的实际离手时点，成形仍采用原动作的时间。

## 与其他改造配合

数量复制会移动各份形体的维持时点，仍各有完整寿命；真实身体只做一次。历时伸缩同时缩放维持时点和秒数，保持对应进度。生成体急速只改变运动和路径，保留维持秒数。修士创法复用相同命令，保存实际选择，不在加载时重抽。

形变维持已用秒数保存在普通施放状态中，跟随已有回退快照。维持开始、结束和身体阶段参与原有拆步，维持期间不会反复追赶尚未到达的形变标记。材料定型和接触驻留继续使用原规则，恢复后才继续剩余的形变维持；总寿命始终有限。

## 游戏内使用与资源

性质页增加“额外维持（秒）”，输入后点击应用，使用原有编译、撤销和正式保存。已有维持可以在身体页或所选形体参数中调整姿态时点和秒数；总寿命和显现窗口仍需覆盖完整阶段，无效候选给出具体原因。

| 资料或资源 | 用途 |
| --- | --- |
| `ConstructionHold` | 可选维持资料，身体和形变共用 |
| 现有 `water_wave` | 在翻卷过程维持浪体，显示与接触使用同一形变 |
| 现有掌击和剑刺动作 | 维持真实末端、握持及躯干，收势按原速度继续 |
| 现有 `branch` | 静态领域延长，保留原运动、次数和作用量 |

本批不新增贴图、网格、烟雾或独立播放的判定替身。完整流体、打击美术及大尺度极端条件继续按原 TODO 推进。
