## 规则

部位增加可选`SourceLoss`：缺省0表示当前控制者失效时结束，1表示已支付的独立过程可继续。该字段由同一编译入口校验、复制和保存，碎片继承原主体规则。未声明的旧构造不改变死后行为。

来源失效首先中断身体并归还控制，再按每个部位当前控制者处理；反射后的独立分支以新控制者为准。仍跟随来源的根、手部连接及其未脱离后代结束；允许独立的已脱离分支继续。静态放置且未借用来源连接的独立根也可以继续。死亡不追加资源或作用量，原支付者失效时回收不转赠池中新人物。已经自然完成的结果不因事后校验来源而改标为中断。

活着的控制者仍使用真实敌我规则。失效后的独立部分读取最后有效阵营及个人敌意的稳定编号，目标仍遵守可受攻击条件；不会把所有人物都当作敌人。追踪与目标连接沿用最后有效位置，目标失效不重新选人。

来源关系在主线程每真实帧至多采集一次，不扫描全世界寻找敌人；人物作用与形体交锋共用这份关系，水路传导也使用同一规则。失效后的来源中心推力读取最后有效脚下，不随尸体搬运或对象池中的新位置变化。原版无法保留已经移除的攻击者对象时，模组接触记录仍保留原稳定来源编号及原能级。

任务或工程给出的明确有效边界取消整次施放，包括独立部分。换世界清除全部临时执行、身体控制及发布画面，正式世界事实由各自玩法恢复。

| 变化 | 当前明确行为 |
|---|---|
| 施法者死亡或失去生命 | 立即解除身体，逐部位应用`SourceLoss`；旧资料结束，符合条件的明确独立部分继续 |
| 目标死亡或原对象身份变化 | 不再更新跟随和追踪位置，保留最后位置；仍可按实际几何碰到其他满足目标规则的人物，不重新锁定 |
| 握持武器换走、损坏或丢失 | 原握持判定失效，立即中断身体及仍依赖手部的形体；真实物品由装备玩法维护 |
| 反射后的控制者失效 | 只处理属于该控制者的部位；其他控制者的独立分支不被一并取消 |
| 明确任务来源中断 | `ConstructionWorldScope`取消整次施放，不由独立标记绕过任务条件 |
| 世界切换或读档 | 丢弃旧瞬时施放及发布画面；保存的定义与已学关系恢复，伤害、支付及旧接触不重放 |

设施供能、具体器官失去、抓持双方关系和其他旧能力来源仍在后续所属任务实现；本项不以构造执行的规则代替全部来源迁移。没有添加另一套设施计时或存档区段。
