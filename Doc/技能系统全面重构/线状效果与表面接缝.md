# 9.04 线状效果与表面接缝

## 开工时固定的范围

- A：旧铁剑扫击和长兵突刺的实体仍按真实动作摆动。原版只在刃口或尖端画短暂的面，不画从施法者贯穿整段突刺的光带。大幅移动也不会留下一整路长尾。Worldfall 使用真实器物和已有的接触反馈，清理兼容层额外补画的线。保存、费用和命中范围保持原规则。9.02 已按导通位置制作的雷击通道保留。
- B：近景保留粗细层次；当矿粒、水纹或发光细纹小于画面可分辨的尺度时，细纹融进原有底色。地形、角色和原版像素画不改。
- C：闭合水面的泡沫、波纹在同一条边上连续；旧石材的纹理不因模型展开边界而断开。原形体、绕行和破坏范围保持原规则。

## 结束条件

复用已有铁剑、突刺角色及雷、水、岩的演示。铁剑扫击、兵器突刺检查刃口附近的表现、实际接触及退场；同一流程看原版与 Worldfall，远景确认无跨身细线，雷通道仍可见。水与岩各看近、远及旋转后边缘，观察细纹缩小后的连续画面；检查失败后能恢复，三平台资源重新打包。保留针对本项的可复验入口、原帧和实现说明。完整编号验收后才合并和推送 `codex/dev`。烟雾、通用粒子、声响和全流派联合验收按后续编号推进。

## 结果

- 原版扫击只保留外缘短面，按运动距离与经过时间共同截断；突刺只在末端留下短芒，砸落与旧战技的连排残影减少。Worldfall 不再将这组短面转成贯穿人物的细线，继续绘制真实武器。原有命中宽度和技能条件未变。
- 岩纹、细小发光纹和水波按每像素能承载的细节逐渐变柔；泡沫和旧岩纹按材料位置取样，不沿展开坐标断开。Windows、Linux、macOS 的形体资源包均重新构建。三维原帧里树冠的点阵来自 Worldfall 自身的遮挡显示，不在本项修改范围。
- 在原版与 Worldfall 取景；正式铁剑扫击有扣血，突刺有对应的伤害结算记录，两招均自然退出并归还铁剑。远处的非法目标不能施放。原连锁雷击仍随实际路径出现。首次水洼场景未打出伤害，随后在平地验证扫击；紧接的突刺没受理，最终另开同一平地场景单独验证突刺。过程按分段记载。
- 水幕和岩脊拍摄近远、两侧实际画面；带泡沫的水面和岩面另比较同一闭合边两个端点的设备输出，可见像素差均为零。原版水幕保留 2.2 秒常速远景短片。此次软件渲染仅用于功能与画面核对；全视角连续验收仍在 9.10。
