# 持续雨云与世界原理参数

## 范围

继续10.13、11.03和11.22中缺失的降雨过程。新增可组合的 `weather.rain` 原理，真实作用面接触地块后产生原版雨云。雨云的移动、三秒成云等待、雨滴和消散仍执行原版规则，施放结束后天气独立继续。

旧雨云法术原有的学习、法杖、法力和持续词条继续生效，实际产生的云交给同一天气拥有者保存。此批完成实际天气与保存接入，没有把旧容器、旧轨迹或旧编辑界面算作已全部迁移。

## 原理参数

`ConstructionWorldEffect.Duration` 是可选的持续秒数。原理登记默认值后才接受该字段；雨云默认12秒，声明的持续时间必须大于零且不超过3600秒。未声明持续参数的原理不会忽略误填值，例如给 `land.cleanse` 填持续时间会明确拒绝。

编译计划独立复制参数；外部修改资料不改变已开始的过程。创法比较采用已经解析的持续时间，因此缺省和明确填写12秒有相同含义，真实持续差别仍保留。

在已有构造的接触作用中可声明：

```json
{
  "Action": "weather.rain",
  "Duration": 40,
  "MaximumTiles": 1
}
```

次数、间隔和重入仍由共同地块接触规则控制。`MaximumTiles: 1` 表示此部位的这项原理最多接受一块不同地，不承诺天气覆盖只有一块地；之后雨滴按原版云图宽度、当前位置和实际移动产生。若声明多块地接触，每块都可以各自产生天气，应按实际用途控制次数，不能把一片作用面误当成只会召唤一朵云。

实际提交上下文同时携带当前归属者、原术和共同接触时点，不把本轮末端时间当作成云时间。预估只读地块，不生成云或支付资源。当前城市工程没有评价持续降雨的收益与副作用，因此不擅自加入原有净化或地形任务。

## 世界时间与独立天气

实测发现原版云龄跟随效果更新，在暂停后仍会前进。模组生成的云现在将已经推进的世界时间差交给原版更新；同一世界时点不会随显示帧重复消耗寿命，加载期间也不会额外老化。自然天气不受此处接管。

云仍保存原版实际云龄、移动速度、两项行动间隔、生成或消散阶段，以及当前显示进度。已经形成的独立天气不因发起者死亡而自动消失，来源编号作为历史事实保留。既有雨滴造成的结果由原版玩法拥有，不通过读档重放旧施放或批量补发过去的雨滴。

## 保存及清理

新增正式世界区段 `constructed_weather` 第一版，只保存本模组真正生成且尚未回收的云。记录云与人物的长期编号、产生能力、实际位置、云龄、寿命、速度、行动间隔、消散阶段、原图编号和朝向。不保存原版对象引用、委托、贴图或本次施放编号。

恢复时创建原版云并交还上述实际状态，继续已经开始的降雨，不重新等待三秒成云。原版对象池回收时立即解除身份；同一个原版对象再利用不会继承旧云的记录。换世界会清除旧天气，重复读取不会叠加本模组雨云。

集合数量和每朵云的外部记录分开检查。一朵云损坏时只报告并丢弃这一条，其他有效天气继续；沿用正式存档的原档备份与恢复报告。原版淡出最后一帧可能产生负透明度，这仍是可恢复的实际消散进度，不能当成整段资料损坏。

没有新增玩家设置、模型或贴图；显示及音效复用原版雨云。新增区段是可选资料，旧正式存档无须手动迁移，但不能从旧文件中推测原来未保存的临时云。
