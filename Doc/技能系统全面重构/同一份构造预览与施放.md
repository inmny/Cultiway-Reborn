# 同一份构造预览与施放（8.09）

本项完成条件：

- 编译结果冻结整招需求、资源选择方式、冷却、作用量、实际模型和接触规则。窗口摘要、正式说明、准入和施放读取这些结果。资质折算、整数取整、任选顺序及同一余额合计都用正式支付入口，预览只读，不能冻结或扣除人物资源。推荐需求仍是明确的编辑动作。
- 选中实际人物时，选点预览使用正式准入的距离，区别于法术在选定地点上的实际接触形状；没有可用人物或缺少特定目标、器物时说明差别。预览播放同份计划，使用原有模型变形、位置和接触采样；缺少现场事件时不捏造命中或后续结果。不增加独立玩法、价格公式或场景测试体系。
- 复用已有测试世界和一个有动力变化的构造。实机验证改造前后预览、说明与正式开始采用同一组数值，包含需求与实际扣费不同的资源、一处选点距离边界、预览无世界副作用、正常出手及结束。遇到无可用报价或无效草稿时，显示原因并能恢复。保存重开仍用原资料；没有格式变化，不重复冷启动存档检查。
- 交付代码、复验入口及实机证据。只在整项验证完成后勾选 8.09 并合并推送。其他资源错误定位与窗口极端布局留给 8.10、8.12。

已通过报价与选点分段：万法阁把体力需求 2.25 和此人实际扣除的 3 点分别显示。余额为零时给出不可支付提示；输入负距离会拒绝，撤销能恢复原值。保存重开后，超过 5.25 格拒绝且不扣费，恰好在边界时扣除 3 点并正常施放、结束。共用支付另验证了任选顺序、同一余额合计、锁与失败返还。


属性页的「播放形体预览」支持暂停、重播及独立开关接触轮廓。地点用地图坐标，人物用实际对象；选点距离沿用正式准入。窗口单独播放编译结果和打开时的现场输入，不向世界登记新施放。人物或器物没有满足条件的姿态时会提示；实际命中、格挡及地块变化要由正式运行确认。正式说明由展开后的部位、条件和过程生成，编辑中的改动不会回头改变已编译的说明。

图形段复用报价段的世界和水剑：5.30 格被拒绝，5.25 格可播放。画面先呈现水，再按编译时钟在 0.4 秒换成冰；暂停、重播和接触轮廓分别验证，正式施放的接触边界与预览相同。打开、播放、关闭没有扣费、确认世界事件或发布世界形体；关掉预览后可以实际扣除三点体力，出手并结束。
