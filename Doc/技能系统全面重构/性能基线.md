# 旧系统与原版性能基线

对应1.03。使用1.02的四份固定世界，分别记录实际运行负载。本项建立可重复的起点，规模优化仍由工作包13验证。

## 测量入口与隔离

```bash
python3 Scripts/SpellDemos/benchmark_baselines.py
```

需要先结束已有WorldBox，避免多个游戏争用同一显卡。入口建立两份私有游戏目录，顺序运行并退出各自进程，不改变玩家的模组启用记录。原版对照只加载NML及DebugToolbox；模组对照只额外加载Cultiway，不加载Worldfall及其他玩法模组。游戏只读文件可共用，NML缓存、模组目录、配置、临时会话、日志和保存世界独立。原版对照有同样的测量工具开销，不声称完全没有测量工具。

原版对照读取模组无技能场景的同一份原版人物及地形资料。核对双方的角色编号、起点、生命、伤害及镜头，不将禁用技能总开关当作卸载模组。每次重复从原始快照重载，以相同种子和敌对启动条件自主交战。普通交战使用已学火球、水箭的旧执行器；顶尖飞掌和持续雨云记录当前新框架起点。

入口参数`--repeat`默认2、`--warmup`默认4实秒、`--seconds`默认20实秒。重复的次序为无技能、普通交战、顶尖交锋、持续天气，再运行原版无技能对照；本轮不交错多进程。每轮解除帧上限和垂直同步，保留x1世界速度，读取实际1280×720画面和固定镜头。1.02首次记录只验证了启动尺寸参数，实际画面仍为1920×1080；现已增加窗口设置、显式切换尺寸并等待实际尺寸吻合。不能将先前配置值当成已经测量的画面。

## 数值含义

原版的`MapBox.calculateCurElapsed()`使用固定步长乘速度设置。解除帧上限时，x1仍可能每实秒推进多于一个世界秒；本报告的世界速度是实测吞吐，不把它解释为请求倍率失效。若比较固定游玩帧上限，必须在相同上限重新测量，不能直接把本次解限帧的帧率差当成单次法术成本。

逐帧间隔在Unity主线程同一调度点用单调时钟读取，给出均值、中位数、95分位、99分位和最大值，保留每帧原始间隔。世界速度直接取实际世界时间增加量除以墙钟时长，不能用请求的x1或画面帧数代替。进程总处理器用时另外记录，属于所有线程的总用时，可能大于墙钟时长；不代表GPU耗时。

主体计数每0.25实秒读取一次：原版单位、活动旧技能实体、活动构造施放、显示实例和持续雨云。旧实体排除模板、停用、回收及待回收对象。显示实例可能含附加显示，不等于实际碰撞主体；持续雨云独立于已经结束的施放。计数峰值为采样峰值，可能遗漏更短暂的尖峰，不声称逐帧最大数。

场景人数指准备的参与者数，原版自然生成的其他生灵仍计入实际总数；不将参与者数冒充持续恒定的世界人数。两种环境从同一人物起点出发，但不宣称不同框架运行中的随机调用和世界结果完全相同。

同一采样点记录托管堆、Unity已分配及保留内存、进程常驻及私有内存，另记各代垃圾回收次数。测量过程中不主动回收内存、不截图录像、不挂逐次施法跟踪，也不逐事件保存观察列表。采样本身仍有固定开销。当前结果是这台机器、这些小世界、这些镜头下的起点，不能外推为城市或世界级最终性能。未锁定处理器/显卡频率，未扣除采样开销，读取次序及缓存、垃圾回收和温度都可能影响结果；两轮原始值分别保留，不给出单法术固定耗时。

## 修正与失败记录

首次共享采样函数放在局部输入声明之前，调试编译拒绝捕获这些输入，未产生计时结果。修正函数位置后，第二轮已采样，但原版初始数值核对失败。原版在载入完成后的下一帧才补齐特质、种族及实际数值；提前读取的生命约100、伤害1，与准备角色约1.5万生命、约14伤害不符。独立读回确认暂停等待下一帧后数值自行恢复，重新计算属性未再改变结果。原版入口现显式暂停等一帧，不通过写生命或伤害伪造一致。最终结果只采用修正后重新采样并通过初始状态比较的一轮，旧失败数据保留。
