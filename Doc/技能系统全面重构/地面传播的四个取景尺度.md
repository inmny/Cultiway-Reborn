# 地面传播的四个取景尺度（11.20）

## 完成条件

- 复用 4.32 的原城及 256×256 世界，使用 11.16 正式可习得的两招。原版和 Worldfall 各录制城域及全域连续画面。近景看实际发力，中景看波面由真实触地展开，城域远景和全图各能看清同一次施放的已到达位置及自然收尾。
- 以世界时间编码。对每种尺度保留同步记录的传播、实际伤害及地块变化。代表帧核对渲染波面与同一已完成传播的格子，空隙或未达位置没有提前亮起。城域净土的地块结果引用 11.17 的实际薄面检查，全图防火的作用与解除用其原版行为记录核对。
- 交付可复录入口、每种视角的原始帧、同步事实及成片。只补本轮发现的取景或已确认状态显示问题。最终美术和密集性能保留对应编号。

## 波面的绘制

原版首次录制时，波面内部的柱面接缝形成重复暗线。相邻活动格现在通过共享拐角接成连续的起伏面，只在与空格相邻的边缘绘制侧面。每格中心保留真实地面高度与波面当前厚度，地块分区交界沿用同一帧的相邻厚度。传播速度、到达格、碰撞及实际地块结果沿用原规则。

录像保留起势、落脚、中途传播及自然结束。核对画面发布的格子和实际网格中心，与同一时点的接触格一一对应。近景先检查发力前没有传播面，随后在中景及两种远景各取实际波面样本。

四段均从万法阁正式底稿另创，由实际化神施放，分别支付 100 或 500 真元。落脚时目标生命未变，实际到达后各受一次伤害。收尾时波面移除，人物控制归还。表中的接触格来自各自世界时点，画上格子及网格中心高度均与同一时点的接触数据一致。原版城域前后对照显示，波面内部的重复暗线已消失。

Worldfall 全域第一次正式使用未受理且未扣费。复查同一人物已可正常使用后续录通过，保留首次失败和续录脚本的编译失败。续录发现默认远景的远处雾带遮住波前，最终独立复录 Worldfall 全域，改用它自带的自由飞行宽角机位，将地图四边收进画面。其余三段沿用已通过的录制。

本机证据目录 `~/.local/state/cultiway-dev/evidence/functional-world-views-1120/` 有 `native-city.mp4`、`native-world.mp4`、`worldfall-city.mp4`、`worldfall-world.mp4` 和 `delivery.json`。索引包含原始帧的世界时间、路程、生命变化、实际地块结果、结束确认、早期录像及失败记录。两套独立游戏使用软件渲染，Worldfall 为 0.9.8。最终画质与密集性能分别由第 16 章及 13.17 验收。
