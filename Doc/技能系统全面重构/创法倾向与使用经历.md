# 创法倾向与使用经历

本批落实7.02，继续扩展7.03、7.16及保存验证。倾向改变实际构造选择，不能以这个工作包替代完整的自由结构生成、功能能力或最终美术。

## 从已有事实形成倾向

复用已有角色语义汇总，读取灵根、主修功法掌握、旧法术知识、修炼实践和其他已登记资料；新贡献器补充正式构造知识及使用事实。没有为每个来源另造平行档案。

| 来源 | 使用的真实资料 | 对创作的影响 |
|---|---|---|
| 灵根 | 已登记灵根的连续元素组成及类型语义 | 改变材料和结构方向的选择权重 |
| 功法 | 实际主修功法语义及掌握程度 | 未掌握和熟练掌握有不同影响 |
| 已有知识 | 原有已学法术、新构造的实际材料 | 接触过的性质更易进入后续创作 |
| 性格 | 原版进攻、理性、管理等实际数值 | 改变显化、环绕、驻留、碎解或重复等选择 |
| 使用及实践 | 原有魔法使用计数、修炼实践、新构造真实开始的次数及平均元素组成 | 长期实际使用逐渐改变偏好，读取和绘制不加经验 |

当前可选实际材料为金、木、水、火、冰。材料关联各自已有规则和显示表面；没有把其他流派仅换个名字冒充已经实现。八维倾向保留在输入中，尚未完整提供的流派仍按第9包继续制作。

选择保留基础探索权重，水灵根可以创出其他材料，已学木术也不永远锁在木术。当前生成规则支持更多真实材料和贴地形态，但仍沿用现有结构方向，更多关联、空间及战技创作继续推进。

## 确定输入与正式使用

`ReadInspiration(actor)`从当下事实产生纯数值输入；`Generate(actor,seed,input)`可固定输入复现。自然或开发请求受理时保存相同输入，不等排队结束才重新读取灵根和知识。身体能否支持当前显化动作也随输入固定；正式出手仍检查实际身体。

新构造只有在正式入口受理、真实开始和支付后记一次使用。多次命中、多个部位、显示帧及未能支付的请求不重复增加。平均组成和有限计数保存在人物区段`ability_use_history`第一版中，常驻数据不会随使用次数无限增长。现有魔法使用记录直接读取，不重复记一份。

构造材料由编译计划的真实材料决定，染色不改变经验性质。这里记的是实际使用过的构造性质，不把一次法术的所有预定材料当作已经命中或发生了全部反应。

## 请求资料升级

人物`ability_creation`升为第二版，保存确定的元素、进攻／控制偏好和身体条件。固定输入采用保存层约定的公共字段，并在读取边界拒绝缺失或损坏的输入。

首版尚未完成的请求没有保存这些输入，无法可靠还原当时的完整创作条件。按既定恢复政策，只取消这类未完成请求，保留原种子、等待和说明；原档及恢复报告自动备份。原有正式构造及已学关系保持，不重新创作。首版已经完成的请求正常转换，不重复授予。当前格式的待处理请求则按完整输入恢复。

## 验证入口

- `verify_inspiration.script`：读取实际人物资料，逐项检查灵根、功法、旧／新知识、性格、四十次真实施放和受理后的输入保持；对同一组种子比较生成材料分布。通过正式保存器检查完整字段与往返，并使用首版世界检查局部取消、说明、备份和原档未回写。
- `verify_inspiration_restart.script`：真正退出重启后，验证当前人物已经改变时仍按受理输入生成，原正式能力和使用事实保持，重复存读档不重放。

测试依据及实际画面位于`artifacts/skill_rebuild/inspiration/`。比较的是实际生成部位和正式施放结果；生成倾向不能仅靠名称、颜色或权重表宣称成立。

## 实际结果

真实人物运行21项、当前格式冷启动9项通过；原请求30项、按月活动6项、功法领悟7项、请求冷启动10项回归通过。保存进程3003927，恢复进程3031312。当前格式未丢弃其他区段，待处理请求完整结果与保存前预期相同，重复存读档没有重复授予；40次正式使用事实保持。真实首版文件的未完成请求单独取消，说明、备份和原文件未回写已检查。
