# 操作输入输出与需求

落实3.03。现有操作继续使用已验证的共同执行代码；本批在编译入口建立统一约定，并把实际使用的约定保留在只读计划中。3.04继续实现输出绑定，3.13继续开放新执行操作登记，本批不将这两项提前计为完成。

## 约定内容

每类操作说明输入与输出的种类、必需参数、可选参数、单次状态、共享或运行资源，以及对实际作用的影响。主体、父连接、世界材料、真实水域和支付记录分别表达；明确在运行时取得的输入，不要求创建能力时已有具体人物或水格。

| 操作 | 实际输入与输出 | 状态、资源与实际影响 |
|---|---|---|
| 生长 | 部位 → 部位、尺寸过程 | 尺寸进度同步改变同一主体的显示和实际作用范围 |
| 旋转 | 部位 → 部位、转动过程 | 保留旋转起点，实际挂点与作用随同一姿态旋转 |
| 脱离 | 部位、实际连接 → 自由部位、断开结果 | 解除真实父连接，保留当时位置、方向和速度 |
| 飞行 | 部位，可选目标位置 → 部位、运动过程 | 保存速度、加速度及路径；相对目标路径需要实际目标，贴地运动需要地表及作用形状 |
| 制作动作 | 部位 → 部位、姿态过程 | 需要明确制作动作，骨架、挂点和作用区使用同一时钟 |
| 材料转换 | 部位，可选世界材料 → 材料、转换结果 | 真实材料规则改变物态与实际作用；世界选择另需世界材料维护者 |
| 停止 | 部位、真实条件 → 部位、停止结果 | 保留当时尺寸与姿态，停止运动和形变，不重新生成主体 |
| 聚合 | 部位、实际父部位 → 部位、聚合过程 | 保留起始布局和历时，连续汇入明确的父布局 |
| 碎解 | 部位 → 实际部件集合、碎解结果 | 需要真实可分离分件，保留材料、归属、姿态及余力分配 |
| 流散 | 部位 → 部位、流散过程 | 需要生成几何及地表，建立有限水格、体积和动量；不是贴一层水面 |
| 收束 | 生成部位、支付记录，可选世界材料 → 收束过程、回能结果 | 只回收尚存实际支付份额；世界材料选择还要核对归属 |
| 留置 | 生成部位 → 世界材料、转交结果 | 将材料交给世界独立维护，原施放结束不抹掉已接受结果 |
| 导电 | 生成部位、实际水域 → 传播过程、作用结果 | 需要真实触水入口，沿连通水路消耗余力并形成有限波次和命中 |

输入输出为共同构造资料，不能据此声称任意输出已经可以接入任意其他操作。输入名称与种类用于下一项的明确绑定；当前自动输入仍由已有共同主体、父连接及世界确认路径提供。

## 编译接入

参数集合从真实操作字段取得类型及默认值。每类操作明确接受哪些字段、哪些必须填写、哪些只适用于条件操作。没有声明的非默认参数会在编译时报告操作索引及字段名；已有格式中统一序列化的无作用默认值继续接受。数值范围、真实动作、材料规则及特殊结构关系由已有对应编译代码核对，避免重复维护两套数值限制。

计划保留每个真实部位、原操作索引、约定和按实际参数补齐的状态及资源需求。条件操作增加事件状态；贴地飞行增加地表要求；世界材料转换或回收增加世界维护者要求；相对目标路径声明必需目标。运行计算继续读取既有纯数值计划，不逐帧反射或解释原始资料。

本批不增加模型、贴图或玩家设置。能力定义及世界外层格式不变，正式能力仍保存稳定的现有操作编号和参数；`ability_constructions`部分升为2版，保留从1版逐步转换。

## 实现与证据

`ConstructionOperations`为当前13类已有操作提供统一约定。`ConstructionOperationContract`公开只读输入、输出、真实参数类型、状态、资源及作用说明。字段反射只在编译边界识别非默认参数，数值计算仍使用原有紧凑字段和执行方法；没有新增运行解释器。

`AbilityCompiler`在每个真实展开部位的操作入口核对参数归属，再调用对应数值编译。移除原来重复的专用字段归属判断，保留数值范围、动作、材料、父连接及真实分件检查。错误会包含实际部位与原操作索引，例如`root/leaf@tip_0/Operations[1]`。编译后的`Operations`保存各实际操作需求，`OperationResources`汇总资源需求；新的编辑不会改写旧计划。

私有Linux游戏64464经NML加载最终代码，27项专项通过。全部71份当前正式能力及可复现输入编译通过，覆盖全部13类执行种类；专项还验证错误字段、缺少必要参数、条件要求、集合展开后的错误路径、贴地与目标需求、世界材料转换、实际支付输入、只读集合和计划独立性。真实飞行位移、生长接触尺寸、材料转换后的命中材料均通过。256项正式首版编号、旧数字构造和原资源兼容回归通过。

旧正式构造可能保存无关操作原来会忽略的`Clip`、`Seconds`、`Vector`或`TurnRate`。`ConstructionsV1ToV2`沿原部位层级，在框架提供的副本里只清除这些不属于当前操作的字段，保留原有实际参数、连接和完整结构；未知种类继续交给原来的局部恢复报告。新创作及改造继续严格拒绝错位参数，不放宽新规则。玩家无需手动处理存档。专项通过正式世界恢复入口验证1版转换后重新登记能力，也核对嵌套字段、有效参数和原输入保持。

SDK0错误、16条已有警告，按项目DotSettings整理。没有模型或着色改动，本批不重复资源构建与录像；3.04和3.13保持待办。新增约定只描述已经存在的执行能力，没有把未来映像、空间或抓投操作列成可用功能。
