# 命名步骤参与数值改造

推进3.09的必要接入。本批解决3.04新增命名步骤后，共用改造仍只处理原部位操作的问题；不把本批当作统一成本、冷却及范围规则全部完成。最早未完成项仍为3.09。

## 同一份真实构造

尺寸、速度和完整历时遍历作者实际声明的原部位操作与命名步骤，各处理一次，不重复处理编译器为原命名操作建立的观察项。尺寸同时更新命名导电的传播及数量参数、世界材料转换的实际体积；速度更新独立运动、曲线、旋转、分件运动及聚合时长；历时同步改变操作时点、条件延迟、动作时长、波间隔、路径和运动参数。

制作动作缺省时长先从实际目标资源固定，再进行伸缩；命名动作不再因为仍写零而沿用原时长。显示、骨架和作用继续读取改造后的同一执行计划。

## 复制的是完整关系

每份保留独立步骤名称、部位引用、原部位操作引用及同份步骤输出。根结构重新包装时，绝对事件来源和命名步骤引用一起重定位；身体及相对引用保留实际含义。环绕包装采用相同重定位，不把旧根上的操作错误指向新组织中心。

复制的整次时钟增加本份延迟。事件出生后的局部时钟和真实碎片时钟不再重复增加延迟。身体只产生一次的事件由各份先接受，再增加等待时间；不能把接收门槛推到身体已经收势之后而漏掉事件。

数量保留每份寿命和独立接触。后续[结构规模与资源需求计算](结构规模与资源需求计算.md)已接入完整结构计费，真实身体仍只算一次；正式施放一次支付总额。操作输出与命名步骤的128项预算在复制前一起检查。本批原始实现没有新增施放、逐帧解释器或保存格式。

随动改造会移除直接根投送和解除连接的命名步骤。若后续明确依赖被移除的飞行结果，创建时报具体缺失引用，不能伪造一个完成结果；没有该依赖的普通投送可正常改为随动。
