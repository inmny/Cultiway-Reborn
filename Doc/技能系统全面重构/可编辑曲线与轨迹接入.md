## 具体说明

Fly的Path由有序关键点、相对控制柄、坐标参照、是否循环及局部前向组成。每两个关键点形成三次曲线，编译时生成数值系数与加速度上界。运行不解释制作说明，也不在工作线程查人物、资源或实体库。它改变真实主体位置，显示没有另一条独立运动路径。

Local使用开始飞行时的三个局部方向，单位为地图格。TargetLine把横坐标映射到真实释放点与该时刻目标之间的位置，零至一表示全程，其余两轴为横向及离地偏移。目标位置在开始飞行时固定，之后移动目标不会拖拽已发出的整条弧线。中心线仍可用原有TurnRate继续追踪；局部曲线参照保持释放方向，能与中心线叠加，不要求预先登记整招。

位置由中心位置加曲线偏移计算，避免长时间循环反复加偏移差而漂移。解析速度同时提供给反射及实际姿态。Forward为空保留作者旋转，否则沿实际速度转向，TurnRate限制朝向变化；原有Spin可以继续提供局部旋转。没有路径的既有正式飞行行为不变。

InheritVelocity默认为true，继续保留脱落点速度；明确设为false才在开始飞行时由新运动接管初速度。曲线首点必须为零，避免开始时瞬移。非循环路径结束后保持末偏移，中心飞行继续；全体结束仍由原有Lifetime及接触规则维护。循环必须闭合，允许拐点，不把它当成无界新建主体。

每步同时拆到飞行开始、曲线关键点及循环边界。根据实际参照中的加速度上界缩短步长，使主体中心的曲线平移对接触线段的最大位置偏差不超过0.0025格；转向及自转合计每步至多六度。关键点最多65个，相邻至少0.001秒；明确制作范围和曲率预算，过快、过弯的资料应延长历时或缩小弯曲。当前目标相对坐标按一万格跨度计算编译预算，覆盖本次游戏地图；更远跨度及更密取样不作为已支持范围。

反射在实际接触位置同时改变中心速度与曲线三个参照方向，重新确定中心位置，后续曲线继续镜像；移动表面的相对速度传递仍保留。不会只反转当前一帧然后沿旧曲线飞回。保存预测前态与回退一并恢复中心、参照、速度和次数。材料定型仅暂停内部骨架，不停止外部曲线路径。

正式资料格式仍为版本1，Path为新增可选字段，旧操作编号和缺省的速度继承不变。完整控制点、柄、循环、参照、朝向和速度交接随构造保存，载入不重新随机生成路径。

## 5.05 A交付：从参数展开普通曲线

`ConstructionPathCurves`提供波形、明确折线、三维盘旋及目标弧线的资料生成入口。它们展开成原有`ConstructionPath`控制点，之后仍可自由改变点、柄、坐标参照与朝向。循环往复或盘旋只保存一周；半径指数衰减的盘旋保存完整时段，超出64曲段预算明确拒绝。波形和盘旋使用解析位置及速度生成三次曲段，折线保留真正折点。初始相位及盘旋从零偏移连续开始，不在出手时瞬移到圆周另一处。

这层只在资料准备时计算。施放中继续使用原有编译路径，不再调用这些生成函数或查找曲线名称及旧轨迹委托；位置、速度、朝向、接触、并行、预测及保存继续原有路径。普通往复和盘旋保留中心前进、追踪及既有条件；目标弧线按明确行程接管初速度与加速度，不与旧速度重复相加。半径衰减后的盘旋中心由初始偏移确定，并非把主体在结束时吸回来源。

现有“运动与曲线”页新增“参数生成路径”。选择形状并输入幅度、周期或衰减，点击应用后才修改草稿；命令参数本身不写进法术。输入不合法或曲率超预算时，原草稿与撤销记录保留。生成后可继续编辑全部控制点，也可移除曲线偏移并保留原中心飞行、追踪及作用。没有新增整招样板、游戏设置、资源文件或存档区段，现有正式资料格式及创法规则号不变。

开发代码可直接写入已有飞行操作，例如：

```csharp
flight.Path = ConstructionPathCurves.Wave(.8f, Vector3.right * .45f);
flight.Path = ConstructionPathCurves.Zigzag(.8f, Vector3.right * .45f);
flight.Path = ConstructionPathCurves.Spiral(2f, .8f, Vector3.right * .6f, Vector3.up * .3f, .5f);
flight.Path = ConstructionPathCurves.Arc(1f, 2f);
```

幅度向量采用开始飞行时的局部方向；目标弧线采用原有目标相对坐标，调用者应像窗口一样明确交接原速度。生成结果是自足资料，可交给现有编译、保存、编辑及`demo_all.py --construction`入口，不依赖生成函数在未来重新运行。
