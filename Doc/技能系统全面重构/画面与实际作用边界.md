用同一次真实施放的画面、当时的有效区和实际结果核对边界。复用已有世界、人物与正式模型，测试用方块只作为原有判定的证据。每组保留效果清晰的画面和坐标；边界样本包含作用内、刚越界，以及必要的恢复。若画面让人误读实际结果，先修正这处差异。简化形状的容差和共用调试显示归 6.19。

- [x] 圆与高度：地面目标在可见核心旁由受击进入无伤区；相同平面位置因高度分离不受击，恢复至地面后可重新受击。
- [x] 细长刃：实际刃面及旁边的空隙分别命中和落空。
- [x] 浪前沿：水浪触达前无伤，前沿经过后实际作用。
- [x] 护盾边缘：截住确实穿过护盾的来袭物；刚越过真实边缘的来袭物正常通过。
