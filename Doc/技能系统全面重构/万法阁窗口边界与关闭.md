# 万法阁窗口边界与关闭（8.12）

本项结束条件：使用现有世界、水剑和窗口控件。空收藏有明确提示，搜索无结果后可清除并继续选；构造目录超过一屏仍可以滚动到末项，并能按全名搜索。很长的名字不盖住其他控件，有办法看到完整名字。小窗口下菜单、编辑页及关闭按钮都在画面内；英文万法阁显示正确标题。逐页只查能打开及返回，不重复已有施法或保存验证。

复用一个原始构造批量造目录条目，只用于布局，不增加技能、身体、装备样本。反复打开、关闭菜单和编辑窗口，核对回调不会叠加或访问旧资料，预览资源和人物引用会释放。用同一档重新载入世界，仅检查正开着的窗口、菜单和外部事件都解除绑定。保留独立复验入口及小窗口的实际截图。8.13 的战技编辑和 8.14 的身体资料不进本项。

选项菜单仍用原版滚动条。关闭弹层时清掉点击和提示回调、把按钮还给原窗口；再次打开按当前目录重新绑定。长名称保留在搜索和编辑资料中，列表装不下时用提示正文换行显示。常驻万法阁只在打开时监听目录；改造窗口只在存在实际草稿时监听世界退出和资源更新。按原版关闭键后若需要确认放弃，仍保留这次草稿的世界退出通知，避免在换世界时重新打开旧草稿。

## 实机验证

复用 8.11 的正式存档和水剑，使用 960×540 游戏窗口。空收藏明确说明状态且仍可导入；构造目录滚到真实末项，搜索无结果后用长名末尾找到条目，提示正文和编辑资料均保留完整名称。六个编辑页都能切换和关闭。英文万法阁标题与新提示均显示正常。

反复开关确认只订阅一次并在关闭后解绑。关闭实际形体预览后没有旧画面、人物或草稿；改动名字未保存时能继续编辑，切世界后不能带回上一世界的草稿与选人菜单，重新打开只读当前人物和原术。没有改动存档格式或增加资源。

本机证据在 `~/.local/state/cultiway-dev/evidence/wanfa-window-edges-812/`。`passed-behavior/` 是列表与关闭流程通过的记录，其中旧长名提示截图仍有截断；`final-catalog/` 是移入提示正文后的列表和画面复验，`full-label-en-small.png` 可看到完整名称的末尾。第一次把长名误当排序末项的脚本结果另行保留。复验命令见[演示入口](../../Scripts/SpellDemos/README.md#812-万法阁的列表边界和窗口关闭)。
