# 身体与器物格挡（6.09）

开工前约定：主动架起的手掌或真实持物，只在实际动作的有效段内，以当前姿态的同一接触面拦截来招。来向超出防御面、从边缘漏过、尚未架起、已经收势或原器物失效，都按正常来招处理。格挡有有限余量，双方按真正消耗结算；完整拦下时不补人物伤害，破防时只留下实际余力。不把身体周围扩大成圆，也不改变旧动作和原版普通攻击的规则。

- A：接通防御面、方向及有限余量。生成来招先沿共同时间找到实际掌面或器物面，再处理人物命中；同一招不重复消费已经确认过的同一相撞。正向、侧向（或背面）与窗口外都用同一来招核对。复用现成世界、同一对人物、现有掌面和一件兵器。
- B：同一路径接通真实身体攻击，按来势分别确认全挡、破防后剩余效果和攻防双方收势。正式资料走共用构造；补一条游戏内可学可用的防御入口，验证正常结束、器物失效和结束后再次使用。已完成的普通近战、持续抵住、存档和装备共用行为不重跑矩阵。

交付代码、限定复验入口和真实接触记录；合并在整条验收后。拨开、卸力、各类防御成品以及整套录像按 9.46 等后续条目验收。
