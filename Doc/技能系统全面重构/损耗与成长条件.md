# 损耗与成长条件

## 规则

继续4.09、5.18及8.06，条件开始和同主体过程共用损耗、长大及收缩阈值，不增加整招类型。

- 剩余力量条件使用本次部位初始作用量的比例，在真实交锋扣减后向下越过指定比例时触发；零力量先通知损耗，再自然结束，独立后续部位可以保留。
- 长大和收缩分别使用明确方向，尺寸以该部位原始尺寸为1。只接受真实过程越过阈值，不在出生时把初始尺寸当作生长，也不在最早接受时点补发旧事件。
- 事件保留发生时的前后数值、材料、位置及朝向。各订阅者判断自己的阈值，后续过程改变来源状态不会改写已经发生的事实。
- 成长阈值在共同时间上拆步，冻结或停止时不提前越过。仅有实际生长来源才允许配置成长条件；真实身体暂不提供这些生成主体条件。
- 每项开始或操作仍只确认一次，状态随同一预测快照恢复；资料、编辑、修士创法和存档共用正式入口。
- 数量及环绕重绑来源，历时改造改变发生时间但不改变比例或局部尺寸阈值。材料筛选只属于材料事件，不混作数值条件。
