# 9.06 粒子的来源与寿命

本项先清掉无由出现的粒子，再让实际接触、状态表面和实际改变各有来源。飞行路径、伤害范围和地形作用保持原有规则；粒子只作辅助，不改变招式主体。

- A：移除旧弹体按碰撞范围逐格撒点的路径。保留按路程采样的原版地形作用、实际命中的局部反馈、法宝按明确锚点发射的粒子。复用混沌弹的场景确认航段干净且仍实际命中，再用同一场景确认一种原有地形变化仍发生。
- B：碎屑具有实际接触点、运动方向和距离；持续状态从角色表面按世界时间发射；世界状态变化只在发生后反馈。复用既有招式和状态验证出生位置、方向、有限寿命、暂停和换世界；两种视角使用同一份粒子资料，换镜头不重新触发。沿用 9.05 已通过的真实扣血和减水证据，只有受本次代码影响的部分重测。
- 交付：提交代码、可复验入口、受影响行为的游戏内证据和说明。单批可本地提交；两批验收通过后才勾选整项、合并并推送。声音和打击强调留给 9.07，连续录像留给 9.10。

## 实现边界

旧法术的地面作用仍以 0.6 地图单位采样，原有的冻结、地面烧灼等照常执行。删除的是额外按碰撞范围逐格发射的系统。法宝仍由登记的锚点、方向与间隔发射。

受击碎屑随实际扣血和攻击来向出现。兵器和屏障使用有棱面的实体碎屑；地面抬升、下降和水体变化按实际结果取材质和方向；草木生长使用叶片。碎屑和水珠不叠加亮度。状态粒子从持有者身体表面向外上升，发射间隔和存活都按世界时间计算。原版与 Worldfall 共用一次生成的粒子；换世界时清空，状态存档无需迁移。

复验沿用 `verify_material_feedback.py`。`travel` 看飞行与旧地形作用，`weapon` 看真实命中和免疫对照，`surface` 看状态粒子的暂停、结束与换世界，`terrain` 看由正式入口触发的排水。

## 实机结果

- 混沌弹先实际移动超过一次地面采样间距：途中零粒子；命中后目标扣血，三枚粒子均在接触处，之后散尽。冰枪飞行途中已有经过的水面冻结，说明删粒子未影响旧地形作用。
- 同一把木剑实际扣血后产生两枚低亮实体碎屑，均从身体处沿受击方向抛出。免疫和超距不产生受伤碎屑；普通原版击中提示、御器退场和归还正常。
- 守护祝福的粒子从持有者表面向外上升，暂停并往返原版、Worldfall 后仍是同一批。恢复世界时间才继续发射；状态结束散尽，重新施加可再发射，换档清掉当时仍活动的粒子。
- 排水按正式施法规则受理。每一颗观察到的水珠都与当时已实际排水的地块相符，朝内下落，随后散尽；施放前已有水面没有法术水珠。
