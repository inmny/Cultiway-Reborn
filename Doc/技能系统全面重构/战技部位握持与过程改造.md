# 8.13 战技部位、握持与过程改造

这一项让万法阁直接编辑实际参与动作和判定的资料，保存仍走同一套构造入口。同一编号下的三个子批次可分别提交，全部验证通过后再合并到 `codex/dev`。

- **A 部位、握持和普通接触。** 同类徒手动作的左右部位可成对切换，动作仍由真实身体完成；保留既有命名骨段和器官入口。持械动作使用原版实际武器槽。持械动作从原武器的真实握点选握法，普通接触可选实际部位或器物提供的作用面，并按已有姿态标记限制接触时间。用同一人物和铁剑验证实际握持、接触范围和无效改动拒绝，检查撤销及保存重开。
- **B 步法和发力。** 有相应落脚资料的普通动作和既有三轴动作使用同一平面曲线入口；瞄准和接触后的回弹可编辑，实际施展仍受身体、足底和原有费用限制。复用同一人物检查位移、一次接触和收势归还。
- **C 内部阶段和整体验收。** 使用同一动作的时段、重复、单段作用和结果后的收势，不增加固定连招。补齐影响实际阶段选择的编辑缺口，并核对抓握、格挡与普通接触共用形体时各自的生效条件；从编辑、学会、支付、施放、命中及失败恢复走到正式保存和载入，并保留复验入口和画面证据。

沿用已有世界和装备。有资料缺口的身体及器物、不同动作形态间缺失的转换，归 8.14 处理。

平移路径定义脚下往哪走，姿态关键点定义何时抬脚和重新落地。两条资料共用时钟和地形约束；到不了时仍按现有规则停下。接触或收势引用窗口内可见的姿态标记。

## A：部位、握持和普通接触

万法阁的身体页可以把同类徒手动作换到另一侧，姿态、实际发力部位和占用一起更新。持械动作沿用原版唯一的右手武器槽；握法读取器物实际资源，铁剑提供常规与靠护手两种握点。普通接触可选整组表面或其中一处，再选择生效和结束标记。编辑先编译候选，非法区间拒绝后仍保留原草稿及撤销记录。已有抓握、格挡等共用表面的动作暂不开放普通接触独立调整，留待 C 核对各自的实际生效条件。

改动沿用原有资料结构，不增加存档版本或手动迁移。

实机分段完成：先在同一人物身上验证徒手改到左手且可实际绑定，持械动作不开放不存在的左手装备槽；再编辑一把铁剑，保存、重开，实际确认靠护手握点对齐、普通接触仅取剑尖、标记前后没有接触形状。同一份保存资料再经正式入口施放，取得实际右臂控制，0.6 秒正常结束并归还控制，武器仍是原物。最初发现的左手持械拒绝、测试准备以及画面取样失败均保留。构建 0 错误。中英文截图与分段证据索引位于 `~/.local/state/cultiway-dev/evidence/martial-binding-813a/delivery.json`。

## B：步法和发力

本批只补两个入口：普通身体可以按姿态逐点编辑双足、离地高度和整身朝向，并与三轴部位共用原来的平面步法曲线；有对应求解的部位可编辑按目标距离瞄准与接触回弹。起势和收势回到自然站姿，接地足不得在地面滑动，非法候选保留原草稿。整身朝向和躯干转体分别编辑，不改变原费用或伤害结算规则。

结束条件：用 A 的同一世界、人物和铁剑，从窗口改造并保存重开；实际施放应移动、只接触目标一次、正常收势归还控制，并拒绝一次非法足部编辑。交付本批复验入口和中英文画面。正式冷读与连续录像留到整项验收。

已分段验证：窗口拒绝接地滑步且保留草稿，抬脚可以撤销重做；保存重开后，双足、前移曲线、瞄准和回弹参数均保留。用窗口保存的同一把铁剑动作走正式施放，人物向前移动约 0.176 格，确认一次攻击接触，0.6 秒正常收势并归还控制；同一姿态取样确认接触回弹会缩短伸手距离。本段观察到原版伤害已排队，但没有收到出队结算，不能计作已扣血；与实际支付、抓握和格挡一起在 C 复验。首次施放与补验中的记录脚本错误独立保留，最终仅补跑施放段。构建 0 错误。证据见 `~/.local/state/cultiway-dev/evidence/martial-footwork-813b/delivery.json`。

## C：内部阶段和整体验收

本批结束条件：能在窗口给现有姿态点命名，已有接触、控制与收势引用随有效重命名保存；删除仍被使用的名字要拒绝。补齐编辑同一动作时段、接触表面和阶段时缺的入口，先检查完整候选。用现成身体、铁剑和原世界验证抓握或格挡不借用普通命中的时段和表面，普通命中也不借用抓握的表面。再走一次正式支付、伤害出队、控制失败与归还、正式存档和另起进程冷读，留下连续录像。全部通过后再关闭 8.13，并合并推送到 `codex/dev`。

已关闭的缺口：窗口可给姿态命名，改名同步已有接触、抓握和收势；删除仍被使用的名字会拒绝。阶段可以单独命名，并从现有姿态取起止时刻。实机保存重开后保留这些设置；铁剑的抓握刃口与普通接触剑尖使用不同表面。执行层分别判断普通命中、格挡和控制的有效范围，抓握不因普通攻击的阶段间隔而提前归还。

用同一原世界和铁剑实测：窗口成品改用体力，余额不足不启动，余额够时从 50 扣到 46；不可移动目标拒绝抓握，来源控制正常归还，随后仍能释放。可移动目标的抓握在 0.19 秒成立，跨过攻击间隔，在 0.27 秒归还；抓握刃口没有触发普通伤害。此站位未接触后段剑尖，整段检查仍保留失败，后段伤害与格挡、正式冷读和连续录像待验收。构建 0 错误。分段记录位于 `~/.local/state/cultiway-dev/evidence/martial-process-813c/delivery.json`。
