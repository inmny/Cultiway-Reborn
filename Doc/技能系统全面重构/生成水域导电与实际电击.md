## 规则

`Conduct`使用部位在确认时点的实际接触体选择入口。液态水的共同水深达到`MinimumDepth`才可导电，默认0.02地图格。相邻水柱必须在高度上真实接触；不从颜色、外观覆盖、敌我或同一施放推断连通。所有来源的水共同导电，材料量和原支付归属不因导电改变。

传播采用同格宽的四邻距离，稳定顺序遍历。每进入一格按`TravelCost × 格宽`消耗力量，`Range`限制沿路径距离，`MaximumCells`限制本次总传播格数，`MaximumTargets`限制不同人物数。人物实际身体接触已传播水柱，且符合当前施放的目标关系时，消耗完整`DamagePerTarget`力量（至少为1）并交给原有雷电伤害与抗性结算；剩余量不足一次完整作用时不以最低伤害放大微量余数。同一传播内人物只作用一次。

实际消耗通过既有余力接口扣除，未耗力量可继续后续操作，消耗过的份额不能再退款。导电不是人物与施法主体的直接接触，不伪造`ActorContact`，另记录实际水路、消耗、目标和结算结果。真实伤害回调改变或清空世界时立即停止后续结算。

## 参数和实际归属

| 参数 | 含义 |
|---|---|
| `Range` | 从每个真实入口起沿四邻水路的最大距离，不是跨空地的圆形伤害范围 |
| `MinimumDepth` | 同一格所有来源的共同液态水深下限 |
| `TravelCost` | 每进入一格按实际格宽消耗本次余力 |
| `DamagePerTarget` | 每个人物的完整力量消耗，至少为1；不够一次完整作用时不扣血 |
| `MaximumCells` | 一次传播最多到达的格数 |
| `MaximumTargets` | 一次传播最多作用的不同人物数 |

尺寸改造扩大入口形体、水路距离及有界容量，不扩大现实人物和水柱高度。资料复制、撤销与保存保留实际数值，施放时不再重复套改造。条件和定时导电与材料转换按同部位资料顺序确认，因此先冻结再导电和先导电再冻结具有不同的真实结果。

当前控制者决定人物筛选和雷电伤害归属，原施放来源另行记录；已经混流的材料依然保留原支付者。导电消耗的是发出电击的施放，不领走池中其他修士的材料资源。已有反射可改变控制者，传播不另造没有来路的攻击者。
