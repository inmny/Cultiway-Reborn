# 9.08：落空与收尾去向

本项按以下三段验收。复用同一现成世界和已有剑形主体；不增加身体、兵器和流派样本。

- **落空与移动目标。** 同一部位分别沿固定方向飞行和连接移动目标。目标横移后，固定路线保留自己的去向，在没有实际接触时不扣血；追随路线靠实际位置重新取得接触。检查接触时主体仍在实际表面，结束后旧路径没有迟到伤害，也不留悬空主体。
- **格挡与中断。** 检查被挡住、以及施放方来源中断两种结果。已失去作用的主体和未发生的后续效果从共同画面移除；已独立交出的实体按自己声明的寿命和去向结束。这一段检查画面和实际执行是否同时收回，沿用既有伤害、格挡和归还规则，不重复 9.07 的声效对照。
- **材料转换与残留。** 用同一形体做一次真实水转冰，比较实际材料和画面表面更新的时间；对照本次随术退场的部分和真正留在世界的部分。临时残留按自身期限消失，不因为换成冰就获得额外攻击或永久留下。

交付：保留能分别复验三段的命令、真实作用及共同画面的时间点和代表帧，修复实测暴露的共用去向问题。材料美术细化、三视角连续录像分别归后续流派条目与 9.10。上述三段完成后，关闭 9.08 再合并推送 `codex/dev`。

同一独立游戏分四条命令验证，分别记录：

| 场景 | 真实作用和画面的结果 |
|---|---|
| 固定路线与追随路线 | 目标横移后，固定路线仍走原方向，无接触和伤害；追随路线离开原路线，转向目标的新位置，实际接触一次并扣 95 点生命。两次都正常退场，无迟到命中。 |
| 格挡 | 木障吸收约 100 点作用，后方无伤。攻体消失时共同画面只剩木障；木障按自己的期限退场。 |
| 中断 | 来源真实死亡，起势主体随之移除；越过原定展开时点仍没有新主体、接触或伤害。 |
| 转换与残留 | 同一流水在凝冰后切换实际物态和冰面，只交出一份约 12 体积的冰体。原术退场后冰体仍在共同画面中，到期只结束一次，未产生额外接触。 |
