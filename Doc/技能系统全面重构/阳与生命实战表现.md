# 9.22 阳与生命实战表现

本项交付「日轮照甲」和「护生修复」。局部交锋采用同一批实机人物和地块。9.40 的城域攻击另有规模与目标验收，本项不把局部录像当作那一项的完成依据。

| 用例 | 固定游戏行为与画面 | 必要实机检验 |
| --- | --- | --- |
| 日轮：攻击 | 从暖色实体内核向明确方向压出有厚度、可看见流动层的光；接触宽度与外缘一致。继续通过原本的攻击路径结算人物伤害。 | 正面实伤、相邻边界外对象无伤；释放和散去不再触发额外结算。 |
| 日轮：护持 | 暖色内核张成有厚度的合拢甲面，命中先消耗实际容量；被削弱后外层降亮，破层留短暂退光。 | 可吸收阴系射击与原版箭，耗尽后下一击照常结算；退出后可再次施放。 |
| 护生：组织 | 恢复的载体与恢复完成后的组织接合区分开，只按实际回补在受伤处长出柔软的有厚度的薄层。 | 真实伤员逐段增益，健康对象没有接合表现；中断后已增加的生命保留。 |
| 护生：活木 | 沿实际接触逐段修复受损的活树或植被，结算后从木芯往外出现与组织不同的绿色枝芽。沿用地块操作、生命上限及接触频率，受影响的地块有限。 | 真正有损伤的存活植被恢复；健康植被、枯木和房屋不被修复。停止后保留已恢复的生命；换世界清理临时画面。 |

正式入口继续使用原有光束、阳盾和治疗的费用与目标资格；修复规则能与普通地块接触、范围及投送方式组合。完成时提供复验入口和原版、Worldfall 常速实机录像。该项完整验收后才合并并推送至 `codex/dev`。

## 实机验收

- 日轮照甲：正面目标受到光束伤害，范围外目标无伤。阳盾容量从 300 降到 290，再降到 197.2；耗尽后已经没有拦截面，甲片仍短暂退光。随后从来袭方向反打的光束实际伤人，原施术者可以再次付费启盾。
- 护生修复：可编辑样例实际花费 6 点法力，在中断前分三段给伤员恢复 93 点生命、给同一棵受损活树恢复 3 点生命；健康对象、枯木和房屋不受影响。原复苏场也经过正式学习入口复验：扣费同时治疗伤员和活木，换世界清除仍活跃的法术及画面。
- [护生修复构造资料](构造输入/护生修复.json)可在编辑与演示流程复用。四段实机常速原片、代表画面、结算检查和失败记录见 `~/.local/state/cultiway-dev/evidence/sun-and-life-922/delivery.json`。使用独立游戏的软件渲染环境确认两种视角的画面与实际作用。
