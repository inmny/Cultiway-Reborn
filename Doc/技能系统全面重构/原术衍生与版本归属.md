# 原术衍生与版本归属

本批落实7.04与7.12，并继续7.03、7.14及保存相关任务。修士能在已学构造上继续创作，当前共用变化不等于完整法术、战技及功能创作范围。

## 从实际掌握继续创作

自然请求在受理时按确定种子选择：已有构造时，65%选择一份真正掌握的原术，其余继续独立探索。没有已学构造时走原有创作。功法领悟、修炼和突破继续使用同一有限队列，不添加每帧遍历。

先复制原术，再按实际存在的部位和操作选择一次改变。没有按原术编号登记整招分支，也不把两个独立能力的释放次序保存为配方。

| 当前变化 | 保留与改变 | 共用执行 |
|---|---|---|
| 换材 | 只改变选中部位的实际材料，清除该部位原物态及表面覆盖，保留其他部位 | 现有材料、物态和实际作用 |
| 换形 | 替换一个有可用结构的末端形体，其他结构和过程保持 | 现有形体资源、接触与运动 |
| 触生 | 原有部位实际接触后，额外生长子结构 | 共同接触事件、嵌套及生长 |
| 随身 | 原主体改由来源人物维持位置 | 现有连接与随动改造 |
| 环绕 | 在原主体外建立旋转支点，内部过程继续 | 现有嵌套、随动与旋转 |
| 复生 | 保留完整原术结构，产生两份分次显现，支付相应增加 | 现有数量与历时改造 |
| 显化 | 原术只有身体动作时，保留发力及收势，增加真实离手主体 | 现有身体显化与投送改造 |

选择时排除明确缺少的基础条件，例如流散部位不直接换成另一种初始材料，不把有专用动作或碎解部件的末端随意换形。最后仍由完整的正式编译入口判断部位、事件、时段和预算是否成立；复杂组合可能失败，记录具体原因后结束本次请求，不在同一次机会里无限重抽。更完整的补全、操作组合及近似重复控制继续按原TODO推进。

## 独立结果及直接来源

每份结果保存自己的完整结构、新编号、新作者与种子。可选的`Parent`只记录直接来源编号、修订、原作者及本次改变，不递归复制整条传承链。旧构造没有该字段时视为无单一来源；恢复结果不要求原术仍存在，也不按来源重新生成。

玩家改造及另创也记录相同来源。改造产生独立定义，只替换指定人物的掌握关系；其他人继续掌握原编号，已经开始的施放继续使用原计划。手工登记仍是开发及恢复接口，不能把直接覆写同编号冒充上述独立改造语义。

直接学习与传授已登记结果时，学习者增加对该确定版本的掌握，不改变创造者或其他人的资料；另存及改造才创建独立编号和当前作者，原作者记在直接来源中。实际法术书及功法传承入口仍按7.13接入，资料归属完成不能代替传承玩法完成。

## 请求第三版

人物`ability_creation`升为第三版。受理时复制一份完整原术及原有倾向；正式处理按这些输入生成。受理后学习、替换或修改其他版本不回头改变该请求，完成后释放临时原术副本，正式结果保存自己的构造和直接来源。

第二版请求当时没有选择原术，因此转换为明确无原术，继续原有独立创作，不从当前知识补选。第一版先按既有规则转换，缺少倾向的未完成请求仍局部取消、保留原档与说明。资料逐版转换后只运行当前实现。

## 验证及资源

`verify_derivation.script`检查多种真实结构变化、原输入保持、自动选源、未知来源拒绝、排队后人物改造、其他学习者版本保持、保存完整原术及真实第二版升级。`verify_derivation_restart.script`在真正退出重启后检查第三版快照、来源、独立掌握、相同完整结果及不重复授予。

复现草稿可用`Generate(actor,seed,inspiration,source)`；指定已学原术排队可用`TryQueueCreation(actor,seed,sourceId)`。原有`Generate(actor,seed)`继续生成独立探索草稿；不指定原术的排队使用与自然入口相同的选源规则。比较排队预期结果时必须读取已受理状态的`Inspiration`和`Source`，不能重新读取人物后猜测原输入。

本批复用已有形体、材料与动作，没有新增整招资源。运行输入、保存夹具与画面证据位于`artifacts/skill_rebuild/derivation/`。法术书及功法传承、完整身体动作创作、近似重复和长期增长尚需继续实现。

## 实际结果

衍生运行20项通过，同一份两层原术的64个种子覆盖六类变化并全部通过正式编译；身体掌击另行验证保留动作并显化离体主体。按自然选源规则的12次受理中，7次选择已学原术、5次独立探索。输入草稿和正式原术保持，失败不登记半成品，受理后人物替换掌握版本不会改变排队输入。

原编辑27项、请求30项、倾向21项回归通过；真正退出重启后，第三版衍生10项、请求10项、倾向9项通过。3040848保存、3049387恢复；完成后再次存读档不重抽或重学，当前格式没有丢弃其他区段。编辑检查包括新编号复制、原有冷却、其他持有者、旧施放继续命中以及改造后曲线与冰质的实际作用。开发构建0错误、16项已有警告，经NML实际重新编译加载。
