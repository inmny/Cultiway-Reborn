## 具体说明

### 当前保留的能力

`Source/Core/SkillLibV3/Settings/` 提供单招参数、元素性质登记，以及蓝图和技能容器之间的转换。保留元素性质、作用范围倍率、效果强度倍率、持续时间、对象接触开关和导电水域设置。作用、显示、费用、强度评估与蓝图签名继续读取这些参数。

蓝图仍保存原来的稳定参数字段，避免仅因代码类型改名就改动参数含义。原版和 Worldfall 的模型、材质、轨迹与命中显示继续使用既有入口。

修士自主频繁施法仍由战斗系统独立调度，可以同轮释放数种已掌握的法术；它不需要组合配方。导电水域与雷法接触仍按实际存续区域工作，独立掌击仍使用身体动作和原版近战结算。

### 已删除的部分

- `Source/Core/SkillLibV3/Recipes/` 中的配方定义、串联编译和延迟发射执行。
- 施法、接触和结束时对配方的调用，运行参数中的配方归属及后续载体快照。
- 万法阁组合页、组成部分切换、后续触发设置和空的预设选择。
- `RecipeField`、`RecipeBurst`、`RecipePalm` 三个组合专用技能及其专门显示和身体动作分支。
- 组合专用本地化；通用参数改用 `Locales/skill_settings.csv`。

配方样板此前已经删除，本次清理其余执行与编辑代码。没有保留旧玩法的运行分支。

### 旧资料如何转换

| 资料 | 旧版本到当前版本 | 处理 |
|---|---|---|
| 技能蓝图 | 第 4 版 → 第 5 版 | 删除 `Recipe`，保留主体、元素、范围、强度、持续时间、碰撞设置、轨迹及词条；有后续部分时记录提示 |
| 世界物件部分 | 第 2 版 → 第 3 版 | 逐个转换技能；普通主体继续恢复，已删除的组合专用主体单独跳过，其余物件继续加载 |
| 万法阁全局资料 | 第 5 版 → 第 6 版 | 同样转换蓝图，记录丢弃提示，并清理失效主体及其选中记录 |

更早的正式版本继续经过已存在的相邻转换；旧转换不删除，也不将未来版本强制改成当前版本。

世界读取沿用原档保护、备份和恢复报告。后续部分丢弃及失效主体会进入报告，原文件不在读取时改写。万法阁转换提示写入日志，转换完成后清空临时提示，避免每次保存重复报告。

全局资料升级前另存 `.legacy.bak` 原文件；已有副本时使用独立文件名，避免覆盖此前的原件。正常轮换备份继续工作，后续保存不会覆盖这份升级原件。

### 验证入口

- `dotnet build Cultiway.csproj -c Debug --no-restore`：开发编译检查。
- `dotnet run --project Scripts/WorldSaveTests/WorldSaveTests.csproj`：包含实际转换链、参数保留、局部丢弃提示、原输入保留及全局原件保护。
- `Scripts/WorldSaveTests/runtime/verify_skill_settings.script`：独立世界构造旧资料，实际保存读取；核对普通技能、被移除主体、原档字节及当前格式再次读取，并检查通用参数实际施法和编辑窗口。
- `Scripts/SpellDemos/`：使用保留的单招和来源能力检查实际释放，继续维护统一演示入口。

验证记录放在 `artifacts/skill_settings/`。这次清理不等于完成外观修正；范围不匹配、外观过度复用、战技烟雾等仍按[全量演示问题与修正](../城域战斗表现/第5阶段-全量演示问题与修正.md)继续处理。

本轮开发构建为零错误、十六条已有警告，纯数据检查通过。实机检查确认世界保留两项普通技能、全局库保留可用主体并清理失效选中记录，旧配方后续部分及已删除主体均有局部丢弃提示；原档与备份字节一致，当前格式再次保存读取不再触发转换。实际施法保留水性质、1.8 倍范围、0.7 倍强度、4.5 秒持续和关闭对象接触；叠加境界后的实际范围倍率与计算结果同为 4.14。

编辑器只保留五个单招页面，通用参数仍能编辑，见[实机结果](../../artifacts/skill_settings/runtime-result.json)和[编辑页截图](../../artifacts/skill_settings/单招参数编辑页.png)。另外经正式规划与执行入口检查，观察到同一时刻生成火球、沧浪和灵藤，见[并行调度结果](../../artifacts/skill_settings/parallel-result.json)；该检查手动推进战斗入口，不代替所有原版人物任务的自然交战验证。

统一演示工具另完成火球原始、词条、轨迹变化，以及飞剑法宝主动和独立掌击，共五段实机检查，均通过且录制期间无运行错误。掌击实际伤及一名目标，法宝与普通法术也记录到目标受伤，见[施法检查目录](../../artifacts/skill_settings/施法检查/演示目录.md)。检查同时修正掌击演示的准备顺序，避免提前推进四帧时先消耗近战冷却。
