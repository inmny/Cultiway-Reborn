# 官道

## 玩法

文化的“结构”栏目新增“官道”，与城墙、护城河和村庄布局独立选择。

- 村庄大厅完工后自动检查道路连接，已有大厅的存档也会自动检查。
- 以本国首都为起点，优先把最近的未连通村庄接到已经连通的村庄。
- 道路连通段和本国村庄共同构成路网节点，因此可以经过其他村庄抵达首都。
- 只使用现有陆地，绕开高山、山峰、城墙和水域；隔海村庄暂不接通，不填海修桥。
- 优先复用现有道路，保护城市建筑和铁路。普通树木可以按原版铺路规则清除。
- 首都变更、村庄易主和道路中断后重新检查。取消文化选项后停止主动修建，保留已有道路。

## 实现

从首都沿地图上实际存在的道路逐格检查，并通过本国村庄换接其他道路段。原版当前没有维护 `road_island`，因此不依赖这份空记录。连接候选只能来自同一国家、同一陆地连通区域。

每次选择距离最近的一对“未连通村庄—已连通村庄”，分帧寻找四向连续陆路并分批铺路。每个画面帧只推进一次，避免高倍率时重复消耗同一帧的预算。规划途中大厅被毁、村庄易主或首都变更时取消当前工程，重新选择连接。

连接记录来自地图上实际存在的道路，不额外维护一份存档路网。读档后重建检查结果；没有可行路线的连接暂缓重试，避免一直重复扫描。

## 护城河修正

护城河选地时跳过原始地形为高山、山峰的格子。城门向内、向外延伸的道路遇山停止，避免沿山体挖出长条平地或道路。

## 验证

- 大厅未完工时不触发；大厅完工后加入路网。
- 相邻村庄先相连，所有有陆路可达的目标村庄均能经路网抵达首都。
- 水域、高山、山峰和封闭城墙不会被官道改造。
- 移动首都、村庄易主、道路中断和世界切换后不会沿用失效工程。
- 原版道路连通记录为空或一直待更新时，仍能识别已接通村庄，继续连接其他村庄。
- 护城河和城门道路遇高山、山峰时保留山体。
