# 第2阶段-九大战技效果与视觉

**状态**：实现完成，待实机验收
**适用范围**：守卫、枪骑、决斗家三个流派的首批九个战技

## 设计结论

- 视觉采用克制武技：基础招依靠武器动作、金属火花和尘土，高阶招才出现短促斗气轨迹。
- 保留九个稳定战技 ID 和三个流派定位，允许重做具体效果与时序。
- 资源采用混合制作：九个图标由 imagegen 生成高分辨率绿幕源图后确定性像素化；地面、尘土、碎片和状态标记由程序生成；武器主体直接使用施放时的真实武器精灵，沿连续运动实时绘制；原版只复用 `fx_hit`、`fx_hit_critical` 和少量金属火花等低语义接触反馈。
- 骑士特效不得出现魔法阵、元素爆炸、球形护盾、凭空生成的盾牌或坐骑。

## 共享战斗合同

### 施放与结算

1. 能力成功受理时一次性确认并支付完整斗气，同时启动该战技的独立冷却。
2. 支付失败、冷却未结束或目标在受理前失效时，不启动动作、冷却和视觉。
3. 动作受理后若因目标离开、武器更换或施法者失去行动能力而落空，不返还斗气和冷却。
4. 所有武器伤害都以施放开始时的真实武器构造 `AttackData`，通过 `MapBox.checkAttackFor()` 结算。
5. 每段伤害分别保留暴击、武器攻击类型、装备命中效果、击杀回调和骑士击杀斗气。
6. 破甲、震慑和击退只在对应武器命中产生正数最终伤害后生效；被闪避或完全吸收的攻击只播放接触反馈。
7. 直接攻击可命中敌对地面角色和建筑；击退、震慑、破甲与范围附带效果只作用于角色。
8. 九招都不能以飞行目标为对象。自身范围技能只扫描地面敌对角色。

### 武器与中断

- 直接攻击、冲锋、坠击和连斩记录施放开始时的 `Item`；命中前换装会取消剩余动作。
- 格挡架势和反击架势绑定施放时武器；换装、死亡或失去对应流派准入时立即移除。
- 守护壁垒已经授予友军后独立持续到期，不因施法者换装或死亡提前消失。
- 普通受伤不打断动作；死亡、冻结、囚禁和明确的行动禁止状态会打断尚未发生的攻击段。
- 冲锋与坠击各自使用局部位移会话，不把角色位移塞进通用技能轨迹协议。

### 防御叠加

- 格挡架势与反击架势都是一次性状态，同一角色不能重复叠加，只能刷新持续时间。
- 守护壁垒在全局只保留一份 `25%` 减伤，重复施加只刷新为较长剩余时间。
- 格挡或反击可以与友军给予的壁垒乘算；前者只保护一次命中，后者保护整个持续时间。
- 三类防御都只处理有敌对来源的直接伤害，不降低饥饿、衰老、地形和自伤。

## 视觉语法

| 流派 | 主轮廓 | 动势 | 色彩 | 反馈重点 |
|---|---|---|---|---|
| 守卫 | 低、宽、贴地的横弧和裂纹 | 先收紧，再向外展开 | 铁灰、暗金、土褐 | 重量、阻挡、阵线稳定 |
| 枪骑 | 窄、长、方向明确的轴向枪芒 | 起点到终点连续推进 | 冷白、钢蓝、尘灰 | 距离、速度、贯穿方向 |
| 决斗家 | 细、短、边缘清晰的单体剑痕 | 停顿后快速切换方向 | 银白、深红、少量金属火花 | 时机、精度、连续节奏 |

基础战技只允许一个主视觉事件；中阶战技可以加入位移或范围事件；高阶战技使用“起手、过程、终结”三段表现。斗气颜色只出现在武器运动轨迹，不给角色覆盖持续发光的全身光环。原版 `slash_*`、`fx_block`、`fx_move`、`fx_jump`、`fx_explosion_wave` 和 `fx_boulder_impact` 不参与九招的主体表现。

`MotionRibbonTrail` 是 Cultiway 自有的程序化运动视觉，不属于原版 slash。骑士参数使用硬边、短历史、窄柔光：`GlowWidth` 不超过 `CoreWidth` 的 `1.45` 倍，`GlowAlpha` 不超过 `0.16`，历史通常不超过 `0.2` 秒，避免沿用御器技能的大面积双层光带。

### 真实武器运动

武器动作参考御器技能的执行体，但不复制御器的施法规模：

1. 施放开始时从当前 `EquipmentAsset` 解析真实武器精灵和染色结果，将该精灵写入一个短生命周期的武器运动执行体。
2. 执行体借用施放时的 `Item`。动作期间隐藏角色手中的同一物品，动作结束或取消后立即恢复；不复制一份静态剑弧贴图。
3. 执行体只使用连续运动原语：`Sweep`、`Thrust`、`Crush` 和 `GuardTurn`。位置、角度、伸展量都由经过时间和目标方向计算。
4. `MotionRibbonTrail` 每帧读取真实武器主体的位置和来源锚点，实时构造扫掠扇面、轴向枪芒或位移路径；命中时点由同一运动进度驱动。
5. 取消条件与技能执行体一致：换装、死亡、强控、目标失效或世界清理会停止碰撞并回收运动体，不能留下悬空武器或拖尾。
6. 不同武器只改变真实精灵、尺寸、材质色、运动半径和运动原语参数，不再为斧、锤、剑、枪各画一套固定弧帧。

武器动作的核心识别来自“哪一把真实武器以什么轨迹运动”，地裂、尘土和碎片只补充力量与命中时点，不承担武器轮廓。

### 表现预算

- 只有对象在镜头内时才生成斩击、火花、尘迹和自制动画。
- 范围技能对全部合法目标结算，但单次最多给八个可见目标生成独立 `fx_hit`。
- 范围技能只播放一次主音效，不为每个目标叠加同一声响。
- AI 自动施放不触发全局镜头震动；玩家主动施放苍穹坠击时允许一次轻微震动。
- 移动尘迹生成间隔不低于 `0.08` 秒，单次冲锋或坠击最多保留八个尘迹节点。
- 视觉 API 只生成 Effect，不调用会附带伤害、状态或地形修改的原版 Power。

## 守卫战技

### 格挡架势 `GuardStance`

| 项目 | 设计 |
|---|---|
| 目标 | 自身 |
| 动作 | 瞬发，可移动和普通攻击 |
| 状态时间 | `2.5` 秒 |
| 核心效果 | 下一次敌对武器伤害在最终伤害的适应阶段乘以 `0.55`，随后消耗状态 |
| 不触发 | 零伤害、环境伤害、状态伤害、无敌对来源伤害 |
| AI | 生命低于 `70%` 或近期有至少两名攻击者时进入候选；生命低于 `35%` 时最高权重 |

效果流程：

1. 角色把斧或锤横架在身前，创建一层绑定当前武器的格挡状态。
2. 合法伤害到达最终伤害适应阶段时降低 `45%`。
3. 同一命中结束后移除状态，不能让多段攻击共用一次格挡。
4. 状态自然到期时只淡出提示，不产生返还或追加效果。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.14s` | 真实斧或锤执行 `GuardTurn`，从攻击预备角转到身前防守角；播放当前武器短促挥动声 |
| 状态期间 | 只保留低矮暗金状态折角，不给武器叠加循环动画 |
| 成功格挡 | 真实武器朝攻击方向完成一次短偏转，接触点叠加一束 `fx_spark`，播放金属格挡声 |
| 自然结束 | 状态折角两帧暗化，手中真实武器恢复普通渲染 |

### 震退 `Repulse`

| 项目 | 设计 |
|---|---|
| 目标 | 自身周围地面敌对角色 |
| 半径 | `2.2` 格 |
| 动作 | `0.18` 秒蓄力，命中后 `0.25` 秒恢复；期间原地 |
| 伤害 | 每个目标一次 `0.65x` 武器伤害 |
| 控制 | 向外推开约 `1.3` 格并震慑 `0.35` 秒 |
| AI | 两名敌人时普通权重，三名以上高权重；没有近身敌人时为零 |

效果流程：

1. 施法者以当前武器完成一次低位横扫或砸地动作。
2. 命中时快照半径内敌人，每个目标只结算一次，不乘用武器自身多目标数量。
3. 每个产生正数伤害的角色沿“施法者到目标”的方向受到击退和短暂震慑。
4. 建筑不进入范围扫描，避免一次动作清扫成片建筑。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.18s` | 斧使用真实武器的低位 `Sweep`，锤使用真实武器的 `Crush`；轨迹颜色来自真实武器材质 |
| `0.18s` | 自制环形地裂和向外尘屑在同一帧展开；只播放一次沉重落地声 |
| 命中后 | 最多八个可见目标生成 `fx_hit`，控制状态复用低密度黄色状态粒子 |
| `0.18-0.43s` | 地裂六帧快速暗化，角色处于短恢复动作 |

### 守护壁垒 `GuardianBulwark`

| 项目 | 设计 |
|---|---|
| 目标 | 自身及半径 `3.5` 内最多三名友军 |
| 选择顺序 | 施法者必选；其他角色按生命比例、距离、稳定角色 ID 排序 |
| 动作 | `0.22` 秒砸地号令，随后可移动 |
| 状态时间 | `4` 秒 |
| 核心效果 | 敌对来源直接伤害乘以 `0.75`，全局同类状态不叠加 |
| AI | 自身或友军生命低于 `45%`，或至少四名敌人正在接近时使用 |

效果流程：

1. 施法者以武器触地发出一次守护号令。
2. 自身固定获得壁垒；再选择生命比例最低的三名合法友军。
3. 每名目标获得同一固定强度状态；已有壁垒时只刷新较长剩余时间。
4. 状态只表达队伍互相掩护，不生成碰撞墙，也不阻挡移动或投射物。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.22s` | 真实斧或锤执行一次短 `Crush`，施法者脚下同时出现自制武器触地闪光和暗金阵列折线 |
| 授予瞬间 | 折线沿地面向三名友军各闪一次，不保持连接线 |
| 状态期间 | 目标脚边保留低矮双折角标记，每 `0.7s` 轻微明暗变化；不覆盖身体 |
| 状态结束 | 折角向内收拢两帧后消失 |

## 枪骑战技

### 破甲突刺 `ArmorPiercingThrust`

| 项目 | 设计 |
|---|---|
| 目标 | `1.9` 格内敌对地面角色或建筑 |
| 动作 | `0.12` 秒收枪，命中后 `0.16` 秒恢复 |
| 伤害 | `1.2x` 武器伤害 |
| 附加效果 | 对角色施加 `3` 秒、`-20%` 护甲的破甲；同类效果只保留一份并刷新 |
| AI | 普通有效目标为中权重；高护甲且没有破甲的目标为高权重 |

效果流程：

1. 以施法者和目标当前位置确定一条轴线，不追踪飞行目标。
2. 枪尖沿轴线完成一次真实武器命中。
3. 只有正数最终伤害才给角色施加破甲；建筑只承受伤害。
4. 破甲不按枪骑数量叠层，避免集群瞬间把护甲降穿。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.12s` | 枪尖后收，生成一条很短的冷白聚线，不出现圆形蓄力阵 |
| `0.12s` | 真实长枪沿 `Thrust` 曲线送出，`AxialThrust` 根据枪尖实际位置实时收束 |
| 正伤害命中 | 自制甲片碎裂五帧叠加一束 `fx_spark`；播放一次金属穿刺声 |
| 被闪避或吸收 | 只播放普通接触火花，不播放甲片碎裂 |

### 破阵冲锋 `FormationCharge`

| 项目 | 设计 |
|---|---|
| 目标 | 距离 `2.5-6` 格的敌对地面角色或建筑 |
| 路径 | 施放时锁定方向和终点，要求直线路径可通行 |
| 动作 | `0.12` 秒压低枪身，最长冲锋 `0.65` 秒 |
| 主命中 | 路径上第一个敌对对象承受 `1.1x` 武器伤害 |
| 控制 | 主目标击退约 `1.8` 格并震慑 `0.4` 秒；其周围 `0.9` 格敌人只被向两侧推开 |
| AI | 有清晰冲锋距离和路径时进入候选；近身、路径阻塞或前方是友军密集区时为零 |

效果流程：

1. 施放时记录起点、目标当前位置和当前长枪，不在途中大角度追踪目标。
2. 位移会话每帧扫描上一位置到当前位置之间的窄胶囊区域，首个敌对对象触发碰撞。
3. 主目标产生正数伤害后承受击退与震慑；附近敌人只向通道两侧让开，不受伤害和震慑。
4. 命中、抵达终点、路径阻塞、换装、死亡或失去行动能力时结束会话。
5. 冲锋落空也消耗完整斗气和冷却，促使 AI 只选择可靠直线。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.12s` | 真实长枪压低并锁定冲锋方向，脚下自制四帧短尘展开 |
| 冲锋期间 | 真实长枪随角色移动，`Path` 拖尾取枪尖实际位置，并以不低于 `0.08s` 间隔生成自制尘迹 |
| 主命中 | 自制窄向冲击和枪尖碎光展开，接触点叠加 `fx_hit_critical`；播放一次重型穿刺声 |
| 侧向推开 | 只生成自制短尘迹，不为每个角色播放命中声 |

### 苍穹坠击 `SkyfallStrike`

| 项目 | 设计 |
|---|---|
| 目标 | 距离 `4-9` 格的敌对地面角色或建筑 |
| 落点 | 施放受理时快照目标地块，不在空中追踪 |
| 动作 | `0.16` 秒起跳、约 `0.48` 秒跃进、`0.22` 秒落地恢复 |
| 主伤害 | 原目标仍在落点 `1.2` 格内时承受 `1.6x` 武器伤害 |
| 范围伤害 | 落点半径 `2` 内其他敌对角色承受 `0.45x`，并被推开约 `1` 格 |
| AI | 只对同级强敌、首领或至少四人的敌群使用；普通弱敌为零权重 |

效果流程：

1. 受理时验证落点可站立，并记录目标地块、武器和攻击王国。
2. 角色沿固定抛物线跃向落点；过程不提供无敌，也不改变为飞行单位。
3. 落地时先判断原目标是否仍在主命中范围，再扫描范围内其他地面敌人。
4. 原目标离开落点后不会被追踪；若仍处于冲击范围，只按 `0.45x` 范围伤害结算。
5. 原目标死亡不取消落地冲击；施法者死亡、换装或被强控时取消剩余动作。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.16s` | 真实长枪先压低再向下锁定，起点播放自制压地起跳四帧；落点出现自制非魔法裂纹预告 |
| 跃进期间 | 真实长枪固定在角色运动方向前方，枪尖保留窄钢蓝 `Path` 拖尾；不生成传送闪光 |
| 落地瞬间 | 自制放射地裂、中心尘柱和外推尘环六帧同步出现，落地声单独播放 |
| 命中反馈 | 主目标生成 `fx_hit_critical`，其他目标最多八个生成 `fx_hit` |
| 镜头 | 仅玩家主动施放时触发一次轻微短震，AI 施放不震动全局镜头 |

## 决斗家战技

### 蓄势重击 `CommittedStrike`

| 项目 | 设计 |
|---|---|
| 目标 | 当前武器近战范围内敌对地面角色或建筑 |
| 动作 | `0.22` 秒蓄势，命中后 `0.25` 秒恢复；期间原地 |
| 普通伤害 | `1.25x` 武器伤害 |
| 孤立伤害 | 角色目标周围 `1.8` 格没有其友军时提高到 `1.55x` |
| AI | 孤立且生命充足的目标为高权重；目标濒死或施法者被多人包围时降低权重 |

效果流程：

1. 施法者举剑蓄势，动作受理后不会自动追步或修正站位。
2. 命中时重新检查目标距离，并判断目标身边是否有同阵营角色。
3. 建筑始终使用 `1.25x`；孤立判定只服务角色单挑。
4. 目标离开近战范围则重击落空，不自动改打附近敌人。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.22s` | 真实长剑连续抬起并停顿，最后 `0.05s` 加速进入重击轨道；不生成持续光球 |
| 命中时 | 真实长剑完成一次宽 `Sweep`，`RadialSweep` 读取剑尖实际轨迹并同步展开 |
| 普通命中 | 使用 `fx_hit` 和当前剑命中声 |
| 孤立加成 | 改用 `fx_hit_critical`，程序化轨迹末端加入少量深红，不增加范围 |

### 反击架势 `CounterStance`

| 项目 | 设计 |
|---|---|
| 目标 | 自身 |
| 状态时间 | `3` 秒 |
| 触发条件 | 下一次来自近身敌对角色的正数武器伤害 |
| 防御 | 该次最终伤害乘以 `0.5`，随后消耗状态 |
| 反击 | 当前伤害结算结束后，以施放时的剑对原攻击者执行 `1.0x` 武器伤害 |
| AI | 近期受到近战攻击且生命低于 `75%` 时进入候选；已有架势时为零 |

效果流程：

1. 创建绑定当前剑的一次性反击状态。
2. 只有攻击者是存活角色、攻击类型为武器且命中时仍处于近战距离才触发。
3. 在最终伤害适应阶段降低本次伤害并消费状态。
4. 当前伤害调用栈结束后排入反击，避免在结算中递归调用攻击。
5. 攻击者死亡、离开剑程或施法者换装时，状态仍已消耗，但不寻找替代目标。
6. 反击伤害携带专用来源标记，不能触发另一名决斗家的反击架势。

| 时点 | 视觉与声音 |
|---|---|
| 激活 | 自制两道细剑线交叉后停留为低亮银色折角，播放短促拔剑声 |
| 状态期间 | 折角每 `0.6s` 轻微闪动一次，不产生粒子光环 |
| 触发 | 真实长剑朝攻击来源完成一次短 `GuardTurn`，接触点叠加 `fx_spark` |
| `0.06s` 后 | 同一把真实长剑沿反方向完成 `Sweep`，`RadialSweep` 读取实际剑尖轨迹并同步出现 |
| 自然结束 | 折角直接暗化，不播放格挡或挥剑声 |

### 传奇连斩 `LegendaryFlurry`

| 项目 | 设计 |
|---|---|
| 目标 | 当前武器近战范围内敌对地面角色或建筑 |
| 动作 | `0.12` 秒起手，三段命中位于 `0.12/0.28/0.48` 秒，末段后恢复 `0.22` 秒 |
| 伤害 | 固定 `0.55x / 0.65x / 0.9x`，总倍率 `2.1x` |
| 目标规则 | 三段锁定同一对象，不自动追步、不切换目标 |
| AI | 只对同级强敌、首领或孤立高价值目标使用；多人包围和弱目标时为零 |

效果流程：

1. 启动前一次性支付 `360` 斗气并启动一次冷却。
2. 三段各自重新检查施法者、目标、原始剑和近战距离。
3. 任一检查失败就取消剩余段数，不返还已支付斗气。
4. 每段独立走真实武器攻击，因此装备命中效果最多触发三次。
5. 连斩不获得范围伤害、追踪位移、无敌或硬控制；强度全部集中在单体节奏。

| 时点 | 视觉与声音 |
|---|---|
| `0.00-0.12s` | 剑尖生成一次短银白闪光，角色不出现全身蓄力光 |
| 第一段 | 真实长剑沿左下至右上的短 `Sweep`，普通 `fx_hit` |
| 第二段 | 同一运动体反向完成更长 `Sweep`，普通 `fx_hit` |
| 第三段 | 同一运动体完成近垂直宽 `Sweep`，末端加入深红轨迹，使用 `fx_hit_critical` |
| 全过程 | 三次武器声与实际伤害严格同步；不额外播放范围爆炸声或镜头震动 |

## AI 权重摘要

| 战技 | 零权重条件 | 普通机会 | 高权重条件 |
|---|---|---|---|
| 格挡架势 | 已有格挡且没有更长刷新价值 | 生命低于 `70%` | 生命低于 `35%` 或近期攻击者至少三名 |
| 震退 | 半径内少于两名敌人 | 两名近身敌人 | 三名以上或施法者被包围 |
| 守护壁垒 | 没有受伤友军且敌人未接近 | 一名友军低于 `45%` | 多名低血友军或四名敌人接近 |
| 破甲突刺 | 目标已有破甲、超距或飞行 | 普通有甲目标 | 高护甲精英或首领 |
| 破阵冲锋 | 近身、超距、直线阻塞 | 合法远距目标 | 后排强敌或可打开缺口的目标 |
| 苍穹坠击 | 弱小单体、落点无效 | 同级强敌 | 首领或落点至少四名敌人 |
| 蓄势重击 | 目标即将被普通攻击击杀 | 普通高血目标 | 孤立强敌 |
| 反击架势 | 已有反击或没有近期近战威胁 | 近期受到近战攻击 | 低生命且原攻击者仍在近身 |
| 传奇连斩 | 弱目标、多人包围或资源应保留 | 孤立同级目标 | 首领、传奇角色或高价值单挑目标 |

## 实现边界

| 模块 | 职责 |
|---|---|
| `KnightTechniqueAbilityProvider` | 从 Catalog 枚举当前武器可用战技，统一提供来源展示、AI 画像、玩家入口、斗气与冷却检查 |
| `KnightWeaponStrikeResolver` | 快照并验证真实武器，执行倍率攻击，并把正数最终伤害结果交给破甲、控制等后续效果 |
| 共享武器运动原语 | 从御器现有实现中抽取真实武器精灵解析、手持物隐藏、`Sweep`、`Thrust`、`Crush`、拖尾配置和回收协议，御器与骑士共同使用 |
| `KnightWeaponMotionSession` | 为单次战技配置方向、时长、半径、角度和命中进度；传奇连斩在同一运动体内连续切换三段轨道 |
| 守卫执行文件 | 格挡、震退、壁垒的状态和范围逻辑 |
| 枪骑执行文件 | 突刺以及冲锋、坠击两个独立位移会话 |
| 决斗家执行文件 | 蓄势单击、延后反击和固定三段连斩 |
| `KnightTechniqueStatusBridge` | 在最终伤害阶段处理格挡、壁垒、反击，并将反击排到当前伤害栈之后 |
| `KnightTechniqueVisuals` | 只负责地面、尘土、碎片、状态标记和通用接触反馈，不绘制固定武器弧，不参与伤害判断 |

每个战技拥有一个稳定 `SkillContainer` 用于展示和冷却。九招不共享巨型运行时状态或按 ID 分发的总处理器；通用部分只提取真实武器命中、Provider、伤害阶段桥、武器运动原语和环境视觉生成五类明确重复能力。御器现有 `WeaponControlMotionState` 与 `WeaponControlTrajectories` 应重构为中性共享实现，不能复制成一套只改类型名的骑士版本。

### 通用反馈与程序化表现

| 资源或系统 | 使用战技 | 用法 |
|---|---|---|
| 真实武器精灵执行体 | 九个战技 | 使用 `ItemRendering.getItemMainSpriteFrame()` 及实际染色结果；动作期间借用并隐藏角色手中同一武器 |
| `Sweep` 连续运动 | 震退、蓄势重击、反击架势、传奇连斩 | 以起止角、半径、时长和缓动函数逐帧计算真实武器位置 |
| `Thrust` 连续运动 | 破甲突刺、破阵冲锋 | 按枪尖伸出和收回曲线逐帧计算位置，冲锋期间改为前向持枪锚定 |
| `Crush` 连续运动 | 锤类震退、守护壁垒、苍穹坠击落地 | 让真实武器越过角色上方后加速落向命中方向 |
| `GuardTurn` 连续运动 | 格挡架势、反击架势 | 在较小角域内把真实武器转向攻击来源，随后接入反向反击轨道 |
| `fx_hit`、`fx_hit_critical` | 全部伤害战技 | 只作为接触点反馈，不承担招式轮廓；范围技能受八目标视觉上限约束 |
| `fx_spark` | 格挡架势、反击架势、破甲突刺 | 少量金属碎光；若与自制帧冲突可直接关闭，不影响招式识别 |
| `MotionRibbonTrail.RadialSweep` | 震退、蓄势重击、反击架势、传奇连斩 | 直接采样真实武器端点和角色锚点，构造连续扫掠面 |
| `MotionRibbonTrail.AxialThrust` | 破甲突刺、破阵冲锋 | 直接采样真实枪尖位置，构造连续轴向枪芒 |
| `MotionRibbonTrail.Path` | 破阵冲锋、苍穹坠击 | 使用短历史、低透明路径表现位移，颜色来自真实武器材质 |

固定帧武器弧与原版 `slash_*`、`fx_block`、`fx_move`、`fx_jump`、`fx_explosion_wave`、`fx_boulder_impact` 明确不使用。首版不新增音频文件，只复用当前武器攻击、金属命中、格挡和落地声音。

## 验收重点

- 不看技能图标时，也能仅凭轮廓分辨守卫的横向重量、枪骑的轴向位移和决斗家的短促单体节奏。
- 任一战技关闭 `fx_hit` 和 `fx_spark` 后，仍能只靠真实武器运动、程序化轨迹和环境帧被正确识别。
- 慢放和暂停逐帧检查时，剑弧、枪芒和斧锤轨迹必须来自真实武器端点的连续运动，不得暴露预绘制弧帧或武器重影错位。
- 每次伤害、破甲、震慑、格挡、反击和范围冲击都与对应视觉帧处于同一游戏时点。
- 换装、死亡、强控、目标死亡和目标离开范围时，剩余动作按本设计取消且不残留执行体、状态标记或拖尾。
- 一百名混合流派骑士持续战斗时，视觉数量受限，AI 施放不会持续震屏或叠加同类声音。
- 暂停、倍速和恢复后，状态提示、落点标记、位移角色和伤害事件仍保持同步。
