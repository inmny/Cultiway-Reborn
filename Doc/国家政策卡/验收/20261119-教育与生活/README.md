## 观察与限制

- 教育和救助默认关闭。教育默认6岁；童工仍需达到原版8岁门槛，童工岗位优先。入学年龄高于成年年龄时不会把成年人送入儿童课程。
- 本次真实功法书阅读为符合仙道条件的儿童建立主修功法和掌握度；普通儿童没有越过资格限制。
- 流浪救助只借宿没有登记住户的本城住宅。走到门口时重新检查房屋与政策。登记住房、家庭归属和住户集合不变；没有可用空房仍可正常露宿。
- 第一次连续推进测试期间，原版找房已把起初的空房分配给其他居民，因此借宿没有发生，符合政策限制。随后单独建立新的空房并保留明确的空房条件，实际步行、进屋及睡眠流程通过；两次原始结果均保留。
- 切换全局语言时，其他既有窗口产生17条缺失文本提示，涉及器官编辑、万法阁、百宝阁和地理页等。它们与本次卡片及职业页无关；本次界面所有文本无缺失、无超高裁切，行为测试没有异常。界面结果文件保留这些原始提示，没有隐藏或修改游戏日志。
- 为验证军营位置，抽取12个随机操练目的地，所有有效点均在本城军营横纵各8格范围内；没有可用军营时不选择操练目的地。明确军令的目标选择逻辑未改动。
