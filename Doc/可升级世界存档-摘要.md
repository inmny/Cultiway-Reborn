# 可升级世界存档

2026-10-20，按用户确认的范围实施。

覆盖整个模组，分批接入。从本次正式格式开始保证升级读取，现有标注“存档无效”的预览世界可以重新开档。遇到删除的玩法或无法转换的资料，保留原档、提示受影响部分，并继续恢复其他内容。

## 存档约定

- 人物资料随原版人物保存，世界资料随原版世界保存；复制或分享原版世界时一起携带。不把人物进度放入跨世界的全局配置文件。
- 每份资料包含统一格式版本，以及各玩法独立的数据版本。模组版本只作为说明，日常改贴图或调整数值不触发数据转换。
- 各玩法使用稳定编号和明确的数据记录；不保存运行时实体编号、图片、缓存、资源对象或临时技能执行。
- 改字段、改编号或重组数据时，由所属玩法提供相邻版本转换。先转换、检查，再使用当前玩法代码；不同时保留两套玩法实现。
- 读取不回写原文件。发生转换或局部丢弃时，在玩家继续操作前备份原世界，并输出可查看的恢复报告。备份失败时保护原保存位置，另存到其他位置仍然允许。
- 同一动物上一个玩法恢复失败，不阻止它的其他资料和其余动物恢复。未知部分在本次游戏中不生效；原始资料留在原档备份里。
- 当前代码读到较新的格式，也按“保留原档、跳过无法理解的部分”处理，不能冒充已经完成反向转换。
