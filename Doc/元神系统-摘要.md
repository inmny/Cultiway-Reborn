# 元神系统-摘要

**状态**：命魂双载体、节点神魂战斗与元神主体功能已实现并构建通过；游戏内完整矩阵尚待手工验收  
**目标境界**：化神  
**当前范围**：元神初成、命魂神游、普通分念、节点神魂战斗、无身续生、夺舍塑体、法相化身和设施锚点网络  
**存档边界**：不实现存档、读档、迁移或兼容代码

## 命魂双载体

命魂已从模组地图节点改为临时人物载体。肉身继续由原人物承载，命魂载体只负责魂体的位置、受击、自身状态、动画和技能起点；人物身份、境界、技能、资源、冷却、装备、法器和最终归属始终只有原人物一份。

出窍后肉身与命魂都可独立移动、选敌和施法。两边共享技能、资源和冷却，技能实际效果分别按肉身或命魂持有的心神份额线性缩放。命魂可使用已学法术和合法法器能力，不能使用明确依赖肉身的技能，并且只受神魂伤害或含阴属性的伤害。

完整规则、技术调整和验收矩阵见[命魂双载体战斗调整方案](元神系统/命魂双载体战斗调整方案.md)。旧的命魂 ECS 施法路径已删除，不保留兼容或回退分支。

## 已移除内容

以下能力和相关运行状态、人工智能、本地化、系统入口均不存在：

- 察神和任何领域扫描。
- 神识领域与主动威压。
- 守一护魂。
- 友方附神、附神迟滞、附神扰念和净化附神。
- 重分念与可调分念份额。
- 敌方锚点锁定、侦测、污染、净化和其他锚点攻防。
- 人物、城市或宗门情报，以及传念、托梦、搜魂、借感和情报标记。

夺舍仍有被动神魂防御。它直接按目标当前神识、魂魄、境界、元神和主心神份额计算，不需要开关，也不产生护魂状态。

## 核心规则

- 九转元婴渡过煞风劫后确定性形成元神。
- 元神继承原元婴的谱系、品阶、元素、形成特性和强度，不再次随机。
- 化神当前属性和形成效果只由元神快照提供，元婴只保留为历史谱系。
- 一个修士始终只有一个人物身份、一套技能、一套资源和一套社会关系。
- 命魂在体时只有原人物肉身；命魂出窍时，原人物肉身与临时命魂人物成为两个可独立战斗的载体。
- 临时命魂人物不是第二身份，不拥有技能、资源、装备、法器、修炼或社会数据；这些内容全部读取原人物总账。
- 命魂、肉身残留、普通分念、高阶节点和创伤锁定份额合计始终为 `100%`。
- 肉身与命魂共享技能、资源和冷却，技能效果分别按各自实际心神份额线性缩放。
- 普通分念、法相、化身和显圣仍是模组节点，不是独立人物；它们与双载体、受控法器共用神识负荷与分念槽位。
- 系统不扫描人物、节点、建筑、城市或世界。命魂只使用普通人物已有的局部战斗选敌，不获得察神、隐藏发现或长期目标记录。

## 元神蕴养

元神从第 `0` 层开始，最高蕴养到第 `9` 层。成功蕴养后保留当前灵气的四分之一；失败后保留一半灵气并受到神魂创伤。

| 层数 | 调整完成后的作用 |
| ---: | --- |
| 0 | 命魂人物化出窍、三种神游姿态、双载体独立战斗、合法技能施放、归一、基础神念攻击和肉身毁灭后元神续存 |
| 1 | 提高命魂完整度、恢复和神魂攻防数值，没有独立操作 |
| 2 | 继续提高上述数值，没有独立操作 |
| 3 | 最多维持一道普通分念，可移动、聚焦、追踪短时锁定或归返 |
| 4 | 开放普通分念与高阶节点的位置施法和分念控宝；命魂合法施法不需要等到本层 |
| 5 | 普通分念上限提高到两道，开放定点守护和跟随友方 |
| 6 | 提高元神强度、节点完整度和恢复，没有独立操作 |
| 7 | 本命法器寄托、设施锚点、锚点连接与迁移、锚点显圣 |
| 8 | 普通分念上限提高到三道，开放战斗法相 |
| 9 | 稳定化身与本相肉身重塑 |

当前化神夺舍的代码门槛是“处于无身元神状态”，没有额外要求第 `9` 层。

## 心神分配

### 命魂神游

| 姿态 | 命魂份额 | 肉身残留 | 双载体结果 |
| --- | ---: | ---: | --- |
| 守一 | 可用心神的 `40%` | `60%` | 两边都可完整战斗，命魂与肉身效果倍率分别约为 `40%` 和 `60%` |
| 均衡 | 可用心神的 `60%` | `40%` | 两边都可完整战斗，命魂与肉身效果倍率分别约为 `60%` 和 `40%` |
| 尽出 | 可用心神的 `90%` | `10%` | 两边仍可完整战斗，肉身只发挥约 `10%`，但保持独立行动 |

创伤锁定先从总心神中扣除，再按姿态分配剩余份额，因此实际倍率使用分配后的真实份额。命魂出窍、移动和维持均消耗灵气，基础牵引范围为 `160` 格；绑定本命法器后可扩展到 `240` 格。

### 普通分念

- 第 `3` 层开放。
- 每道普通分念固定投入 `15%` 心神，不能选择其他份额。
- 划出分念后，命魂必须保留至少 `40%` 心神。
- 第 `3～4` 层最多一道，第 `5～7` 层最多两道，第 `8～9` 层最多三道。
- 分念受击、击破或失去牵引都会造成真实代价，不具备独立续命资格。

玩家可以聚焦本人节点，随后下达移动、定点守护、跟随友方、追踪短时锁定、控宝和归返命令。追踪只接受仍有效的节点战斗锁定，锁定失效后任务结束。

## 神识预算与控宝

```text
分念槽位 = 1 + floor(log2(1 + 神识 / 16))
```

会占用槽位或负荷的内容包括：

- 命魂离体后仍独立战斗的肉身，三种姿态下都占用一个分念槽。
- 普通分念、法相、化身和显圣。
- 普通分念与高阶节点的追踪、控宝、战斗和锚点迁移。
- 本命法器寄托、设施锚点网络和需要心神控制的法器。

命魂本体属于主念，不额外占用分念槽。肉身和命魂都从原人物读取同一批技能、资源和冷却；第 `4` 层后，聚焦普通分念可以接管下一件正在运转且由本人祭炼的法器，也可以主动解除控制。节点能力从分念位置出现，但资源、冷却和归属仍由原人物承担。

## 节点神魂战斗

### 短时锁定

- 短时节点锁定只服务普通分念、法相、化身和显圣，命魂不再登记为模组节点。
- 节点锁定只由真实神魂攻击或其他明确神魂接触产生，不存在主动侦测入口。
- 锁定只保存稳定节点句柄和到期时间，不保存位置历史、来源、危险度或情报。
- 基础持续 `7` 秒，同一目标再次接触时刷新。
- 每名人物最多同时持有 `32` 项。
- 节点失效、人物死亡、到期或世界切换时清理。

临时命魂人物已经是可以明确选择的普通战斗目标，攻击它不需要先取得节点锁定，也不会因此恢复察神或隐藏目标发现。

### 基础神念攻击

- 改为魂体专属的普通主动技能，可以直接攻击明确选中的敌方人物，包括临时命魂人物。
- 攻击普通分念或高阶节点时，目标仍必须处于短时节点锁定中。
- 攻击距离为 `12` 格，冷却 `2` 秒，每次消耗最大灵气的 `2%`。
- 伤害读取攻击者元神强度，并按当前命魂份额线性缩放。
- 命中节点会损伤完整度并干扰牵引；持续干扰可使牵引变为波动、受阻或切断。
- 对方临时命魂人物可以作为普通战斗目标直接反击，不需要节点锁定。

命魂和节点的完整度损失都会按比例转为人物的创伤锁定份额。命魂归一，或其他节点停止任务时，创伤才会按规则自然恢复。

## 肉身毁灭、夺舍与重塑

- 肉身被不含阴属性的普通致命伤害摧毁时，原人物转为无身元神而不是死亡。
- 命魂已经出窍时，原人物移动到临时命魂人物的位置并接收其魂体生命和合法局部状态，随后回收临时载体。
- 人物编号、姓名、关系、宗门、功法、技能、资源、法器、元神和化神境界全部保留。
- 临时命魂人物和无身元神都免疫不含阴属性且未明确标记为神魂伤害的伤害；有效魂伤可以造成真正神魂死亡。
- 魂系攻击统一使用纯阴属性。
- 无身元神可对低于化神的明确宿主进行夺舍，也可接受友方自愿承载。
- 第 `9` 层可在有效本命法器旁，用三个游戏年和三倍最大灵气重塑形成元神时冻结的本相肉身。

敌方夺舍的防守值来自目标稳定属性和当前主心神，不读取主动护魂、友方附着或领域状态。

## 本命法器与设施锚点

### 本命法器寄托

第 `7` 层可把下一件完全祭炼的装备法器设为唯一备用命魂锚点。它持续占用 `20%` 神识负荷，可扩展牵引、供无身元神休养，并在致命魂伤时提供一次有代价的转移机会。

### 设施锚点网络

第 `7` 层开放宗门元神台和城市香火坛：

- 每名人物最多设立 `2` 座设施，每座最多连接 `4` 条路线。
- 设立、连接、维护和解除都要求本人或分念实际到场。
- 锚点有负载、容量、物质建筑归属和有限香火愿力。
- 建筑被摧毁、占领或失去合法归属时，锚点崩塌。
- 玩家可连接两座授权锚点，并让临时命魂人物、聚焦节点或无身元神沿现有连接引导迁移。
- 锚点不包含侦测、污染、净化、敌方锁定或攻防规则。

## 显圣、法相与化身

- **锚点显圣，第 `7` 层**：在授权锚点投入 `20%` 心神形成短时投影，只能使用非攻击能力。
- **战斗法相，第 `8` 层**：投入 `50%` 心神形成短时战斗节点，可攻击明确敌人，伤害属于纯阴神魂伤害。
- **稳定化身，第 `9` 层**：在授权锚点准备载体后投入 `30%` 心神，长期存在并可攻击明确敌人。

三者都不是独立人物，锚点失效、资源不足、超时或节点被击破时按各自规则归返或消散。

## 人工智能

命魂离体时，原人物总账统一协调肉身与命魂两个独立战斗载体：

- 肉身和命魂可以分别移动、选择不同的局部战斗目标，并释放当前载体允许的技能。
- 两边共享技能冷却和资源；同一技能发生竞争时只能有一边成功提交。
- 命魂只使用普通人物已有的局部选敌，不获得察神、隐藏目标发现、范围领域或长期目标记录。
- 已有短时节点锁定时，可以对普通分念和高阶节点使用神念攻击并令本人分念追踪。
- 第 `8` 层后对高价值明确敌人显化法相。
- 第 `9` 层后准备稳定化身，并在无身且安全时尝试重塑肉身。
- 本人设施近期实际受击时，可以投下显圣支援。
- 战斗结束后召回普通分念和法相；超距、资源不足或收到命令时召回命魂。

人工智能不会使用元神专属扫描，也不会保存目标历史。普通人物战斗本来具有的局部选敌不视为元神侦测能力。
