## 具体说明

### 交付结果

玩家可以通过游戏界面完成“加入世界 → 选择人物 → 选择星球 → 查看携带清单 → 抵达 → 回乡”。本阶段承接第1阶段已经可靠的旅行流程。不同模组配置的实际接入由第3阶段完成，界面先预留环境信息。

### 入口与世界管理

提供底栏“星图”入口，人物信息页提供“前往其他世界”。原版存档窗口增加“加入星图”的可见入口。主菜单入口属于后续可选扩展，首版在游戏世界内完成操作。

将已有存档加入星图时，说明会建立独立副本；以后原存档与星图世界各自保存。首次加入即可选择名称和分类，保留原世界名作默认值。

星球管理支持打开世界、新建世界、重命名、收藏、重新定位副本和移出星图。存在进行中旅程或仍由该世界保存的唯一旅客资料时，先处理归属再移出。移出与删除文件区分，日常“移出星图”保留可恢复文件。

受管世界正常保存后，给出一次简短保存反馈，显示所在星球。普通原版存档继续按原入口使用；从原版另存出来的副本再次加入星图时按分支处理。

### 星图表现

星图使用可拖动、可缩放的平面画布，以原世界缩略图裁成圆形并加简单明暗形成星球。初期即可表达参考图的视觉目标。

| 信息 | 表现 |
| --- | --- |
| 世界大小 | 显示半径在上下限内随 `sqrt(地图宽度 × 地图高度)` 增长，详情展示真实尺寸 |
| 星球位置 | 首次自动摆放并保存；新增星球只寻找新位置，不重排整个星图 |
| 当前世界 | 固定的当前世界标记与文字 |
| 选中世界 | 统一选中外圈，详情随选择刷新 |
| 可抵达 | 正常显示，点击后查看详情 |
| 需要重启 | 专用小标记与“需切换模组后继续”文字 |
| 缺少必要资源 | 锁定标记，详情列出具体缺项 |
| 旅途中 | 在出发地和目的地之间显示进度标记；首版表示操作阶段 |
| 收藏 | 收藏标记，可按名称搜索 |

星球的显示位置与未来航程成本分别保存。玩家拖动布局只改变界面摆放，不会缩短实际航路。

单击星球只选中，点击详情中的“打开世界”或“前往”才执行操作。世界较多时提供搜索、收藏筛选、缩放复位和列表视图；超长列表复用条目，星图只刷新可见节点。

小分辨率下，详情改为独立页面，保留原版返回导航。星图和详情之间不再套多层装饰边框。

### 一次完整旅行

1. 在人物信息页选择“前往其他世界”，或从星图选择“选择旅客”。首版一次选择一人。
2. 选择目的地。候选目的地即显示可达状态，不把缺项等到出发后才告知。
3. 查看人物姓名、年龄、目标世界和携带清单，分列“正常携带”“封存”“阻止旅行的原因”。普通成功情况保持简洁。
4. 确定落点。已有星门或安全落点直接选择；尚无落点时，进入目标世界后暂停，由玩家点选合法地面。未完成前人物仍由旅途托管。
5. 点击“出发”，显示正在保存、切换世界、安置人物、完成等阶段。
6. 抵达保存提交后定位人物，打开简短抵达信息，恢复原来的暂停选择。

预览信息在检查时冻结，实际执行使用同一份人物和目标规则。出发前的最终检查发现资源或存档版本变化时，回到预览刷新差异。

“打开世界”只切换观察的世界；“前往”携带已选人物。两个动作的按钮文案和结果必须清楚区分。

### 状态与恢复

| 状态 | 界面反馈与动作 |
| --- | --- |
| 尚无世界 | 显示“加入已有存档”和“新建世界” |
| 无可旅行人物 | 显示选择入口或该人物被阻止的具体原因 |
| 等待落点 | 保持目标世界暂停，提供选点和返航 |
| 等待更换模组 | 显示目标需要的组合、当前差异和重启后继续入口 |
| 导出或导入失败 | 说明已保留的人物位置，提供重试或返航 |
| 重启发现未完成旅程 | 在星图显示“继续抵达”或“返航” |
| 已经抵达的请求再次执行 | 定位现有人物，显示完成结果 |

用户可见信息使用“修为封存”“缺少种族资源”等具体说法。文件校验值、内部编号等信息进入可展开的诊断区，不挤占正常旅行流程。

### 界面实现落点

独立旅行模组拥有自己的星图窗口、世界详情和旅行确认页，使用加载器与原版窗口能力。修仙模组只添加人物页入口、能力说明等接入内容。

仓库内的修仙入口放在 `Source/Content/UI/` 或功能自身的界面目录，并按 `Prompts/UI.md` 使用现有控件。公共 UI 不引用修仙接入类型。新增底栏按钮按既有分区、顺序和稳定编号注册。

已找到的原版参考是 `.GameSource/Resources/windows/saves_list.prefab`。实现前核对实际层级、导航、滚动条和按钮组件。此处只确认参考文件存在，尚未认定其中每个节点可以直接复用。

### 验收场景

| 场景 | 通过条件 |
| --- | --- |
| 空星图、1颗星球、50颗星球 | 加入、搜索、缩放和选择均可用，名字不遮住主要动作 |
| 极小和极大地图 | 星球大小有区别，真实尺寸清楚，节点仍能点击 |
| 长世界名、长人物名、多项模组差异 | 文本可以换行或滚动，动作区稳定 |
| 较小分辨率、中英文切换 | 详情可阅读，返回、关闭和底部按钮可见 |
| 点选星球、拖动画布、滚轮缩放 | 不误触打开世界或出发 |
| 旅途等待重启、缺失存档、导入失败 | 明确显示人物目前在哪，并可恢复操作 |
| 反复开关窗口和重复点击 | 不重复绑定事件、不生成多份旅客 |

实现 UI 后做适量构建检查，并在本地游戏中完成上述交互验证，附正常星图和携带预览截图。
