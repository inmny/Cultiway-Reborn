## 具体说明

### 交付目标

前三阶段已经提供可靠的运输与模组兼容能力。本阶段将手动出发扩展为飞船、飞升等玩法入口，它们共用人物包、世界保存和抵达流程。

推荐先做星门与结伴旅行，再做飞船，最后接飞升条件。每一种方式完成往返和中断测试后再增加下一种。

### 结伴与货物

一次旅程可以携带一组人物、个人物品和明确归属的货物。全组在同一次保存提交中出发，在目标的同一次保存提交中抵达。

群体资料先建立人物与物品的编号表，再恢复夫妻、亲子、师徒等已支持的组内关系。没有同行的人物保留故乡引用，不能错误指向目标的同编号居民。

共享货物只登记一份，指定目的地接收方式。源城市的仓库、其他人物的装备、宗门公有财产等，必须经过相应玩法确认所有权后才能转为货物。宠物、坐骑和特殊生命形态分别接入，先通过单体迁移再加入队伍。

队伍中有人不满足目的地规则时，预览显示具体成员和原因。首版群体模式要求全员通过，玩家可以在出发前移除成员。操作中断后，整组仍以同一个有效旅程状态恢复。

### 飞船旅行

基础循环为“建造星港 → 准备飞船 → 选择航线 → 登船与装货 → 起航 → 目标星港抵达”。飞船可由独立科技接入提供，也可与其他科技模组合作。

| 规则 | 建议 |
| --- | --- |
| 出发条件 | 源世界有可用星港和飞船，船员与货物满足要求 |
| 运载限制 | 明确的乘客数量与货物容量 |
| 航路 | 已建立的固定航线；星图摆放位置只影响显示 |
| 目的地 | 兼容目标世界，优先使用星港落点 |
| 航程 | 按航线记录的距离和飞船能力计算 |
| 燃料 | 与出发世界版本一起扣除，保存失败时不生效 |
| 到达 | 按约定恢复可用船只或航行记录，保证船体和货物归属唯一 |

第一版飞船旅行以可靠运输为主。航行事故、拦截和战斗等内容，应在独立规则具备中断恢复方式后增加。

### 飞升旅行

由修仙模组判断境界、资源、天劫或仪式等条件，并提供允许前往的目标世界列表。旅行核心执行已经满足条件的迁移。

建议基础循环为“满足飞升条件 → 选择上界 → 查看当地规则与封存说明 → 完成仪式 → 出发”。境界、消耗和天劫强度沿用修仙玩法自己的规则，不在旅行核心中再定义一套境界体系。

| 问题 | 建议 |
| --- | --- |
| 上界怎么产生 | 玩家选择已存在且满足条件的世界；后续可增加飞升时创建世界模板 |
| 上界有什么差异 | 世界灵气、允许的修炼体系、落点和进入条件等由接入部分声明 |
| 能否下界 | 世界对返程开放时允许；限制需在出发预览中写清 |
| 上界限制战力 | 对当前可用能力施加规则，保留个人原始成长资料 |
| 肉身或元神如何通过 | 分别定义支持形态，不能把特殊形态默认当作普通人物处理 |
| 旅程中断 | 完成出发提交前仍在源世界；之后由人物包托管，可续行或按规则返航 |

新建上界时，先完成世界生成和完整保存，再把它发布为可抵达星球。生成失败不消耗人物，也不发布一个空壳目的地。

### 时间与结算

未打开世界继续冻结。旅途中人物按旅程记录的耗时增加年龄，消耗和时间只结算一次；读取或重试同一旅程不会再扣一遍。

即时旅行只消耗实际设定的旅行时间，游戏读档耗费的现实时间不计算为人物年龄。飞船的长航程在星图记录进度，目标世界尚未打开时人物保留为等待抵达状态。

若允许玩家发船后继续观察源世界，航程以当前活动世界推进的游戏时间累计，暂停与读档不累计。经过模组配置切换后读取已保存进度继续；另一颗未打开的星球不会因此自动发展。

消耗和奖励跟随旅行状态提交：燃料和仪式材料在有效出发时结算，落地奖励在有效抵达时结算。旅途返航是否退还消耗由相应交通方式明示。

离线世界发展属于另一个功能范围。将来如需加入，先定义可简化计算的经济和人口规则，再决定与人物旅行时间怎样衔接。

### 验收场景

| 场景 | 通过条件 |
| --- | --- |
| 夫妻、父母子女或师徒结伴 | 已支持的组内关系正确，未同行者留为故乡记录 |
| 一组人共享一批货物 | 只保存一份货物，归属与数量正确 |
| 导入到队伍中间失败 | 不发布半组抵达，整组可恢复 |
| 出发或抵达提交前后退出 | 船员、货物、船体和消耗与旅程状态一致 |
| 航程完成后多次重启 | 年龄、燃料、奖励各结算一次 |
| 飞升消耗后目标环境不可用 | 人物资料受托管，可以继续或按明确规则返航 |
| 目标世界比源世界年代早很多 | 同行人物年龄保持，关系正确 |
| 源世界继续活动、目的地尚未打开 | 旅程等待或推进符合规则，目标世界仍停在有效保存状态 |

## 资源说明

以下为独立旅行模组或相应玩法接入部分的拟定资源，制作前核对本地原版同类资源尺寸、帧顺序和命名。

| 资源 | 具体设计 | 数量与归属 |
| --- | --- | --- |
| 星门 | 地面门框、中心可识别的传送区域，区分关闭和可用状态 | 1套建筑与启用效果，旅行模组 |
| 星港 | 有明确停泊区的地面建筑，支持选中与出发入口 | 1套建筑，飞船玩法提供方 |
| 飞船 | 停泊、准备、起航三种状态；船型变化在基础版后增加 | 1种船型及必要动画，飞船玩法提供方 |
| 航程标记 | 星图中的船形标记、航线和进度 | 1套界面资源，旅行模组 |
| 飞升入口图标 | 与修仙现有图标风格一致，清楚表达前往上界 | 1张，修仙接入 |
| 飞升效果 | 人物附近的光柱或空间裂隙，包含开始、持续、结束 | 1套效果，修仙接入 |
| 抵达效果 | 小型落地光环，可兼容星门与飞升的色彩变化 | 1套可复用效果 |
| 声音 | 打开星图、起航、飞升、抵达 | 优先核对原版可复用声音，缺少项再制作 |
| 本地化文本 | 乘客、货物、航程、燃料、飞升条件和上下界规则 | 按资源所属模组维护 |

本阶段的资源只列设计需求；本次未生成或修改贴图、动画、声音和游戏代码。
