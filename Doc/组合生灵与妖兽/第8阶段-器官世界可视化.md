# 第8阶段-器官世界可视化

本文解决一个问题：妖兽在世界里看不出身体长过什么。第 1 阶段的附加图层管线已经完整（器官等级声明图层、编译器按通道选胜出者、渲染系统池化绘制），但没有登记任何内容，所以当前的妖兽在世界里就是原版动物本身。

本阶段的目标：让轮廓明显的器官真实出现在世界画面上——龟有背甲、狼头上有角、九尾狐身后有尾冠；内部器官（代谢、腺体、灵窍）永远不上世界表现，只在详情界面显示。本文不改动身体规则与效果结算，只处理"看得见"这一层。

## 具体说明

### 步骤 1：通配符

现状的逐帧对照（`FramesByBaseFrame`）要求一张主体动画帧对应一张图层帧。蛇有待机、行走、游泳多套动画、每套多帧，一个图层要配十几张贴图，对角、龟甲这类基本不随动画变形的部件完全不成比例。

处理方式：

- `CreatureVisualLayerAsset` 增加整动画通配能力：`FramesByBaseFrame` 没有命中时，回退读取一张通配贴图（单一路径字段），跟随主体当前动画的任意帧绘制。
- 逐帧对照仍然合法，且优先于通配符；需要逐帧变形的图层（翅膀扇动、尾巴摆动）以后按原版帧名逐帧补充，不需要迁移。
- 绘制契约不变：图层跟随主体位置、左右翻转、缩放、可见性；查不到贴图的帧不绘制；不可见或死亡的单位不租用绘制对象。
- 通道胜负规则不变：同一外观通道只保留器官等级最高的胜出者；单个身体方案最多三层（`MaximumOverlayLayers`）。

程序对照：

```text
CreatureVisualLayerAsset
  FramesByBaseFrame[]     // 逐帧对照，优先
  WildcardSpritePath      // 通配贴图，逐帧未命中时使用
  Anchor / Offset / Scale / TintPolicy   // 维持现状
```

### 步骤 2：骨架与锚点

每个物种的主体轮廓不同，角、背甲、尾的位置必须按物种登记，不能共用一组偏移。

- `CreatureVisualRigAsset` 按物种登记：`CompatibleActorAssetIds` 指向原版动物资产，`Anchors` 提供 `head`、`back`、`tail` 三个命名锚点。
- 物种清单与启灵白名单一致：蛇、狼、熊、龟、狐、鳄鱼、蛙、兔、鼠、鸡、羊、企鹅、龙，另加化形后的东方人（人形只承载显化类图层，见边界说明）。
- 锚点坐标从 `.GameSource` 的各物种待机帧实际像素核对取得，不凭猜测填写。
- 各物种固定形态（`yao.<物种>.base`）的 `VisualRigId` 填对应骨架；图层通过 `RigCompatibility` 限定适用骨架，跨物种的图层复用同一份贴图。

### 步骤 3：首批器官

只上轮廓清晰、玩家能一眼认出的部件。同一通道冲突时按既有规则由器官等级决出胜出者，例如背甲与双翼同在背部通道，等级高者显示。

| 器官 | 图层 | 通道 | 锚点 | 玩家看到的 |
| --- | --- | --- | --- | --- |
| 玄甲 `yao.shell.black` | 背甲整块 | shell | back | 龟背上明显的甲壳轮廓 |
| 雷角 `yao.horn.thunder` | 单角 | horn | head | 头顶弯角 |
| 辨邪角 `yao.horn.evilspotter` | 单角 | horn | head | 头顶直角（与雷角同通道互斥） |
| 扶摇翼 `yao.wing.fupeng` | 双翼展开 | wing | back | 背后一对宽翼（静态，首版不扇动） |
| 凶翼 `yao.wing.fierce` | 双翼收拢 | wing | back | 背后一对窄翼（与扶摇翼同通道互斥） |
| 尾冠 `yao.crown.tails` | 合并尾团 | tail | tail | 身后一团尾影，按 1/3/6 尾三个等级三张合并图 |

明确不做：毒牙、兽牙、水息肺、毒腺、再生组织、各类灵窍——内部与口腔部件只在详情界面显示；巨口在真身上由原版资产本身表达。

### 步骤 4：着色类

鳞甲、皮毛、羽毛属于"质感变化"，用整块新贴图性价比低，走淡染路线：

| 器官 | 方案 |
| --- | --- |
| 基础鳞片 `yao.scale.basic` | 半透明鳞纹图层，势力色淡染（`KingdomColor`） |
| 蛟鳞 `yao.scale.jiaolong` | 同一张鳞纹，冷色系淡染，等级越高透明度越低 |
| 细鳞甲 `yao.scale.fine` | 同上，与基础鳞片同通道按等级胜出 |
| 火羽 `yao.feather.fire` | 羽纹图层，暖色淡染 |
| 月华皮毛 `yao.fur.moonlight` | 冷白淡染，带轻微提亮 |
| 幻梦灵瞳 `yao.eye.illusion` | 眼部小光点，`Glow` 提亮 |

鳞纹、羽纹各做一张通配淡染底图，全物种复用；不同的只是着色策略与透明度。着色类不占用"轮廓部件"的通道名额之外的新通道，同样受三层上限约束。

淡染图层的绘制方式是**按主体轮廓遮罩**：运行时把淡染纹理平铺进主体精灵的矩形，逐像素与主体透明度相乘，只保留身体范围内的部分，再按图层着色策略（势力色或固定色）上色。合成结果按"图层 × 主体帧 × 颜色"缓存，同一动画帧只合成一次；主体图集不可读时记录失败并跳过该图层，不逐帧重试。合成体与主体共用枢轴和像素密度，零偏移、同缩放绘制，保证与身体逐像素对齐。

### 步骤 5：资源与验证

资源统一放在 `GameResources/actors/species/other/Yao/Organs/` 下，用 pixel-text 流程制作基础四件（龟甲、角、双翼、尾团）加两张淡染底图（鳞纹、羽纹），风格与原版动物像素密度对齐。

验证清单：

- 启灵前后对比：凡兽无图层，启灵后先天器官图层出现。
- 同通道胜负：装雷角的兽换装辨邪角后只显示一个角。
- 三层上限：背甲 + 双翼 + 尾团同装时，按等级与通道顺序保留三个。
- 翻转与缩放：单位左右朝向切换时图层镜像；体型属性变化时图层同步缩放。
- 不可见、死亡、下水、化形切形态时图层正确消失或跟随。

### 边界说明：与显化三态的关系

第 6 阶段文档定义的保留/显化/休眠三态尚未实现（当前人形只有"标签兼容保留/丢弃"两态）。本阶段的世界图层全部作用于**真身**；人形上的显化图层（人形头顶显角、身后显尾）依赖三态规则落地后再接，不在本阶段范围内。
