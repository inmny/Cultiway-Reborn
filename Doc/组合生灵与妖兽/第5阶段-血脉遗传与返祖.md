# 第5阶段-血脉遗传与返祖

本阶段实现妖兽繁衍、冻结基因传递、显性/隐性器官等位、血脉纯度、后天器官固化和有限返祖。目标是让后代有谱系差异，但不出现祖先属性递归叠加或混血能力无上限增长。

## 具体说明

### 步骤 1：血脉与基因

#### 静态血脉

`YaoBloodlineAsset` 是内容定义，不为每个始祖动态创建 Asset：

```text
Id
ThemeSemantics[]
AllowedBodyPlanIds[]
InnateOrganIds[]
HiddenAllelePool[]
MorphRoutes[]
CorePatternIds[]
TribulationAffinity
AtavismRules[]
```

首批只注册三条血脉：

| 血脉 | 允许路线 | 特色 |
| --- | --- | --- |
| 蛟龙 | 蛇形、蛟形、龙形 | 水息、鳞甲、雷角和行云 |
| 月狐 | 狐形 | 幻梦灵瞳、尾冠和狐火 |
| 金乌 | 鸟形 | 真火灵窍、火羽和高温适应 |

血脉专属能力通过静态器官、Morph 和生命周期规则表达，不从始祖当前属性快照复制。

#### 有界基因

```text
YaoGenome
  Version
  PrimaryBloodlineId
  PrimaryPurity
  HiddenBloodlineId
  HiddenPurity
  Loci[8]
  GenomeGeneration
  Seed
```

```text
YaoGeneLocus
  DominantOrganId
  RecessiveOrganId
  DominantWeight
  RecessiveWeight
  Locked
```

八个位点与妖兽八槽对应，但位点是遗传槽，不等于当前表达槽。一个位点最多两个等位；没有等位时为空。所有纯度和权重归一到明确上限，总合不能超过血脉和身体预算。

禁止：

- 保存任意祖先列表并在每次属性计算时回溯。
- 把父母的境界、妖丹强度、装备、临时 Status 或当前总属性写入后代。
- 每次混血都创建新的动态血脉 ID。
- 让显性和隐性两个等位同时无条件表达完整强度。

### 步骤 2：繁衍快照

双亲遗传不能使用 `ActorExtend.RegisterActionOnNewCreature`：现有回调在 `ActorManager.createBabyActorFromData` 返回时触发，早于原版 `BabyMaker.makeBaby` 设置父母、家庭、出生 Trait 和遗传。扩展现有 `PatchBabyMaker.makeBaby_postfix(Actor __result, Actor pParent1, Actor pParent2)`，在 `__result` 有效时调用 `YaoInheritanceService.ResolveBirth(__result, pParent1, pParent2)`。

`ResolveBirth` 立即深拷贝双方当前状态，建立仅在本次同步调用中使用的不可变 `YaoBirthPayload`：

```text
Parent1Genome
Parent2Genome
Parent1BodyPlanId
Parent2BodyPlanId
ParentBloodlineSeeds
BirthSeed
```

WorldBox 当前没有妖兽孕期，本 Payload 不进入 ECS 和存档。它只防止遗传计算过程中读取可变父母数组；后代完成初始化后只保存自己的结果。

出生解析时：

1. 由稳定种子选择一个身体方案和允许形态。
2. 每个位点从双亲显性/隐性等位中按规则抽取最多两个等位。
3. 应用小概率、有限的空位变异或等位降阶。
4. 合并主/隐性血脉并归一纯度。
5. 依据双亲境界、血脉纯度和出生资源选择 `LatentBeast` 或 `AwakenedOffspring`，但绝不继承父母境界。
6. `LatentBeast` 只保存 `YaoGenome` 与谱系摘要，继续作为凡兽进入阶段 2 启灵候选；启灵前不表达妖兽器官和能力。
7. `AwakenedOffspring` 从启灵 0 级开始，只把兼容先天器官写入新 `YaoBodyState` 真身计划并通过 `YaoFormPlanService` 表达。
8. 其他等位留在 `YaoGenome`，等待启灵或突破表达。

`YaoPersistence` 必须同时保存已有 `Yao` 的妖兽和仅有 `YaoGenome` 的潜伏凡兽，否则隐性血脉会在读档时消失。后代不继承父母的器官消化队列、领地、行为目标、妖丹裂痕和天劫状态。

### 步骤 3：表达规则

#### 显性优先

每个槽位由以下顺序决定当前表达：

1. BodyPlan/Morph 的硬兼容性。
2. 当前境界和血脉允许性。
3. 显性等位的权重。
4. 隐性等位的返祖潜力。
5. 当前身体复杂度和稳定度。

同一槽位只有一个器官结果写入 `YaoBodyState` 的对应 Form 计划，再派生当前 `CreaturePhenotype`。不同位点的协同通过静态 `SynergyRule` 给出小幅加成，不能把两个器官分别乘出无限倍率。

#### 血脉纯度

纯度影响：

- 血脉专属器官的最低表达等级。
- 专属 Morph 路线的解锁门槛。
- 核心模式和天劫亲和。
- 返祖概率的上限。

纯度不直接乘到全部属性。低纯度可以拥有稀有隐性等位，高纯度也可能因身体不兼容而不能表达完整形态。

#### 后天与先天

`YaoOrganProvenance` 明确区分：

```text
Innate
Inherited
BloodlineExpressed
Digested
Solidified
Somatic
Atavistic
```

- `Digested` 和 `Somatic` 默认不进入基因。
- `Solidified` 只能由大境界突破规则产生。
- `BloodlineExpressed` 是基因表达结果，不是新的独立器官副本。
- 详情页始终同时显示当前表达和遗传潜力，避免把隐性等位误认为已经生效。

### 步骤 4：固化

妖兽完成一个大境界成功提交后，可以触发一次 `YaoGenomeSolidification`：

条件：

- 当前没有未完成排异或裂丹。
- 后天器官已经稳定使用一段世界时间。
- 身体稳定度、境界和固血资源达标。
- 目标器官有合法遗传位点和至少一条可表达路线。

结果：

- 最多选择一个 `Digested` 器官写入显性或隐性等位。
- 旧等位被替换或降为隐性，不能无限追加。
- `GenomeGeneration` 增加一。
- 当前个体的器官不被重建，只有后代和未来返祖读取新基因。
- 记录固血原因、代价和失败抑制时间。

固化不是把器官强度快照存入基因，而是保存静态 `OrganId + Rank` 和有限权重。

### 步骤 5：返祖

返祖只在三个正式节点判定一次：

- 出生表达。
- 凡兽启灵。
- 妖修大境界成功提交。

`YaoAtavismResolver` 读取隐性等位、血脉纯度、当前身体和真实语义经历，最多选择一个返祖结果：

1. 替换一个当前器官。
2. 切换到一个兼容的固定 Morph 路线。
3. 激活一个低阶血脉器官。

返祖失败时保留当前形态并进入冷却，不在同一节点重复抽取。返祖成功必须通过 `YaoFormPlanService` 原子更新 `YaoBodyState` 中所有受影响 Form，再由共享 `ValidatePlan` 和 `CreatureExpressionService` 表达活动 Form，旧来源按 Revision 对账。

例：

- 蛇兽携带隐性蛟龙鳞甲，在妖躯突破时替换普通表被，仍保持蛇形。
- 达到血脉和妖丹门槛后，才允许切换蛟形 Morph。
- 没有凤凰血脉的火属性器官不能直接返祖为涅槃心。

### 步骤 6：谱系与平衡

谱系只保留有界展示信息：

```text
ParentIds[2]
GenomeGeneration
PrimaryBloodline
VisibleAtavismCount
LastSolidificationReason
```

不为每个后代建立永久世界级谱系实体。父母 ID 使用原版 ActorData 已有关系，领域只保存当前需要的稳定摘要。

生态约束：

- 妖兽繁衍需要真实配偶、栖息地和资源条件，不能通过血脉系统无中生有。
- 同一血脉的高纯度个体设置种群承载和出生冷却，避免稀有路线指数增长。
- 后代的初始器官复杂度必须小于或等于双亲冻结计划的有界预算。
- 血脉优势必须伴随资源、天劫、繁殖或兼容代价。

### 步骤 7：验收

建立两代蛟龙路线：

1. 父代蛇兽拥有显性水息肺和隐性蛟龙鳞甲。
2. 母代拥有毒腺和低纯度蛟龙血脉。
3. `PatchBabyMaker` Postfix 深拷贝双亲状态后，父母继续进阶不会改变已生成的幼兽；不使用过早的 NewCreature 回调。
4. 子代可能继承一个显性器官和一个隐性等位，但总复杂度不超预算。
5. 子代启灵或妖躯突破时最多发生一次返祖，且实际替换器官/形态。
6. 后天吞噬的器官不会自动出现在子代；大境界固血后才有一项可能遗传。
7. 两代血脉纯度和强度不会因祖先回溯而递归膨胀。
8. 保存并加载子代基因、谱系摘要和返祖冷却后，结果保持确定性；同步出生 Payload 不进入存档。
9. 删除父母或清理世界不会留下独立血脉 Asset、出生 Payload 或关系实体。
