# 第5阶段-血脉遗传与返祖

本阶段让玩家看到妖兽真正形成家系：同一对父母的后代可能表现出不同器官，也可能只是普通凡兽，却暗中携带蛟龙、月狐或金乌血脉。潜伏血脉会在启灵或大境界突破时尝试返祖，但一次最多改变一个器官或一条固定形态路线。

遗传只传递有上限的血脉和器官等位，不会把父母的境界、妖丹、装备和全部属性复制给孩子，也不会沿着无限祖先名单反复叠加力量。

## 具体说明

### 步骤 1：血脉与基因

#### 玩家会看到什么

详情页会显示一条主血脉、一条隐性血脉、血脉纯度，以及八个身体位点中可能遗传的显性和隐性器官。血脉名称代表一条预先设计好的成长路线，不代表自动获得整套能力。

例如，携带蛟龙血脉的蛇兽可能先表现水息和鳞甲，达到足够境界、妖丹和纯度后，才有机会变成蛟形或龙形。

#### 静态血脉定义

每条血脉由静态定义 `YaoBloodlineAsset` 保存：

```text
Id
ThemeSemantics[]
AllowedBodyPlanIds[]
InnateOrganIds[]
HiddenAllelePool[]
MorphRoutes[]
CorePatternIds[]
TribulationAffinity
AtavismRules[]
```

首批只登记三条血脉：

| 血脉 | 允许的成长路线 | 玩家能看到的特色 |
| --- | --- | --- |
| 蛟龙 | 蛇形、蛟形、龙形 | 水息、鳞甲、雷角和行云 |
| 月狐 | 狐形 | 幻梦灵瞳、尾冠和狐火 |
| 金乌 | 鸟形 | 真火灵窍、火羽和高温适应 |

血脉专属能力由静态器官、固定形态和生命过程规则组成，程序对应 `CreatureOrganAsset`、`CreatureMorphAsset` 等定义。不能读取某位始祖当前的属性，再把那份完整记录复制给后代；也不能为每个始祖或每次混血动态创建新血脉定义。

#### 有上限的基因

每只携带血脉的动物使用 `YaoGenome`：

```text
YaoGenome
  Version
  PrimaryBloodlineId
  PrimaryPurity
  HiddenBloodlineId
  HiddenPurity
  Loci[8]
  GenomeGeneration
  Seed
```

每个位点保存：

```text
YaoGeneLocus
  DominantOrganId
  RecessiveOrganId
  DominantWeight
  RecessiveWeight
  Locked
```

八个位点对应妖兽的八类身体槽，但遗传位点不等于当前已经长出的器官槽。`YaoGenome` 只适用于妖兽八槽基线；超过八槽的身体方案不得登记遗传位点。每个位点最多保存一个显性和一个隐性等位；没有内容时为空。纯度和权重必须归一到明确上限，总和不能超过血脉与身体预算。

禁止以下做法：

- 保存任意长度的祖先列表，并在每次计算属性时回头扫描。
- 把父母境界、妖丹强度、装备、临时状态效果（`Status`）或当前总属性写给孩子。
- 每次混血都创建新的动态血脉编号。
- 让同一位点的显性和隐性等位同时无条件发挥完整效果。

### 步骤 2：出生时固定遗传结果

#### 玩家会看到什么

妖兽繁衍后，孩子会立刻得到一份固定的遗传结果。父母在孩子出生后继续突破、换器官或死亡，都不会回头改写这个孩子。

孩子有两种出生结果：

- 潜伏凡兽：外表和能力仍是普通动物，只携带血脉，等待以后启灵。
- 启灵后代：从启灵 0 级开始，可以表达少量兼容的先天器官，但绝不继承父母境界。

#### 必须使用正确的出生回调

双亲遗传不能使用 `ActorExtend.RegisterActionOnNewCreature`。这个回调发生在 `ActorManager.createBabyActorFromData` 返回时，时间太早；此时原版 `BabyMaker.makeBaby` 还没有完成父母、家庭、出生特性（`Trait`）和原版遗传设置。

程序必须扩展现有回调：

```text
PatchBabyMaker.makeBaby_postfix(
  Actor __result,
  Actor pParent1,
  Actor pParent2)
```

当 `__result` 有效时，调用：

```text
YaoInheritanceService.ResolveBirth(__result, pParent1, pParent2)
```

#### 出生时的临时资料

`ResolveBirth` 立即深拷贝双亲当前状态，形成只在本次同步调用中使用的 `YaoBirthPayload`：

```text
Parent1Genome
Parent2Genome
Parent1BodyPlanId
Parent2BodyPlanId
ParentBloodlineSeeds
BirthSeed
```

`YaoBirthPayload` 只是出生计算用的临时资料，不进入实体组件，也不进入存档。WorldBox 当前没有妖兽孕期，因此无需长期保存它。后代初始化结束后，只保存自己的结果。

#### 出生规则

1. 根据稳定种子选择一个身体结构和允许的固定形态。
2. 每个位点从双亲显性、隐性等位中抽取最多两个等位。
3. 允许小概率出现空位变化或等位降级，但变化有固定上限。
4. 合并主血脉和隐性血脉，并重新归一纯度。
5. 根据双亲境界、血脉纯度和出生资源，选择潜伏凡兽（`LatentBeast`）或启灵后代（`AwakenedOffspring`）。
6. 潜伏凡兽只保存 `YaoGenome`；有限谱系摘要也放在其中。它继续按阶段 2 的普通凡兽规则等待启灵，启灵前不表达妖兽器官和能力。
7. 启灵后代从启灵 0 级开始，把原物种、启灵时间、种子、境界和初始妖力写入 `Yao`，再把兼容的先天器官写入新的 `YaoBody` 真身 `Organs`，并由 `YaoFormPlanService` 表达。
8. 没有表达的等位继续留在 `YaoGenome`，等待以后启灵或突破。

存档服务 `YaoPersistence` 必须同时保存已有 `Yao` 的妖兽，以及只有 `YaoGenome` 的潜伏凡兽，否则隐性血脉会在读档时消失。

后代完成初始化后发布 `YaoBirthResolvedEvent`，事件只携带孩子、双亲、出生结果和主次血脉编号。启灵后代先建立自己的 `Yao` 和 `YaoBody`，确实带有血脉时再建立 `YaoGenome`；它不继承父母的 `YaoDigestion` 或 `YaoCore`。

后代不继承父母的消化队列、领地、当前工作目标、妖丹裂痕和天劫过程 `YaoTribulation`。

### 步骤 3：表达规则

#### 玩家会看到什么

界面必须区分“已经长出的器官”和“可能遗传或返祖的器官”。隐性等位只代表潜力，不能提前提供属性、能力或外观。

#### 一个槽位只能表达一个结果

选择当前器官时，按以下顺序检查：

1. 当前身体结构和固定形态是否允许，程序对应 `CreatureBodyPlanAsset` 与 `CreatureMorphAsset`。
2. 当前境界和血脉是否允许表达。
3. 显性等位的权重。
4. 隐性等位的返祖潜力。
5. 当前身体复杂度与稳定度是否足够。

同一槽位最终只能得到一个器官。不同位点之间可以通过静态协同规则 `SynergyRule` 获得有限加成，但不能让两个器官互相相乘，形成无限增长。

`YaoBody` 是永久身体方案的唯一来源，`YaoFormPlanService` 是唯一改写入口。遗传表达、返祖和形态变化都必须先写入 `YaoBody` 中受影响形态的 `Organs`，再派生当前 `CreaturePhenotype`；任何系统都不能反过来直接修改派生结果。

#### 血脉纯度

纯度只影响以下内容：

- 血脉专属器官可以表达到的最低等级。
- 专属固定形态路线的解锁门槛。
- 妖丹方向和天劫应对优势。
- 返祖概率的最高值。

纯度不能直接乘到全部属性。低纯度个体仍可能携带稀有隐性等位；高纯度个体也可能因为身体不兼容，而无法表达完整形态。

#### 器官资料自带来源

每个形态的 `Organs` 都直接保存器官位置、编号、等级和来源：

```text
YaoBody
  Forms[]
    Organs[]
      SlotId
      OrganId
      Rank
      Origin
```

`Origin` 使用以下程序值：

```text
Innate
Inherited
BloodlineExpressed
Digested
Solidified
Atavistic
```

对应含义是先天、直接遗传、血脉表达、吞噬所得、固血完成和返祖所得。

规则：

- 吞噬所得（`Digested`）默认不进入基因。
- 短时身体适应不属于永久器官资料，使用现有持续状态表达，不写入 `YaoBody` 或 `YaoGenome`。
- 固血完成（`Solidified`）只能由大境界突破规则产生。
- 血脉表达（`BloodlineExpressed`）是现有基因的表达结果，不是又创建一份器官。
- 详情页始终同时显示当前表达和遗传潜力，不能让玩家把隐性等位误认为已经生效。

### 步骤 4：固化

#### 玩家会看到什么

妖兽完成大境界突破后，可能把一个长期稳定使用的后天器官“炼入血脉”。从此它的后代和未来返祖有机会得到这个器官。每次大境界最多固化一个，不能把所有吞噬所得器官一次性塞进基因。

程序入口为 `YaoGenomeSolidification`。

固血条件：

- 当前没有未结束的排异或裂丹。
- 后天器官已经稳定使用足够长的世界时间。
- 身体稳定度、境界和固血资源达到门槛。
- 目标器官有合法遗传位点，并且至少有一条可以实际表达的身体路线。

成功结果：

- 最多选择一个吞噬所得器官（`Digested`），写入显性或隐性等位。
- 旧等位只能被替换或降为隐性，不能无限追加。
- 基因代数 `GenomeGeneration` 增加一。
- 当前个体已经长出的器官不重新构建；新基因只供后代和未来返祖读取。
- 在 `YaoGenome` 中记录固血原因、代价和失败抑制时间。

固血保存的是静态器官编号、等级和有限权重，程序对应 `OrganId + Rank`，不是把当前器官强度和全部属性原样复制下来。

### 步骤 5：返祖

#### 玩家会看到什么

返祖只会在关键成长时刻发生，不会每帧反复抽取。成功时，妖兽会明确替换一个器官、显现一个低阶血脉器官，或进入一条预制的固定形态路线；失败则保持原样并进入冷却。

返祖只在以下三个节点各判定一次：

- 出生表达。
- 凡兽启灵。
- 妖修大境界成功提交。

返祖判定器 `YaoAtavismResolver` 读取隐性等位、血脉纯度、当前身体和真实经历，最多选中一种结果：

1. 替换一个当前器官。
2. 切换到一条兼容的固定形态路线，程序对应 `CreatureMorphAsset`。
3. 激活一个低阶血脉器官。

返祖失败时保留当前形态，并进入冷却；同一个节点不能重新抽取。返祖成功时，由 `YaoFormPlanService` 按既定槽位和形态规则生成新方案，把带有来源的新器官资料写入 `YaoBody` 中所有受影响的形态；如果改变了当前形态，再由 `CreatureExpressionService` 让新身体生效。

返祖完成事件 `YaoAtavismCompletedEvent` 只说明妖兽编号、触发节点、改变的形态、槽位、器官或固定形态。永久结果仍然只读取 `YaoBody` 和 `YaoGenome`。

例子：

- 蛇兽携带隐性蛟龙鳞甲，在妖躯突破时用鳞甲替换普通表被，但仍保持蛇形。
- 只有血脉纯度和妖丹都达到门槛后，才允许进入蛟形。
- 没有凤凰血脉的火属性器官，不能直接返祖成涅槃心。

### 步骤 6：谱系与平衡

#### 玩家会看到什么

谱系页只展示父母、代数、主血脉、可见返祖次数和最近一次固血原因，不绘制无限家谱。

`YaoGenome` 内保存的谱系摘要：

```text
ParentIds[2]
GenomeGeneration
PrimaryBloodline
VisibleAtavismCount
LastSolidificationReason
```

父母编号使用原版单位数据（`ActorData`）已有关系。`YaoGenome` 只保存当前需要的有限摘要，不为每个后代增加谱系组件或永久世界级谱系实体。

繁殖与环境规则：

- 妖兽繁衍需要真实配偶、合适栖息地和足够资源，不能由血脉系统凭空生成后代。
- 同一高纯度血脉受到种群承载量和出生冷却限制，避免稀有血脉指数增长。
- 后代初始器官的复杂度，不能超过双亲在出生时提供的身体承载预算。
- 血脉优势必须带有资源、天劫、繁殖或身体兼容方面的代价。

繁殖工作不读取独立生态组件。系统直接根据当前单位、`Yao`、`YaoBody`、妖力、血脉、附近配偶、栖息地和资源决定是否繁殖。
