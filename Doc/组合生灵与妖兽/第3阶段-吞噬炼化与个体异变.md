# 第3阶段-吞噬炼化与个体异变

本阶段让妖兽通过真实捕食和尸体精华获得有限语义样本，经过消化、候选选择、炼化和排异后替换器官。吞噬不复制目标单位，而是把交互压缩成可解释、可平衡的静态能力切片。

## 具体说明

### 步骤 1：精华与样本

#### 一次性精华令牌

真实生物死亡后不直接把全部能力交给妖兽。只有在妖兽实际到达并执行吞噬行为时，领域适配器才尝试领取一次精华：

```text
YaoEssenceClaim
  SourceActorId
  SourceDeathSequence
  ClaimedByActorId
  ClaimedAt
  SemanticFragments[]
```

`SourceActorId + SourceDeathSequence` 是幂等键。死亡重复事件、尸体对象重复扫描、直接删除和世界清理都不能产生第二份精华。

如果原版尸体对象没有稳定可用的长期句柄，使用死亡事实生成短命 `YaoEssenceDeposit` ECS 实体，并保存到期时间和位置。工序完成或过期后回收，不依赖尸体 GameObject 是否仍存在。

#### 白名单语义

`YaoEssenceProfileAsset` 由内容作者显式注册：

```text
ProfileId
SourceSemantics[]
ExtractedFragmentId
StrengthRange
AllowedCategories
ForbiddenBloodlines[]
```

首批碎片：

| 碎片 | 来源事实 | 可提出的方向 |
| --- | --- | --- |
| 水生呼吸 | 实际水生/水下生存语义 | 水息肺、两栖囊 |
| 毒性腺体 | 实际毒素攻击或毒素状态 | 毒腺升级、滤毒表皮 |
| 火焰亲和 | 实际火元素交互 | 火心、火羽表被 |
| 硬质表被 | 实际高护甲或硬壳语义 | 鳞甲、甲壳 |
| 愈合组织 | 实际再生语义或长时间伤后恢复 | 低阶再生组织 |
| 飞行附肢 | 实际飞行交互 | 翼化候选，只能解锁固定翼形态 |

样本提取读取已注册的 `SemanticProfile` 和有限的领域映射，不复制目标的 Trait、Skill、ActorAsset、ECS 组件、装备或全部属性。

### 步骤 2：消化

`YaoDigestion` 为 Actor 组件，最多三个条目：

```text
Queue[3]
  FragmentId
  SourceActorId
  Strength
  StartedAt
  CompleteAt
  Cost
  State
```

状态：`Queued`、`Digesting`、`Ready`、`Resolved`、`Rejected`。

规则：

- 只有妖兽自己的 `YaoDevourJob` 可以修改队列。
- 进食成功后先锁定样本，再支付空间和最低妖力成本。
- 妖兽死亡、世界清理或目标过期时按明确规则释放或损失条目。
- 消化时间使用世界模拟时间；暂停不推进。
- 同时只能处理一个主动消化条目，其他条目等待。
- 队列满时不能继续领取新的精华，避免无限堆积。

消化结算三选一：

1. `PowerGain`：转化为有限妖力或进阶经验。
2. `SomaticShift`：获得一次短时、不可遗传的体感适应。
3. `OrganCandidate`：生成一个静态器官候选。

选择由妖兽当前饥饿、妖力、主要威胁、身体容量和血脉倾向决定。首版 AI 不提供手动菜单；调试命令可以强制指定结果，但正式玩法不暴露。

### 步骤 3：候选

`YaoOrganCandidateService` 对静态器官目录评分。候选必须同时满足：

1. 语义样本与器官所需碎片匹配。
2. 目标槽位存在且容量足够。
3. 当前 Morph 和 BodyPlan 兼容。
4. 妖兽境界、身体稳定度和血脉限制满足。
5. 不与已表达器官冲突，或明确属于替换关系。
6. 预计代价不使妖兽立即进入必死状态。
7. 不在该 Actor 的失败抑制期内。

评分只读取：

```text
SampleStrength
BodyCompatibility
BloodlineAffinity
CurrentNeed
Synergy
ComplexityCost
StabilityCost
ReplacementCost
FailureMemoryPenalty
```

候选最多保留三个，并记录被淘汰原因。使用妖兽稳定种子和消化序号产生很小的确定性扰动，禁止每帧随机重选。

首批候选：

| 样本 | 器官 | 槽位 | 收益 | 代价 |
| --- | --- | --- | --- | --- |
| 水生呼吸 | 水息肺 | 代谢 | 水域生存、两栖寻路 | 陆地恢复下降 |
| 毒性腺体 | 强化毒腺 | 吐息腺 | 毒素强度和持续增加 | 妖力消耗提高 |
| 硬质表被 | 细鳞甲 | 表被 | 轻度减伤 | 速度下降 |
| 愈合组织 | 低阶再生 | 代谢 | 脱战恢复 | 持续妖力消耗 |

飞行碎片只能提出“翼化结构”候选，并要求一个可用的固定翼形态；本阶段不实现飞行形态。

### 步骤 4：炼化结算

炼化只能通过 `YaoFormPlanService` 修改 `YaoBodyState` 中的权威 Form 计划；当前 `CreaturePhenotype` 不能被反向编辑：

```text
读取活动 Form 权威计划
  -> 深拷贝候选计划
  -> 替换一个槽位或占用声明的多槽
  -> 共享 ValidatePlan / Compile
  -> 计算妖力、稳定度和排异结果
  -> 成功后原子写回 YaoBodyState 对应 Form
  -> 若它是活动 Form，再提交 CreatureExpressionService
```

只有真身 Form 默认接收吞噬器官；已经存在的人形或其他真身由静态转换规则同步其 `Retained/Manifested/Dormant` 映射，不能保留旧计划等待下次切换时回退。

成功结果：

- 更新 `YaoOrganProvenance` 为 `Digested`。
- 消耗样本和妖力。
- 增加短暂稳定期或代谢负担。
- 记录新表现型签名和来源。
- 发布 `YaoOrganDigestedEvent`。

失败结果：

| 失败等级 | 后果 |
| --- | --- |
| 轻微排异 | 样本损失、妖力下降、短时虚弱 |
| 严重排异 | 当前槽位器官暂时失效、生命受损、进入冷却 |
| 结构崩溃 | 旧器官保留但新候选销毁，身体稳定度下降 |
| 致命失败 | 仅在高阶或强行炼化时允许，实际死亡或永久损伤 |

失败不能自动改写血脉，也不能把一个失败候选加入永久能力。失败历史按器官 ID 和失败类型有界保存，并随时间衰减。

已夺取器官默认不遗传。只有妖修大境界突破的“固血”规则才能把至多一个兼容器官写入 `YaoGenome`，详见阶段 5。

### 步骤 5：行为表达

器官的效果必须在游戏中产生可观察结果：

- 水息肺改变水域可达性、溺水判定和目标选择，而不是只增加一个“水生”标签。
- 强化毒腺在真实攻击中通过共享主动能力 Provider 使用 SkillV3，并受妖力与冷却限制。
- 细鳞甲进入最终伤害适应入口，实际降低有限的物理伤害，同时影响移动。
- 低阶再生只在脱战周期通过领域系统申请恢复，不能每帧直接加血。

妖兽 Job 读取共享编译后的有限 `Affordance` 摘要：

```text
CanBreatheWater
CanUseVenom
CanRecoverOutOfCombat
PreferredTerrainTags
```

这些摘要由器官静态定义产生，不由 Job 反射读取任意类型。

### 步骤 6：验收

场景：一条已启灵的灵蛇在水域捕食鱼类。

1. 蛇必须实际到达并执行吞噬，远处尸体不能被隔空领取。
2. 同一鱼尸被两条妖兽争抢时，最多一条成功领取精华。
3. 水生语义产生水息肺候选，毒性语义不应平均转成所有类别。
4. 队列满时不产生额外精华；消化进度按世界时间推进。
5. 成功炼化水息肺后，蛇能在水域移动并改变溺水/寻路结果。
6. 失败排异产生真实资源和 Status 后果，不能悄悄回滚成免费尝试。
7. 替换器官后旧能力、属性、视觉和来源状态按 Revision 对账。
8. 吞噬不会复制鱼的名字、Trait、技能、武器、ActorAsset 或全部属性。
9. 妖兽死亡和清理世界后没有重复领取、悬挂队列或过期 Deposit。
