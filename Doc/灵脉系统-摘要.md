# 灵脉系统-摘要

## 一、定位

灵脉是由山川地势孕育、沿地形行气、在藏风聚水处结穴的动态地理资源。

它不是地下管线，不是新的地理地区层，也不是第二套灵气。角色仍然只从所在格子的天地灵气中修炼；龙脉决定灵气从哪里生发、如何向下游输送、在哪里聚集、带有什么元素倾向，以及局部过度消耗或污染后如何变化。

当前实现采用风水龙脉解释：

```text
祖山源域
→ 干龙与支龙形成宽广脉域
→ 过峡、汇流与入首划分局部脉节
→ 山环水抱处形成主穴和副穴
→ 结穴地内部显化一个自然灵眼
→ 余气由水口净化或散去
```

## 二、已经确认的设计

| 项目 | 当前规则 |
| --- | --- |
| 空间本体 | 宽窄不定、边缘自然消散的脉域，不是中心线 |
| 世界数量 | 普通地图通常有 3 至 6 条龙脉，随陆地面积平方根缓慢增长 |
| 地形关系 | 山起水收；祖山生气，峡谷束气，盆地与曲水聚气，开阔地泄气 |
| 资源模型 | 全世界仍只有洁净天地灵气和浊气两种逐格资源 |
| 运行单位 | 局部脉节分别保存储量、恢复、输送、通畅度和纯净度 |
| 结穴关系 | 每条龙脉有一处主穴和零至三处副穴，每处结穴地有一个灵眼 |
| 龙脉交汇 | 外缘可以重叠；强脉域罕见汇聚时形成交龙地，由两侧共同供养 |
| 元素 | 金、木、水、火、土、阴、阳、混沌倾向，只提供正向修炼加成 |
| 地图 | 独立水墨望气图直接显示，不做发现、迷雾或探查进度 |
| 普通世界 | 只有主穴和高阶副穴显示克制的自然征兆 |
| 地形变化 | 重大结构变化长期稳定后重新求解地势，并保留能够匹配的运行时身份 |
| 保存 | 不保存；进入世界时生成，离开世界时全部清除 |

## 三、运行时对象

### 3.1 龙脉 `SpiritVein`

龙脉是一个没有成员的 `MetaObject<SpiritVeinData>`，保存一整套山川灵脉的共同身份：

- 当前世界内稳定的元对象编号、布局编号和名称。
- 祖山源域与水口位置。
- 龙脉规模与总体元素。
- 全部支龙、脉节、结穴地和灵眼编号。
- 当前主穴编号。
- 收藏、自定义名称和原版选中状态。

它不登记、扫描或统计角色。龙脉对象只由当前世界的管理器维护，不进入存档和历史统计。龙脉本身也不保存一个覆盖全网的储量，避免整条龙脉同时充盈或同时枯竭。

规模分为：微型、小型、中型、大型、祖脉。

### 3.2 支龙 `SpiritVeinBranch`

支龙是汇入干龙的一片独立来气，拥有名称、规模、源域、汇流位置、元素和所属脉节。支龙规模分为微型、小型、中型和大型。

### 3.3 脉节 `SpiritVeinSection`

脉节是月度运行单位，分为：

- 祖山源域。
- 上游行龙。
- 过峡束气。
- 支龙汇流。
- 入首聚气。
- 结穴地。
- 水口。
- 余脉。

每个脉节独立保存容量、当前灵气、恢复、最大供灵、最大下行输送、通畅度、纯净度和上下游关系。

### 3.4 结穴地 `GatheringGround`

结穴地是一片连续灵地，不是一个点。它保存范围、明堂可建区域、聚气、藏风、泄气、品相和主客来龙。

品相分为：下品、中品、上品、极品、天成。

类型包括主穴、副穴、交龙地和移穴后留下的残穴。宗门评价的是整个明堂，而不是必须把建筑压在灵眼格上。

### 3.5 灵眼 `SpiritVeinEye`

每处结穴地有一个灵眼。灵眼不重复建立资源池，而是读取相连脉节的充盈和纯净度。

自然显化包括：灵泉、地窍、石髓、木华、风眼、火穴、阴潭、阳池和混沌地窍。显化只轻量调整现有容量、恢复、输出、净化或污染敏感度，不增加新资源。

灵眼浓度是动态状态：稀薄、凝聚、浓郁、成雾、化液。

## 四、逐格脉域

逐格数据直接描述当前位置的龙脉环境：

- 主要龙脉与主要脉节。
- 次要来气龙脉与次要脉节。
- 灵势强度与次要来气强度。
- 行气方向。
- 聚气、藏风和泄气程度。
- 所属结穴地。

没有“是否位于脉线上”，也不通过“到中心线的距离”计算影响。不同龙脉外缘重叠时保留主次两股来气；交龙地会由两个脉节实际供灵。

## 五、生成方法

1. 主线程分批复制当前地形、地貌地区和元素环境，不把游戏对象交给后台。
2. 后台选择彼此分散的祖山源域和合理水口。
3. 使用不可见引导骨架确定总体下行方向和支龙汇流关系。
4. 将多股引导贡献扩展成宽窄变化、边缘不规则的连续脉域。
5. 根据流向混合、山势环抱、水势、地面平缓和泄气程度计算逐格风水值。
6. 将龙脉划成具有上下游关系的局部脉节。
7. 在脉域内选择一处主穴和少量副穴，并识别罕见交龙地。
8. 为每处结穴地选择一个自然灵眼并计算轻量显化修正。
9. 安装前检查编号、归属、上下游关系、逐格数组、储量范围和一穴一眼约束。
10. 回到主线程命名并建立初始天地灵气。

不可见引导骨架只存在于一次后台生成过程中。安装后的查询、供灵、污染、宗门选址、悬停和绘制都不读取它。

## 六、月度运行

每月顺序固定为：

1. 各脉节按灵气潮汐、纯净度和脉节角色恢复。
2. 上游在自身储量、输送上限和通畅度内向下游输送。
3. 遍历已有脉域格，计算主要与次要脉节共同形成的动态目标。
4. 地块低于目标时，由两侧脉节在各自预算内补充，并扣除实际输出。
5. 各脉节从自己的代表格抽样浊气，局部降低纯净度或付费净化。
6. 污染只沿上下游关系逐月少量传播。
7. 结穴地与灵眼刷新当前充盈、纯净度和浓度。

因此可以出现上游壅积、下游衰弱、主穴被吸空而副穴仍活跃、支龙污染逐年汇入干龙等局部现象。

## 七、修炼与宗门

- 修士仍先扣地块天地灵气，角色不会直接从脉节领取资源。
- 当地元素与灵根相合时提供正向加成，最高 25%；不相合不会降低旧结果。
- 当前灵气、脉域强度、脉节长期供给、纯净度、结穴品相、明堂可建面积和泄气程度共同影响宗门选址。
- 灵眼可以位于水中或山壁，宗门只需在明堂内选择合适可建位置。
- 不加入灵脉所有权、占领、聚灵阵、护山大阵或宗门争夺。

## 八、名称与身份

正式命名的对象是龙脉、支龙、结穴地和灵眼：

```text
苍梧龙脉
听松支龙
落霞明堂
落霞灵泉
```

祖山、过峡和水口显示所在地貌描述，不强制生成另一套专名。名称由世界编号、对象编号、地区、元素和显化稳定生成。

短期储量、污染、纯净度和规模变化不改名。重大地势重流时，龙脉按祖山位置匹配旧身份，并复用原来的 `SpiritVein` 实例和元对象编号；收藏、自定义名称和选中引用不会因重算失效。结穴地在原址附近延续时保留名称，完成远距离移穴后新穴获得新名，仍有来气的旧主穴成为残穴并保留原名。

## 九、视觉

望气图不绘制路线、箭头、圆形节点或徽章：

- 地形先被轻微压暗，仍可辨认山川城市。
- 整片脉域使用半透明水墨晕染，边缘随逐格灵势自然消散。
- 多条短墨丝在脉域内部沿行气方向移动，远景自动隐藏细节。
- 结穴地使用范围化雾气与自然显化纹理，不使用统一图标。
- 污染使颜色变浑浊；壅塞使局部发暗；充盈程度控制灵丝数量和透明度。
- 悬停整片脉域即可查看，不要求鼠标碰到中心线。

普通地图只在主穴和上品以上副穴附近显示微弱薄雾、水纹、石隙辉光或热流。打开望气图后这些征兆自动隐藏。

## 十、明确不做

- 不保存龙脉、脉节、结穴地、灵眼、名称或灵气数据。
- 不增加 `GeoRegionLayer`。
- 不为龙脉登记角色成员或进行人口统计。
- 不为龙脉创建碰撞实体。
- 不拆分八张元素灵气地图。
- 不让普通生物群系变化频繁重流。
- 不增加独立详情窗口，首版只使用原版 Tooltip。
- 不保留旧路径模型、固定影响半径、线条渲染或灵眼徽章兼容层。
