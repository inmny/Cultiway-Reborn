# 后续阶段-植被与群系物件

## 目标

本阶段是建筑和单位三维化之后的独立扩展方向：将 Cultiway 自有的树木、花草和群系地表装饰以一致的像素低多边形风格扩展为 3D 模型，使 Worldfall 3D 世界中的修仙生态仍能辨认原有群系特色。

当前清单记录30类植被物件，基础显示接入已覆盖。2026-10-14 黑森林已离线实装：`Dark_tree` 的四种活树和四种枯树共24个模型，`Dark` 的六种花草外观共18个模型，游戏表现均待用户查看。[树木记录](黑森林树木实装-摘要.md)、[花草记录](黑森林花草实装-摘要.md)分别说明实际方法和限制。用户随后确认其余14群系、28类植被全部改用 Blender 自建；全部外观、残骸和三档的逐项进度见[群系自建总览](群系树木与花草自建-摘要.md)。植物修士属于单位阶段，不能和静态树木混计完成进度。沿用每个物体独立子代理、同时最多3个的约定。

其余28类现已全部离线发布，共867个模型；连同已保留的黑森林42个模型，30类植被共909个距离模型。全部本轮自建物件的实际导入、看图、接口与文件检查已通过，密集场景、坡面、碰撞和游戏实际状态切换仍待用户统一测试。

## 具体说明

### 步骤1

范围从 `Source/Content/Biomes.cs`、`Buildings.cs` 中登记的专属树/花草与 `GameResources/buildings/` 资源对应关系整理，不按目录猜资产用途。优先选差异明显的竹、烛火、墓园、珊瑚、血肉、知识、稻米和巨灵群系各一个代表。

### 步骤2

黑森林花草按用户的新要求，直接参照 Worldfall 静态花草结构用 Blender 制作：不另生成高清细节，按原图比例保留小芽、草簇、三头/四头红花及矮菌伞。近景52至340个三角面，远景24至160个三角面，保留主要花叶数。已实装黑森林树木保持原平台网格；其余树木和花草按每一幅原图重新设计实体。共用的只限小几何、导出与检查，不共用各群系的完整轮廓。

- 树木模型由树干、枝冠、叶簇/特殊冠形构成；花草由低矮植株和少量花/叶片构成。
- 用树冠色块与树干色块复现原贴图的主色，细节控制在远景可辨认的程度。
- 透明叶片、发光植物和水下珊瑚需先确认 Worldfall 的材质能力；不支持时使用实体色块或保留 2D 原图。

### 步骤3

已经接入原生树木/花草绘制入口：根据原图外观编号和残骸状态选择正式三档模型，沿用原生朝向、随机尺度、距离、选择与交互。风动只允许原注册中会摇摆的活树，烛火只动明确火焰部件。没有另写碰撞和采集逻辑；原有能力实际表现继续在步骤4检查。

### 步骤4

在竹林、树冠密集地和珊瑚群系分别进行近景与远景检查，确认树影/碰撞没有明显穿地，批量模型不会造成突出的卡顿或内存增长。
