制作过程为各自原贴图 → 内置 imagegen 单物体风格参考 → 本地 Trellis 真正生成带贴图 GLB → 每个物体的独立 Blender 子代理重建干净的闭合低面纯色几何。每批最多三个子代理；显卡生成串行，所有 Blender 渲染使用 CPU。子代理服务容量中断后从保存进度继续；王座的已准备重开脚本由主代理执行。

原始 Trellis 网格、UV、PNG 和生成回执都保留。本轮低面几何以它们和原图为形体依据，不宣称直接沿用源网格的全部 UV 或纹理原色。源面数分别为 145640、149646、136640；原始模型保存在各可编辑文件的隐藏参考集合。

候选保留模型名字、原部件顺序、父部件、动作轴、槽名前缀与 Flags。熔炉将旧通用石塔槽的缺省色改为器官、骨、根的艺术色，并记录类别与颜色映射；王座和祭坛保留旧槽缺省色后追加艺术色。三者的固定配色均明确写 `kingdom_slots: none`，不把红脸、紫眼误作国家色。

已完成实际 Blender 导出和四视角查看；近中远及废墟为完整候选。保存后独立重开，实际重导的候选与之前一致；GLB/FBX 均只包含近景几何。主代理另检查三份文件的名字、槽前缀、Flags、轴、法线、三角面、占地边界和交付文件，三个候选均通过。动作轴比较采用 1e-7 容差，适应 Blender 单精度存储；没有移动实际轴。

游戏验收保持 `pending`。施工、废墟状态切换和实际 Worldfall 显示仍按用户安排，留到全部模型完成后统一测试。这些预览不计为全量模型已经完成，也不计为游戏验收通过。
