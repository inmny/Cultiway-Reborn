# 第0阶段：Worldfall 接入与制作规范

## 最新制作约定（2026-10-19）

当前按用户安排先完成模型，再统一测试游戏。新增文明与群系建筑使用原图约束的Blender自建，不调用图片或三维生成平台；每物体一个独立代理、最多三个同时工作，同物体纠正交回原代理。主要特点、开口、体量、前后关系和真实占地优先，不用像素逐格拉厚或正面板替代立体结构。

39类东人与诡族文明建筑已完成1395个状态与距离模型，另13类群系建筑已完成138个模型的离线发布，七类已有特殊建筑保持原版本。当前59类注册非植被建筑都有运行资源，游戏效果仍逐版本验收。实际结果见[文明建筑](东人与诡族文明建筑-摘要.md)与[剩余群系建筑](剩余群系建筑-摘要.md)。下方2026-10-12的数量与暂停状态均为历史，不代表当前制作总数；原版依赖和游戏证据只对应其记录的版本。

当前材质补充：木构3、真实砌砖4、瓦顶5和金属10可沿用原生纹理；树皮2、真叶1、自然整石14与普通纯色0分别使用。肉体、骨骼、晶体、蜡体及整块灵体表面不能误用砖石4。国家色分区独立声明，东人木构仅瓦顶随国家变，诡族及本批群系专属建筑固定原色。保留原部件、父子、转轴与颜色槽前缀，总槽数最多64；正背绕序和单位法线随最终GLB独立重导入核对。

### 地下坑腔的显示

斯卡文疫巢按用户确认改为地面深坑：模型地面为Z=0，内壁和封闭坑底进入负Z，上方开放，不能抬高整座模型冒充凹坑。完好、废墟及三距离档共用`cultiway_ground_pit=1`、`pit_cut_inner`、`pit_cut_radius`和`pit_floor`；半径及坑底使用模型尺寸，实际数值以当前生产文件为准。

普通地表会盖住负Z部分。因此`WorldfallGroundPits.cs`在场景收集后读取实际绘制网格的位置和缩放，在原生`GpuTerrain.Pack`完成后、显卡上传前，只压低坑口内的两项显示高度。原生`TerrainCache`的高度数组、建筑落点、地图、存档、颜色、材质和标记保持原值；坑口出现、移除或换位置时重新上传旧新范围，移除后恢复表面。关闭三维显示或不接入Worldfall时不启用这一显示处理。原有碰撞和寻路仍由原地图负责，不能把显示深坑当作可走入的地下空间。

坑缘须覆盖实际格点插值后的下降坡面，不能只比较连续半径。离线核对使用实际程序集的打包方法，再顺序执行本次后置函数，检查六档、原始数组未变、坑外和颜色标记未变、移除恢复、边界及换世界。实际上传数据另在Blender中重建双线性表面，与最终GLB一起检查遮挡。这是离线数据和几何证据，不证明游戏着色器、地形远景或补丁安装已经验收；结果见[地表核对](../../Art/Worldfall/remaining-buildings-v1/ground-pit-check.json)，游戏状态保持待用户实测。

## 历史结论（2026-10-12）

用户纠正：诡族建筑是中式，浅绿斜盖基础住宅是打开的棺材。两份错误的有机造型生产资源已撤销，当前制作数以清单为准；旧状态、调色和选择结果只作旧网格运行记录，新棺材与中式建筑须重做再验收，详见 造型纠正（历史文件已清理）。大殿、东人及其他已核对物体的有效结果保留。

基础接入、可选依赖回退和固定测试场地已经实际验证。覆盖228个注册资产：135类非船单位、4类船只、59类建筑、30类植被。15:37清单核对有效文件发布33项，全部符合64槽限制；文件发布不等于游戏验收完成。棺材、熊猫、东人一级住宅、中式基础政厅和东人基础草屋已有本版游戏证据；瞭望塔木构提色版功能复测通过，正面仍暗，最终外观未通过。两栋诡住宅和东人二级住宅已完成最新离线适配，烛灵已发布，后续游戏待测。旧有机诡建筑不计当前有效发布或外观通过。实时数量见 [模型清单](Blender模型清单.json)，实测与限制见 复测记录（历史文件已清理），不将接入覆盖写成全量建模完成。

用户最新安排是先完成全部模型建模，再统一游戏测试。当前只继续原图、高清参考、真实Trellis、Blender三档和状态、离线姿态与一次独立重开检查；新模型的游戏状态保持待测。双足人物参考原版人类动作关系，按各自真实肩髋和原骨架适配，四足与悬浮单位保持自身结构。10452实例已恢复原世界44个单位、设置并移除全部临时补丁后关闭，后续制作不再逐批启动游戏。

15:58用户暂停后的最新清单为34项离线发布，38项参考图资产、38项真实Trellis资产，全部有效发布仍符合64槽限制。吸血鬼已发布；狼人、橡树人和知识灵保留当前检查点，基础草顶政厅原网格已生成待适配。没有把新模型写成游戏通过，恢复顺序见 暂停交接（历史文件已清理）。

用户最新要求优先群系与文明单位、建筑，全量范围保留；逐项顺序见 [优先顺序](群系与文明优先顺序.md)。诡族建筑保持中式结构与浅绿灵体配色，原图确有的冰蓝窗口和点缀固定；无紫色国家模板的主体、木梁和瓦顶不改成国家色或棕色。基础住宅是空的打开棺材。

用户要求的后续制作流程已改为 **imagegen 单物体图 → Trellis 带贴图网格 → 本物体独立 Blender 子代理适配 → 游戏验收**。同时最多 3 个子代理，显卡推理排队。原始 GLB 与贴图保留，生成文件、候选模型、实际生产资源分别记录。

## 固定约定

- X 横向、Y 深度、Z 向上，正面和建筑入口朝 -Y。单位脚底为 Z=0；灵体的悬浮间距明确记录。
- 建筑台基宽为 1，深为实际占地深宽比；运行时按占地宽度缩放，并修正偶数占地的中心偏移。大殿是 15×7。
- 保留材质槽原有前缀、动作部件、父子关系与转轴。近、中、远三档使用同一尺度与朝向；人物的男女及战士版本逐项保存。
- 每个模型最多 64 个颜色槽，每面槽号 0–63。2026-10-11 实测并核对渲染器，超限会截到第 64 槽，造成白虎等模型错误配色；必须在 Blender 导出时限制总槽数，再实际游戏复测。原槽前缀也计入 64 项。
- 材质类别使用本机实际 `MeshKind`：木材 3、石材 4、瓦顶 5、布料 7、皮肤 8、头发 9、金属 10、眼部 15；不与地面类别编号混用。导出的所有法线必须有限且长度为 1，零法线按对应三角面修正，并在实际可编辑文档中保存后重开导出验证。
- 建筑按资产实际能力提供施工、完工与废墟。保留施工模型状态名里的 `@`、`~`，状态切换关联同一个原生建筑。
- 原图五档紫色是国家色模板。建筑写 `kingdom_slots`；大殿、经藏阁、藏宝阁等文明木构建筑使用 `roof,roof_dark`，瓦屋顶随国家变色，墙柱梁与檐底固定木色，金饰与灰石固定。人物国家衣料使用 `shirt/shirt_dark`，皮肤和头发沿用原生规则。
- 宗门建筑的野生归属不能代替城市国家：优先所在城市，城外通过宗门关联寻找所属城市。废墟保留最后一次国家色再变暗。
- 人物换国家或服装时刷新衣色。甲胄面积大时，以未染色原图的紫色模板判定国家色档；没有模板的皮肤保持原图取色。鬼人的青蓝脸色不被普通人体肤色覆盖。
- 非原生人形的双足单位使用实际持有的原生装备网格，跟随 `wing_r` 右臂的真实掌心；不把可更换武器做进身体。缓存按实际装备编号、类型和图标刷新，距离档改变重新计算握持位置，浸水时遵循原生隐藏规则。萨满与战士的法杖、长矛已在正式补丁下验证卸下、换装与恢复；其他武器及攻击另测。
- 施工阶段副本按阶段删除未显示部件，名称带 `@0` 等后缀；来源应比较实际同名部件的坐标、面和槽号，不能只按完整名字或对象引用判断。东人瞭望塔四阶段已实际核对一致；旧有机诡政厅同源检查保留为历史，中式新版本另验。

完整操作约定见 [建模约定](../../Scripts/Worldfall/建模约定.md)，Trellis 参数与命令见 [Trellis 使用](../../Scripts/Worldfall/Trellis使用.md)。运行资源是 `Content/Worldfall/Models/<资产ID>/models.json`；Trellis GLB 需在 Blender 中转换，不能直接充当已完成的游戏资源。
