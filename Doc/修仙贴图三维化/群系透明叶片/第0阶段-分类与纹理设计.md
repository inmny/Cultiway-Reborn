# 第0阶段：分类与纹理设计

## 处理原则

逐一查看原图和旧生成器的部件记录，先确定真正的叶片。绿色不一定是叶片，粉红色也不一定是肉质。颜色槽同时用于杆与叶时，按生成器的面区段或部件标签拆分，不整槽删除。换叶片时逐项保留不相关的杆、枝、根、书册、器官和石块。用户后续授权的新增枝桠、补叶柄、加粗树干、重做器物及纠正物种另列实际修改范围，不把新几何说成原样保留。

不能把整棵树的照片放在一张平面上。窄竹叶、羽状蕨叶、卷叶、稻叶、攀书绿叶和不同冠簇各有自己的透明纹理，并在原有枝叶锚点前后分层放置。禁止所有群系统一套橡树阔叶贴图。

## 资产分组

| 树类 | 叶片处理 | 保留实体 |
| --- | --- | --- |
| 竹林 | 按2竿与5竿的原图叶扇，使用窄竹叶簇；灰残叶保持灰色 | 竹竿、节、枝和根 |
| 蕨类 | 树蕨展开复叶、小拳卷及蓝绿、黄老叶分别设计；main_5改为银杏式扇形叶、增加枝桠并形成梭形冠 | 其他外观原杆枝根；main_5保留主干并新增分枝；无叶残骸 |
| 知识 | 只处理侧叶、页上绿芽和真正小叶 | 书页、封面、书脊、绿藤杆及跨页绿带 |
| 稻田 | 窄长稻叶按各自伸展方向布置 | 稻穗、稻粒、杆及原图浅色基部 |
| 纳垢 | 分别确认垂冠、四瓣小冠及残片；叶区单独纹理 | 结节堆、囊体、厚口腔、断干及器官性垂头 |
| 色孽 | 原图粉红冠簇用相应叶簇色调 | 卷枝、立柱、肉质立像及带状物；无叶残骸 |
| 橡树 | 六种带冠树及残骸真正绿芽，逐外观布置；承接main_2样板 | 树干、主枝、根、桩、石块与木片 |
| 黑暗森林 | 用户确认是冷杉；短针叶枝片沿枝层展开、尖顶塔形，四种生长阶段分别设计 | 原树干根脚、全部无叶枯树与main_3既有下沉 |
| 恐虐、奸奇等器物类 | 原图没有真叶的外观不新增叶片 | 枯枝、骨刺、头骨、晶体、雕像和符号实体 |

知识与恐虐已实际查看原图：知识有攀书小绿叶，书本自身不是叶片；恐虐原图是裸枝与器物，不能为满足群系名单而添加树冠。其他特殊外观的分类由该资产代理结合实际几何进一步记录。

用户随后明确要求蕨类增加叶量、按真实蕨类与裸子植物设计。长羽叶外观改为树蕨式多层展开伞冠，卷叶保留卷曲新叶并补展开叶，蓝绿与黄叶借鉴苏铁式冠顶长复叶。允许增加叶簇与前后层，不再死守旧模型过少的叶数；现有非叶杆根与显示大小保留。形态依据[Kew树蕨资料](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:17082540-1/general-information)与[Kew苏铁属资料](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:326847-2/general-information)，取展开冠丛、成排小叶和卷叶的结构用于模组风格设计，未直接使用整树照片作贴图。

## 图片与三档

用户再次明确`main_5`是裸子植物且叶量仍不足，随后指定银杏样式，并要求重新绘制、增加枝桠、整体树冠为梭形。该外观单独制作v2：实体分枝交错分层，中部冠幅宽，冠底与顶端收尖；绿色银杏扇叶沿枝形成连续冠形。先前羽状复叶和上下两团冠方案撤回。叶型依据[Kew银杏资料](https://www.kew.org/plants/ginkgo-tree)，梭形为用户指定造型。其他39模型仍保持已发布版本。

黑暗森林后续明确按冷杉制作。v2把大垂片改为深色短针叶枝片，细针叶沿细枝两侧排列，使用小枝片分层组成塔形冠。以[Arnold树木园针叶树资料](https://arboretum.harvard.edu/collections/conifer-collection/)核对冷杉属`Abies`，不把名称含`abies`的云杉属`Picea`混作冷杉。木体与枯树仍保留，v1的去叶面记录与v2的针叶重绘分别保存。

每种不同叶型保留透明2K来源；运行图单边不得超过512，窄叶或远档可用256。透明通道为0/255二值，RGB保留原色与叶脉细节。相似叶型可复用纹理，但须保留各自的叶轴、数量与位置。

每组原生交叉贴片是两个竖直四边面，共4三角；只绕竖轴旋转，不提供倾斜假字段。三档保留各主要叶簇、轮廓与层次，减少重叠与小分簇。数量和面数由各物体实际设计，不把橡树72组硬套所有树类。

## 花草的物种与部位

用户随后要求群系花草也改透明叶片。花草入口不等于全部是草：竹林是包着笋壳的竹笋，珊瑚是贝壳与海藻，蕨类是真正蕨类，其他还包括花、菌、骨片和器官。先确认各帧再制作，分类和实际发布进度见[花草检查页](../../../Art/Worldfall/biome-flora-leaf-cards-v1/index.html)。

蕨类花草用连接根部的叶柄、连续叶轴和成对小羽片表现，保留原主叶数量与卷端。不能直接把旧厚叶渲成图片后当作蕨叶。珊瑚海藻用透明片表现柔长、分叉叶带；贝壳保留立体壳身、壳纹、厚度和可辨壳腔，不做浅色圆团。贝壳的纠正需要修改实体，检查记录应明确区分。

花心、短根茎、菌帽与柄、骨片及肉团保持实体；将原厚花头改为透明花瓣时，可缩小为花心并单独记录。小花草保留2K来源，近中运行图优先256、远128，不要求每片小叶都占512图集空间。所有图片的叶轴基部与实体叶柄实际连接，不能只把矩形片底边放在根附近。
