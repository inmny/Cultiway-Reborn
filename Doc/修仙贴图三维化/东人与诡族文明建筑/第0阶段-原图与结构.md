## 材质与预算

东人紫色屋瓦是国家色模板，元文化帐篷篷顶的精确洋红条纹和缝边同样单独随国家改变；布料与瓦片保留各自材质。木墙柱梁、白布、金饰和石基分槽；天然草顶不变色。现代楼及元文化皮肤依自身原图，不能套用普通木楼。诡族浅绿固定，原图蓝白窗口或灯焰按实际造型，不能新增水晶。普通自然灵体表面使用Plain0，避免误加砌砖纹。

已核对本机原版`DynamicColorPixelTool.checkSpecialColors`与`Toolbox`：国家主色只替换`#FF00FF / #DE00DE / #A700A7 / #7F007F / #580058`五个精确模板色。现代住宅晾衣区的普通紫红彩衣不因颜色接近就强行变国家色；六级住宅的红橙屋顶、米黄墙与实际彩衣均保留固定色。诡族依用户明确约定固定浅绿，不套国家色。

以Worldfall相关内置模型为参照：普通住宅1453面、人类住宅变体2679/1339/511、猫住宅1372/702/274、瞭望塔1136/700/292、城镇政厅3468/1460/484及4933/2416/831。具体近中远预算按本物体结构先写入任务和`strategy.json`，不是一律5000面；关键开口、层数、侧背体量优先。

## 风车注册类的原图判断

四个`windmill`目录不能直接套风车房。东人零级按厚圆磨盘、中心孔、环座和木支架构形；一级各动画帧中，小石轮和木叉沿水平圆盘换位，按碾盘、立石轮与木轴构形。具体机械用途仍是根据图像的推断，不作为用户确认的事实。诡族两级为青蓝色圆顶与贴地流体边缘，保留真实青蓝色，不套普通浅绿木构规则，也不添加叶轮或水晶。

这四项保留原部件名与轴，旧`sails`留空，实际主体静态放入`base`，避免按旧风帆轴旋转整个物体。原图动画来源完整记录，连续转动或流体变化另留游戏验收；整石和流体不使用建筑砌砖纹。
