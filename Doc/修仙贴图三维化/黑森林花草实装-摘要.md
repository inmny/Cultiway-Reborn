# 黑森林花草实装

本轮按用户要求，参照本机 Worldfall 1.0.0 的群系花草结构制作 `Dark`，不包含已完成的 `Dark_tree`。原图为 `GameResources/buildings/Dark/main_0.png` 至 `main_5.png`，对应同一花草资产的六种随机外观；不是六个生长阶段。`mini_0.png` 仍为二维小地图图标。

## 生成依据

Worldfall 自带花草保存在程序集的预生成网格资源中；本机安装包未提供生成这些网格的建模脚本。本轮只参考其低面花叶、茎杆、单个静态 `plant` 部件、颜色槽和绘制规则，不复制或分发它的网格及程序集。

面数统一指三角面。本机程序集的散列与[已保存的内置模型统计](验收/2026-10-12-Worldfall内置面数/README.md)一致：

| 参照物 | 近景 | 中景 | 远景 |
| --- | ---: | ---: | ---: |
| 普通草丛 `plant_grass` | 132 | 84 | 48 |
| 普通花朵 `plant_flower` | 432 | 272 | 160 |
| 郁金香 `plant_tulips` | 353 | 188 | 104 |
| 腐化群系植株 `plant_corrupted` | 272 | 204 | 102 |
| 矮蘑菇 `plant_mushroom_button` | 528 | 308 | 136 |

本轮使用 Blender 按原图直接生成低面形体，不另用 Imagegen 或 Tripo 推测高细节。低像素图没有提供厚度和背面；这些补全部分作为建模假设记录，不宣称已还原原图无法显示的细节。

## 六种外观与预算

| 原图 | 需要保留的特点 | 近／中／远上限 |
| --- | --- | --- |
| `main_0` | 三向青绿小芽，低矮 | 100／60／40 |
| `main_1` | 偏右的小芽，比前者窄 | 100／60／40 |
| `main_2` | 疏松青绿草簇 | 160／100／60 |
| `main_3` | 顶、左、右三个红花头及分枝 | 432／272／160 |
| `main_4` | 四个红花头，保留不对称分布 | 432／272／160 |
| `main_5` | 红色宽顶、灰色短柄；按低矮菌伞补全 | 440／308／136 |

可见茎叶只采用原图的 `#40846A` 和 `#446669`。透明像素里的棕色不参与取色。红色为本物体固定颜色，不是国家色。远景保留主要叶片、花头数量，通过减少圆周和表面分段降低面数。

## 接入规则

- 基础模型族 `building_cultiway_Dark` 对应 `main_0`；其余五种使用 `_v1` 至 `_v5`。各自都有 `_m`、`_f`，共18个模型。
- 在 `SceneCollector.DrawPlantModel` 绘制前，按同一个游戏物体的 `animData_index` 更新原生模型族缓存；后续仍使用 Worldfall 原生距离选择、朝向、地形落地和点击标签。
- 模型使用 `kind=plant`、`palette=fixed`、`cultiway_plant=1`、`kingdom_slots=none`。`Flora.Colors` 的固定配色路径让本物体使用自己的颜色槽，避免通用植株取色覆盖青绿茎叶和红花。
- 使用单个 `plant` 部件，根脚在模型空间 `Z=0`；替换原先三部件的通用小树形体。花草没有人物或树木的关节动作，不添加树木落叶粒子。
- 尺寸按原图像素关系分别制作，随后由原生入口乘约0.5至0.75的随机比例。原生入口把根脚放在地形高度下0.01，并让花草无阴影；本轮沿用这些行为。
- 原生花草超过约55格不继续绘制三维网格；本轮沿用原生范围，不能把存在远景网格等同于无限距离显示。
- 关闭3D时仍使用原贴图。接入代码放在 `S3COND2_WORLDFALL` 编译条件内，并沿用已有的程序集版本检查。
