## 黑暗森林之前如何完成

### 树木：图片生成与平台原网格适配

先按原贴图分清四种主外观和四种枯树；主编号是随机外观，不是生长阶段。原图经过 Imagegen 制成高清单体图，再由 Tripo 生成带2K贴图的网格，保留已有成熟树与七份新增来源。平台设置控制在5000面，但导出后实际三角面需要单独统计，不能把平台设置直接写成实际数量。用户要求生成后不再减面，所以当前24个距离模型没有为了三个距离档继续改变原始网格。Blender 完成坐标、尺寸、材质到 Worldfall 最多64颜色槽的转换以及重新导入检查。

Worldfall 当前实际使用颜色槽，不直接读取原2K图片；原图、带贴图GLB和可编辑来源保留，便于继续调整。树高归一为2，正面-Y、Z向上。成熟 `main_3` 的根系实际游戏里裸露，因此在每次原生放置后按模型高度下沉；0.18曾被用户指出过深，目前改为0.12，即树高的6%。偏移只绑定这一外观的三档，且每次从原生重设坐标开始，不逐帧累积。

详见[黑森林树木实装](../黑森林树木实装-摘要.md)。这一旧资产不重新生成，也不把它混记成本轮 Blender 自建。

### 花草：直接按原图构形

六幅原图分别拆解成小芽、草簇、三头红花、四头红花和矮菌伞。参照 Worldfall 自带草、花、蘑菇的面数，用 Blender 实体叶片、茎、花与菌盖制作18个模型。未另生成高清参考图，未调用三维生成平台。独立导入后看到的侧面过薄和菌柄尖针已修正，最终近景52至340个三角面、远景24至160个三角面。

详见[黑森林花草实装](../黑森林花草实装-摘要.md)。本轮其他群系沿用这条直接构形路线。

## 本轮具体操作

1. 从 `Source/Content/Buildings.cs` 的注册信息核对树木、花草和风动开关，再列出 `GameResources/buildings/<资产ID>/` 的每一幅图。`.GameSource/Assets` 本机缺失时明确记录；这里只参考已有原生绘制入口与面数统计，不复制 Worldfall 模型。
2. 最近邻等比放大原图，实际看全部外观和残骸。记录主部件数量、位置、开口、色块和根脚。`main_N_A` 的第二个编号是动画帧；`mini_*` 为二维图标，不制作额外三维模型。知识群系残骸文件名中原有空格照常解析。
3. 一个资产交一个独立建模代理，同时最多三个，代理不再派生。只共用圆杆、实体叶、转面体等小几何、文件导出和检查；各物体的轮廓、路径、部件与颜色由自己的设计脚本决定。
4. 按可辨认的大形体拆解。枝条保持连接，杯口和骨骼孔洞保持打开，宽树冠用有厚度和前后展开的叶簇，不能把像素拉厚或一个通用球冠当成完成。肉囊、脑状块和圆肉块需要饱满体量，主体纵深通常取正面宽度的0.6至0.85；书页、碑板和叶片可以较薄。根和分枝前后展开，不能把所有部分放在同一薄层。背面和深度是推断时明确注明。
5. 写近、中、远面数预算，参考[内置面数报告](../验收/2026-10-12-Worldfall内置面数/内置模型原始统计.json)。先保护主要枝、杆、花头、孔洞；减去截面细分与次要纹理。三档使用同一份结构参数，不能因删掉路径节点使侧枝悬空。
6. 每种树形统一等比归一到高2；花草按原图比例取实际高度，不放大成树。三档以同一根脚和尺度放置。最低点Z=0，正面-Y；禁止只拉宽拉高来伪造比例一致。
7. 使用原图固定配色，颜色槽总数最多64，国家色为none。默认材质0，不给自然物件叠游戏程序砖缝；蜡体也不叠木板纹。材质类别会影响游戏着色，不能只凭“石材”的名称选4。详见[实际砖纹排查](材质纹理排查-2026-10-14.md)。仅明确的火焰颜色可发光；木杆、蜡体和残骸不跟着发光。植物与文明建筑的国家色规则不能混用。
8. 树木的主外观与残骸分别制作。原图残骸若仍有灰色叶簇或保持完整珊瑚形体，照图保留，不能一律做成光杆枯木。花草没有残骸原图时不虚构新的状态。

## 资源说明

| 文件 | 用途 |
| --- | --- |
| `GameResources/buildings/<ID>/*.png` | 保留不变的原始贴图 |
| `Art/Worldfall/biome-native-v1/source-inventory.json` | 全部28类资产的原图清点 |
| `Art/Worldfall/<ID>/native-biome-v1/build.py` | 本物体自己的结构与三档生成参数 |
| `model.blend`、`glbs/*.glb` | 可编辑来源和实际导出的各外观三档 |
| `original-inspection.json`、`native-strategy.json` | 原图判断、预算、形体拆解与补全假设 |
| `Scripts/Worldfall/biome_native.py` | 共用小几何、外观分组与候选导出入口 |

这条路线检查的是原图主要特征、立体完整性和档位稳定性。没有平台高面初稿作为误差基准时，不填写“保形减面通过”或“原网格重拓扑成功”。
