# 橡树 main_2 透明叶簇 v2

2026-10-16，用户要求去掉实体叶冠，并增加透明叶簇的覆盖范围和数量。这一要求取代v1保留封闭冠心的处理。

只修改橡树 `main_2` 的近、中、远三档。树干、主枝、根脚和根边石块保留原三角、坐标、颜色槽、部件关系及尺寸；其他39个模型逐字段保留。叶冠全部由透明PNG交叉贴片组成，不以隐藏的实体冠心填空。

叶簇在四团原树冠内部、外缘及前后分层布置，保留层冠分界和垂叶。扩大的是PNG实际不透明区域的覆盖，而不只扩大图片的透明边框。近中远实际组数为72、48、28，纯树体三角324/240/156，含叶簇612/432/268。相对v1，近景叶片实际覆盖宽增加14.7%、深增加15.7%，正面不透明投影面积增加48.6%、侧面增加36.5%。全部6个最终GLB已在新Blender进程实际导入，树体逐三角与JSON匹配，39个其他模型保持原样。

复用v1的叶簇和垂叶图片，2K来源随可编辑文件保留。Worldfall原生入口限制运行图片单边不超过512，因此实际使用512/256版本；颜色与透明孔来自PNG，树体仍使用原模型格式。

原生交叉贴片只有双面竖直面，不支持倾斜或水平摆放。接近正上、正下时叶簇会变窄；去掉实体冠心后，这一角度下不再有实体叶冠承接。应查看实际仰俯视对照，不把普通视角的覆盖改善当作所有角度均已解决。

本版已离线实装。候选、可编辑文件、独立Blender重新导入后的正侧背和仰俯视、三档对照位于检查包（历史文件已清理）。无实体叶冠、其他模型保留和透明区域覆盖分别记录，游戏效果仍由用户自行查看。用户追加的其他树类改造见[本批总览](../群系透明叶片-摘要.md)。
