# 黑森林树木实装

2026-10-14：按用户要求补齐黑森林 `Dark_tree` 的高清参考图，通过 Tripo API 生成对应模型并接入 Worldfall。控制为 P2 四边面 5000、2K 贴图；保留平台原网格，不本地减面、重建或改绘贴图。游戏效果由用户自行查看。

## 外观与状态

原版 `BuildingAsset.loadBuildingSprites()` 将编号配成四组外观，`Building.initAnimationData()` 随机选择编号，存档保存为 `frameID`。这四种大小不是按树龄逐步生长。每种正常树形各有自己的无叶枯树，不能只把成熟树缩小或压暗。`mini_0.png` 仅用作小地图二维图标。

## 接入方式

Worldfall 1.0.0 的 `TreeFamily` 第二参数来自位置随机值，不是原图编号，且普通树木没有单独的废墟模型切换。仅改这个入口会出现所有树形都用一棵成熟树、枯树仍留着叶片的问题。

为 `Dark_tree` 在 `SceneCollector.DrawAsModel` 前按 `animData_index` 和 `isRuin()` 更新原生模型选择缓存，保留普通树木入口。尺寸仍由当前二维贴图的可见高度决定，随机朝向、整体风动、树冠遮挡和选择沿用 Worldfall。模型转换只作轴向与等比缩放、根脚归零及原 UV 取色；Worldfall 的运行格式最多64种逐面颜色，2K原贴图保留在原始模型中。

无叶枯树跳过 `WindTree` 的树冠风动和落叶粒子，正常树形仍沿用原生风动。原生入口只按树形分类添加树冠，不读取枯树状态，直接使用会让无叶枯干仍产生树叶。

树木保留每种状态自己的色表，不套用文明建筑把完好材质复制给废墟的处理。成熟树与其枯树存在25个同名但异色的槽，复制会覆盖枯木原有的暗棕色。活树的 `leaf` 原槽按本模型实际UV叶色设置，供原生落叶粒子取色。

## 执行与检查

- 高清图逐张查看原贴图、使用内置 Imagegen 制作和目视检查；未做90%轮廓重合量化的图不标成该指标通过。
- API 提交一次后保存任务编号，后续仅查询和下载；实测多边面与游戏三角面分开记录，5000是平台控制值。
- Blender 离线核对模型、真实贴图分辨率、材质槽、有效索引、法线、父子与根脚。候选在 Art 内检查后发布到 `Content/Worldfall/Models/Dark_tree/models.json`。
- 发布后清除本物体旧的试图、底模、重复导出和临时文件，保留当前输入、原始模型、最终可编辑文件、转换脚本与检查记录。
- 已发布24个模型，构建0错误、29项原有警告；游戏验收待用户查看，不以构建通过代替实测。

## 成熟树根下沉修正（2026-10-14）

用户游戏实测反馈 `main_3` 成熟树的放射根裸露。正常成熟树的三档几何相同，模型高度为2，宽大根部到 `Z=0.18` 附近已收拢为树干：该高度横截面宽约0.184、深约0.170。

在原生 `MeshInstance.Place` 放置后，仅将这三档正常成熟树向下移动 `0.18 × 本次纵向比例`，约为整棵树高度的9%。每次先由原生入口重设坐标，因此偏移不会逐帧累积。原始网格、面数、纹理和模型文件的校验值保留；其他树形、枯树和花草的放置规则继续沿用各自原有设置。离线预览仍展示完整原网格，不能把它当作下沉后的游戏落地截图。

来源 GLB 的根区横截面与正式资源相差不超过一百万分之一，三档一致。最低叶尖原本位于 `Z=0.130923`；在平地上，下沉0.18会使98个叶三角部分进入地面，其中32个完全进入，约占全部叶面的0.54%。这些面仍保留在模型中，没有删除或改形。

修正后构建通过：0错误、29条既有警告。实际露根情况待用户重启游戏复测。

用户复测反馈下沉过多，现将实际下沉量由0.18改为0.12模型单位，即树高的6%，相对上一版上提树高的3%。成熟正常树三档同步调整；此前0.18的根区测量和叶片入地数量仅描述上一版，不是当前偏移的结果。新的落地效果待用户复测。

## 树干与树冠格纹修正

用户追加反馈黑森林树干或树冠出现类似砖石格纹。实际用到的类别是树干木材3与树冠布料7，旧转换脚本继承了程序叠纹类别；仅检查建筑石材4无法排除这类纹理。已将24个模型全部槽改为纯色0，并同步转换脚本。除 `SlotKind` 外正式资源字段严格不变，原2K图片、网格、颜色、法线、轴、位置与成熟树0.12下沉保持。没有生成新模型、调用API或把旧图称为新材质实测。

核验见 `Art/Worldfall/Dark_tree/tripo-api-v2/worldfall-v1/material-kind-fix.json`。新资源需重启游戏后加载，格纹是否消失仍待用户复测。
