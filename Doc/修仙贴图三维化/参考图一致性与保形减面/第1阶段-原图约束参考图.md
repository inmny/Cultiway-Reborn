## 具体说明

### 原图与尺寸分别取依据

原图的轮廓、台基宽度、入口、屋顶层数、柱子和装饰的相对位置作为外观约束。地面占地读取注册字段，记录 X 方向宽 W、Y 方向深 D；建模坐标为 Z 向上、正面 -Y。

区分三个范围：注册的放置范围、几何的接地范围、包含屋檐/角枝的整个模型范围。占地矩形不要求物体填满；原图没有大台基时不新增大台基。屋檐或树枝的合理外伸另记。

归一化建模仍按 X 宽度 1、地面深度约束 D/W 表达，但须沿用当前接入的原点与放置规则。原图宽高比例包含物体高度和相机投影，不能直接用来计算 D/W，也不通过拉伸整张参考图伪造地面尺寸。

| 首批资产 | 注册占地 | D/W | 重点结构 |
| --- | ---: | ---: | --- |
| 七重溃烂熔炉 | 10×6 | 0.600 | 冠部分叉、绿色主体、低处开口、根部 |
| 颅献黄铜王座 | 18×8 | 0.444 | 背柱、冠饰、尖刺、面具、前方台阶 |
| 万变星璇祭坛 | 19×7 | 0.368 | 四柱、眼状中心、卷曲框架、低台基 |

深度较小的建筑须在比例底模和俯视图中体现深度约束。记录可见台基的范围与占地关系；禁止通过放大基座补齐整个占地。

### 结构标注与比例底模

每个资产先保存一份结构表：部件名称、原图范围、中心、数量、相对高度、遮挡关系、材料和国家色归属。能确定的细节按原图记录；看不清或没有出现的背面、侧面、深度标作设计假设。

用 Blender 制作比例底模：只解决体量、地面深度、前后关系和相机，不提前把细枝、框架、开口或屋檐改成粗大形状。底模叠加投影要能对上原图。先匹配视角再比较轮廓；只能统一平移、等比缩放，不能分别拉宽拉高。

原图如果接近正面，则清晰主图仍保留该视角。输入 Trellis 的四分之三图可以后续从底模转出，但它的正面必须回投验证。额外视图不得各自凭提示词重新设计。

### 图像生成改为受约束编辑

按照 imagegen 的精确物体编辑方式：实际查看本资产原图和底模后，把**原图设为外观依据、底模设为几何依据**，风格图仅承担表面表现。原图的清晰化编辑优先保持视角与位置，再局部补出像素分辨率不足的细节。

输入中带标注的图用于解释结构；最终单物体图不得包含文字、尺寸线、网格、多个角度、背景景物或外部投影。预览图可有说明，Trellis 输入另存为透明图。

建议提示词模板：

```text
用途：将给定像素贴图转换为忠实的清晰单物体三维建模参考。
图1是外观依据；图2是已匹配原图相机和实际占地的比例底模。
保持图1的视角、外轮廓、长宽高比例、部件数量、相对位置、遮挡关系和主要颜色分区。
保持图2的接地范围、前后厚度和部件关系。对不清楚的像素细节做保守补全。
允许提高边缘与材料辨识度，保持均匀柔和光照。
必须保留：[从本物体结构表逐项填写]。
国家色区域：[填写具体区域]；固定材料：[逐项填写]。
透明背景，单个完整物体，无文字，无尺寸线，无额外平台或装饰。
```

参考图提示词不设面数上限。取消“减少为若干尖刺”“为看见中心而缩短前柱”等改变结构的自由。面数在初稿后的减面阶段决定。

### 多视图一致性

主图通过后，固定同一套底模和材料分区，渲染正、侧、背、俯视图。生成模型后再用实际初稿替代底模输出同样视图。侧背补全只能在固定几何上局部编辑，不独立生成新的形态。

当前本机 Trellis 2 只输入其中一张单物体图；其余视图帮助 Blender 修正侧背面。因为单图生成没有接收底模的几何或占地数字，**参考图中的深度约束仍然可能被 Trellis 改变**，必须在生成后的占地与多视图检查中验证。

### 通过标准（设计初值，尚未实测）

| 项目 | 标准 |
| --- | --- |
| 原图主轮廓 | 在同视角、等比对齐后，降到原图尺度叠加；主轮廓重合比例目标 ≥90%，另看每个重要部件 |
| 细线与小装饰 | 用原图 1 像素边缘容差辅助判断；单独检查，不被整体指标掩盖 |
| 关键位置 | 入口、眼睛、冠顶、柱顶等相对位置目标误差 ≤原图 1–2 像素，逐项记录 |
| 部件数量与关系 | 四柱、三层屋顶、棺盖、角枝等确定结构必须一致 |
| 地面范围 | 接地几何符合注册范围及底模；同时保存俯视图和占地格线图 |
| 侧背面 | 与同一个底模相容，新增假设有记录 |
| 材料与国家色 | 文明木构墙柱为木材、屋顶为国家色；人物国家衣料与皮肤分开；诡族保留浅绿灵体 |

轮廓不通过时先核对相机和对齐，再局部修图或底模；不把配色漂亮当作结构通过。以上数值是样板试验的起点，后续只能根据实际误差调整并记录原因。

## 资源说明

每个资产独立保存在 `Art/Worldfall/<资产ID>/reference/v2/`，不覆盖 v1。

通过检查的 `trellis-input.png` 另存一份相同字节的 `reference/trellis-input-v2.png`，对应现有 `trellis.ps1 -Revision 2` 的输入约定，记录两份文件的相同校验值。完整的标注、底模和检查材料留在 v2 子目录；当前不需要先改共享生成脚本。

| 文件 | 设计内容 |
| --- | --- |
| `source.png`、`source-enlarged.png` | 原图无损备份与整数倍最近邻展示 |
| `structure.json` | 部件、比例、遮挡、材料、国家色及不确定部分 |
| `blockout.blend` | 原图匹配相机、占地网格与比例底模 |
| `reference-main.png` | 保持原图视角的清晰主图 |
| `reference-front.png`、`reference-side.png`、`reference-back.png`、`reference-top.png` | 来自固定几何的检查视图 |
| `trellis-input.png` | 一张透明完整物体图，供当前运行器生成 |
| `prompt.txt`、`reference.json` | 实际编辑提示词、输入角色、版本、相机与生成记录 |
| `source-reference-overlay.png`、`reference-check.json` | 原图与清晰图的对齐对比及逐项结果 |

透明背景保留真实透明通道。参考图目标是辨清结构，不预先把风格转换成某个固定面数的粗几何。
