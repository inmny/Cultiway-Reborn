# 东人与诡族文明建筑

2026-10-18已完成离线制作与实装：22类东人、17类诡族基础建筑，包含现有东人元文化建筑皮肤，合计155个主要外观、1395个状态与距离模型。沿用原图约束、Blender自建、三档模型、独立重开、检查页和统一发布流程，不使用图片或三维生成平台。原图动画帧和小地图不计为独立建筑；同一建筑的外观变体分别建模。

每个资产交给独立子代理，每批最多三个，不再派生。主代理统一运行约定、核对一次最终方向联系图并发布；游戏效果由用户统一检查，不启动、关闭或操作游戏。

东人紫色瓦顶表达国家色，木墙柱梁保持自然木色；草顶、现代建筑和元文化分别按真实原图分区。诡族保留浅绿中式灵体风格，国色为空，基础住宅为空棺。建筑外观编号和文化风格的选择另接到现有Worldfall建筑入口，保留原生状态、点击与缩放处理。

诡族码头已恢复右后端高塔、塔冠与两侧蓝白灯；横纵栈桥仍连续同高。高塔是独立向上立起的结构，不能因桥面同高而删去，见[新版五向对照](../../Art/Worldfall/docks_Cultiway.Gui/native-civ-v1/directions-large.png)。土地庙及鼎落地，灯杆前移到鼎左右；政厅与图书馆的楼层、庭院和低台阶已按用户指正分别重做。

全部最终GLB已独立重导入，主代理已查看当前原图与最终方向联系图。实际Worldfall程序集离线检查通过465项选模、5580项配色及3720项施工阶段；开关Worldfall条件的开发构建均0错误。记录和生产文件校验值一致。

本轮没有独立平台初稿或高清生成图，检查页直接展示原始像素图与最终实导，不能将自建模型称作平台保形减面结果。原图动画来源保留，本批模型为静态参考造型；连续动作、透明发光表现，以及施工、国家色、文化改变和性能的实际游戏效果仍由用户统一测试。本轮没有启动或操作游戏。
