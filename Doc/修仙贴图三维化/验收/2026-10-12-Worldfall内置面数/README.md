# Worldfall 自带模型面数统计

统计日期：2026-10-12。统计对象是本机安装的 Worldfall 自带模型，不包含 Cultiway 自制模型。

读取了 **52 个内置资源包、4,117 个模型定义**。按近中远档合并后为 **2,235 个基础模型系列**，其中 **940 个系列有完整的近、中、远三档**。系列数包含造型变体、施工、废墟、室内物件等，不能当作单位或建筑种类数。

这里的“面数”统一指三角面数：每个模型所有部件的 Tri 索引数之和除以 3。没有把三个距离档相加作为单次显示的面数；顶点数也没有当作面数。

## 来源与统计条件

- 程序集：`D:\Program Files (x86)\Steam\steamapps\common\worldbox\Mods\Worldfall\Assemblies\Worldfall.dll`
- 程序集版本：`1.0.0.0`；mod.json 声明版本：`0.9.4`。二者在本机不一致，因此保留两项以便复查。
- SHA-256：`C5D7BB791AA97C9DD234FE99C2531B839907456A1EEC19755B91BC7D82342DC6`
- 通用库 1 个（1,290 个定义），物种资源包 49 个，城镇资源包 2 个。物种包主要提供对应文明建筑、船只及其状态资源。
- 使用 Worldfall 自己的 MeshLibrary.Load / ModelPack.Load 只读解析嵌入资源，未调用游戏初始化、模型接入或补丁。没有把运行时生成的副本重复计入。
- 所有定义名称唯一；全部资源的模型数与汇总一致，全部模型的部件面数之和与模型总面数一致。
